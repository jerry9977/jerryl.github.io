# Lecture 21：Anomaly Detection

## 1. 这节课在讲什么

Lecture 21 讲的是 Anomaly Detection，也就是异常检测。

前面 Lecture 19 讲 clustering 的时候，已经提过 outliers 会影响 clustering。比如 K-means 里面，如果有一个很远的 outlier，它会把 centroid 拉偏，最后导致 cluster shape 被 distortion。

所以 Lecture 21 可以理解成在回答一个问题：

> 如果 dataset 里面有一些“不像正常数据”的点，我们应该怎么找出来？

这里的 anomaly 不只是“错的数据”。很多时候 anomaly 反而是我们最想找的东西。

例如：

* bank fraud：突然在陌生国家刷卡
* insurance fraud：claim amount 和 normal profile 差很多
* hacked account：突然大量 unusual posting
* cybersecurity：异常 login attempt
* weather：异常高温、seismic anomaly
* medicine：很少见但很重要的疾病 case
* machine learning：outlier 影响 clustering 或 model fitting

所以我需要先改掉一个直觉：

> Anomaly 不一定是垃圾数据。
> 它可能是 noise，也可能是最重要的 signal。

---

## 2. Anomaly 和 Noise 的区别

### 2.1 Noise 是什么

Noise 是 random error 或 measurement variance。

例如：

* sensor 有一点点误差
* 手动输入时输错一点
* measurement 本身有 small variation
* data collection 有 random fluctuation

Noise 通常不是我们关心的 pattern，它只是 normal data 上面的一点 random disturbance。

所以：

> Noise 是 normal mechanism 产生的数据上面加了一点 random error。

---

### 2.2 Anomaly 是什么

Anomaly 是一个 data object，它和 normal objects 差得很明显，好像是由另一个 mechanism 生成的。

可以理解成：

> Normal data 是一个 mechanism 产生的。
> Anomaly 像是另一个 mechanism 产生的。

例如，一个人在 Melbourne 日常消费都是 $20-$100，突然出现一笔 $5000 的 overseas transaction，这就不像是同一个 behaviour mechanism。

所以 anomaly 的重点不是“数值大不大”，而是：

> 它是否违反了 normal data 的生成规律？

---

### 2.3 为什么不能直接删掉 outliers

Lecture 里面讲了 ozone depletion 的例子。

1985 年，研究人员发现 Antarctica 的 ozone level 掉到 normal level 以下很多。但是 NASA satellite 之前其实已经记录到了很低的 ozone concentration，只是这些 readings 太低，被 program 当成 noise 直接 discarded 了。

也就是说：

> 他们以为那是 bad data。
> 结果那其实是 important discovery。

所以 anomaly detection 里面一个很重要的 lesson 是：

> 不要看到 outlier 就直接 remove。
> 要先问：这是 noise，还是有意义的 anomaly？

在 assignment 或 exam 里面，如果问 “should we remove outliers?”，不能直接说 yes。应该说：

> It depends on the domain.
> 如果是 measurement noise，可以 remove。
> 如果 anomaly 本身是 target，例如 fraud / disease / intrusion，就不应该直接 remove，而应该 investigate。

---

## 3. Anomaly Detection 的问题形式

Lecture 里面给了三种 anomaly detection problem 的 formulation。

### 3.1 找出 score 超过 threshold 的点

第一种是：

> Given database (D)，找出所有 anomaly score 大于 threshold (t) 的 points。

也就是：

$$
f(x) > t
$$

就标记成 anomaly。

这种适合我们已经有一个 clear threshold 的情况。

例如 fraud system 里面，如果 transaction risk score 超过 0.9，就 flag。

所以：

> threshold-based detection = score 超过某个 cutoff 就报警。

---

### 3.2 找出 top-n 最 abnormal 的点

第二种是：

> 找出 anomaly score 最大的 top-n data points。

这种不一定有 fixed threshold，只是想让 human analyst 看最 suspicious 的几个。

例如：

> 今天有 1 million transactions，我只想看最奇怪的 top 100。

所以：

> top-n anomaly detection 更像 exploratory analysis。
> 它不一定说其他点完全 normal，只是优先检查最 abnormal 的点。

---

### 3.3 对新来的 test point 算 anomaly score

第三种是：

> Given mostly normal data (D)，对一个 new point (x) 计算 anomaly score。

这很适合 streaming data 或 monitoring system。

例如：

* 新 transaction 来了，马上判断是不是 fraud
* 新 login event 来了，马上判断是不是 suspicious
* 新 sensor reading 来了，马上判断是不是 machine failure

所以：

> online anomaly detection = 每来一个新点，就根据 existing normal profile 判断它 abnormal 不 abnormal。

---

## 4. Anomaly 的三种类型

Lecture 21 里很重要的一部分是 anomaly types。

主要有：

1. Global / Point anomaly
2. Local / Contextual anomaly
3. Collective / Group anomaly

---

## 5. Global / Point Anomaly

### 5.1 什么是 Global Anomaly

Global anomaly 也叫 point anomaly。

意思是：

> 一个点和整个 dataset 都很不一样。

例如在一个 2D plot 里面，大部分 points 都在两个 clusters 附近，但有一个 point 离所有 clusters 都很远。那它就是 global anomaly。

可以这样记：

> Global anomaly = 和所有 normal data 比，都很奇怪。

---

### 5.2 例子

例如信用卡交易：

平时：

$$
20, 35, 50, 80, 100
$$

突然出现：

$$
5000
$$

这很可能是 global anomaly。

因为它不只是 local context 里奇怪，而是整体上就很奇怪。

---

### 5.3 Global anomaly 的问题

Global anomaly 的核心问题是：

> 怎么定义 “significantly deviates”？

也就是：

* 用 distance？
* 用 probability？
* 用 density？
* 用 cluster membership？

所以 global anomaly 本身只是一个概念，后面的 statistical / proximity / density / clustering methods 才是具体 detection 方法。

---

## 6. Local / Contextual Anomaly

### 6.1 什么是 Local Anomaly

Local anomaly 是：

> 一个点不一定和整个 dataset 差很多，但它和附近的 neighbours 差很多。

也就是说，它不是 globally weird，而是 locally weird。

例如有两个 clusters：

* 一个 cluster 很 dense
* 一个 cluster 很 sparse

一个点离 dense cluster 稍微远一点，可能就是 abnormal。
但同样的距离如果出现在 sparse cluster 附近，可能就很 normal。

所以：

> Local anomaly 要看 neighbourhood。

---

### 6.2 什么是 Contextual Anomaly

Contextual anomaly 又叫 conditional anomaly。

意思是：

> 一个点是否 abnormal，要看 context。

Context 可以是：

* time
* location
* season
* user profile
* neighbouring points
* graph relationship

例如：

$$
10^\circ C
$$

这个温度本身不一定 abnormal。

如果是在 Paris 的 winter，可能 normal。
如果是在 Paris 的 summer，可能 abnormal。
如果是在 Melbourne，情况又更复杂，因为 Melbourne weather 本身就很 unpredictable。

所以：

> 同一个 value，在不同 context 里可能 normal，也可能 anomaly。

---

### 6.3 我可以这样记

Global anomaly 问的是：

> 这个点和整个 dataset 比，奇怪吗？

Local / contextual anomaly 问的是：

> 在它自己的 context 里，这个点奇怪吗？

这就是为什么 density-based methods 很重要。因为 density-based methods 不只是看 absolute distance，而是看 local neighbourhood 的 density。

---

## 7. Collective / Group Anomaly

### 7.1 什么是 Collective Anomaly

Collective anomaly 是：

> 单个 data point 看起来不一定 abnormal，但一组 data points 放在一起就 abnormal。

例如：

一次 login attempt from unusual IP 可能只是 user traveling。
但是短时间内从很多不同 IP 连续 login attempt，就可能是 attack。

所以：

> Collective anomaly = group as a whole is abnormal。

---

### 7.2 例子

#### Intrusion detection

单独一次 failed login 不奇怪。
但是 100 次 failed login，而且来自不同 IP，就很奇怪。

#### Heartbeat

一个短 heartbeat interval 可能 normal。
但是连续很长一串 abnormal intervals，就可能表示 health issue。

#### Stock / transaction

单笔小额交易 normal。
但是短时间内大量小额交易 split payment，可能 suspicious。

---

### 7.3 Collective anomaly 需要 relationship

要 detect collective anomaly，需要知道 data points 之间的 relationship。

这些 relationship 可以是：

* sequential relationship：time series
* spatial relationship：location
* graph relationship：network / social graph / transaction graph

所以：

> Collective anomaly 不能只看 individual point。
> 要看 points 之间的 order、space 或 connection。

---

## 8. 三种 Anomaly Detection Paradigms

Lecture 里讲了三种 paradigm：

1. Supervised anomaly detection
2. Semi-supervised anomaly detection
3. Unsupervised anomaly detection

这部分和前面 supervised / semi-supervised / unsupervised learning 的区别有关。

---

## 9. Supervised Anomaly Detection

### 9.1 基本想法

Supervised anomaly detection 需要 labelled data：

* normal examples
* anomaly examples

然后我们可以把它当成 binary classification：

$$
y \in {normal, anomaly}
$$

所以看起来很简单：

> 有 label，就 train classifier。

---

### 9.2 问题 1：anomaly labels 很难拿

现实里 anomaly 很 rare。

例如 fraud transaction 本来就很少，真正被确认的 fraud 更少。
Medical rare disease 也一样，positive cases 很少。

所以 dataset 会 extremely imbalanced。

例如：

$$
99.9% normal,\ 0.1% anomaly
$$

这个时候 classifier 很容易学成：

> 永远预测 normal。

这样 accuracy 可能很高，但完全没用。

---

### 9.3 问题 2：无法 detect emerging anomalies

Supervised model 只能学到 training data 里面出现过的 anomaly pattern。

如果出现一种新的 fraud strategy，training data 没有见过，model 可能 detect 不出来。

所以：

> Supervised anomaly detection 对 known anomalies 有用，
> 但对 unknown / emerging anomalies 不可靠。

---

### 9.4 问题 3：false positive 很多

Anomaly detection 通常想提高 recall，因为不想漏掉真正的 anomaly。

Recall 是：

$$
Recall = \frac{TP}{TP + FN}
$$

如果我们为了 catch all anomalies，把 threshold 调很低，model 会 flag 很多 cases。

这样 false positives 会变多。

Lecture 里面用 alarm system 举例：

> 如果 alarm 每次有人进 house 都响，它可能不会 miss intrusion。
> 但它也完全不 practical。

所以：

> High recall often causes high false positive rate。

---

## 10. Semi-supervised Anomaly Detection

### 10.1 基本想法

Semi-supervised anomaly detection 通常只有 normal labels。

也就是说，我们有一批 confirmed normal data，然后 train 一个 model 学：

> normal behaviour 长什么样。

之后，如果一个新 point falls outside the learned normal boundary，就标记成 anomaly。

可以理解成：

> 只学 normal，然后把不像 normal 的都当 suspicious。

---

### 10.2 例子

比如 factory machine sensor data。

我们有很多 normal operating data，但很少有 failure data。

所以我们可以 train model 学 normal sensor range。如果 future sensor reading 和 normal pattern 差很多，就 flag。

---

### 10.3 问题

Semi-supervised 的问题是：

> previously unseen legitimate data 也可能被误认为 anomaly。

例如 user 从来没在 Japan 消费过，第一次去 Japan 旅游刷卡，model 可能 flag。
但这不一定是 fraud。

所以：

> Semi-supervised anomaly detection 容易有 high false alarm rate。

---

## 11. Unsupervised Anomaly Detection

### 11.1 为什么 Lecture 重点是 Unsupervised

Anomaly labels 很难拿，所以很多 real-world anomaly detection 是 unsupervised。

Unsupervised anomaly detection 没有 labels。它假设：

> Normal objects 有某种 pattern。
> Anomalies 会偏离这个 pattern。

Normal pattern 可能是：

* follow a statistical distribution
* belong to dense regions
* form large clusters
* have nearby neighbours

所以 unsupervised anomaly detection 的 general steps 是：

1. build a profile of normal behaviour
2. find points that differ significantly from this normal profile
3. ask human / domain expert to validate

---

### 11.2 最大问题：validation

因为没有 labels，所以 detection 出来的 anomaly 不一定是真的 anomaly。

例如 clustering 找出一个 small cluster，它可能是：

* fraud group
* rare but legitimate user group
* data collection artifact
* missing value pattern
* minority subgroup

所以 unsupervised method 的 result 通常需要 human validation。

我可以这样记：

> Unsupervised anomaly detection 可以 suggest suspicious points，
> 但不能 automatically prove they are truly abnormal.

---

## 12. 四种 Unsupervised Anomaly Detection Methods

Lecture 21 重点讲四种：

1. Statistical / model-based
2. Proximity-based
3. Density-based
4. Clustering-based

最重要的不是背公式，而是知道：

> 什么时候用哪个 method，each method assumes 什么，以及它会 fail 在哪里。

---

## 13. Statistical Anomaly Detection

### 13.1 基本想法

Statistical anomaly detection 假设 normal data follows some statistical model。

例如最简单的是 Gaussian distribution：

$$
x \sim \mathcal{N}(\mu,\sigma^2)
$$

如果一个 point 在这个 distribution 下 probability 很低，就认为它是 anomaly。

所以：

> Statistical anomaly = poorly fit by the statistical model。

---

### 13.2 Gaussian assumption

最常见的简单版本是假设 data 是 normal distribution。

也就是大部分 data 在 mean 附近，越远离 mean probability 越低。

先 estimate：

$$
\mu
$$

和：

$$
\sigma
$$

然后看某个 point 离 mean 有多少个 standard deviations。

---

### 13.3 Z-score

Z-score 公式是：

$$
z =
\left|
\frac{x-\mu}{\sigma}
\right|
$$

意思是：

> 这个 point 距离 mean 有几个 standard deviation。

如果：

$$
z > 3
$$

通常就认为它是 anomaly。

因为在 Gaussian distribution 里面：

$$
\mu \pm 3\sigma
$$

大概包含 99.7% 的 data。

所以 outside 3 sigma 的点就很 rare。

---

### 13.4 Lecture 里的 temperature example

Dataset 是：

$$
x={24.0, 28.9, 28.9, 29.0, 29.1, 29.1, 29.2, 29.2, 29.3, 29.4}
$$

算出来：

$$
\mu = 28.61
$$

$$
\sigma = 1.51
$$

对于：

$$
x=24
$$

Z-score 是：

$$
z =
\left|
\frac{24-28.61}{1.51}
\right|
=======

3.04
$$

因为：

$$
3.04 > 3
$$

所以 24 被认为是 anomaly。

我可以这样记：

> Z-score 是问：这个点离 mean 有多远？
> 如果超过 3 个 standard deviations，就很 suspicious。

---

### 13.5 Statistical method 的优点

Statistical methods 的优点：

* mathematically clear
* 给出 quantitative anomaly score
* 如果 distribution assumption 对，效果很好
* simple univariate case 很容易算

---

### 13.6 Statistical method 的缺点

最大问题是：

> Real data 很少真的符合 simple Gaussian distribution。

现实数据可能：

* not Gaussian
* multimodal
* variable density
* high-dimensional
* categorical + numerical mixed
* skewed distribution

特别是在 high dimensions 里面，要 estimate true distribution 很难。

所以 Lecture 里面说，statistical method 在 ML 里面不一定常用，特别是 high-dimensional real data。

我可以这样记：

> Statistical method 很干净，但 assumption 很重。
> 如果 normality assumption 不成立，结果可能 misleading。

---

## 14. Proximity-based Anomaly Detection

### 14.1 基本想法

Proximity-based method 的核心想法是：

> Anomalies are far away from other objects。

也就是说，一个点如果离它的 nearest neighbours 很远，就可能是 anomaly。

这和 KNN 很像，只是 KNN 用 neighbours 来投票分类；这里用 neighbours 的 distance 来算 anomaly score。

---

### 14.2 k-th nearest neighbour distance

一种 common approach 是：

> 用到第 (k)-th nearest neighbour 的 distance 作为 outlier score。

如果这个 distance 很大，说明这个点周围没有很多 close neighbours，所以可能 abnormal。

可以写成：

$$
score(x) = distance(x, k\text{-th nearest neighbour})
$$

所以：

> score 越大，越 abnormal。

---

### 14.3 为什么 k 很重要

如果：

$$
k=1
$$

只看最近的一个 neighbour。

有些 point 虽然整体上很 isolated，但它旁边刚好有一个 close neighbour，所以不会被认为 abnormal。

如果：

$$
k=5
$$

它可能就被 detect 出来了，因为第 5 个 neighbour 很远。

所以：

> Proximity-based method 对 (k) 很 sensitive。

不同 (k) 可能导致完全不同的 anomaly score。

---

### 14.4 Proximity-based 的优点

优点：

* 不需要 assume Gaussian distribution
* 比 statistical model 更 flexible
* 可以处理 multiple modes
* distance score 很直观
* 和 KNN 思路相似，容易理解

---

### 14.5 Proximity-based 的缺点

缺点：

第一，complexity 高。
因为很多时候要 compare every point with every other point：

$$
O(n^2)
$$

第二，对 (k) 很 sensitive。

第三，不能处理 variable density 很好的数据。

---

### 14.6 Variable density problem

这是 proximity-based 最大的问题。

假设有一个 dense cluster 和一个 sparse cluster。

一个 point 离 dense cluster 稍微远一点，可能已经很 abnormal。
但 proximity method 只看 absolute distance，可能觉得它还不算太远。

另一方面，sparse cluster 里面的 normal points 彼此距离也很远。
Proximity method 可能误以为 sparse cluster 里的 normal points 是 anomalies。

所以：

> Proximity-based method 看 absolute distance。
> 但 anomaly 有时候要看 relative distance。

这就引出 density-based method。

---

## 15. Density-based Anomaly Detection

### 15.1 基本想法

Density-based method 的核心想法是：

> Outliers are objects in regions of low density。

也就是说，一个 point 周围如果很 sparse，它就可能是 anomaly。

但更准确地说，不只是看 absolute density，而是看：

> 它的 local density 是否比 neighbours 的 density 低很多。

---

### 15.2 Basic density score

一种 basic density score 是：

$$
density(x,k)
============

\left(
\frac{1}{k}
\sum_{y \in N(x,k)}
distance(x,y)
\right)^{-1}
$$

这里：

* (N(x,k)) 是 (x) 的 (k) nearest neighbours
* average distance 越大，density 越小
* inverse 之后，distance 越小，density 越大

所以：

> density 是 average neighbour distance 的 inverse。

如果一个 point 离 neighbours 都很远：

$$
average\ distance \uparrow
$$

那么：

$$
density \downarrow
$$

它就可能是 anomaly。

---

### 15.3 Basic density 的问题

Basic density 只看 absolute density，所以在 variable density data 里仍然会 fail。

例如：

* sparse cluster 的 points absolute density 低，但它们可能 normal
* dense cluster 附近稍微偏离的 point absolute density 不一定最低，但 locally abnormal

所以我们需要 local density comparison。

---

## 16. Local Outlier Factor / Relative Density

### 16.1 核心直觉

Local density-based method 的想法是：

> 比较一个 point 的 density 和它 neighbours 的 density。

如果一个 point 的 density 明显低于 neighbours 的 density，就说明它 locally abnormal。

这就是 Local Outlier Factor, LOF 的直觉。

我可以这样记：

> LOF 不问“这里 density 低不低”。
> LOF 问“这个点比它附近的人 density 低多少”。

---

### 16.2 Relative density formula

Lecture 里面给的 relative density / LOF score 形式是：

$$
relative\ density(x,k)
======================

\left(
\frac{
density(x,k)
}{
\frac{1}{k}
\sum_{y \in N(x,k)}
density(y,k)
}
\right)^{-1}
$$

这个公式看起来有点绕，因为最后有 inverse。

先看里面这一部分：

$$
\frac{
density(x,k)
}{
average\ density\ of\ neighbours
}
$$

如果 (x) 的 density 比 neighbours 低很多，那么这个 ratio 会很小。

再取 inverse 之后，score 会变大。

所以：

> LOF score 越大，越 abnormal。

---

### 16.3 为什么 LOF 可以 detect local anomaly

假设 point (x) 离 dense cluster 稍微远一点。

它自己的 density 低。
但它的 neighbours 在 dense cluster 里面，density 很高。

所以：

$$
density(x) \ll average\ density(neighbours)
$$

ratio 很小，inverse 后 score 很大。

因此 (x) 会被 flag。

这正好解决了 proximity-based method 的问题。

---

## 17. Density-based Example：为什么 x=0.5 比 x=4 更 abnormal

Lecture 里面有一个 univariate dataset：

$$
{1, 1.05, 1.1, 1.15, 1.2, 1.21, 1.3, 1.4, 1.45, 1.5,
4.55, 5.6, 6.8, 7.58, 8.6, 9.7, 10.3, 11.4, 12.3,13.5}
$$

我们加入两个 new points：

$$
x=0.5
$$

和：

$$
x=4
$$

然后用 2-NN 和 Manhattan distance 算 inverse relative density。

---

### 17.1 表面上看，两者都离最近 cluster 不算特别远

(x=0.5) 离最近点 (1) 的距离是：

$$
|0.5-1|=0.5
$$

(x=4) 离最近点 (4.55) 的距离是：

$$
|4-4.55|=0.55
$$

这两个 absolute distances 差不多。

如果只用 proximity-based method，它们可能看起来差不多 abnormal。

---

### 17.2 但 local density 不一样

(x=0.5) 附近的 cluster 是：

$$
1, 1.05, 1.1, 1.15, ...
$$

这些点非常 dense，彼此之间距离很小。

所以 (x=0.5) 和它们的距离，在这个 local context 里显得很大。

而 (x=4) 附近的点是：

$$
4.55, 5.6, 6.8, ...
$$

这些点本来就比较 sparse，所以 (x=4) 和它们的距离不算特别 abnormal。

所以：

> (x=0.5) 是 locally abnormal。
> (x=4) 可能只是 sparse region 的 normal point。

---

### 17.3 这个例子的重点

这个例子不是为了让我们死背计算，而是要理解：

> Absolute distance 不够。
> 要看这个 distance 相对于 local density 是否 abnormal。

所以 density-based method 比 proximity-based method 更适合 variable-density data。

---

## 18. Density-based Method 的优缺点

### 18.1 优点

Density-based method 的优点：

* 可以 detect local anomalies
* 比 proximity 更适合 variable density
* 不需要 assume Gaussian distribution
* 可以处理 multi-modal data

---

### 18.2 缺点

缺点：

* 计算复杂度可能高
* 仍然需要选择 (k)
* 如果 dimensionality 很高，distance / density 可能不可靠
* density definition 本身可能受 feature scaling 影响

所以使用前通常要做 normalisation / scaling。

---

## 19. Clustering-based Anomaly Detection

### 19.1 基本想法

Clustering-based method 的核心假设是：

> Normal data belong to large and dense clusters。

如果一个 point：

* 不属于任何 cluster
* 离 cluster centroid 很远
* 属于很小的 isolated cluster

它就可能是 anomaly。

---

### 19.2 为什么 clustering-based method 有点 tricky

这里有一个 chicken-and-egg problem：

> Outliers 会影响 clustering。
> 但我们又想用 clustering 来找 outliers。

例如 K-means 会被 outlier 拉偏 centroid。
所以如果一开始 cluster 就被 outlier distorted，后面的 anomaly score 也会受影响。

因此 clustering-based anomaly detection 通常会 iterative：

1. cluster data
2. detect suspicious points
3. remove / flag them
4. recluster
5. repeat

---

## 20. Cluster-based Outlier Detection / CBLOF

### 20.1 Large clusters 和 small clusters

Cluster-based method 会先把 clusters 分成：

* large clusters：normal major groups
* small clusters：可能是 group anomalies

然后根据 point 属于 large cluster 还是 small cluster，用不同方式计算 outlier score。

---

### 20.2 Large cluster 里的 point

如果 point (t) 属于 large cluster (C_i)，score 可以是：

$$
CBLOF(t)
========

|C_i| \times distance(t, C_i)
$$

意思是：

> 如果一个 point 在 large cluster 里面，但离 cluster centroid 很远，它可能是 outlier。

为什么要乘以 cluster size？

因为 large cluster 代表很多 normal points。
一个 point 在这种 big normal group 的边缘，越远越 suspicious。

---

### 20.3 Small cluster 里的 point

如果 point (t) 属于 small cluster (C_i)，score 可以是：

$$
CBLOF(t)
========

|C_i|
\times
\min_{C_j \in LC}
distance(t, C_j)
$$

这里 (LC) 是 large clusters。

意思是：

> 如果一个 small cluster 离 nearest large cluster 很远，那么这个 small cluster 可能是 group anomaly。

所以 small cluster 里的 points 会根据它们到 large clusters 的距离来算 anomaly likelihood。

---

### 20.4 完整形式

可以写成：

$$
CBLOF(t)=
\begin{cases}
|C_i| \times distance(t, C_i), & \text{if } C_i \in LC \
|C_i| \times \min_{C_j \in LC} distance(t, C_j), & \text{if } C_i \in SC
\end{cases}
$$

其中：

* (LC)：large clusters
* (SC)：small clusters
* (C_i)：point (t) 所属 cluster
* (distance(t,C_i))：point 到 cluster centroid 或 cluster representation 的距离

---

### 20.5 Clustering-based method 能 detect group anomaly

这是 clustering-based method 很重要的优势。

Proximity-based 和 density-based methods 很多时候 focus on individual point。

但 clustering-based method 可以发现：

> 有一小群 points 彼此很近，所以它们不是 individual outliers；
> 但这一小群整体离 main clusters 很远，所以它们是 collective anomaly。

例如：

* 一组 fraud accounts 互相很像
* 一批 abnormal machine readings 形成 small cluster
* 一群 bots 行为一致，但和 normal users 差很远

所以：

> Clustering-based method 不只看 single-point anomaly，也能看 group anomaly。

---

## 21. Cluster-based Method 的 two-phase approach

Lecture 里面提到一个 common two-phase approach。

### 21.1 Point-level filtering

第一步是 point-level filtering。

也就是：

> Iteratively remove points that significantly reduce clustering quality。

这些 points 可能是 individual anomalies。

例如一个 far-away point 让 K-means centroid 被拉偏，那么它可能先被 removed / flagged。

---

### 21.2 Cluster-level filtering

第二步是 cluster-level filtering。

也就是：

> Discard small clusters that are far from others。

这些 small clusters 可能代表 group anomalies。

所以流程可以理解成：

1. 先移除很明显的 individual outliers
2. 再重新 cluster
3. 找出 isolated small clusters
4. 把它们当成 collective anomalies

---

## 22. Clustering-based Method 的优缺点

### 22.1 优点

优点：

* 可以 detect individual anomalies
* 可以 detect group anomalies
* some clustering techniques complexity lower
* result 比单纯 distance score 更 structured
* 如果 data 本身有 cluster structure，很自然

---

### 22.2 缺点

缺点：

* 需要决定 large / small cluster threshold
* sensitive to number of clusters (K)
* initial clustering 会被 outliers 影响
* 如果 cluster shape 很复杂，K-means 等方法可能不合适
* feature scaling 很重要

所以：

> Clustering-based method 很适合有 cluster structure 的 data，
> 但它本身依赖 clustering quality。

---

## 23. 四种方法怎么选

### 23.1 如果 data roughly Gaussian

用 statistical method。

例如：

* 单变量 sensor reading
* temperature data
* normally distributed measurement
* 有 clear mean / standard deviation

可以用：

$$
z =
\left|
\frac{x-\mu}{\sigma}
\right|
$$

如果：

$$
z > 3
$$

就 flag。

但要记住：

> Gaussian assumption 不成立时不要乱用。

---

### 23.2 如果 anomaly 是 far from neighbours

用 proximity-based method。

适合：

* clear distance metric
* data density relatively consistent
* global outliers
* multiple modes but density not too variable

可以用：

$$
distance\ to\ k\text{-th nearest neighbour}
$$

但要注意：

> (k) 很 sensitive，而且 variable density data 会 fail。

---

### 23.3 如果 anomaly 是 locally sparse

用 density-based method。

适合：

* variable density data
* local anomalies
* dense cluster 附近的 suspicious points
* proximity distance 不够 reliable 的情况

重点是 LOF：

> Compare point density with neighbour density。

如果 local density 比 neighbours 低很多，就 flag。

---

### 23.4 如果 anomaly 可能是一小群

用 clustering-based method。

适合：

* data has cluster structure
* group anomalies matter
* small isolated clusters are suspicious
* 想找 collective anomalies

例如 bots、fraud rings、abnormal user groups。

重点是：

> Normal points usually belong to large dense clusters。
> Small isolated clusters may be group anomalies。

---

## 24. 和 Lecture 19 Clustering 的连接

Lecture 19 讲 clustering，Lecture 21 很多方法都和 clustering 相关。

K-means 的问题之一是 outlier sensitivity。
Lecture 21 反过来利用这个问题：

> 如果某些 points 不应该被 cluster，但被强行 cluster，它们可能 distort centroid。
> 那它们可能就是 anomaly。

但也要注意：

> 因为 outliers 会 distort clustering，所以 clustering-based anomaly detection 经常需要 iterative removal。

此外，Lecture 19 讲了 different cluster structures：

* different sizes
* different densities
* non-spherical clusters

这些都会影响 anomaly detection。

例如 variable density data 中，proximity-based method 不够，density-based method 更合适。

---

## 25. 和 KNN 的连接

Proximity-based anomaly detection 很像 KNN。

KNN classification 是：

> 找 nearest neighbours，然后 majority vote。

Proximity anomaly detection 是：

> 找 nearest neighbours，然后看 distance 是否太大。

所以它们共享一些问题：

* 需要 distance metric
* 需要 choose (k)
* feature scaling 很重要
* high-dimensional data 里 distance 可能变得 less meaningful

我可以这样记：

> KNN 用 neighbours 的 labels 做 prediction。
> Proximity anomaly detection 用 neighbours 的 distances 做 anomaly score。

---

## 26. 和 Evaluation 的连接

Anomaly detection 的 evaluation 很难，因为很多时候没有 labels。

如果有 labels，可以用：

* precision
* recall
* F1
* ROC-AUC
* PR-AUC

但 anomaly class rare，所以 accuracy 不适合。

例如 99.9% normal 的 dataset，model 永远预测 normal，也有 99.9% accuracy，但 anomaly recall 是 0。

所以：

> Anomaly detection 不能只看 accuracy。
> 通常更关心 recall 和 false positives 的 trade-off。

但如果完全 unsupervised，没有 labels，那就只能：

* human validation
* domain expert review
* check top-n flagged cases
* compare with known incidents
* inspect whether anomalies make sense

## 27. 常见 exam 问法

### 27.1 问你选 method

如果题目说：

> data has several clusters with different densities, and some points are abnormal relative to their local neighbourhood.

应该答：

> Density-based method / LOF is suitable because it compares local density with the density of neighbours. Proximity-based method may fail because absolute distance does not account for variable density.

---

### 27.2 问 global vs local anomaly

如果题目说：

> A point is far away from all other points.

答：

> Global / point anomaly.

如果题目说：

> A point is not globally far away, but it is unusual compared with its dense local neighbourhood.

答：

> Local anomaly / contextual anomaly.

---

### 27.3 问 collective anomaly

如果题目说：

> Each login attempt looks normal individually, but many attempts together in a short time are suspicious.

答：

> Collective anomaly, because the group or sequence deviates from normal behaviour even though individual instances may not be anomalous.

---

### 27.4 问 supervised anomaly detection 的问题

应该提：

* labels for anomalies are hard to obtain
* anomalies are rare
* class imbalance
* cannot detect unknown / emerging anomalies
* high recall may lead to many false positives

---

### 27.5 问 statistical method 的 limitation

应该提：

* assumes data follows a parametric distribution
* Gaussian assumption often unrealistic
* hard in high dimensions
* struggles with multimodal and variable-density data

---

## 28. Lecture 21 里最重要的公式

### 28.1 Z-score

$$
z =
\left|
\frac{x-\mu}{\sigma}
\right|
$$

意思是：

> 看一个 point 离 mean 有多少个 standard deviations。

如果：

$$
z > 3
$$

在 Gaussian assumption 下通常认为 anomaly。

---

### 28.2 Mean

$$
\mu =
\frac{1}{N}
\sum_{i=1}^{N}x_i
$$

意思是：

> 所有 data points 的 average。

---

### 28.3 Standard deviation

$$
\sigma =
\sqrt{
\frac{1}{N}
\sum_{i=1}^{N}
(x_i-\mu)^2
}
$$

意思是：

> data around mean 的 spread。

---

### 28.4 Basic density

$$
density(x,k)
============

\left(
\frac{1}{k}
\sum_{y \in N(x,k)}
distance(x,y)
\right)^{-1}
$$

意思是：

> average distance 越小，density 越高。
> average distance 越大，density 越低。

---

### 28.5 Relative density / LOF-style score

$$
relative\ density(x,k)
======================

\left(
\frac{
density(x,k)
}{
\frac{1}{k}
\sum_{y \in N(x,k)}
density(y,k)
}
\right)^{-1}
$$

意思是：

> 把自己的 density 和 neighbours 的 average density 比较。
> 如果自己 density 明显低，score 会变高。

---

### 28.6 CBLOF

$$
CBLOF(t)=
\begin{cases}
|C_i| \times distance(t, C_i), & \text{if } C_i \in LC \
|C_i| \times \min_{C_j \in LC} distance(t, C_j), & \text{if } C_i \in SC
\end{cases}
$$

意思是：

> 如果 point 在 large cluster，检查它离自己 cluster 有多远。
> 如果 point 在 small cluster，检查它离 nearest large cluster 有多远。

---

## 29. 方法对比表

| Method           | 核心想法                                | 适合什么                                 | 主要问题                                     |
| ---------------- | ----------------------------------- | ------------------------------------ | ---------------------------------------- |
| Statistical      | low probability under model         | simple Gaussian-like numeric data    | assumption 很强，high-dimensional 难         |
| Proximity-based  | far from nearest neighbours         | global outliers, distance meaningful | sensitive to (k)，variable density 会 fail |
| Density-based    | low density relative to neighbours  | local anomalies, variable density    | complexity 高，仍需 choose (k)               |
| Clustering-based | normal data in large dense clusters | group anomalies, clustered data      | sensitive to clustering quality 和 (K)    |

---

## 30. 我自己的理解

这节课其实不是在教一个 single algorithm，而是在教：

> anomaly 的定义要和 normal behaviour 的定义绑定。

如果 normal 是 Gaussian distribution，那 anomaly 是 low probability point。
如果 normal 是 nearby neighbours，那 anomaly 是 far-away point。
如果 normal 是 dense region，那 anomaly 是 low-density point。
如果 normal 是 large cluster，那 anomaly 是 small isolated cluster 或 far-from-centroid point。

所以每个 method 的本质都是：

> 先定义 normal，然后找不像 normal 的东西。

## 31. Lecture 21 总结

Lecture 21 的核心是：

> Anomaly detection 是找出和 normal data-generating mechanism 明显不同的数据点或数据组。

我需要重点记住：

Anomaly 不等于 noise。
Noise 是 random error。
Anomaly 是可能由 different mechanism 产生的 object。
Anomaly 可能是最重要的 signal，不应该直接 remove。
Ozone depletion example 说明把 anomaly 当 noise 删除可能会错过 important discovery。

Anomaly detection 有三种 task formulation：
找 score 超过 threshold 的 points。
找 top-n most anomalous points。
对 new test point 计算 anomaly score。

Anomaly 有三种主要类型：
Global / point anomaly。
Local / contextual anomaly。
Collective / group anomaly。

Global anomaly 是和整个 dataset 比都很不同。
Local anomaly 是和 neighbours 比很不同。
Contextual anomaly 是在某个 time / location / context 下 abnormal。
Collective anomaly 是 individual points 不一定 abnormal，但 group as a whole abnormal。

Supervised anomaly detection 需要 normal 和 anomaly labels。
它的问题是 anomaly rare、class imbalance、emerging anomalies 难 detect、false positives 可能很多。

Semi-supervised anomaly detection 只用 normal data 学 normal boundary。
它的问题是 legitimate but unseen data 可能被误判成 anomaly。

Unsupervised anomaly detection 假设 normal data 有 pattern。
General steps 是 build normal profile，然后找 significantly different points。
最大问题是 validation。

Unsupervised methods 有四类：
Statistical。
Proximity-based。
Density-based。
Clustering-based。

Statistical method 假设 normal data follows distribution。
Z-score 用来判断 point 离 mean 有多远。
如果 (z>3)，在 Gaussian assumption 下可以 flag anomaly。
缺点是 real data often not Gaussian，high dimensions 很难 model。

Proximity-based method 认为 anomaly 离 neighbours 很远。
常用 k-th nearest neighbour distance 做 score。
缺点是 sensitive to (k)，而且 variable density data 会 fail。

Density-based method 认为 anomaly 在 low-density region。
Basic density 是 inverse average distance to k nearest neighbours。
LOF / relative density 比较 point density 和 neighbour density。
它适合 local anomalies 和 variable-density data。

Clustering-based method 认为 normal data 属于 large dense clusters。
Large cluster 里的 far-from-centroid point 可能 anomaly。
Small isolated cluster 可能 group anomaly。
它可以 detect collective anomalies。
缺点是需要 cluster thresholds、sensitive to (K)，initial clustering 会被 outliers 影响。

一句话总结：

> Lecture 21 讲的是：不要只问一个 point 离不离群，而要先定义 normal behaviour 是什么；statistical、proximity、density、clustering-based methods 只是四种不同的 normal profile。
