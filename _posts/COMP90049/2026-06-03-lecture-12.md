# Lecture 12：特征选择

## Feature Selection

## 1. 为什么需要 Feature Selection

### 1.1 这节课回到 Data

前面几节课我们已经学了很多 model，例如 KNN、Decision Tree、Naive Bayes、Linear Regression、Logistic Regression 和 SVM。之后又学了 evaluation、overfitting、underfitting、bias-variance tradeoff。Lecture 12 回到 machine learning pipeline 里的另一个关键部分：

> Data / Features

Machine Learning 不是只有 model。Model 学得好不好，很大程度取决于你给它什么 features。如果 features 里有很多 irrelevant、redundant 或 noisy information，model 可能会变慢、变复杂，也更容易 overfit。

所以 Feature Selection 的核心问题是：

> 在所有 features 里面，哪些 feature 真正有助于 prediction？

---

### 1.2 医生诊断的例子

Transcript 里老师用了一个很直观的例子：如果你去医院发烧，医生不会让你做所有检查，而是会根据症状选择相关 tests。因为不是所有 tests 都对诊断有用。

Machine Learning 也是一样。不是所有 feature 都值得放进 model。好的 features 像有用的症状，可以帮助 model 判断 label；差的 features 可能只是 noise，甚至会误导 model。

所以我可以这样记：

> Feature Selection = 不是什么 feature 都要，而是选对 prediction 真正有用的 feature。

---

## 2. Feature Selection 的目标

### 2.1 Main Goal：提高 performance

Feature Selection 的主要目标是改善 model performance。这里的 performance 可以用不同 metric 衡量，例如：

* accuracy
* precision
* recall
* F1
* MSE
* RMSE

如果某些 features 和 label 没关系，把它们放进 model 可能不会帮助 prediction，甚至会增加 noise。移除这些 features 之后，model 可能 generalise 得更好。

所以：

> Feature Selection 的核心目标是让 model 在 validation / test data 上表现更好。

---

### 2.2 Side Goal 1：减少 model complexity

如果原始 dataset 有几千甚至几百万个 features，model 会变得很复杂。复杂 model 可能训练慢、prediction 慢，也更容易 overfit。

例如：

$$
d = 2000,\quad n = 500
$$

也就是 feature 数量比 sample 数量还多。这种情况下，model 很容易记住 training data，而不是学到 general pattern。

所以减少 features 可以让 model 更小、更快，也可能更稳定。

---

### 2.3 Side Goal 2：提升 interpretability

如果一个 model 使用 1000 个 features，很难解释为什么它做出某个 prediction。但如果 feature selection 后只留下 10 个重要 features，解释就容易很多。

例如在 medical classification 里面，如果 model 只依赖几个关键 symptoms，医生更容易理解这个 model。
在 stock analysis 里面，如果 model 只依赖几个关键 financial indicators，也更容易解释。

所以：

> Fewer features → smaller models → faster and easier to understand.

---

### 2.4 Side Goal 3：更了解 data

Feature selection 也可以帮助我们理解问题本身。被选出来的 features 可能告诉我们：

> 哪些 variables 和 target 最相关。

这在 data analysis 和 research report 里很有用。因为你不仅要说 model 表现好，还要解释为什么这些 features 有意义。

---

## 3. Feature Selection 的基本形式

### 3.1 从 d 维降到 k 维

假设原始 data 有：

$$
d
$$

个 features。

Feature selection 后，我们只保留：

$$
k
$$

个 features，其中：

$$
k < d
$$

也就是说：

$$
X \in \mathbb{R}^{n \times d}
$$

变成：

$$
X' \in \mathbb{R}^{n \times k}
$$

这里 (n) 是 samples 数量，(d) 是原始 feature dimension，(k) 是被选中的 feature dimension。

注意：Feature selection 不是创造新 feature，而是从原始 features 里面选 subset。这个和 PCA 不一样。PCA 是 feature transformation / dimensionality reduction，会创造新的 component；Feature selection 是保留原本的 feature。

---

## 4. Nomenclature：几组重要分类

### 4.1 Univariate vs Multivariate

Lecture 12 先区分两种 feature selection 思路。

**Univariate method** 是一次只看一个 feature。它问：

> 这个 single feature 自己能不能预测 label？

例如单独看 (x_1) 和 (y) 的关系，再单独看 (x_2) 和 (y) 的关系。

**Multivariate method** 是同时看一组 features。它问：

> 这一组 features 合在一起，对 prediction 有没有帮助？

这很重要，因为有些 features 单独看没用，但组合起来有用。

---

### 4.2 Filter、Wrapper、Embedded

Lecture 12 也区分三种 feature selection methods。

**Filter method** 不依赖具体 classifier。它直接用 statistical criteria 衡量 feature 和 label 的关系，例如 mutual information、chi-square、correlation。

**Wrapper method** 会真的 train model。它尝试不同 feature subset，然后看 model 在 validation data 上表现如何。

**Embedded method** 把 feature selection 融入 model training 过程。例如 L1 regularisation 会在训练时把某些 feature weights 推到 0。

我可以先这样粗略记：

> Filter：先看 feature 本身。
> Wrapper：试不同 feature subset，看 model 表现。
> Embedded：feature selection 在 training 里面发生。

---

## 5. Univariate Filter Methods

### 5.1 Filter 的核心直觉

Univariate filter method 的直觉是：

> 对每个 feature 单独打分，选分数高的 features。

它不需要 train classifier，所以通常比较快。因为每个 feature 分开计算，所以 complexity 通常是 linear in number of attributes。

Filter method 关心的是：

> 一个 feature 是否和 label 有 strong relationship。

这里 “correlated” 是宽泛说法，不一定只是 Pearson correlation。因为 feature 可能是 continuous，也可能是 discrete。

---

### 5.2 Continuous Feature：Signal-to-Noise Ratio

对于 continuous feature，slides 给了 Signal-to-Noise Ratio，简称 S2N。

假设 binary classification 里有两个 classes：

* positive class
* negative class

某个 feature (X_i) 在两个 classes 里的 mean 分别是：

$$
\mu_+
$$

和：

$$
\mu_-
$$

standard deviation 分别是：

$$
\sigma_+
$$

和：

$$
\sigma_-
$$

Signal-to-Noise Ratio 是：

$$
S2N =
\frac{\mu_+ - \mu_-}
{\sigma_+ + \sigma_-}
$$

直觉是：

> 两个 class 的 feature mean 差越大越好；
> 每个 class 内部分布越集中越好。

如果两个 classes 在这个 feature 上分得很开，而且每个 class 自己又不太分散，那么这个 feature 就很有用。

如果两个 classes 的 distribution 高度重叠，即使 mean 有一点差，也不一定是好 feature。

所以我可以这样记：

> S2N 高 = class separation 大，within-class noise 小。

---

### 5.3 Discrete Feature：能不能直接预测 label

对于 discrete feature，我们看它的 value 是否能区分 label。

例如：

| x1 | x2 | c |
| -- | -- | - |
| A  | C  | Y |
| A  | D  | Y |
| B  | C  | N |
| B  | D  | N |

这里 (x_1) 很好，因为：

$$
x_1=A \Rightarrow c=Y
$$

$$
x_1=B \Rightarrow c=N
$$

但 (x_2) 不好，因为：

$$
x_2=C
$$

时既可能是 (Y)，也可能是 (N)。

所以 discrete feature 的直觉是：

> 如果 feature value 能稳定对应 label，它就是 good feature。

---

## 6. Mutual Information

### 6.1 Mutual Information 衡量什么

Mutual Information 用来衡量两个 variables 之间的 dependence。这里我们关心：

$$
I(Y, X_i)
$$

也就是 label (Y) 和 feature (X_i) 之间共享多少 information。

如果：

$$
I(Y,X_i)=0
$$

表示 (Y) 和 (X_i) independent。这个 feature 对 label 没有什么帮助。

如果：

$$
I(Y,X_i)>0
$$

表示 (Y) 和 (X_i) dependent。这个 feature 和 label 有关系。

所以 feature selection 时，我们会选择：

> high mutual information 的 features。

---

### 6.2 Independence 的连接

如果 (Y) 和 (X_i) independent，那么：

$$
P(Y,X_i)=P(Y)P(X_i)
$$

Mutual Information 的公式里有：

$$
\log
\frac{P(Y,X_i)}
{P(Y)P(X_i)}
$$

如果 independent，那么：

$$
\frac{P(Y,X_i)}
{P(Y)P(X_i)}
=

1
$$

所以：

$$
\log 1 = 0
$$

因此 mutual information 就是 0。

这个很重要，因为它说明 MI 本质上是在问：

> joint probability 和 independent assumption 差多少？

差得越多，dependence 越强。

---

### 6.3 Continuous Mutual Information

对于 continuous variables，Mutual Information 写成：

$$
I(Y,X_i)
=

\int
\int
P(Y,X_i)
\log
\frac{P(Y,X_i)}
{P(Y)P(X_i)}
dYdX_i
$$

这个公式不用死背积分细节。重点是：

> 对所有 possible values，计算 joint distribution 和 independent distribution 的差异。

如果 feature 和 label 没关系，MI 接近 0。
如果 feature 很能预测 label，MI 比较大。

---

### 6.4 Discrete Mutual Information

对于 discrete variables，积分换成 sum。

如果 (X_i) 有 (k) 个 values，binary label 是：

$$
Y \in {-1,+1}
$$

那么：

$$
I(Y,X_i)
=

\sum_y
\sum_x
P(Y=y,X_i=x)
\log
\frac{P(Y=y,X_i=x)}
{P(Y=y)P(X_i=x)}
$$

这里需要从 data 里面 estimate：

* (P(Y))
* (P(X_i))
* (P(Y,X_i))

例如 training set 有 8 rows，label (-1) 出现 4 次，(+1) 出现 4 次：

$$
P(Y=-1)=\frac{4}{8}
$$

$$
P(Y=+1)=\frac{4}{8}
$$

如果 (X_2=1) 出现 3 次：

$$
P(X_2=1)=\frac{3}{8}
$$

如果 (Y=-1) 且 (X_2=1) 只出现 1 次：

$$
P(Y=-1,X_2=1)=\frac{1}{8}
$$

然后把所有 ((Y,X_2)) 的 combinations 加起来，就得到 (I(Y,X_2))。

---

### 6.5 Mutual Information 和 Information Gain 是同一个东西

Slides 特别提到：

> Mutual Information is another name for Information Gain.

在 Decision Tree 那一节，我们用 Information Gain 选择 split feature：

$$
IG(Y,X)=H(Y)-H(Y|X)
$$

在 Feature Selection 这里，也可以写成：

$$
I(Y;X)=H(Y)-H(Y|X)
$$

意思是：

> 知道 feature (X) 以后，label (Y) 的 uncertainty 减少了多少。

所以我可以把它和 Lecture 5 连起来：

> Decision Tree 用 Information Gain 选 split feature；
> Feature Selection 也可以用 Mutual Information 选 useful features。

---

## 7. 其他 Univariate Filter Criteria

### 7.1 Chi-square Test

Chi-square test 用来判断 categorical variables 之间是否有 significant association。

在 feature selection 里，它适合：

> classification tasks with categorical features

例如 feature 是：

* colour
* school type
* postcode group
* product category

target 是 class label。Chi-square 可以衡量 feature 和 label 是否 independent。

---

### 7.2 ANOVA F-value

ANOVA F-value 可以用来评估 continuous feature 和 class label 之间的关系。

它适合：

> classification tasks with continuous features

例如：

* age
* income
* stock return
* temperature

如果某个 continuous feature 在不同 classes 里的 distribution 差异明显，它可能有较高 F-value。

---

### 7.3 Correlation-based Feature Selection

Correlation-based Feature Selection 会计算 feature 和 target variable 的 correlation，例如 Pearson correlation。

如果一个 feature 和 target 的 correlation magnitude 高，它可能更有用。

但要小心：correlation 通常主要捕捉 linear relationship。如果 feature 和 target 的关系是 nonlinear，correlation 可能低，但 feature 仍然可能有用。

---

## 8. Univariate Selection 可能失败

### 8.1 单个 feature 不够

Univariate method 的限制是：它一次只看一个 feature。

但有些问题里面，单个 feature 看起来没什么用，两个 features 合起来才有用。Slides 用类似 XOR 的情况说明。

例如两个 features：

$$
X_1
$$

和：

$$
X_2
$$

单独看 (X_1)，两个 classes overlap。
单独看 (X_2)，两个 classes 也 overlap。
但如果同时看 (X_1) 和 (X_2)，classes 可以被很好地区分。

所以：

> Univariate feature selection 可能错过 feature interaction。

---

### 8.2 股票分析里的直觉

如果放到 stock analysis，可以这样理解：单独看 volume 可能不能判断上涨，单独看 price return 也可能不够。但 volume spike + positive momentum 合在一起，可能更有意义。

这就是 feature interaction：

> 单个 feature 弱，但组合有 predictive power。

所以 univariate filter 很快，但不一定能找到最好的 feature subset。

---

## 9. Multivariate Feature Selection

### 9.1 Multivariate 的核心

Multivariate feature selection 会考虑 feature subset，而不是 single feature。

它问的是：

> 哪一组 features 合起来，在 validation data 上表现最好？

例如 weather data 里有：

* Outlook
* Temperature
* Humidity
* Windy

可以尝试：

$$
{}
$$

$$
{Outlook}
$$

$$
{Temperature}
$$

$$
{Outlook, Temperature}
$$

$$
{Outlook, Temperature, Humidity}
$$

然后对每个 subset train model，evaluate validation performance，最后选表现最好的 subset。

---

### 9.2 Multivariate 的优点

Multivariate method 的优点是：

> 可以找到对某个 learner 来说 validation performance 最好的 feature set。

因为它真的看 feature combination 的效果，所以可以处理 feature interaction。

这比 univariate method 更接近最终目标：不是单个 feature 分数高，而是整个 model performance 好。

---

### 9.3 Multivariate 的缺点：太贵

缺点是 computational cost 很高。

如果有 (d) 个 features，每个 feature 可以选或不选，那么所有 possible subsets 数量是：

$$
2^d
$$

因为：

$$
\binom{d}{0}
+
\binom{d}{1}
+
\binom{d}{2}
+
\dots
+
\binom{d}{d}
=

2^d
$$

如果 (d=10)，还可以尝试：

$$
2^{10}=1024
$$

但如果：

$$
d=60
$$

那么：

$$
2^{60}
$$

就完全不可行。

所以：

> Multivariate exhaustive search 在 feature 多的时候不 practical。

---

## 10. Feature Subset Assessment

### 10.1 用 validation data 评估 subset

Multivariate feature selection 通常需要 validation data。流程是：

1. 选择一个 feature subset
2. 用 training data train model
3. 用 validation data evaluate performance
4. 尝试其他 subsets
5. 选择 validation performance 最好的 subset
6. 最后在 test data 上做 final evaluation

这里要注意：test data 不能参与 feature selection。否则会 data leakage。

所以：

> Feature selection 也是 model development 的一部分，只能用 training / validation，不能用 final test。

---

### 10.2 Feature selection 不一定总是提高 performance

Slides 和 transcript 都提醒：Feature selection 是 optional，不是每个问题都必须做。它可能提高 performance，也可能没有帮助，甚至可能因为误删有用 feature 而变差。

所以实际项目里应该问：

* feature 是否太多？
* model 是否太慢？
* 是否 overfitting？
* 是否需要 interpretability？
* 是否存在 redundant / irrelevant features？

如果没有这些问题，feature selection 不一定必要。

---

## 11. Filter、Wrapper、Embedded Methods

### 11.1 Filter Methods

Filter method 的特点是：

> independent of classifier

它先用 statistical criteria 对 features 打分，然后选 top features。常见 criteria 包括：

* Information Gain / Mutual Information
* Chi-square
* Correlation coefficient
* ANOVA F-value

Filter method 的优点：

* fast
* simple
* 不需要反复 train model
* 适合很多 features 的情况

缺点：

* 不一定对应最终 model performance
* 可能忽略 feature interactions
* 可能选出 individually strong 但 collectively redundant 的 features

所以我可以这样记：

> Filter 选的是“看起来和 label 有关系”的 features。

---

### 11.2 Wrapper Methods

Wrapper method 会用 classifier 来评估 feature subset。

它问：

> 这个 feature subset 真的能让 model 表现好吗？

流程通常是：

1. 选择一个 candidate subset
2. train classifier
3. evaluate with cross-validation / validation data
4. 根据 performance 继续 search

Wrapper 的优点：

* 直接优化 model performance
* 可以考虑 feature interactions
* 对具体 learner 更有针对性

缺点：

* computationally expensive
* 每个 candidate subset 都要 train model
* 可能 overfit validation set
* feature 很多时不可行

所以：

> Wrapper 选的是“对这个 model 真的有用”的 feature subset。

---

### 11.3 Embedded Methods

Embedded method 把 feature selection 放进 model training 过程。

它不是先单独选 feature，也不是每个 subset 都重训一个 model，而是在 training 过程中利用 model 内部信息决定哪些 features 重要。

常见例子：

* L1 regularisation
* LASSO
* SVM weights based feature elimination

Embedded method 的优点：

* 比 wrapper 更 efficient
* 比 filter 更贴近 model
* selection 和 training 一起发生

所以：

> Embedded method = feature selection embedded in model training.

---

## 12. Forward Selection

### 12.1 Forward Selection 怎么做

Forward Selection 是 wrapper method 的一种。

它从 empty feature set 开始：

$$
S={}
$$

然后每一步尝试加入一个 feature，选择让 validation performance 提升最多的 feature。

例如有 4 个 features：

$$
{x_1,x_2,x_3,x_4}
$$

第一步尝试：

$$
{x_1},{x_2},{x_3},{x_4}
$$

假设 (x_2) 最好，就保留：

$$
S={x_2}
$$

第二步尝试：

$$
{x_2,x_1},{x_2,x_3},{x_2,x_4}
$$

继续选择最好的一组。

---

### 12.2 Forward Selection 的计算成本

如果有 (d) 个 features，Forward Selection 需要 train-evaluate cycles：

$$
d+(d-1)+\dots+1
=

\frac{d(d+1)}{2}
$$

这比 exhaustive search 的 (2^d) 少很多，但如果 (d) 很大，仍然很慢。

---

### 12.3 Forward Selection 的优缺点

优点：

> 如果 optimal subset 很小，Forward Selection 比较合适。

因为它从 0 features 开始，逐步加重要 features。

缺点：

> Greedy search 不保证 global optimal。

因为每一步只选当前最好 feature。如果某两个 features 单独看一般，但合起来很好，Forward Selection 可能永远走不到那个 combination。

所以我可以这样记：

> Forward Selection 快过 exhaustive search，但可能卡在 sub-optimal solution。

---

## 13. Backward Elimination

### 13.1 Backward Elimination 怎么做

Backward Elimination 也是 wrapper method，但方向相反。

它从 all features 开始：

$$
S={x_1,x_2,\dots,x_d}
$$

每一步尝试 remove 一个 feature，看移除后 validation performance 是否下降。

如果移除某个 feature 不影响 performance，甚至让 performance 变好，那说明这个 feature 可能 irrelevant 或 noisy，可以删掉。

---

### 13.2 Backward Elimination 的计算成本

Backward Elimination 的 train-evaluate cycles 也是：

$$
d+(d-1)+\dots+1
=

\frac{d(d+1)}{2}
$$

所以它也比 exhaustive search 便宜，但 feature 多时仍然 expensive。

---

### 13.3 Backward Elimination 的优缺点

优点：

> 如果 optimal subset 很大，Backward Elimination 比较合适。

因为它一开始保留所有 features，只逐步删除没用的。

缺点：

* computational cost 仍然高
* greedy，不保证 global optimal
* feature 很多时不 practical
* 一旦早期删错 feature，后面可能无法恢复

所以：

> Forward Selection 适合从少量 features 开始找；Backward Elimination 适合从大量 features 中删掉没用的。

---

## 14. Embedded Method：SVM Feature Selection

### 14.1 用 SVM weights 判断 feature importance

Lecture 12 用 SVM 解释 embedded feature selection。

SVM 学到一个 parameter vector：

$$
\theta=(\theta_1,\theta_2,\dots,\theta_d)
$$

每个 (\theta_j) 对应一个 feature (x_j)。

如果某个 weight 很小：

$$
|\theta_j| \approx 0
$$

说明这个 feature 对 decision boundary 的影响很小。我们可以把这个 feature 移除。

所以 embedded SVM feature selection 的逻辑是：

1. 用所有 features train SVM
2. 看每个 feature 的 weight (\theta_j)
3. 删除 weight 最小的 feature
4. 重新 train
5. 重复直到达到 stopping criterion

这叫 embedded，因为 feature selection 利用了 model training 后得到的 internal weights。

---

### 14.2 为什么 embedded 比 wrapper 省

Wrapper 每次要尝试很多 candidate subsets，每个 subset 都 train 一个 classifier。Embedded method 则利用已经训练出来的 model weights 来 guide search。

所以它避免了“每个 subset 都重新 train classifier”的巨大成本。

我可以这样记：

> Wrapper 是外面包着 model 反复试。
> Embedded 是 model 训练时顺便告诉你哪些 features 重要。

---

## 15. Regularisation 和 Feature Selection

### 15.1 L0 Norm：直接数 nonzero features

我们真正想做的是：让不重要的 feature weight 变成 0。最直接的方式是优化 nonzero weights 的数量，也就是 L0 norm。

L0 objective 可以理解成：

$$
||\theta||_0
=

\sum_{j=1}^{d}
I(\theta_j \neq 0)
$$

它数的是：

> 有多少 feature weights 不是 0。

如果某个：

$$
\theta_j=0
$$

这个 feature 就被移除了。

所以 L0 feature selection 的目标是：

> 用尽量少的 nonzero features，同时保持 good classification margin / performance。

---

### 15.2 L0 的问题

L0 norm 的问题是：

* not continuous
* not convex
* optimisation 很难
* 可能需要搜索所有 (2^d) feature subsets

所以虽然 L0 很符合 feature selection 的直觉，但实际优化很困难。

---

### 15.3 L1 Norm：可优化的近似

为了解决 L0 太难的问题，可以使用 L1 norm：

$$
||\theta||_1
=

\sum_{j=1}^{d}
|\theta_j|
$$

L1 norm 是 convex 的，而且会 encourage sparsity。也就是说，它倾向于把某些 weights 推到 exactly 0。

如果：

$$
\theta_j=0
$$

那么 feature (j) 就被 effectively removed。

所以 L1 regularisation 常用于 embedded feature selection。

我可以这样记：

> L0 是直接数 feature，但太难优化。
> L1 是可优化的近似，而且能产生 sparse solution。

---

### 15.4 L1 vs L2

L2 norm 是：

$$
||\theta||_2^2
=

\sum_{j=1}^{d}
\theta_j^2
$$

L2 通常会让 weights 变小，但不一定变成 0。
L1 则更容易让一些 weights 变成 exactly 0。

所以 feature selection 更常用 L1，而不是 L2。

> L2 shrinks weights.
> L1 selects features.

---

## 16. Practical Advice

### 16.1 没有一种方法永远最好

Lecture 12 最后强调：没有一种 feature selection method 在所有问题上都最好。

Filter 快，但不一定对应最终 model performance。
Wrapper 更贴近 model，但很慢。
Embedded 比 wrapper 更 efficient，但依赖具体 model。
L1 可以自动选 feature，但也受 scaling、regularisation strength 等因素影响。

所以实际项目里通常要结合：

* data size
* feature dimension
* model type
* computational budget
* interpretability requirement
* validation performance

来决定方法。

---

### 16.2 Feature selection 要放在正确 pipeline 里

Feature selection 不能在整个 dataset 上先做，然后再 split train/test。这样 test data 的 information 会 leak 到 feature selection 里。

正确方式是：

1. split train / validation / test
2. feature selection 只在 training / validation process 中做
3. selected features 确定后
4. 最后只用 test set 做 final evaluation

所以：

> Feature selection 本身也是 model development 的一部分，不能偷看 test set。

---

### 16.3 Feature selection 和你的 project / report

如果你在 project 里做 feature selection，report 里不能只写 “I used SelectKBest”。你需要解释：

* 为什么原始 features 太多或有 noise
* 用了什么 selection method
* selection criterion 是什么
* 为什么这个 method 适合你的 data
* 最后选了多少 features
* performance 有没有改善
* 选出的 features 是否有解释意义

尤其是如果你的 task 是 stock prediction，你可以说：

> 我不只是把所有 financial indicators 丢进 model，而是尝试筛掉 weak / redundant indicators，保留和 target 更相关的 signals。

---

## Lecture 12 总结

Lecture 12 的核心是：

> Feature Selection 是从原始 features 里面选择对 prediction 最有用的 subset，让 model 更快、更简单、更可解释，也可能更能 generalise。

我需要重点记住：

Feature selection 不是创造新 feature，而是选择原始 feature subset。
主要目标是提升 validation / test performance。
Side goals 包括 faster model、smaller model、better interpretability、understanding data。
Univariate method 一次只看一个 feature。
Multivariate method 看 feature subset。
Filter method independent of classifier。
Wrapper method 用 classifier 评估 feature subset。
Embedded method 在 model training 过程中做 feature selection。
Continuous feature 可以用 Signal-to--Noise Ratio：

$$
S2N=
\frac{\mu_+-\mu_-}
{\sigma_+ + \sigma_-}
$$

Mutual Information 衡量 feature 和 label 的 dependence：

$$
I(Y,X_i)
=

\sum_y
\sum_x
P(Y=y,X_i=x)
\log
\frac{P(Y=y,X_i=x)}
{P(Y=y)P(X_i=x)}
$$

如果：

$$
I(Y,X_i)=0
$$

说明 feature 和 label independent。

Mutual Information 和 Information Gain 是同一个思想：

$$
I(Y;X)=H(Y)-H(Y|X)
$$

Chi-square 适合 categorical features。
ANOVA F-value 适合 continuous features。
Correlation 可以衡量 feature 和 target 的 linear relationship。
Univariate selection 可能错过 feature interaction。
Multivariate selection 可以找更好的 subset，但所有 subsets 有：

$$
2^d
$$

种组合，所以很贵。
Forward Selection 从 empty set 开始逐步 add feature。
Backward Elimination 从 all features 开始逐步 remove feature。
Forward / Backward 都是 greedy，不保证 global optimal。
SVM weights 可以用于 embedded feature selection。
L0 norm 直接数 nonzero weights，但 hard to optimise。
L1 norm 是 convex approximation，可以 encourage sparse solution：

$$
||\theta||_1
=

\sum_{j=1}^{d}
|\theta_j|
$$

L1 更适合 feature selection，因为它能把一些 weights 推到 0。
Feature selection 不是 always necessary，但在 high-dimensional、noisy、slow、overfitting 或需要 interpretability 的问题里很有用。
Feature selection 不能偷看 test set，否则会 data leakage。

一句话总结：

> Lecture 12 讲的是如何从 data 里挑出真正有用的 signals：filter 看 feature 和 label 的统计关系，wrapper 直接看 feature subset 对 model performance 的帮助，embedded 则让 model 在训练过程中自己把不重要的 feature 权重压低甚至变成 0。
