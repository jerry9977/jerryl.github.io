# Lecture 11：模型评估（Overfitting, Underfitting, Bias and Variance）

## 1. 从 Evaluation Metrics 到 Model Diagnosis

### 1.1 这节课在回答什么问题

Lecture 10 主要讲的是 evaluation 的基本方法，例如 train / validation / test split、holdout、cross-validation、accuracy、precision、recall、F1、MSE、RMSE 等等。也就是说，上一节课重点是：

> 如何评价 model 表现。

Lecture 11 进一步问：

> 如果 model 表现不好，为什么不好？

例如，一个 model 在 training data 上有 95% accuracy，但在 validation data 上只有 60%。这个时候不能只说“model 不好”，而是要诊断到底发生了什么：是 model 太复杂、太简单、data split 有问题、data distribution 不一致，还是 evaluation 本身不稳定。

所以 Lecture 11 的核心是：

> Evaluation 不只是给一个 score，而是用 score 去理解 model 的行为。

---

### 1.2 Generalisation 仍然是核心

Machine Learning 的目标不是在 training data 上拿高分，而是要在 unseen data 上表现好。这个能力叫：

> Generalisation

如果 model 只记住 training data，它可能 training accuracy 很高，但 validation/test accuracy 很差。这种情况说明它没有真正学到 general pattern。

所以我可以这样记：

> Training performance 告诉我 model 有没有学会 training data。
> Validation/Test performance 告诉我 model 有没有 generalise。

Lecture 11 后面所有内容，其实都是围绕这个问题展开：

> model 为什么不能 generalise？

---

## 2. Underfitting、Overfitting 和 Appropriate Fitting

### 2.1 Underfitting

Underfitting 是指：

> model 太简单，不够 expressive，无法 capture data 里的真实 pattern。

例如 data 其实是 curved pattern，但我强行用一条 straight line 去 fit。这个 model 的 assumption 太强，所以它连 training data 都学不好。

Underfitting 的典型表现是：

* training error high
* validation error high
* 两边都差
* model 太简单

所以 high bias 通常对应 underfitting。

我可以这样记：

> Underfitting = model 连 training data 都没学好。

---

### 2.2 Overfitting

Overfitting 是指：

> model 太复杂，不只 capture pattern，还 capture noise。

例如一个 Decision Tree 太深，最后每个 leaf 都只对应很少几个 training examples。它可能在 training data 上几乎完美，但这些 branch 可能只是记住了 training data 里的偶然情况。

Overfitting 的典型表现是：

* training error low
* validation error high
* training 和 validation 之间 gap 很大
* model 太复杂

所以 high variance 通常对应 overfitting。

我可以这样记：

> Overfitting = model 把 training data 里的 noise 也学进去了。

---

### 2.3 Appropriate Fitting

Appropriate fitting 是比较理想的情况：

> model capture essential pattern，但没有过度 capture noise。

它不会强行 fit 每一个 training point，也不会简单到看不出主要 trend。它可能会在 training data 上犯一些错，但这些错误是可以接受的，因为它保留了更好的 generalisation ability。

所以：

> 好 model 不一定 training accuracy 最高，而是 validation/test performance 最稳定。

---

## 3. Learning Curve

### 3.1 Learning Curve 是什么

Learning curve 是一个 diagnostic tool，用来观察 model 在不同条件下的表现。

一般来说：

* y-axis 是 performance，例如 accuracy、error rate、loss、MSE
* x-axis 是某个变化条件，例如 training set size、model complexity、number of iterations

通常会画两条线：

* training learning curve
* validation learning curve

Training curve 告诉我 model 在 training data 上学得怎么样。Validation curve 告诉我 model 在 unseen / holdout data 上 generalise 得怎么样。

所以 learning curve 的作用是：

> 通过 training 和 validation performance 的变化，诊断 model 是 underfitting 还是 overfitting。

---

### 3.2 为什么 training performance 一开始可能很高

一个有趣现象是：当 training samples 很少时，training accuracy 可能特别高。原因是 sample 少，model 很容易 memorize 这些 examples。

但随着 training data 增加，training performance 可能下降一点，因为 model 看到更多复杂情况，无法再轻松记住每一个 sample。

这不是坏事。它说明 data 更接近真实分布，model 需要学习更 general 的 pattern。

所以我可以这样理解：

> 少量 training data 上的高 accuracy 不一定可靠，可能只是 memorisation。

---

### 3.3 Training set size 的 learning curve

如果 x-axis 是 training data size，我们可以观察：

> 多一点 training data 是否能改善 validation performance。

通常：

* more training data → model 学到更多 pattern
* more evaluation data → evaluation estimate 更可靠

但这里有 trade-off。如果 data 总量固定，training data 多了，evaluation data 就少；evaluation data 太少，test score 本身不稳定。Training data 太少，model 又学不好。

所以选择 split ratio 本质上是在平衡：

> enough data to train vs enough data to evaluate。

如果 validation performance 随着 data size 增加还在上升，说明更多 data 可能有帮助。如果 performance 已经 flatten，说明 model 可能已经接近 saturated。

---

## 4. Model Complexity

### 4.1 Model complexity 是什么

Model complexity 可以理解成 model 有多 flexible，或者 model 有多少 adjustable parameters。

例如：

Decision Tree:

> depth 越深，leaf nodes 越多，model 越复杂。

Polynomial Regression:

$$
\phi(x)=[1,x,x^2,\dots,x^D]
$$

这里 (D) 越大，polynomial order 越高，model 越复杂。

所以：

> Model complexity 越高，model 越能 fit complex patterns，但也越容易 overfit。

---

### 4.2 Polynomial Model Example

Slides 用 polynomial regression 解释 complexity。假设 model 是：

$$
y = \mathbf{w}\cdot\phi(x)
$$

其中：

$$
\phi(x)=[1,x,x^2,\dots,x^D]
$$

如果：

$$
D=0
$$

model 只是一个 constant，非常简单，容易 underfit。

如果：

$$
D=1
$$

model 是 straight line。

如果：

$$
D=2
$$

model 是 quadratic curve。

如果：

$$
D=8,9,10,11
$$

model 会变得非常 flexible，可能开始弯来弯去，强行穿过 training points。

这就是 model complexity 的典型变化：

> D 太小 → underfit。
> D 适中 → good fit。
> D 太大 → overfit。

---

### 4.3 Complexity vs Error Curve

当 model complexity 增加时，training error 通常会持续下降。因为越复杂的 model 越能 fit training data。

但 validation/test error 通常是 U-shape：

* complexity 太低：training 和 validation 都差，underfitting
* complexity 适中：validation error 最低，generalisation 最好
* complexity 太高：training error 低，但 validation error 高，overfitting

所以我可以这样记：

> Training error 通常喜欢复杂 model。
> Validation error 会告诉你复杂到哪里开始 overfit。

真正要选的不是 training error 最低的 model，而是 validation error 最低的 model。

---

## 5. Data 也可能是问题

### 5.1 不是所有问题都来自 model

如果 training accuracy 很高，但 validation accuracy 很低，不一定全部是 model 的错。也可能是 data 的问题。

例如：

* training data 和 validation data distribution 不一致
* training data 不 representative
* validation data 来自不同 population
* data collection 有 bias
* 同一个 patient 的多个 records 被错误分到 train/test 两边
* label 有 human annotation error
* sensor measurement 有 noise

所以 Lecture 11 强调：现实项目里，不应该只盯着 model。很多时候要先理解 data 是怎么收集的。

我可以这样记：

> Model diagnosis 之前，先问 data 是否可信、representative、和 test situation 对齐。

---

### 5.2 Sampling Bias

Sampling bias 是指 dataset 本身不是 population 的好代表。

例如我要训练一个 general medical classifier，但 training data 只来自一个 hospital、一个 age group 或一个 geographical region。Model 可能在这个 group 上表现很好，但换到别的 population 就变差。

所以 sampling bias 会直接影响 generalisation。

---

## 6. Expectation：理解 Bias 和 Variance 前的数学直觉

### 6.1 Expectation 是什么

Expectation 可以理解成 random variable 的长期平均值。

如果 (X) 是 discrete random variable：

$$
E[X]=\sum_x xP(x)
$$

如果 (X) 是 continuous random variable：

$$
E[X]=\int xP(x)dx
$$

Lecture 用 Bernoulli coin example 解释。如果 coin 是 fair coin，那么：

$$
P(0)=0.5,\quad P(1)=0.5
$$

所以：

$$
E[X]=0\times0.5+1\times0.5=0.5
$$

如果只 flip 10 次，sample average 可能是 0.8；flip 100 次可能是 0.44；flip 10000 次可能更接近 0.5。

所以：

> Expectation 可以理解成无限多 samples 下的 average。

这个概念后面会用来理解 bias 和 variance。

---

## 7. Bias

### 7.1 Bias 有不同类型

Lecture 11 讲了几种 bias：

* model bias
* evaluation bias
* sampling bias

这里最重要的是 model bias。

---

### 7.2 Model Bias

Model bias 是指：

> model 有系统性错误，prediction systematically wrong。

在 regression 里，如果 model 总是预测得比真实值高，或者总是比真实值低，那么 model 有 bias。

例如真实关系是 curved，但我们用 straight line 去 fit。无论给多少 training data，这条 straight line 都无法完全 capture true function。这种 error 是 model assumption 自己造成的。

所以：

> Model bias 是 model 本身带来的偏差。

在 regression 中，可以把 bias 理解成 expected prediction 和 true function 之间的差：

$$
Bias(\hat{f},f)=E[\hat{f}(x)-f(x)]
$$

High bias 通常意味着：

* model too simple
* assumptions too strong
* underfitting

---

### 7.3 Classification 中的 bias

在 classification 中，bias 的公式更复杂，lecture 不要求具体公式。直觉上，如果 model 预测出来的 label distribution 和真实 label distribution 系统性不同，就可以说 model 有 bias。

例如实际 data 是 50% sunny、50% rainy，但 model 总是倾向预测 sunny，这就是 biased toward sunny / majority class。

所以我可以这样记：

> Bias = model 系统性偏向某种错误方向。

---

## 8. Variance

### 8.1 Model Variance

Model variance 是指：

> 如果换一批 training data，model prediction 会变化多少。

如果同一个 learner 在不同 training subsets 上训练后，得到的 models 差异很大，那么这个 learner 的 variance 高。

例如一个很深的 Decision Tree。如果 training data 里稍微多一个 point 或少一个 point，tree structure 可能就变了，prediction 也跟着变。这就是 high variance。

所以：

> Variance 衡量 model 对 training data 变化的敏感程度。

---

### 8.2 Variance 公式直觉

Regression 中，variance 可以写成：

$$
Var(\hat{f})
=

E[(\hat{f}(x)-E[\hat{f}(x)])^2]
$$

这里不是在比较 prediction 和 true value，而是在比较：

> 每次训练出来的 prediction，离 average prediction 有多远。

如果每次训练出来的 model 都差不多，variance 低。
如果每次训练出来的 model 差很多，variance 高。

所以：

> Bias 看 model average prediction 离 truth 多远。
> Variance 看不同 trained models 之间差多远。

---

## 9. Generalisation Error Decomposition

### 9.1 数据生成假设

Lecture 用 regression 来解释 generalisation error。假设真实 data 由一个 true function 加上 noise 生成：

$$
Y=f(X)+\epsilon
$$

其中：

$$
\epsilon \sim \mathcal{N}(0,\sigma^2)
$$

这里 (\epsilon) 是不可避免的 noise，例如 annotation error、measurement error、sensor error。

我们训练出来的 model 是：

$$
\hat{f}(x)
$$

我们关心 expected squared prediction error：

$$
Err=E[(Y-\hat{f}(x))^2]
$$

---

### 9.2 Bias-Variance Decomposition

Regression 中，generalisation error 可以 decomposed 成：

$$
Err = Bias^2 + Variance + Irreducible\ Error
$$

更完整地写：

$$
Err
=

E[(f(x)-\hat{f}(x))^2]
+
E[(\hat{f}(x)-E[\hat{f}(x)])^2]
+
\sigma^2
$$

三个部分分别是：

Bias:

> model 的平均 prediction 离 true function 有多远。

Variance:

> model 因 training data 不同而变化多少。

Irreducible Error:

> data 本身的 noise，无法通过换 model 消除。

---

### 9.3 Irreducible Error

Irreducible error 是最容易被忽略但很重要的部分。它来自 data distribution 和 feature representation 本身。

例如：

* human label error
* sensor measurement error
* missing relevant features
* randomness in the world

这部分 error 你不能靠换 model 完全消除。你只能通过更好的 data collection、更好的 labels、更好的 feature representation 来尝试降低。

所以：

> 有些 error 是 model 学不好，有些 error 是 data 本身就不可能完全预测。

---

## 10. Bias-Variance Tradeoff

### 10.1 Complexity 增加时发生什么

Bias 和 variance 通常有 tradeoff。

如果 model 很简单：

* bias high
* variance low
* underfit

因为它不太受 training data 变化影响，但它的 assumption 太强，无法 fit true pattern。

如果 model 很复杂：

* bias low
* variance high
* overfit

因为它可以 fit training data 很细，但也对 training data 的 small changes 很 sensitive。

所以：

> 增加 model complexity 通常会降低 bias，但提高 variance。

---

### 10.2 总 error 的 U-shape

Total generalisation error 大概是：

$$
Err = Bias^2 + Variance + Noise
$$

随着 model complexity 增加：

* bias decrease
* variance increase
* noise 不变

所以 total error 通常是 U-shape。我们想找的是中间的 sweet spot：

> bias 不太高，variance 也不太高。

这就是 bias-variance tradeoff。

---

### 10.3 Target Diagram 的直觉

经典 target diagram 可以这样理解：

Low bias, low variance:

> shots 集中在 target center，最好。

High bias, low variance:

> shots 很集中，但偏离 target。Model 很稳定，但方向错。

Low bias, high variance:

> shots 平均在 target 附近，但很分散。Model 平均还可以，但不稳定。

High bias, high variance:

> shots 又偏又散，最差。

所以：

> Bias 是偏离 target 的程度。
> Variance 是散开的程度。

---

## 11. 如何从 Learning Curve 诊断 High Bias / High Variance

### 11.1 High Bias 的 learning curve

High bias 通常表现为：

* training error high
* validation error high
* 两条 curves 比较接近
* 增加 training data 帮助不大

因为问题不是 data 不够，而是 model 太简单。即使给更多 data，它也没有足够 capacity 去 capture pattern。

解决方法通常是：

* use more complex model
* add more useful features
* use nonlinear model
* boosting

所以我可以这样记：

> High bias = model 太简单；加 data 不一定救得回来。

---

### 11.2 High Variance 的 learning curve

High variance 通常表现为：

* training error low
* validation error high
* training 和 validation 之间 gap 很大
* 增加 training data 通常有帮助

因为 model 太依赖当前 training data。如果给更多 data，model 可能更稳定，variance 会下降。

解决方法通常是：

* add more training data
* reduce features
* reduce model complexity
* regularisation
* bagging

所以：

> High variance = model 太复杂或太敏感；更多 data 或降低 complexity 可能有帮助。

---

### 11.3 Good Bias-Variance Tradeoff

比较好的情况是：

* training performance 和 validation performance 都不错
* 两者之间 gap 小
* validation performance 已经稳定
* model 没有明显 overfit 或 underfit

这个时候 model 的 complexity 比较合适。

---

## 12. Remedies：怎么处理 High Bias 和 High Variance

### 12.1 High Bias Remedy

High bias 的问题是 model 不够 expressive，所以要让 model 更强。

可以做：

* 使用更复杂的 model
* 增加 features
* 使用 nonlinear features
* 降低过强的 regularisation
* boosting

例如用 straight line fit curved data 失败，那就考虑 polynomial features 或 nonlinear model。

---

### 12.2 High Variance Remedy

High variance 的问题是 model 太 sensitive，所以要让 model 更稳定。

可以做：

* 增加 training data
* 减少 irrelevant features
* 降低 model complexity
* 加 regularisation
* pruning decision tree
* bagging

例如 Decision Tree 太深，就限制 max_depth 或 prune tree。

---

## 13. Evaluation Bias 和 Evaluation Variance

### 13.1 Evaluation metric 本身也是 estimate

Lecture 11 后半段提醒一个很重要的点：

> evaluation score 本身也是一个 estimate。

我们真正想知道的是 model 在真实世界中的 true error rate，但我们通常只有有限的 validation/test samples。所以我们算出来的 accuracy、F1、MSE 都只是 estimate。

如果 test set 太小，score 可能不稳定。如果 test set 不 representative，score 可能系统性偏高或偏低。

---

### 13.2 Evaluation Bias

Evaluation bias 是指：

> evaluation strategy 系统性地 overestimate 或 underestimate model effectiveness。

例如 test set 太简单，model performance 看起来很高，但真实 deployment 中没那么好。这个时候 evaluation 有 bias。

另一个例子是 validation data 被反复用于 model selection，最后 model 可能 overfit validation set。这样 validation score 会变得太乐观。

所以：

> Evaluation bias = 评估结果系统性不准。

---

### 13.3 Evaluation Variance

Evaluation variance 是指：

> 如果换一个 test set，evaluation score 变化很大。

例如同一个 model 在 test set A 上 accuracy 90%，在 test set B 上 accuracy 70%。如果这些 test sets 都是有限 samples，那么 evaluation result 本身就有高 variance。

这有时候很难和 model variance 区分，因为我们看到的都是 performance 变化。但概念上不同：

Model variance:

> 换 training data，model 变化。

Evaluation variance:

> 换 test/evaluation data，score 变化。

---

## 14. 如何控制 Evaluation Bias 和 Variance

### 14.1 Holdout partition size

Holdout split 里面，train/test proportion 会影响 model 和 evaluation 的 variance。

More training data, less test data:

> model variance lower，因为 model 学到更多 data；但 evaluation variance higher，因为 test data 少，score 不稳定。

Less training data, more test data:

> model variance higher，因为 model 学得不够稳定；但 evaluation variance lower，因为 test estimate 更可靠。

所以 holdout 里面也有 tradeoff。

---

### 14.2 K-fold Cross-Validation

K-fold cross-validation 通常比 single holdout 更稳定，因为它会在多个 folds 上重复 train/evaluate，然后取 average。

这可以降低 model 和 evaluation 的 variance。

但缺点是：

> computational cost 更高。

---

### 14.3 Stratification

Stratification 可以降低 sampling bias，因为它让 train/test/folds 中 class distribution 更接近原始 dataset。

例如 minority class 不会被全部分到 test 或全部分到 train。

所以：

> Stratification 可以减少 model 和 evaluation bias。

---

### 14.4 Leave-One-Out Cross-Validation

Leave-One-Out Cross-Validation 是 k-fold 的极端情况：

$$
K=N
$$

每次只留一个 sample 做 validation，其余全部做 training。

它通常 bias 很低，因为每次 training 都用到了几乎所有 data。但 computational cost 很高，尤其是大 dataset。

所以：

> LOO-CV 数据利用率高，但很贵。

---

### 14.5 报告 mean 和 variance

Lecture 最后强调：evaluation 不应该只报告一个 average score。对于 cross-validation，可以报告：

Mean:

$$
\mu=
\frac{1}{K}
\sum_{i=1}^{K}E_i
$$

Variance:

$$
Var=
\frac{1}{K}
\sum_{i=1}^{K}
(E_i-\mu)^2
$$

其中 (E_i) 是第 (i) 个 fold 的 score。

如果 mean 高但 variance 也高，说明 model performance 不稳定。
如果 mean 高且 variance 低，说明 model 更可靠。

所以我可以这样记：

> Average score 告诉我 model 大概多好；variance 告诉我这个 estimate 稳不稳定。

---

## Lecture 11 总结

Lecture 11 的核心是：

> Evaluation 不只是算分数，而是用 training / validation behaviour 来诊断 model 为什么不能 generalise。

我需要重点记住：

Generalisation 是 model 在 unseen data 上表现好的能力。
Underfitting 是 model 太简单，capture 不到 pattern。
Overfitting 是 model 太复杂，capture 了 noise。
Appropriate fitting 是 capture pattern 但不 capture noise。
Learning curve 是 diagnostic tool。
Learning curve 的 y-axis 可以是 accuracy、error rate、loss、MSE。
Learning curve 的 x-axis 可以是 training size、model complexity、iterations。
Training curve 反映 model learning。
Validation curve 反映 model generalisation。
Model complexity 增加时，training error 通常下降。
Validation error 通常是 U-shape。
High bias 通常对应 underfitting。
High variance 通常对应 overfitting。
Expectation 可以理解成 infinite samples 下的 average。
Bias 是 systematic error。
Variance 是 model 对 training data 变化的 sensitivity。
Generalisation error 可以分解为：

$$
Err=Bias^2+Variance+Irreducible\ Error
$$

Bias 和 variance 有 tradeoff。
增加 complexity 通常降低 bias，但提高 variance。
High bias remedy：more complex model、add features、nonlinear model、boosting。
High variance remedy：more data、reduce features、reduce complexity、bagging。
Evaluation metric 本身也是 estimate。
Evaluation bias 是 score 系统性偏高或偏低。
Evaluation variance 是换 test set 后 score 波动大。
K-fold cross-validation 可以降低 evaluation variance。
Stratification 可以降低 sampling bias。
Leave-one-out CV bias 低，但 computational cost 高。
Evaluation 最好报告 mean，也报告 variance。

一句话总结：

> Lecture 11 讲的是如何从 training/validation behaviour 诊断 model：如果两个都差，是 high bias；如果 training 好但 validation 差，是 high variance；真正好的 model 是在 bias 和 variance 中间找到能 generalise 的 sweet spot。
