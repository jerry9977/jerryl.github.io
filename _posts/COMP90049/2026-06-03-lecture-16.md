# Lecture 16：Transformer 与大型语言模型

## Transformers and Large Language Models

## 1. 从 FNN 到 LLM：为什么这是一个新东西

### 1.1 这节课在回答什么问题

前面几节课我们学了 Perceptron、Feed-forward Neural Network、activation functions 和 backpropagation。到这里为止，neural network 的基本训练方式已经讲完了：forward pass 产生 prediction，loss function 计算 error，backpropagation 把 error 传回去，然后 gradient descent 更新 weights。

Lecture 16 开始讲 Large Language Models，也就是 LLM。这里不是单纯把 FNN 变大，而是换了一个很关键的问题：

> Feed-forward Network 能不能像 ChatGPT 一样写一篇文章？

答案是：不能，至少普通 FNN 不能自然地做到。

原因不是 FNN 完全没有 neural network 能力，而是它的输入、输出和学习目标都不适合 language generation。FNN 通常接收一个 fixed-length feature vector，然后输出一个 label 或 value。它更像是在问：

> 这个 input 属于哪个 class？

而 LLM 是在问：

> given 前面的 tokens，下一个 token 最可能是什么？

所以 Lecture 16 的核心转变是：

> 从 fixed input → one label，转向 sequence input → next token prediction。

---

## 2. FNN 和 LLM 的根本区别

### 2.1 FNN 是 Discriminative

FNN 通常是 discriminative model。它学习的是：

$$
P(label|input)
$$

例如给一篇 document，FNN 可以预测：

$$
P(assignment|document)
$$

$$
P(news|document)
$$

$$
P(poem|document)
$$

然后选择 probability 最大的 class。

所以 FNN 可以做 classification。它可以判断一篇文章像不像 assignment、news 或 poem。但是它通常不是用来从头生成一个 document。

我可以这样记：

> FNN 比较像“判断器”：给我一个 input，我告诉你它是什么。

---

### 2.2 LLM 是 Generative

LLM 是 generative language model。它学习的是：

$$
P(token_t|token_1,\dots,token_{t-1})
$$

也就是说，它不是直接预测 class，而是预测 next token。

例如 context 是：

$$
AI\ has\ transformed\ people's
$$

model 会输出整个 vocabulary 上的 probability distribution：

$$
P(life|AI\ has\ transformed\ people's)
$$

$$
P(lives|AI\ has\ transformed\ people's)
$$

$$
P(health|AI\ has\ transformed\ people's)
$$

然后从这个 distribution 里面选出或 sample 一个 token。

所以 LLM 的生成过程不是一次性生成整篇文章，而是：

> 一次预测一个 token，然后把这个 token 加回 context，再预测下一个 token。

---

### 2.3 FNN 和 LLM 的对比

FNN 的输入通常是 fixed-length feature vector。如果输入长度不够，就 padding；如果太长，就截断或压缩。这不太适合自然语言，因为 language 是 sequence，而且 sequence 长度不固定。

LLM 的输入是 token sequence。它不只是看有哪些 words，还要看这些 words 的 order 和 relationship。

所以区别可以总结成：

| FNN                                  | LLM                                |                   |                    |
| ------------------------------------ | ---------------------------------- | ----------------- | ------------------ |
| fixed-length vector                  | token sequence                     |                   |                    |
| predicts label                       | predicts next token                |                   |                    |
| discriminative                       | generative                         |                   |                    |
| learns (P(label                      | input))                            | learns (P(token_t | previous\ tokens)) |
| one input → one output               | sequence → one token at a time     |                   |                    |
| tokens usually treated like features | tokens interact through attention  |                   |                    |
| depth learns abstraction             | depth also captures longer context |                   |                    |
| supervised training common           | self-supervised pretraining common |                   |                    |

这里我需要重点记住：

> LLM 不是普通 classifier。它是一个 autoregressive next-token predictor。

---

## 3. Language Model 是什么

### 3.1 最简单的直觉：猜下一个词

Language model 的基本问题其实很简单：

> 给定前面的 words，猜下一个 word。

例如：

$$
Sweet\ ___
$$

可能后面是：

* potato
* child
* home
* cake
* dreams

如果 context 只有一个 word，可能性很多。但如果 context 变成：

$$
Home\ sweet\ ___
$$

那最可能的答案就是：

$$
home
$$

这说明：

> context 越多，next token prediction 越容易。

---

### 3.2 Bigram Model

Bigram model 是很早以前就存在的 language model。它只看前一个 word：

$$
P(w_t|w_{t-1})
$$

例如它会统计：

$$
P(potato|sweet)
$$

$$
P(home|sweet)
$$

$$
P(child|sweet)
$$

它本质上是根据 corpus 里面 word pair 的 co-occurrence frequency 来预测下一个 word。

所以 bigram 可以理解成：

> 根据前一个 word，查表预测下一个 word。

它很像 autocomplete 的早期版本。

---

### 3.3 N-gram Model

N-gram 会看更长的 context。例如 trigram 看前两个 words：

$$
P(w_t|w_{t-2},w_{t-1})
$$

一般写作：

$$
P(w_t|w_{t-n+1},\dots,w_{t-1})
$$

N-gram 比 bigram 好，因为它有更多 context。但问题是：n 越大，需要统计的 phrase combinations 越多，data sparsity 越严重。

例如：

$$
The\ water\ wasn't\ just\ hot,\ it\ was\ ___
$$

我们人类知道可能是 boiling、scalding 之类。但如果只靠 exact n-gram counting，corpus 里面不一定见过完整 phrase。所以 n-gram 很快会遇到 data sparsity problem。

所以：

> N-gram 加 context 有帮助，但靠 counting 很难 scale。

---

### 3.4 LLM 怎么解决这个问题

LLM 不靠简单 counting，而是用 Transformer neural network 去学习 token 之间的 complex relationships。

它学习的是：

$$
P(w_t|w_1,\dots,w_{t-1})
$$

而不是只看固定长度的 (n-1) 个 words。

所以 LLM 的优势是：

> 它可以利用更长 context，并通过 attention 学习 words 之间的关系，而不是只统计固定短语出现次数。

---

## 4. Autoregressive Generation

### 4.1 Autoregressive 是什么意思

Autoregressive 的意思是：

> model 根据自己之前看到的 tokens 或自己之前生成的 tokens，继续预测下一个 token。

对于 LLM：

$$
P(x_1,x_2,\dots,x_T)
====================

\prod_{t=1}^{T}
P(x_t|x_1,\dots,x_{t-1})
$$

这个公式的意思是：一整段 text 的 probability，可以拆成每一步 next-token probability 的乘积。

所以 generation 是 left-to-right 的：

$$
x_1 \rightarrow x_2 \rightarrow x_3 \rightarrow \dots
$$

例如：

1. input: (AI)
2. predict: (has)
3. context becomes: (AI\ has)
4. predict: (transformed)
5. context becomes: (AI\ has\ transformed)
6. predict: (people's)
7. predict: (life)

所以：

> LLM 一次不是生成一整篇文章，而是循环生成 next token。

---

### 4.2 Decoding Algorithm

Autoregressive decoding 的流程是：

1. 给 model 一个 context：

$$
[x_1,x_2,\dots,x_T]
$$

2. Transformer 输出 vocabulary 上的 probability distribution：

$$
P(w|x_1,\dots,x_T)
$$

3. 从这个 distribution 里面选出一个 next token：

$$
x_{T+1}
$$

4. 把它 append 回 context：

$$
[x_1,x_2,\dots,x_T,x_{T+1}]
$$

5. 重复直到生成 end-of-sequence token：

$$
EOS
$$

所以生成文章其实就是：

> predict → append → predict → append。

---

## 5. Sampling：为什么同一个 prompt 可以有不同答案

### 5.1 Greedy Decoding

Greedy decoding 是最简单的方法。每一步都选 probability 最大的 token：

$$
x_{t+1}=\arg\max_w P(w|x_1,\dots,x_t)
$$

优点是 deterministic。每次都选最可能的 token，所以结果稳定。

缺点是可能 boring，也可能过早走进很死板的 path。因为它永远不探索第二、第三可能的 token。

所以：

> Greedy decoding = 永远选最可能 token。

---

### 5.2 Top-k Sampling

Top-k sampling 会先选出 probability 最高的 (k) 个 tokens，然后只在这 (k) 个里面 sample。

例如：

$$
k=3
$$

model 只会从 top 3 tokens 里面随机选一个。

这样比 greedy 更有 variation，但又不会从整个 vocabulary 里面乱选很低 probability 的词。

所以：

> Top-k = 限制 candidate pool，只从 top k 里面抽样。

---

### 5.3 Top-p / Nucleus Sampling

Top-p sampling 不是固定选择 (k) 个 tokens，而是选择 cumulative probability 达到某个 threshold 的最小 token set。

例如：

$$
p=0.7
$$

那么 model 会选择一组 tokens，使它们的 probability 加起来刚好超过 0.7，然后从里面 sample。

这比 top-k 更 flexible。因为有时候 distribution 很尖，可能只需要几个 tokens；有时候 distribution 很平，可能需要更多 tokens。

所以：

> Top-p = 从 cumulative probability 达到 threshold 的 token set 里面抽样。

---

### 5.4 Temperature

Temperature 控制 distribution 的 sharpness。

如果 temperature 低，distribution 更 sharp，高 probability token 更突出，model 更保守。

如果 temperature 高，distribution 更 flat，低 probability token 也更有机会被 sample，model 更随机、更 creative，但也更容易跑偏。

可以直觉记成：

> low temperature = conservative
> high temperature = creative / random

所以 LLM 输出的“创造性”不是凭空来的，而是来自 sampling strategy 对 probability distribution 的控制。

---

## 6. 为什么 FNN 不适合 Language

### 6.1 Order 很重要

语言不是 unordered bag of words。例如：

$$
The\ dog\ is\ chasing\ the\ cat
$$

和：

$$
The\ cat\ is\ chasing\ the\ dog
$$

这两个句子的 words 几乎一样，但 meaning 完全不同。

如果 model 只把它们当作 bag of words，就会丢掉 word order。

所以：

> language 里 token order 是 information。

---

### 6.2 Relationship 也很重要

除了 order，words 之间的 relationship 也很重要。

例如：

$$
The\ trophy\ didn't\ fit\ in\ the\ suitcase\ because\ it\ was\ too\ big.
$$

这里 (it) 指的是 trophy。

但如果句子是：

$$
The\ trophy\ didn't\ fit\ in\ the\ suitcase\ because\ it\ was\ too\ small.
$$

这里 (it) 更可能指 suitcase。

所以 model 不能只知道 words 出现了，还要知道：

> 哪个 word 和哪个 word 有关系。

这就是 attention 要解决的问题。

---

## 7. Token、Embedding 和 Positional Encoding

### 7.1 Token

LLM 处理的基本单位不是整句话，而是 token。Token 可以是 word、subword、punctuation 或其他文本单位。

例如：

$$
AI\ has\ transformed\ people's\ life
$$

会被拆成一串 tokens。每个 token 再被转成 numerical vector。

所以：

> text 先变成 tokens，tokens 再变成 vectors。

---

### 7.2 Embedding

Embedding 是 token 的 dense vector representation。

可以写成：

$$
x_t \in \mathbb{R}^{d}
$$

其中 (d) 是 embedding dimension。

Embedding 的作用是把 discrete token 变成 neural network 可以处理的 continuous vector。

所以：

> embedding = token 的 numerical meaning representation。

和 one-hot encoding 不同，embedding 是 dense vector。它可以学习 semantic similarity。例如相似 words 的 vectors 可能在 vector space 里比较接近。

---

### 7.3 为什么需要 Positional Encoding

Embedding 本身通常只表示 token identity，不表示 position。

例如句子里两个 “the”：

$$
the\ dog\ chased\ the\ cat
$$

如果只看 token embedding，两个 “the” 的 vector 是一样的。但它们出现在不同位置。

Transformer 本身不像 RNN 那样天然按顺序处理 tokens，所以需要额外加入 position information。

Positional encoding 的做法是给每个 token embedding 加上 position vector：

$$
input_t = token_embedding_t + positional_encoding_t
$$

所以同一个 word 在不同位置会变成不同 input representation。

我可以这样记：

> embedding 告诉 model “这个 token 是什么”。
> positional encoding 告诉 model “这个 token 在哪里”。

---

## 8. Attention 的核心直觉

### 8.1 Attention 是什么

Attention 让每个 token 可以看 sequence 里的其他 tokens，并决定哪些 tokens 对自己更 relevant。

例如处理句子里的 (it) 时，model 要决定它应该看 trophy、suitcase、big、small，还是其他 words。

Attention 的直觉是：

> 每个 token 问：我现在需要从哪些 token 那里拿信息？

所以 attention 不是简单看相邻 words，而是允许 token 和 token 之间建立 relationship。

---

### 8.2 Query、Key、Value

Attention 里每个 token 会产生三个 vectors：

$$
q=xW_Q
$$

$$
k=xW_K
$$

$$
v=xW_V
$$

其中：

* (q)：query，表示“我在找什么”
* (k)：key，表示“我有什么特征可以被别人匹配”
* (v)：value，表示“我真正可以提供的信息”

可以用图书馆比喻：

Query 是你要找的书的需求。
Key 是每本书封面、标题、标签上显示的信息。
Value 是书里面真正的内容。

你不会先读完整本书再决定它有没有用，而是先看 key 和 query 是否匹配。如果匹配，再把 value 里的信息拿过来。

所以：

> Query 用来找，Key 用来匹配，Value 用来传信息。

---

### 8.3 Dot Product：怎么算 relevance

一个 token 的 query 会和其他 tokens 的 keys 做 dot product：

$$
score_{ij}=q_i \cdot k_j
$$

如果 dot product 大，说明 (q_i) 和 (k_j) 方向相似，token (i) 认为 token (j) relevant。

然后把 scores 放进 softmax，变成 attention weights：

$$
\alpha_{ij}
===========

\frac{e^{score_{ij}}}
{\sum_j e^{score_{ij}}}
$$

attention weights 加起来是 1。weight 越大，说明这个 token 越重要。

---

### 8.4 Weighted Sum of Values

得到 attention weights 后，token (i) 会把其他 tokens 的 values 加权平均：

$$
output_i
========

\sum_j \alpha_{ij}v_j
$$

也就是说，token (i) 的新 representation，会混入它认为 relevant 的其他 tokens 的信息。

这就是 attention 的核心：

> 用 query-key match 决定权重，用权重加权 value，更新 token representation。

---

### 8.5 Scaled Dot-product Attention

更常见的公式是：

$$
Attention(Q,K,V)
================

softmax
\left(
\frac{QK^T}{\sqrt{d_k}}
\right)
V
$$

这里：

$$
QK^T
$$

计算所有 query 和 key 的 similarity。

$$
\sqrt{d_k}
$$

是 scaling factor，用来避免 dot product 太大导致 softmax 过于极端。

所以这个公式可以拆成三步：

1. query 和 key 做 dot product
2. softmax 转成 attention weights
3. 用 weights 加权 value

---

## 9. Multi-head Attention

### 9.1 为什么需要多个 heads

一个 attention head 只能学习一种 relation pattern。但 language 里面有很多不同关系：

* pronoun resolution：it 指谁？
* adjective relation：big / small 描述谁？
* syntactic relation：subject 和 verb 怎么连？
* phrase relation：哪些 words 组成一个 phrase？
* topic relation：这句话和前文哪个部分有关？

所以 Transformer 不只用一个 attention head，而是用 multi-head attention。

每个 head 有自己的：

$$
W_Q,\ W_K,\ W_V
$$

所以每个 head 可以学习不同的 matching rule。

---

### 9.2 Head 的直觉

一个 head 可能专门学：

> pronoun 要找 noun。

另一个 head 可能学：

> adjective 要找被描述的 object。

另一个 head 可能学：

> verb 要找 subject。

当然真实 model 里面不一定这么干净，但直觉上就是：

> 不同 attention heads 可以关注不同类型的 token relationship。

所以 multi-head attention 让 model 不只从一个角度看 context，而是从多个角度同时看。

---

## 10. Transformer Block

### 10.1 Transformer 不只有 Attention

Lecture 16 很重要的一点是：Transformer block 不只是 attention。一个 Transformer block 通常包括：

* multi-head self-attention
* feed-forward network
* layer normalization
* residual connection / residual stream

所以：

> Attention 负责 tokens 之间 interaction。
> FFN 负责对每个 token 的 representation 做 nonlinear transformation。
> LayerNorm 负责稳定 scale。
> Residual connection 负责保留和传递信息。

---

### 10.2 Embedding 和 Unembedding

Transformer block 外面还有两个重要步骤。

一开始，tokens 会通过 embedding 变成 dense vectors：

$$
token \rightarrow embedding
$$

然后加上 positional encoding：

$$
embedding + position
$$

经过很多 Transformer blocks 后，最后得到 hidden representation。为了预测 next token，需要把 hidden representation 投影回 vocabulary space，这叫 unembedding。

Unembedding 会给 vocabulary 里的每个 token 一个 score：

$$
z_k
$$

然后 softmax 变成 probability：

$$
P(token=k|context)
==================

\frac{e^{z_k}}
{\sum_j e^{z_j}}
$$

所以：

> embedding 把 token 变成 vector；unembedding 把 vector 变回 vocabulary scores。

---

### 10.3 Feed-forward Network 在 Transformer 里做什么

Transformer block 里面也有 FFN。这个 FFN 通常对每个 token position separately applied。

Attention 主要告诉 model：

> 哪里重要？应该看哪些 tokens？

FFN 进一步处理这些信息：

> 这些信息合起来是什么意思？

所以 lecture 里的直觉可以这样记：

> Attention = where to look。
> FFN = what it means。

Attention 本身主要是 similarity 和 weighted average。FFN 加入 non-linearity，让 model 能学习更复杂的 feature transformation。

---

### 10.4 Layer Normalization

LayerNorm 类似 scaling。因为经过很多 matrix multiplication、attention、summation 后，values 的 scale 可能变得不稳定。

LayerNorm 的作用是：

> 让每一层的 representation 更稳定，避免数值 scale 失控。

可以理解成 neural network 里的 regularising / stabilising trick。

---

### 10.5 Residual Stream

Residual connection 会把 sublayer 的 input 直接加到 output 里：

$$
output = input + sublayer(input)
$$

这样 information 可以跨过某些 transformation 继续往上流。

这有两个好处：

第一，它保留原始信息，不会每层都完全覆盖前一层。
第二，它让 gradient 更容易往回传，帮助深层网络训练。

所以：

> residual stream 像一条信息主干，attention 和 FFN 每次往里面加新信息。

---

## 11. Transformer 的深度：为什么要很多 blocks

### 11.1 多层不是只是为了更抽象

在普通 FNN 里，我们常说越深的 layer 学到越 abstract 的 representation。Transformer 里也有这个效果，但还有另一个重点：

> 越深的 Transformer 可以逐渐整合更长距离、更复杂的 token relationships。

Lecture 的直觉是：

* shallow layers 可能学 local co-location
* 中间 layers 可能学 phrase 或 syntactic structure
* 更深 layers 可能学 long-distance reference
* 很深 layers 可能整合 document-level context

所以 Transformer depth 不只是让 feature 更 abstract，也让 context relationship 更丰富。

---

### 11.2 Same-layer interaction

FNN 的 neurons 在同一层通常不互相交流。信息只从上一层传到下一层。

Transformer 不同。通过 self-attention，同一 sequence 里的 tokens 会互相 attend。也就是说，在同一 Transformer block 内，每个 token 都可以从其他 tokens 那里拿信息。

所以：

> FNN 主要是 layer-to-layer information flow。
> Transformer 同时有 token-to-token information flow。

这是 Transformer 能处理 language structure 的关键之一。

---

## 12. Training LLMs

### 12.1 为什么需要 Self-supervised Learning

Supervised labels 很贵。比如要训练一个模型理解语言，如果每句话都要人工标注 label，成本太高。

但 raw text 非常多。Internet 上有大量未标注 text。

LLM 的思路是：

> 不需要人工 label，因为 text 自己就提供了训练信号。

在 next-token prediction 里，label 就是下一个真实 token。

例如 sequence 是：

$$
So\ long\ and\ thanks
$$

如果 model 看到：

$$
So
$$

它要预测：

$$
long
$$

这里 (long) 就是自动产生的 label。没有人需要额外标注。

所以这叫 self-supervised learning：

> label 从 data 自己里面来。

---

### 12.2 Next-token Prediction Loss

LLM 输出 vocabulary 上的 probability distribution：

$$
P(w|context)
$$

如果真实 next token 是：

$$
w^*
$$

training 会希望 model 给 (w^*) 高 probability。

常见 loss 是 cross-entropy：

$$
L=-\log P(w^*|context)
$$

如果 model 给正确 token 很高 probability，loss 小。
如果 model 给正确 token 很低 probability，loss 大。

所以：

> LLM training = 让真实 next token 的 probability 越高越好。

---

### 12.3 Pretraining 和 Fine-tuning

Lecture 16 提到一个重要 paradigm：

1. Pre-train on large raw text
2. Fine-tune on smaller task-specific data

Pretraining 学的是 general language patterns：

* grammar
* world knowledge patterns
* phrase structure
* word relationships
* common tasks hidden in text

Fine-tuning 则是让 model 更适合某个 specific task 或 response style。

所以：

> Pretraining 学通用语言能力。
> Fine-tuning 调整到具体任务。

GPT 和 BERT 都体现了这种思路。GPT 更偏 autoregressive next-token prediction；BERT 更偏 masked language modelling 和 bidirectional representation。

---

### 12.4 Prompt 的作用

如果只做 next-token prediction，model 可能知道很多 continuation patterns，但它不一定知道你现在想让它做什么任务。

Prompt 就是给 model 的 task signal。

例如：

$$
Translate\ this\ sentence\ into\ Chinese:
$$

这句话告诉 model：接下来不是随便续写，而是做 translation。

所以 prompt 可以理解成：

> 用自然语言放进 context 里的 task instruction。

Lecture 里也提到：如果没有 fine-tuning 或其他 alignment signal，只靠 next-token prediction 仍然有限。Prompt、fine-tuning、RLHF 等方法会进一步告诉 model 应该如何完成任务。

---

## 13. LLM 和 Autocomplete 的区别

### 13.1 相似点

LLM 和 autocomplete 都是在预测 next token。早期 bigram / n-gram autocomplete 也是 language model。

所以从最基础目标看，它们都在做：

$$
P(next\ word|context)
$$

---

### 13.2 不同点

但 LLM 不只是简单 autocomplete。

N-gram autocomplete 主要靠 local frequency counting。
LLM 用 Transformer 学复杂 context 和 token relationships。

所以 LLM 可以做更多任务：

* summarisation
* translation
* question answering
* code generation
* reasoning-like text generation
* instruction following

这些能力不是因为它有某个 task-specific classifier，而是因为大量文本里包含很多 task patterns，并且 Transformer 能从 context 中捕捉这些 relationships。

所以我可以这样记：

> LLM 的训练目标很简单：predict next token。
> 但因为 model 很大、data 很大、context 很长、attention 很强，它学到的 behaviour 很复杂。

---

## 14. Lecture 16 里最重要的公式

### 14.1 Autoregressive Language Model

$$
P(x_1,\dots,x_T)
================

\prod_{t=1}^{T}
P(x_t|x_1,\dots,x_{t-1})
$$

意思是：

> 整段文本的 probability 可以拆成每一步 next-token probability。

---

### 14.2 Next Token Prediction

$$
\hat{x}_{t+1}
\sim
P(w|x_1,\dots,x_t)
$$

意思是：

> 根据 context 产生 vocabulary 上的 distribution，然后 sample 下一个 token。

---

### 14.3 Query / Key / Value

$$
q=xW_Q
$$

$$
k=xW_K
$$

$$
v=xW_V
$$

意思是：

> 每个 token embedding 会被变成 query、key、value 三种 representation。

---

### 14.4 Attention

$$
Attention(Q,K,V)
================

softmax
\left(
\frac{QK^T}{\sqrt{d_k}}
\right)
V
$$

意思是：

> query 和 key 算 similarity，softmax 变成 weights，再加权 value。

---

### 14.5 Cross-entropy for Next Token

$$
L=-\log P(w^*|context)
$$

意思是：

> 如果真实 next token 的 probability 高，loss 小；如果 probability 低，loss 大。

## 15. 和之前 Lectures 的连接

### 15.1 和 Lecture 14 / 15 的连接

Lecture 14 讲了 neural network 的 layers、activation、output functions。Lecture 15 讲了 backpropagation。Lecture 16 其实是在说：

> Transformer 仍然是 neural network，仍然用 forward pass、loss、backpropagation 训练。

不同的是，它的 architecture 更适合 sequence data。它不是普通 FNN，而是有 attention、residual、layer norm、positional encoding 的 deep network。

---

### 15.2 和 Naive Bayes / Logistic Regression 的连接

Naive Bayes 和 Logistic Regression 多数用于 classification。它们通常在问：

$$
P(y|x)
$$

LLM 问的是：

$$
P(token_t|token_1,\dots,token_{t-1})
$$

所以 LLM 的 label 不是人工定义的 class，而是 sequence 里的 next token。

---

### 15.3 和 Evaluation / Bias 的连接

LLM 生成是 sampling from distribution，所以不同 decoding choices 会影响 output。Greedy、top-k、top-p、temperature 都会改变生成行为。

这说明 evaluation LLM 也不简单。因为同一个 model 在不同 decoding setting 下，可能输出不同 answer。

所以不能只说：

> model 会不会生成。

还要问：

> 它在什么 sampling strategy 下生成？
> 它有没有 hallucination？
> 它是否符合 task instruction？
> 它是否安全、公平、可控？

这些会和后面 bias / fairness、evaluation 连接起来。

---

## 16. Lecture 16 总结

Lecture 16 的核心是：

> LLM 是一个 autoregressive language model。它用 Transformer 根据 previous tokens 预测 next token，并通过 attention 让 tokens 之间建立关系。

我需要重点记住：

FNN 通常是 discriminative model，学习：

$$
P(label|input)
$$

LLM 是 generative language model，学习：

$$
P(token_t|token_1,\dots,token_{t-1})
$$

FNN 通常是 fixed-length input。
LLM 处理 token sequence。
FNN 输出 class probability。
LLM 输出 vocabulary 上的 next-token distribution。
Language model 的基本任务是 predict next word / token。
Bigram 只看前一个 word。
N-gram 看前 (n-1) 个 words，但会遇到 data sparsity。
LLM 用 Transformer 学更长 context 和 token relationships。
Autoregressive generation 是 left-to-right。
Generation 流程是 predict、append、predict、append。
Greedy decoding 永远选 most probable token。
Top-k sampling 从前 (k) 个 tokens 里面抽样。
Top-p sampling 从 cumulative probability 达到 (p) 的 token set 里抽样。
Temperature 控制 distribution 的 sharpness。
Language 里 order 很重要，所以 bag-of-words 不够。
Language 里 relationship 很重要，例如 pronoun reference。
Embedding 把 token 变成 dense vector。
Positional encoding 加入 token position 信息。
Attention 让每个 token 根据 relevance 关注其他 tokens。
Query 表示我在找什么。
Key 表示我可以被怎样匹配。
Value 表示我真正提供什么信息。
Attention 用 dot product 比较 query 和 key。
Softmax 把 similarity scores 变成 attention weights。
Attention output 是 values 的 weighted sum。
Multi-head attention 让不同 heads 学不同关系。
Transformer block 包含 multi-head attention、FFN、LayerNorm 和 residual stream。
Attention 负责 token interaction。
FFN 负责 nonlinear transformation。
LayerNorm 稳定 scale。
Residual stream 保留并传递信息。
Transformer depth 可以捕捉从 local collocation 到 long-context relationships 的信息。
LLM training 通常是 self-supervised next-token prediction。
Next token 本身就是 automatically derived label。
Cross-entropy loss 惩罚 model 没有给真实 next token 足够高 probability。
Pretraining 用大量 raw text 学 general pattern。
Fine-tuning 用较小 task-specific data 调整 model。
Prompt 是给 model 的 task signal。
RLHF 等 alignment 方法可以进一步调整 model 输出行为。

一句话总结：

> Lecture 16 讲的是 LLM 为什么不只是一个更大的 FNN：它把语言当作 sequence，通过 positional encoding 保留顺序，通过 attention 建立 token relationships，再用 autoregressive next-token prediction 一步一步生成文本。
