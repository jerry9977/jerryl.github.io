# Lecture 19：Unsupervised Learning 与 Clustering

## Unsupervised Learning, K-means, Agglomerative Clustering, and Clustering Evaluation

## 1. 从 Supervised Learning 到 Unsupervised Learning

### 1.1 这节课在回答什么问题

前面大部分 lectures 都是在讲 supervised learning。比如 KNN、Decision Tree、Naive Bayes、Logistic Regression、SVM、Neural Networks，这些模型通常都有一个共同点：

> training data 有 label。

也就是说，每个 instance 不只是有 features，还有一个 known class 或 target value。

例如：

$$
x_i = features
$$

$$
y_i = label
$$

model 学的是：

$$
x_i \rightarrow y_i
$$

但是 Lecture 19 开始讨论另一种情况：

> 如果 data 没有 label，机器还可以学什么？

这就是 unsupervised learning。

Unsupervised learning 的核心问题不是 “这个 input 应该是什么 label”，而是：

> data 本身有没有 hidden structure？

例如给 model 一堆 fruits，但是不告诉它 apple、banana、watermelon 的名字。它只能根据颜色、形状、大小、甜度等 features，自己把相似的 fruits 放在一起。

所以这一讲的核心转变是：

> 从 learning labels，转向 learning structure。

---

## 2. Supervised vs Unsupervised Learning

### 2.1 Supervised Learning

Supervised learning 有 fully labelled data。

也就是说，training data 里面每个 example 都有 label：

$$
D = {(x_1,y_1),(x_2,y_2),\dots,(x_n,y_n)}
$$

model 的目标是学一个 function：

$$
f(x) = y
$$

例如：

* email → spam / not spam
* image → cat / dog
* patient symptoms → flu / cold
* house features → price

所以 supervised learning 比较像：

> 我已经知道有哪些 classes，现在我要训练 model 去预测新 data 的 class。

---

### 2.2 Unsupervised Learning

Unsupervised learning 没有 labels。

data 只有：

$$
D = {x_1,x_2,\dots,x_n}
$$

没有：

$$
y_i
$$

所以 model 不能直接学：

$$
x_i \rightarrow y_i
$$

它只能根据 features 自己找 pattern。

例如：

* customer segmentation
* grouping similar documents
* grouping similar vehicles
* detecting hidden structures
* finding unusual points

这讲最重要的一句话是：

> In clustering, we learn structure from data alone.

也就是：

> Clustering 不靠 label，而是靠 data points 之间的 similarity。

---

### 2.3 为什么需要 Unsupervised Learning

原因很现实：

> labelled data 很贵。

很多时候，label 需要人工标注，甚至需要 domain experts。例如 medical diagnosis、legal data、exam cheating detection、financial fraud，这些 labels 都不容易拿。

另外，有些 data 因为 privacy 或 access restriction，也很难被完整 labelled。

但是 unlabelled data 很多。

所以 unsupervised learning 的意义是：

> 即使没有 label，我们也可以先从 data 里找 structure。

这种 structure 不一定马上等于真实 class，但是可以帮助我们理解 data，也可以作为后续 supervised / semi-supervised learning 的基础。

---

## 3. Types of Unsupervised Learning

Unsupervised learning 不只有 clustering。这讲简单提到几种类型：

| Type                           | Meaning                               |
| ------------------------------ | ------------------------------------- |
| PCA / dimensionality reduction | 把高维 data 压缩成低维，保留主要信息                 |
| Clustering                     | 找相似 instances 的 groups                |
| Anomaly detection              | 找和 normal pattern 不一样的 rare cases     |
| Association rule mining        | 找 item 之间的 co-occurrence relationship |

这一讲主要关注：

> Clustering。

Anomaly detection 会在后面的 lecture 继续讲。

---

## 4. Clustering 是什么

### 4.1 Clustering 的直觉

Clustering 的目标是：

> 把相似的 data points 放在同一个 group。

这个 group 就叫 cluster。

如果两个 points 很相似，它们应该在同一个 cluster。
如果两个 points 差很多，它们应该在不同 clusters。

所以 clustering 依赖一个核心概念：

> similarity 或 distance。

很多 clustering algorithms 都是 distance-based。例如 K-means 就是根据 point 到 centroid 的 distance 来分配 cluster。

---

### 4.2 Clustering 不等于 Classification

Classification 是 supervised learning。
它的 classes 是提前给定的。

例如：

$$
Y = {cat,dog}
$$

model 学的是：

$$
image \rightarrow cat/dog
$$

Clustering 是 unsupervised learning。
它没有提前给定 classes。

model 只能自己分 groups。分出来的 cluster 可能刚好对应 cat/dog，也可能对应颜色、大小、背景、拍摄角度，甚至一些人类不太好解释的 feature pattern。

所以：

> Classification 的 output 是 known label。
> Clustering 的 output 是 discovered group。

这也是为什么 clustering evaluation 更难，因为没有 guaranteed correct answer。

---

## 5. Clustering 的 Assumptions

Clustering 不是一个完全 objective 的过程。不同 algorithms 会假设 data structure 长得不一样。

所以做 clustering 前，需要知道自己期待什么类型的 clusters。

---

### 5.1 Exclusive vs Overlapping Clustering

Exclusive clustering：

> 一个 item 只能属于一个 cluster。

例如 vehicle clustering：

* car
* truck
* bus

一个 vehicle 通常只能被分进其中一个 group。

Overlapping clustering：

> 一个 item 可以同时属于多个 clusters。

例如一个人可以同时属于多个 identity groups，或者一篇文章可以同时属于 politics 和 economy。

这讲的 K-means 和 agglomerative clustering 都是 exclusive clustering。

也就是说：

> 每个 point 最后只会被分到一个 cluster。

---

### 5.2 Deterministic vs Probabilistic Clustering

Deterministic clustering，也叫 hard clustering：

> 每个 point 被明确分到一个 cluster。

例如：

$$
x_i \in C_1
$$

而不是：

$$
P(C_1|x_i)=0.7,\quad P(C_2|x_i)=0.3
$$

Probabilistic clustering，也叫 soft clustering：

> 一个 point 可以以不同 probabilities 属于不同 clusters。

例如一个 borderline point 可能：

$$
P(C_1|x_i)=0.51
$$

$$
P(C_2|x_i)=0.49
$$

K-means 是 hard clustering。

它不会说一个 point “有点像 cluster 1，也有点像 cluster 2”。它只会直接把 point 分给最近的 centroid。

---

### 5.3 Partitioning vs Hierarchical Clustering

Partitioning clustering：

> 直接把 data 分成几个 flat groups。

K-means 是 partitioning clustering。

例如：

$$
D \rightarrow C_1,C_2,C_3
$$

这几个 clusters 之间没有 parent-child relationship。

Hierarchical clustering：

> clusters 可以有 nested structure。

例如：

$$
vehicles
$$

可以先分成：

$$
large\ vehicles,\ small\ vehicles
$$

然后 large vehicles 再分成：

$$
trucks,\ buses
$$

这种就是 hierarchical structure。

Agglomerative clustering 是 hierarchical clustering。

---

### 5.4 Complete vs Partial Clustering

Complete clustering：

> 每个 data point 都必须被分配到某个 cluster。

Partial clustering：

> 有些 points 可以不被分到任何 cluster。

K-means 和 agglomerative clustering 都是 complete clustering。

所以：

> 它们不会留下 unassigned points。

---

### 5.5 Homogeneous vs Heterogeneous Clusters

Homogeneous clusters：

> clusters 的大小、形状、密度都差不多。

Heterogeneous clusters：

> clusters 可以大小不同、形状不同、密度不同。

现实中的 data 通常更 heterogeneous。
但是很多简单 algorithms，特别是 K-means，更适合 homogeneous clusters。

例如 K-means 很喜欢：

* round clusters
* compact clusters
* similar size clusters
* similar density clusters

如果真实 data 是 weird shapes，K-means 就容易出问题。

---

## 6. K-means Clustering

## 6.1 K-means 在做什么

K-means 是一个非常经典的 clustering algorithm。

它的核心想法是：

> 用 K 个 centroids 代表 K 个 clusters，然后把每个 point 分给最近的 centroid。

K 是你事先指定的 cluster number。

例如：

$$
K=3
$$

表示你希望 model 把 data 分成 3 个 clusters。

---

## 6.2 Centroid 是什么

Centroid 是 cluster 的中心点。
它是 cluster 内所有 points 的 mean。

如果 cluster 是：

$$
C_j = {x_1,x_2,\dots,x_m}
$$

那么 centroid 是：

$$
\mu_j = \frac{1}{m}\sum_{i=1}^{m}x_i
$$

所以 K-means 里的 “means” 指的就是：

> cluster centroid 是 cluster 内 points 的 average。

---

## 6.3 K-means Algorithm

K-means 的流程：

1. Choose K。
2. Randomly pick K initial centroids。
3. Assign each instance to the nearest centroid。
4. Recompute each centroid as the mean of points in that cluster。
5. Repeat until centroids stop changing, or the changes are very small。

可以写成：

$$
repeat:
$$

$$
C_j = {x_i: \mu_j \text{ is the nearest centroid to } x_i}
$$

$$
\mu_j = \frac{1}{|C_j|}\sum_{x_i\in C_j}x_i
$$

直到 convergence。

所以 K-means 是两个步骤不断交替：

> assignment step + update step

Assignment step：

> 把 points 分给最近 centroid。

Update step：

> 根据新的 cluster 重新计算 centroid。

---

## 6.4 K-means 的性质

K-means 是：

| Property                    | Meaning                     |
| --------------------------- | --------------------------- |
| Exclusive                   | 每个 point 只属于一个 cluster      |
| Complete                    | 每个 point 都必须被分配             |
| Partitioning                | 直接把 dataset 切成 K 个 groups   |
| Hard clustering             | 没有 probability membership   |
| Distance-based              | 依赖 distance                 |
| Centroid-based              | 每个 cluster 用 mean 表示        |
| Best for spherical clusters | 最适合 round, compact clusters |

一句话记：

> K-means tries to create compact and spherical clusters.

---

## 7. 为什么 K-means 要 Scaling

K-means 是 distance-based。
所以 features 的 scale 会直接影响 distance。

例如两个 features：

$$
income = 50000
$$

$$
age = 25
$$

如果不 scaling，income 的数值范围远大于 age，那么 distance 基本会被 income dominate。

这会导致 model 以为 income 比 age 更重要，但这只是 scale 造成的，不一定是 feature 本身更重要。

所以 K-means 前通常要 normalisation / scaling。

常见做法：

$$
x' = \frac{x - x_{min}}{x_{max}-x_{min}}
$$

把 feature scale 到：

$$
[0,1]
$$

我可以这样记：

> K-means 看 distance，所以 feature scale 不公平时，distance 就不公平。

---

## 8. K-means 的 Strengths

K-means 的优点：

### 8.1 Simple

K-means 很容易理解。
它就是不断 assign points 和 update centroids。

### 8.2 Efficient

K-means 通常很快，可以处理 large datasets。

### 8.3 Interpretable

每个 cluster 有一个 centroid。
centroid 可以帮助我们解释这个 cluster 的 average pattern。

### 8.4 Often Good Enough

虽然 K-means assumptions 很强，但在很多 practical tasks 里，只要 clusters 比较 compact，它效果可以不错。

所以 K-means 常用不是因为它完美，而是因为：

> simple, fast, interpretable, often good enough.

---

## 9. K-means 的 Limitations

这是 Lecture 19 的重点。

---

### 9.1 Need to Predefine K

K-means 一开始就需要你给 K。

但是现实里你通常不知道应该有几个 clusters。

例如 vehicle crash data 里面，我们可能可以解释成 cars、trucks、buses 三组。
但如果没有 domain knowledge，K 不一定明显。

所以 K-means 的第一个问题是：

> requires predefined number of clusters.

---

### 9.2 Sensitive to Initial Centroids

K-means 的 initial centroids 是 random 选的。

不同 random initialisation 可能导致不同 final result。

有时候会得到 desirable clusters。
有时候会 converge 到 sub-optimal clusters。

这是因为 K-means 是 iterative local optimisation。
它不会保证找到 global optimal solution。

实际做法通常是：

> run K-means multiple times with different initialisations, then choose the best result.

---

### 9.3 Sensitive to Outliers

因为 centroid 是 mean。

outlier 会严重影响 mean。

例如一个 cluster 大部分 points 都集中在中间，但有一个 far-away point。
这个 point 会把 centroid 拉过去，导致 cluster boundary 被扭曲。

所以：

> K-means is sensitive to outliers.

---

### 9.4 Mean 不适合 Categorical Attributes

K-means 需要计算 mean。
但是 categorical attributes 没有自然 mean。

例如：

$$
color = red, blue, green
$$

不能直接平均出一个 meaningful color。

所以 K-means 主要适合 numerical features。

如果 data 主要是 categorical，K-means 不一定合适。

---

### 9.5 Cannot Handle Non-spherical Clusters Well

K-means 假设 clusters 比较 compact / spherical。

如果真实 clusters 是：

* moon-shape
* ring-shape
* spiral-shape
* smiley-face shape

K-means 通常会切错。

因为它只会根据 centroid 和 distance 形成 roughly round 的 regions。

所以：

> K-means is not good for non-spherical clusters.

---

### 9.6 Cannot Handle Different Sizes Well

如果一个 cluster 很大，另一个 cluster 很小，K-means 可能会错误地把大 cluster 切成两半，或者把小 cluster 合并到别的 cluster。

所以 K-means 偏好 clusters 的 size 差不多。

---

### 9.7 Cannot Handle Different Densities Well

如果一个 cluster 很 dense，另一个 cluster 很 sparse，K-means 也容易出错。

因为 K-means 只看 distance，不真正理解 density。

所以：

> K-means struggles with clusters of different densities.

---

## 10. Elbow Method

### 10.1 为什么需要 Elbow Method

因为 K-means 需要 predefined K。
但很多时候我们不知道 K。

所以需要一个方法帮助我们估计合适的 cluster number。

Elbow method 就是其中一种常见方法。

---

### 10.2 Elbow Method 怎么做

步骤：

1. Choose a range of K values。
2. For each K, run K-means。
3. Calculate WCSS for each K。
4. Plot K against WCSS。
5. Find the elbow point where WCSS reduction slows down。
6. Choose that K。

WCSS 通常会随着 K 增加而减少。
因为 cluster 越多，每个 point 离自己的 centroid 通常越近。

但是 K 太大没有意义。
如果每个 point 自己一个 cluster，WCSS 可以非常小，但这不是 useful clustering。

所以 elbow method 找的是：

> 增加 K 之后 improvement 开始不明显的位置。

---

### 10.3 Elbow Point 的直觉

如果从 K=1 到 K=2，WCSS 大幅下降，说明多一个 cluster 很有帮助。
如果从 K=4 到 K=5，WCSS 只下降一点点，说明再加 cluster 帮助不大。

所以 elbow point 是一个 trade-off：

> clusters enough to explain structure, but not too many.

我可以这样记：

> Elbow method chooses K where adding more clusters stops helping much.

---

## 11. Hierarchical Clustering

### 11.1 Hierarchical Clustering 是什么

Hierarchical clustering 不只是给你 flat clusters。
它会产生一棵 nested cluster tree。

这种 tree 可以用 dendrogram 表示。

Dendrogram 记录了：

> 哪些 points / clusters 在什么时候被 merge。

所以 hierarchical clustering 不只是告诉你 final clusters，也告诉你 clustering 的过程。

---

### 11.2 Dendrogram

Dendrogram 是 hierarchical clustering 的可视化。

一般来说：

* leaves 是 original data points
* branches 表示 merges
* y-axis 表示 distance / dissimilarity
* merge 越低，表示 clusters 越相似
* merge 越高，表示 clusters 越不相似

如果我们在某个 height cut dendrogram，就可以得到对应数量的 clusters。

所以：

> dendrogram lets us choose clusters after seeing the hierarchy.

这是 hierarchical clustering 相比 K-means 的一个优点：

> 不一定要一开始指定 K。

---

## 12. Agglomerative Clustering

### 12.1 Bottom-up Approach

Agglomerative clustering 是 bottom-up hierarchical clustering。

一开始：

$$
n \text{ data points} \rightarrow n \text{ clusters}
$$

每个 point 都是自己的 cluster。

然后每一步：

> merge the two closest clusters.

最后：

$$
1 \text{ big cluster}
$$

或者我们可以在剩下 K 个 clusters 的时候停止。

---

### 12.2 Agglomerative Algorithm

流程：

1. Compute distance matrix。
2. Treat each data point as its own cluster。
3. Find the two closest clusters。
4. Merge them。
5. Update the distance matrix。
6. Repeat until one cluster remains, or until desired number of clusters is reached。

可以总结成：

> start small, merge closest, build hierarchy.

---

### 12.3 Distance Matrix

Agglomerative clustering 依赖 distance matrix。

Distance matrix 里的 cell 表示：

> two data points / clusters 之间的 distance。

很重要：

> matrix 里的数字不是 coordinates，而是 distances。

例如：

|        | Inst 1 | Inst 2 | Inst 3 |
| ------ | ------ | ------ | ------ |
| Inst 1 | 0      | 15     | 30     |
| Inst 2 | 15     | 0      | 35     |
| Inst 3 | 30     | 35     | 0      |

这里 15 不是 Inst 1 或 Inst 2 的 coordinate，而是它们之间的 distance。

---

## 13. Linkage：Cluster 和 Cluster 的 Distance 怎么算

### 13.1 为什么需要 Linkage

一开始，每个 cluster 只有一个 point。
所以 point-to-point distance 很简单。

但是 merge 之后，一个 cluster 里面可能有多个 points。
这时问题变成：

> 两个 clusters 之间的 distance 怎么定义？

这就是 linkage。

Lecture 19 讲了几种 linkage：

* single linkage
* complete linkage
* average linkage
* centroid linkage

---

## 14. Single Linkage

### 14.1 Definition

Single linkage 使用两个 clusters 之间最近的两个 points 的 distance。

公式：

$$
D(C_1,C_2)=\min_{x_i\in C_1,x_j\in C_2} d(x_i,x_j)
$$

意思是：

> 只要两个 clusters 中有一对 points 很近，就认为这两个 clusters 很近。

---

### 14.2 Single Linkage 的直觉

Single linkage 很像：

> 用最近的边把 clusters 串起来。

所以它可以 handle irregular shapes。

例如 long chain shape 或 non-spherical clusters，single linkage 可能比 K-means 更适合。

---

### 14.3 Single Linkage 的缺点

Single linkage 很容易受 noise 和 outliers 影响。

因为只要有一个 noisy point 连接两个 clusters，它就可能把本来应该分开的 clusters merge 在一起。

这叫 chaining effect。

所以：

> Single linkage handles weird shapes, but can be fooled by noise.

---

## 15. Complete Linkage

### 15.1 Definition

Complete linkage 使用两个 clusters 之间最远的两个 points 的 distance。

公式：

$$
D(C_1,C_2)=\max_{x_i\in C_1,x_j\in C_2} d(x_i,x_j)
$$

意思是：

> 两个 clusters 里面最远的 pair 也不能太远，才愿意 merge。

---

### 15.2 Complete Linkage 的直觉

Complete linkage 更保守。
它希望 merge 后的 cluster 仍然 compact。

所以 complete linkage 产生的 clusters 通常更 round、更 tight。

---

### 15.3 Complete Linkage 的缺点

Complete linkage 偏好 compact clusters。
所以如果真实 cluster 很长、很弯、形状不规则，它可能会把它切碎。

它也倾向于产生 size 比较相近的 clusters。

所以：

> Complete linkage is less sensitive to noise, but prefers compact and similarly sized clusters.

---

## 16. Average Linkage

Average linkage 使用两个 clusters 之间所有 pairwise distances 的平均。

公式：

$$
D(C_1,C_2)
==========

\frac{1}{|C_1||C_2|}
\sum_{x_i\in C_1}
\sum_{x_j\in C_2}
d(x_i,x_j)
$$

意思是：

> 不只看最近的一对，也不只看最远的一对，而是看整体平均距离。

它比 single linkage 和 complete linkage 更折中。

---

## 17. Centroid Linkage

Centroid linkage 先计算每个 cluster 的 centroid，然后用 centroids 之间的 distance 作为 cluster distance。

公式：

$$
D(C_1,C_2)=d(\mu_1,\mu_2)
$$

其中：

$$
\mu_1
$$

和：

$$
\mu_2
$$

是两个 clusters 的 centroids。

这个方法和 K-means 有点类似，所以也可能继承 K-means 的一些问题，例如 outlier sensitivity。

---

## 18. Single vs Complete Linkage 的核心区别

这个地方很容易考。

最简单的记法：

> Single linkage = closest pair.
> Complete linkage = farthest pair.

| Linkage          | Cluster distance         | Strength            | Weakness                |
| ---------------- | ------------------------ | ------------------- | ----------------------- |
| Single linkage   | 最近的两个 points             | 能处理 irregular shape | 对 noise / outlier 敏感    |
| Complete linkage | 最远的两个 points             | clusters 更 compact  | 可能切碎 irregular clusters |
| Average linkage  | 所有 pairwise distances 平均 | 比较折中                | 计算更复杂                   |
| Centroid linkage | centroids distance       | 直觉简单                | 对 outlier 敏感            |

考试要注意：

> Agglomerative clustering 每一步都是 merge closest clusters。
> Single / complete 的区别是 update distance matrix 时 cluster distance 怎么算，不是 single 找最小、complete 找最大来 merge。

换句话说：

> merge 时永远选当前 distance matrix 里的最小 distance。
> linkage 决定 matrix 里的 cluster-to-cluster distance 怎么更新。

---

## 19. Hierarchical Clustering 的 Strengths

Hierarchical clustering 的优点：

### 19.1 不一定要提前指定 K

K-means 一开始就要 K。
Hierarchical clustering 可以先生成 dendrogram，再决定 cut 在哪里。

所以：

> hierarchical clustering allows post-hoc choice of cluster number.

---

### 19.2 可以看到 nested structure

如果 data 本身有 hierarchy，例如 taxonomy、species、document topics，hierarchical clustering 比 flat clustering 更有解释力。

---

### 19.3 对 cluster shape 的 assumption 较少

K-means 强烈偏好 spherical clusters。
Hierarchical clustering 的 linkage 不同，可以更灵活地处理不同 shapes。

---

### 19.4 Dendrogram 可解释

Dendrogram 可以显示 merge sequence。
这让我们更容易解释哪些 points 比较相似，哪些 clusters 是后来才合并的。

---

## 20. Hierarchical Clustering 的 Weaknesses

### 20.1 Greedy and Cannot Undo

Agglomerative clustering 每一步都 merge 当前最近的 clusters。

一旦 merge 发生，后面不能 undo。

所以如果早期 merge 错了，后面会一直带着这个错误。

### 20.2 No Direct Objective Function

K-means 至少有一个比较明确的 objective，例如 reduce WCSS。
Hierarchical clustering 没有直接优化一个 global objective。

所以它更像是按照 local rules 逐步构造 hierarchy。

### 20.3 Computational Cost

Hierarchical clustering 需要 distance matrix。
如果 data 很大，pairwise distances 会很贵。

### 20.4 Sensitive to Linkage Choice

同一份 data，用 single linkage 和 complete linkage 可能得到很不一样的 dendrogram。

所以 linkage choice 会严重影响 result。

---

## 21. Clustering Evaluation

### 21.1 为什么 Clustering Evaluation 难

Supervised learning 很好评估，因为有 true labels。
例如 classification 可以算 accuracy、precision、recall。

但是 clustering 没有 label。
所以问题是：

> 我们怎么知道 cluster 好不好？

Lecture 19 讲两类 evaluation：

1. Unsupervised clustering metrics
2. Supervised clustering metrics

---

## 22. Unsupervised Clustering Metrics

如果没有 true labels，我们只能看 cluster structure 本身。

一个好的 clustering 通常应该满足两个条件：

> high cohesion + high separation

---

### 22.1 Cohesion

Cohesion 指的是：

> 同一个 cluster 内部 points 有多 close。

如果 cluster 内部 points 都很接近，cohesion 高。

对应的 distance-based idea 是：

> within-cluster distance should be low.

---

### 22.2 Separation

Separation 指的是：

> 不同 clusters 之间有多 far apart。

如果 clusters 之间距离很远，separation 高。

对应的 idea 是：

> between-cluster distance should be high.

---

## 23. WCSS

### 23.1 Definition

WCSS = Within-Cluster Sum of Squares。

公式：

$$
WCSS
====

\sum_{j=1}^{K}
\sum_{x_i\in C_j}
(x_i-\mu_j)^2
$$

其中：

* (K) 是 cluster number
* (C_j) 是第 (j) 个 cluster
* (\mu_j) 是 cluster (j) 的 centroid

---

### 23.2 WCSS 的直觉

WCSS 衡量：

> 每个 point 离自己 cluster centroid 有多远。

如果 WCSS 小，说明 cluster 内部很 compact。

所以：

> WCSS 越低越好。

但是不能只看 WCSS。
因为 K 越大，WCSS 通常越小。
如果每个 point 都自己一个 cluster，WCSS 会非常小，但这没有意义。

所以 WCSS 常用于 elbow method，而不是单独作为最终判断。

---

## 24. BCSS

### 24.1 Definition

BCSS = Between-Cluster Sum of Squares。

公式：

$$
BCSS
====

\sum_{j=1}^{K}
n_j(\mu-\mu_j)^2
$$

其中：

* (n_j) 是 cluster (j) 的 size
* (\mu_j) 是 cluster (j) 的 centroid
* (\mu) 是整个 dataset 的 overall mean

---

### 24.2 BCSS 的直觉

BCSS 衡量：

> cluster centroids 和 overall mean 之间有多分开。

如果 BCSS 大，说明 clusters 之间 separation 比较明显。

所以：

> BCSS 越高越好。

---

## 25. Calinski-Harabasz Index

### 25.1 Definition

Calinski-Harabasz Index，也叫 Variance Ratio Criterion。

公式：

$$
CH
==

\frac{BCSS}{WCSS}
\times
\frac{N-K}{K-1}
$$

其中：

* (N) 是 data points 数量
* (K) 是 cluster number
* (BCSS) 衡量 between-cluster separation
* (WCSS) 衡量 within-cluster compactness

---

### 25.2 CH Index 的直觉

CH Index 想要：

* high BCSS
* low WCSS

所以：

$$
\frac{BCSS}{WCSS}
$$

越大越好。

后面的：

$$
\frac{N-K}{K-1}
$$

用来调整 cluster number 的影响，避免无脑增加 K。

所以：

> Calinski-Harabasz Index 越高，clustering 越好。

我可以这样记：

> CH high = clusters are compact internally and separated externally.

---

## 26. Supervised Clustering Metrics

有时候虽然 clustering 是 unsupervised，但我们手上可能有 true labels，可以用来评估 cluster 是否和真实 class 对齐。

这类 metric 就叫 supervised clustering metrics。

Lecture 19 主要讲：

* homogeneity
* completeness

---

## 27. Homogeneity

### 27.1 Homogeneity 问什么

Homogeneity 问的是：

> 每个 cluster 里面是不是只包含一个 true class？

如果一个 cluster 里面全部都是 same class，那么这个 cluster 很 homogeneous。

例如：

Cluster 1 全部是 cat。
Cluster 2 全部是 dog。
Cluster 3 全部是 bird。

这种 homogeneity 高。

如果一个 cluster 里面混了 cat、dog、bird，那么 homogeneity 低。

所以一句话：

> Homogeneity = cluster pure 不 pure。

---

### 27.2 Homogeneity 的公式

公式：

$$
homogeneity
===========

1-
\frac{H(C|K)}{H(C)}
$$

其中：

* (C) 是 true class
* (K) 是 predicted cluster
* (H(C)) 是 class entropy
* (H(C|K)) 是知道 cluster 后 class 还有多少 uncertainty

如果知道 cluster 后就能确定 class，那么：

$$
H(C|K)=0
$$

所以：

$$
homogeneity=1
$$

---

### 27.3 Homogeneity 的问题

Homogeneity 可以被 trick。

如果每个 point 都自己一个 cluster，那么每个 cluster 都只有一个 point。
这时每个 cluster 当然是 pure 的。

所以 homogeneity 会很高。
但这不是一个好的 clustering。

所以：

> Homogeneity alone is not enough.

---

## 28. Completeness

### 28.1 Completeness 问什么

Completeness 问的是：

> 同一个 true class 的 points 有没有都被放在同一个 cluster？

例如所有 cats 都在 cluster 1，所有 dogs 都在 cluster 2。
这样 completeness 高。

如果 cats 被拆到 cluster 1、cluster 3、cluster 5，那么 completeness 低。

所以一句话：

> Completeness = same class 有没有被拆散。

---

### 28.2 Completeness 的公式

公式：

$$
completeness
============

1-
\frac{H(K|C)}{H(K)}
$$

其中：

* (K) 是 predicted cluster
* (C) 是 true class
* (H(K|C)) 是知道 true class 后 cluster 还有多少 uncertainty

如果知道 class 后就能确定 cluster，那么：

$$
H(K|C)=0
$$

所以 completeness 高。

---

## 29. Homogeneity vs Completeness

这个很容易混，要重点记。

Homogeneity 看的是：

> 一个 cluster 里面混不混 class。

Completeness 看的是：

> 一个 true class 有没有被拆到多个 clusters。

| Situation              | Homogeneity | Completeness |
| ---------------------- | ----------- | ------------ |
| 每个 cluster 只含一个 class  | 高           | 不一定          |
| 每个 class 都在一个 cluster  | 不一定         | 高            |
| 每个 point 自己一个 cluster  | 高           | 低            |
| 所有 points 都在一个 cluster | 低           | 高            |
| cluster 和 class 完全对应   | 高           | 高            |

考试可以这样写：

> Homogeneity penalises clusters containing mixed classes.
> Completeness penalises splitting one true class across multiple clusters.

---

## 30. K-means vs Agglomerative Clustering

| Aspect                | K-means                                  | Agglomerative Clustering   |
| --------------------- | ---------------------------------------- | -------------------------- |
| Type                  | Partitioning                             | Hierarchical               |
| Need K first?         | Yes                                      | Not necessarily            |
| Output                | Flat clusters                            | Dendrogram / hierarchy     |
| Cluster assignment    | Based on nearest centroid                | Based on linkage distance  |
| Works best for        | spherical, compact clusters              | depends on linkage         |
| Handles weird shapes  | Poorly                                   | single linkage can help    |
| Sensitive to outliers | Yes                                      | depends on linkage         |
| Can undo decisions?   | Iterative reassignment can change points | No, merge cannot be undone |
| Scalability           | Usually faster                           | usually more expensive     |
| Interpretability      | centroid-based                           | dendrogram-based           |

一句话：

> K-means is simple and scalable, but assumes compact spherical clusters.
> Agglomerative clustering is more interpretable and hierarchical, but greedy and more expensive.

## 31. Lecture 19 和前面内容的连接

### 31.1 和 KNN 的连接

KNN 和 clustering 都依赖 distance。
所以 feature scaling 也很重要。

KNN 是 supervised，因为 neighbor 有 labels。
K-means 是 unsupervised，因为 data 没有 labels。

可以这样记：

> KNN uses distance to predict labels.
> K-means uses distance to discover clusters.

---

### 31.2 和 Evaluation 的连接

之前 supervised evaluation 有 accuracy、precision、recall、F-score。
这些都需要 true labels。

Clustering evaluation 更难，因为通常没有 labels。

所以 unsupervised metrics 用：

* WCSS
* BCSS
* Calinski-Harabasz Index

如果有 labels，才可以用：

* homogeneity
* completeness

---

### 31.3 和 Semi-supervised Learning 的连接

Lecture 20 会讲 semi-supervised learning。
它会用 labelled data + unlabelled data。

Clustering 可以帮助 semi-supervised learning，因为如果 cluster 里有少量 labelled points，可以把 label 传播给同 cluster 的 unlabelled points。

但是这需要一个 assumption：

> similar points are likely to have similar labels.

如果这个 assumption 不成立，label propagation 就会错。

## 32. Lecture 19 最重要的公式

### 32.1 K-means Centroid

$$
\mu_j
=====

\frac{1}{|C_j|}
\sum_{x_i\in C_j}
x_i
$$

意思是：

> cluster centroid 是 cluster 内 points 的 average。

---

### 32.2 Single Linkage

$$
D(C_1,C_2)
==========

\min_{x_i\in C_1,x_j\in C_2}
d(x_i,x_j)
$$

意思是：

> 两个 clusters 之间最近的 points 决定 distance。

---

### 32.3 Complete Linkage

$$
D(C_1,C_2)
==========

\max_{x_i\in C_1,x_j\in C_2}
d(x_i,x_j)
$$

意思是：

> 两个 clusters 之间最远的 points 决定 distance。

---

### 32.4 WCSS

$$
WCSS
====

\sum_{j=1}^{K}
\sum_{x_i\in C_j}
(x_i-\mu_j)^2
$$

意思是：

> cluster 内部 points 离 centroid 的 squared distance 总和。

WCSS 越低越好。

---

### 32.5 BCSS

$$
BCSS
====

\sum_{j=1}^{K}
n_j(\mu-\mu_j)^2
$$

意思是：

> clusters 和 overall mean 之间的 separation。

BCSS 越高越好。

---

### 32.6 Calinski-Harabasz Index

$$
CH
==

\frac{BCSS}{WCSS}
\times
\frac{N-K}{K-1}
$$

意思是：

> 同时奖励 high separation 和 low within-cluster spread。

CH 越高越好。

---

### 32.7 Homogeneity

$$
homogeneity
===========

1-
\frac{H(C|K)}{H(C)}
$$

意思是：

> cluster 能不能预测 true class。

---

### 32.8 Completeness

$$
completeness
============

1-
\frac{H(K|C)}{H(K)}
$$

意思是：

> true class 能不能预测 cluster。

## 33. 这讲最容易考的点

### 33.1 Concept Questions

可能会问：

> What is the difference between supervised and unsupervised learning?

答：

Supervised learning uses labelled data to learn a mapping from features to labels. Unsupervised learning uses unlabelled data to discover hidden structure, such as clusters.

---

### 33.2 K-means Algorithm

可能会问：

> Describe the K-means algorithm.

答：

K-means first chooses K initial centroids, assigns each point to the nearest centroid, recomputes each centroid as the mean of assigned points, and repeats until convergence.

---

### 33.3 Why Scaling

可能会问：

> Why do we scale features before K-means?

答：

Because K-means is distance-based. Features with larger numerical ranges can dominate the distance calculation, so scaling makes attributes comparable.

---

### 33.4 K-means Limitations

可能会问：

> Give limitations of K-means.

答：

K-means requires predefined K, is sensitive to initial centroids and outliers, is unsuitable for categorical attributes, and struggles with non-spherical clusters, different-sized clusters, and clusters with different densities.

---

### 33.5 Single vs Complete Linkage

可能会问：

> What is the difference between single and complete linkage?

答：

Single linkage defines cluster distance as the minimum distance between any pair of points across two clusters. Complete linkage defines it as the maximum distance between any pair of points. Single linkage can handle irregular shapes but is sensitive to noise, while complete linkage produces compact clusters but may split irregular or large clusters.

---

### 33.6 Homogeneity vs Completeness

可能会问：

> Explain homogeneity and completeness.

答：

Homogeneity measures whether each cluster contains only members of a single true class. Completeness measures whether all members of a true class are assigned to the same cluster.

---

## 34. 我的考前速记版

Unsupervised learning = no labels。
Clustering = group similar instances。
Clustering learns structure from data alone。

K-means = choose K, random centroids, assign each point to nearest centroid, recompute centroids, repeat。
Centroid = mean of points in cluster。
K-means needs scaling because it is distance-based。
K-means works best for compact, spherical, similar-size, similar-density clusters。
K-means is simple, fast, interpretable, but limited。

K-means limitations：

* need predefined K
* sensitive to initial centroids
* sensitive to outliers
* not good for categorical attributes
* not good for non-spherical clusters
* not good for clusters with different sizes
* not good for clusters with different densities

Elbow method = run K-means for different K, plot WCSS, choose elbow where WCSS reduction slows down。

Hierarchical clustering = nested clusters。
Agglomerative clustering = bottom-up。
Start with each point as a cluster, repeatedly merge closest clusters。
Dendrogram = tree showing merge sequence。

Single linkage = closest pair distance。
Good for irregular shape, bad with noise / chaining。

Complete linkage = farthest pair distance。
Good for compact clusters, less sensitive to noise, but may split large / irregular clusters。

Average linkage = average pairwise distance。
Centroid linkage = distance between centroids。

Good clustering = high cohesion and high separation。
WCSS low = compact clusters。
BCSS high = separated clusters。
CH index high = good clustering。

Homogeneity = cluster pure 不 pure。
Completeness = same class 有没有被拆散。

一句话总结：

> Lecture 19 讲的是：当 data 没有 labels 时，我们可以用 clustering 从 features 里面发现 hidden structure。K-means 用 centroids 做 flat partitioning，简单快速但 assumptions 很强；agglomerative clustering 用 linkage 一步步 merge points 形成 hierarchy；clustering evaluation 则主要看 cluster 内部是否 compact、cluster 之间是否 separated，或者在有 true labels 时看 homogeneity 和 completeness。
