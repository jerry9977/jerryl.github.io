# Lecture 1：Introduction and Overview

## 1. Machine Learning 的核心概念

课程一开始主要在回答一个问题：什么是 Machine Learning？日常生活中其实已经有很多 ML 的例子，例如手机的人脸解锁、Spotify 的歌曲推荐、Email spam detection，这些系统并不是人类把所有规则都手动写进去，而是让模型从大量 examples 中学习 pattern。也就是说，Machine Learning 的核心思想是：

> 从 data 中学习规律，并利用这些规律对 unseen data 做 prediction 或 decision。

传统程序通常是：

Rules + Data → Output

但 Machine Learning 更像是：

Data + Output → Learned Model

因此，ML 的重点并不是“让机器拥有智能”，而是让模型能够从 examples 中自动学习 input 和 output 之间的关系。


## 2. Machine Learning 的三个核心组成

Lecture 1 提出，Machine Learning 主要由三个 ingredients 组成：Data、Model 和 Learning。

### 2.1 Data

Data 是模型学习的来源。Data 可以是 image、text、sensor reading、purchase history、medical scan、stock price 等等。课程特别强调：

> 模型能学到什么，很大程度取决于 data 本身。

因此需要考虑：

* data 是否 reliable
* 是否 representative
* 有没有 missing value
* 有没有 noise
* 是 labelled 还是 unlabelled

如果 data 本身存在 bias 或错误，模型也可能学习到错误 pattern。

---

### 2.2 Model

Model 可以理解成一个 function，它负责把 input mapping 到 output。例如：

* Email → spam / not spam
* House features → house price
* Customer features → buy / not buy

后面课程会学习很多不同 model，例如：

* KNN
* Decision Tree
* Naive Bayes
* Logistic Regression
* SVM

虽然算法不同，但本质上都在做同一件事：

> 学习 features 和 labels 之间的关系。

---

### 2.3 Learning

Learning 指的是：

> 如何找到 model 最好的 parameters。

也就是说，模型会根据 data 调整自己，使 prediction error 尽可能小。

例如：

* Linear Regression：学习最佳直线
* Decision Tree：学习最佳 split rule
* Logistic Regression：学习最佳 decision boundary

所以 ML 的主线其实是：

Data → Model → Learning → Prediction

---

## 3. 什么是 Learning？

Lecture 1 提出一个很重要的问题：

> Learning what?

也就是模型到底在学习什么。

在 ML 里面，我们想学习的东西通常叫做：

> Concept / Label / Target

不同任务学习的 concept 不一样：

* Classification：预测 discrete label
* Regression：预测 continuous value
* Clustering：寻找 data structure

例如：

Spam detection：
Email → Spam / Not Spam

Stock prediction：
Market Features → Future Price

Customer Segmentation：
Customers → Similar Groups

---

## 4. Learning Paradigm

课程开始区分不同的 learning paradigm。

### 4.1 Supervised Learning

Supervised Learning 使用：

> Labelled Data

也就是每个 input 都有对应 output：

[
(x, y)
]

模型目标是学习：

[
x \rightarrow y
]

例如：

* spam classification
* house price prediction
* stock up/down prediction

Supervised learning 通常包含：

* Classification
* Regression

---

### 4.2 Unsupervised Learning

Unsupervised Learning 使用：

> Unlabelled Data

也就是说 dataset 里面只有 features，没有 label。

模型目标是：

> 自动发现 data 中隐藏的 structure 或 pattern。

例如：

* Clustering
* Anomaly Detection
* Market Basket Analysis

课程特别强调：

> Clustering 不知道正确答案，它只是尝试把相似 data grouping 在一起。

---

## 5. Instance、Feature 和 Concept

Machine Learning 通常会把 data 表示成一个 table。

每一行叫：

> Instance

代表一个 example。

每一列叫：

> Feature / Attribute

代表 instance 的某个性质。

而我们想预测的那一列叫：

> Concept / Label

例如：

| Outlook | Humidity | Windy | Play |
| ------- | -------- | ----- | ---- |
| Sunny   | High     | False | No   |

这里：

* Outlook / Humidity / Windy → features
* Play → label

课程后面所有模型，本质上都在学习：

[
Features \rightarrow Label
]

---

## 6. Classification、Regression 和 Clustering

### 6.1 Classification

Classification 是：

> 预测 discrete category。

例如：

* Spam / Not Spam
* Fraud / Normal
* Yes / No

输出是离散类别。

---

### 6.2 Regression

Regression 是：

> 预测 continuous numerical value。

例如：

* Stock Price
* Temperature
* House Price

输出是连续数值。

---

### 6.3 Clustering

Clustering 是：

> 在没有 label 的情况下，将相似 instance grouping 在一起。

例如：

* Customer Segmentation
* Student Grouping
* Stock Behaviour Clustering

Clustering 属于 unsupervised learning。

---

## 7. 为什么需要 Evaluation？

Lecture 1 最后强调：

> ML 的目标不是记忆 training data。

真正重要的是：

> 模型能否 generalise 到 unseen data。

因此我们需要 evaluation 去判断：

* model 是否真的学到规律
* 是否 overfit
* 是否能够处理 unseen data

后面的 lecture 会学习：

* accuracy
* precision
* recall
* F1-score
* cross-validation

这些 evaluation method。

# Glossary

**Instance** – dataset 中的一行 data，一个 example。

**Feature / Attribute** – 描述 instance 的属性，通常是 dataset 的 column。

**Concept / Label / Target** – 我们希望模型预测的东西。

**Labelled Data** – 每个 input 都有对应 output 的 dataset。

**Unlabelled Data** – 只有 features，没有 label 的 dataset。

**Supervised Learning** – 使用 labelled data 学习 input 和 output mapping。

**Unsupervised Learning** – 从 unlabelled data 中发现 structure。

**Classification** – 预测 discrete category 的任务。

**Regression** – 预测 continuous numerical value 的任务。

**Clustering** – 在没有 label 的情况下 grouping similar data。

**Generalisation** – 模型在 unseen data 上仍然表现良好的能力。

**Model** – 从 input mapping 到 output 的 function。

**Learning Algorithm** – 用于寻找最佳 model parameter 的方法。

**Parameter** – 模型内部从 data 学习得到的值。

**Vector** – 用数值表示的 feature list。

**Matrix** – 数值组成的二维结构，用于表示 dataset 或 computation。
