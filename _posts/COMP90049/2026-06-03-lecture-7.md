# Lecture 7：线性回归与优化

## 1. 从 Classification 走到 Regression

### 1.1 这节课在换问题类型

前面几节课主要都在做 classification。KNN 可以预测 class，Decision Tree 可以预测 class，Naive Bayes 也是 probabilistic classifier。但 Lecture 7 开始把重点转向 regression，也就是预测 continuous value。

这里的例子是用一个人的 working hours per week 去预测 income。这个 target 不再是 yes / no，也不是 flu / cold，而是一个连续数值。所以我需要先记住：

> Classification 预测 category。
> Regression 预测 numerical value。

例如：

Classification:

$$
x \rightarrow spam / not\ spam
$$

Regression:

$$
x \rightarrow income
$$

所以 Linear Regression 是第一个正式用来预测 continuous target 的 model。

---

### 1.2 Linear Regression 的直觉

老师一开始用 hours-per-week 和 income 的 scatter plot。我们可以观察到：整体上，working hours 越高，income 可能越高。这个 relationship 不一定完美，但看起来有一个 upward trend。

Linear Regression 的想法就是：

> 用一条 line 去 approximate feature 和 target 之间的 relationship。

如果只有一个 feature，这条线是在 2D plane 里面的一条直线。如果有多个 features，这个 line 会变成 higher-dimensional space 里的 hyperplane。

所以这节课的核心问题是：

> 我们怎么找到一条“最好”的线？

---

## 2. Linear Regression Model

### 2.1 Dependent Variable 和 Independent Variable

Linear Regression 里面，target (y) 叫 dependent variable，因为它是我们想预测的值。Feature (x) 叫 independent variable，因为它是用来解释或预测 (y) 的输入。

在 income example 里：

Independent variable:

$$
x = Hours\ per\ week
$$

Dependent variable:

$$
y = Income
$$

所以我们想学的是：

$$
Hours\ per\ week \rightarrow Income
$$

---

### 2.2 Single-variable Linear Regression

如果只有一个 feature，model 可以写成：

$$
\hat{y}=\beta_0+\beta_1x
$$

这里：

$$
\hat{y}
$$

是 predicted value。

$$
\beta_0
$$

是 intercept，也叫 bias term。

$$
\beta_1
$$

是 slope / weight，表示 (x) 增加时，(\hat{y}) 怎么变化。

所以在 income example 里：

$$
\widehat{income}=\beta_0+\beta_1 \times Hours_per_week
$$

我需要特别记住：(\beta_0) 不是 slope。它是当 (x=0) 时，line 在 y-axis 上的 intercept。真正控制 line 斜率的是 (\beta_1)。

---

### 2.3 Multiple Linear Regression

如果有多个 features，例如：

* Age
* Edu-num
* Hours-per-week

那么 model 变成：

$$
\hat{y}
=======

\beta_0+\beta_1x_1+\beta_2x_2+\dots+\beta_Dx_D
$$

例如：

$$
\widehat{income}
================

\beta_0
+\beta_1 Age
+\beta_2 EduNum
+\beta_3 HoursPerWeek
$$

这里每个 feature 都有自己的 weight。每个 (\beta) 表示该 feature 对 prediction 的 contribution。

所以我可以这样记：

> Linear Regression 是把多个 feature 加权相加，然后得到 continuous prediction。

---

### 2.4 Vector Notation

Linear Regression 也可以写成 dot product：

$$
\hat{y}=\boldsymbol{\beta}\cdot \mathbf{x}
$$

其中：

$$
\boldsymbol{\beta}
==================

[\beta_0,\beta_1,\dots,\beta_D]
$$

$$
\mathbf{x}
==========

[1,x_1,\dots,x_D]
$$

这里 (x) 前面加一个 1，是为了让 intercept (\beta_0) 也能放进 dot product 里面。

这很重要，因为后面 Logistic Regression、SVM、Perceptron 都会继续用这种 vector notation。

---

## 3. Training Linear Regression：什么叫找到最好的 line

### 3.1 不同 line 有不同 error

在 scatter plot 上，我们可以画很多条不同的 line。每条 line 都对应一组不同的 parameters：

$$
\beta_0,\beta_1
$$

问题是：哪一条 line 最好？

直觉上，一条好的 line 应该让 prediction 尽量接近 actual value。对于第 (i) 个 data point：

Actual value:

$$
y_i
$$

Predicted value:

$$
\hat{y}_i
$$

Error / residual:

$$
\epsilon_i=y_i-\hat{y}_i
$$

如果 error 很小，说明 prediction 接近 ground truth。如果 error 很大，说明 line 对这个 point 预测得不好。

---

### 3.2 Loss Function

为了比较不同 line，我们需要一个 function 去 measure 所有 mistakes。这个 function 就叫 loss function。

Linear Regression 的 training 可以理解为：

> 找到一组 parameters，让 loss function 最小。

写成：

$$
\hat{\boldsymbol{\beta}}
========================

\arg\min_{\boldsymbol{\beta}} Loss(\boldsymbol{\beta})
$$

这句话的意思是：在所有可能的 (\boldsymbol{\beta}) 里面，选一个让 loss 最小的。

所以我需要记住：

> Training Linear Regression = learning (\beta)。
> Learning (\beta) = minimising prediction error。

---

### 3.3 Mean Squared Error

Lecture 7 主要使用 Mean Squared Error，简称 MSE。

公式是：

$$
MSE=
\frac{1}{N}
\sum_{i=1}^{N}
(y_i-\hat{y}_i)^2
$$

因为：

$$
\hat{y}_i=\boldsymbol{\beta}\cdot \mathbf{x}_i
$$

所以也可以写成：

$$
MSE=
\frac{1}{N}
\sum_{i=1}^{N}
(y_i-\boldsymbol{\beta}\cdot \mathbf{x}_i)^2
$$

MSE 做了三件事：

第一，它计算每个 prediction 和 actual value 的 difference。
第二，它把 difference square，所以 positive error 和 negative error 不会互相抵消。
第三，它对所有 data points 取 average。

所以 MSE 越小，整体 prediction 越接近 ground truth。

---

### 3.4 为什么要 square error

如果直接加：

$$
y_i-\hat{y}_i
$$

positive error 和 negative error 可能互相抵消。例如一个 prediction 高估 10，另一个低估 10，加起来是 0，但 model 其实不是完美。

所以我们用 square：

$$
(y_i-\hat{y}_i)^2
$$

这样所有 error 都变成 positive，而且大的 error 会被惩罚更多。

这也是 MSE 的一个特点：它对 outlier 比较敏感，因为 large error 被平方后会变得很大。

---

## 4. 用 Linear Regression 做 Prediction

### 4.1 Training 完以后怎么预测

当我们找到 optimal line 之后，就可以用它对 new instance 做 prediction。

例如新的人工作 35 hours per week，我们把：

$$
x=35
$$

代入 trained model：

$$
\hat{y}=\beta_0+\beta_1 \times 35
$$

这样就得到 predicted income。

所以 Linear Regression 的 prediction 很快，因为它只需要做一次 linear calculation。

---

### 4.2 Interpolation vs Extrapolation

Lecture 7 很强调：Linear Regression 只能比较安全地在 observed data range 内使用。

如果 training data 的 working hours 范围是：

$$
20 \leq x \leq 60
$$

那么预测 35 hours 属于 interpolation，因为 35 在 observed range 里面。

但如果预测 5 hours 或 100 hours，就是 extrapolation，因为它超出了 training data 的 observed range。

Interpolation:

$$
x \in observed\ range
$$

Extrapolation:

$$
x \notin observed\ range
$$

这里我需要记住：

> Regression line 在 observed range 内可能合理，但超出 range 后不一定 generalise。

老师用 ice cream sales 和 temperature 的例子解释：在 10 到 25 度之间，temperature 越高，ice cream sales 可能越高。但如果温度到 45 度，sales 不一定继续上升，因为人可能不想出门。所以 extrapolation 很危险。

---

## 5. Linear Regression 的 Assumptions

### 5.1 Linear Relationship

Linear Regression 假设 feature 和 target 之间的 relationship 是 linear 的。也就是说，feature 的变化会带来 target 的 proportional change。

例如：

$$
\hat{y}=\beta_0+\beta_1x
$$

这里 (x) 每增加 1，prediction 会增加：

$$
\beta_1
$$

如果真实 relationship 是 curved、threshold-based、或者 saturation-based，那么 linear model 可能 underfit。

所以我可以这样记：

> Linear Regression 很简单，但前提是 relationship 大概可以用 line / hyperplane 表示。

---

### 5.2 Independent Variables 不应该高度相关

Lecture 7 也提到：independent variables 之间最好不要 highly correlated。这个问题叫 multicollinearity。

例如我们同时用：

* working hours per week
* resting hours per week

这两个 variables 可能高度相关，因为一天时间固定，工作多通常休息少。它们携带相似 information。

如果 features 高度相关，model 学到的 (\beta) 可能变得 unstable。也就是说，feature weights 可能很难解释，换一点 data，weights 就变化很大。

所以：

> Linear Regression 不喜欢 highly correlated independent variables。

---

### 5.3 Outlier 会影响 fitted line

MSE 会 square error，所以 outlier 会对 loss 产生很大影响。如果一个 data point 离其他 points 很远，Linear Regression 可能会为了减少这个 outlier 的 error，把整条 line 拉歪。

所以 Linear Regression 的一个缺点是：

> sensitive to outliers。

---

## 6. Optimisation：怎么找 optimal parameters

### 6.1 什么是 optimisation

Linear Regression 讲到这里，其实就变成 optimisation 问题。我们有一个 model，也有一个 loss function。现在的问题是：

> 怎么找到让 loss 最小的 parameters？

Optimization 的一般形式是：

$$
\hat{\theta}
============

\arg\min_{\theta} f(\theta)
$$

或者：

$$
\hat{\theta}
============

\arg\max_{\theta} f(\theta)
$$

如果 (f) 是 loss function，我们通常 minimize。
如果 (f) 是 profit 或 likelihood，我们通常 maximize。

所以 optimization 的核心是：

> 找到 parameter values，让 objective function 达到最好。

---

### 6.2 Objective Function 和 Loss Function

Objective function 是一个比较 general 的概念。它可以是我们想 maximize 的东西，也可以是想 minimize 的东西。

例如：

想 maximize shoe shop profit：

$$
\hat{\theta}
============

\arg\max_{\theta} Profit(\theta)
$$

想 minimize prediction error：

$$
\hat{\theta}
============

\arg\min_{\theta} Loss(\theta)
$$

Loss function 是 objective function 的一种，专门用来 measure mistakes。

所以我可以这样记：

> Objective function = 要优化的目标。
> Loss function = 要最小化的错误。

---

### 6.3 Exact Optimisation 的 recipe

Lecture 7 讲的是 exact optimisation，也就是可以用数学推导直接解出来。

基本 recipe 是：

1. Define function of interest
2. Compute first derivative
3. Set derivative to zero
4. Solve for parameter

如果一个 function 在 minimum 或 maximum 点是 smooth 的，那么它在那个点的 slope 通常是 0。

也就是：

$$
\frac{\partial f}{\partial \theta}=0
$$

这个就是我们找 extreme point 的方法。

---

### 6.4 一个简单例子

假设：

$$
f(\theta)=(\theta-1)^2
$$

先求 derivative：

$$
\frac{\partial f}{\partial \theta}
==================================

2(\theta-1)
$$

set derivative to zero：

$$
2(\theta-1)=0
$$

解出：

$$
\theta=1
$$

所以 (\theta=1) 是这个 function 的 minimum point。

这里重点不是这个例子本身，而是方法：

> 要找 optimum，就看 derivative 什么时候等于 0。

---

## 7. MLE：用 optimisation 解 spam probability

### 7.1 回到 spam example

Lecture 7 用 spam example 连接前面的 probability 和现在的 optimisation。

假设有：

$$
N=100
$$

封 emails，其中：

$$
x=20
$$

封是 spam。

我们想估计：

$$
\theta=P(spam)
$$

如果每封 email 是 spam / not spam，可以建模成 binomial distribution：

$$
p(x;N,\theta)
=============

\binom{N}{x}
\theta^x
(1-\theta)^{N-x}
$$

MLE 的目标是找到一个 (\theta)，让 observed data 最可能发生：

$$
\hat{\theta}
============

\arg\max_{\theta}
p(x;N,\theta)
$$

---

### 7.2 为什么使用 log

直接 maximize likelihood 有时不方便，因为里面有很多 multiplication，而且 probability 相乘可能非常小。通常我们会取 log，变成 log-likelihood。

因为 log 是 monotonic，所以 maximize likelihood 和 maximize log-likelihood 的结果一样。

原本：

$$
p(x;N,\theta)
=============

\binom{N}{x}
\theta^x
(1-\theta)^{N-x}
$$

取 log：

$$
\log p(x;N,\theta)
==================

\log \binom{N}{x}
+
x\log\theta
+
(N-x)\log(1-\theta)
$$

这里：

$$
\log \binom{N}{x}
$$

跟 (\theta) 没关系，所以在优化 (\theta) 时它只是 constant。

---

### 7.3 MLE 解出来是什么

对 log-likelihood 求 derivative，set to zero，最后可以得到：

$$
\hat{\theta}
============

\frac{x}{N}
$$

所以如果 100 封 emails 里面 20 封 spam：

$$
\hat{\theta}
============

# \frac{20}{100}

0.2
$$

这就是前面 Lecture 4 直觉上说的：如果 observed spam rate 是 20%，MLE 就会估计 (P(spam)=0.2)。

这里的重点是：Lecture 7 把这个直觉用 optimisation 数学推出来了。

---

## 8. 回到 Linear Regression：MSE optimisation

### 8.1 Linear Regression 的 objective

Linear Regression 的 objective 是最小化 MSE：

$$
\hat{\boldsymbol{\beta}}
========================

\arg\min_{\boldsymbol{\beta}}
\frac{1}{N}
\sum_{i=1}^{N}
(y_i-\boldsymbol{\beta}\cdot \mathbf{x}_i)^2
$$

每一组 (\boldsymbol{\beta}) 都对应一条 line 或一个 hyperplane。不同 (\boldsymbol{\beta}) 会产生不同 MSE。

所以可以想象一个 loss surface：横轴是 (\beta_0)，另一个轴是 (\beta_1)，高度是 MSE。我们要找的就是这个 surface 上最低的点。

---

### 8.2 Exact solution

Lecture 7 提到，Linear Regression 的 MSE 可以用 exact closed-form solution 求解。也就是说，在小数据或 feature 数量不太大的情况下，可以通过 normal equation 直接算出 optimal (\boldsymbol{\beta})。

矩阵形式下：

$$
\hat{\mathbf{y}}=X\boldsymbol{\beta}
$$

MSE 可以写成：

$$
MSE=
\frac{1}{N}
(\mathbf{y}-X\boldsymbol{\beta})^T
(\mathbf{y}-X\boldsymbol{\beta})
$$

对 (\boldsymbol{\beta}) 求 derivative 并 set to zero 后，可以得到 normal equation：

$$
\hat{\boldsymbol{\beta}}
========================

(X^TX)^{-1}X^T\mathbf{y}
$$

但 lecture 也说明，这种公式细节不一定是考试重点。真正要理解的是：

> Linear Regression 可以把 minimising MSE 转成一个 exact optimisation problem。

---

### 8.3 为什么 correlated features 会让 solution unstable

Normal equation 里面有：

$$
(X^TX)^{-1}
$$

如果 independent variables 高度相关，(X^TX) 可能接近 singular，inverse 会变得 unstable。结果就是 model 的 (\beta) 很不稳定。

所以这也解释了为什么 Linear Regression 不喜欢 multicollinearity。

---

## 9. Linear Regression 的优点和缺点

### 9.1 优点

Linear Regression 的优点是 simple and interpretable。每个 feature weight 都可以解释成该 feature 对 prediction 的 linear contribution。

它也可以有 exact closed-form solution，所以在小数据上不一定需要 iterative training。Prediction 也很快，因为只需要算：

$$
\hat{y}=\boldsymbol{\beta}\cdot \mathbf{x}
$$

所以 Linear Regression 是 continuous prediction task 的一个 strong baseline。

---

### 9.2 缺点

Linear Regression 的最大限制是它假设 relationship 是 linear。如果真实 pattern 是 non-linear，它可能学不好。

它也对 outliers 敏感，因为 MSE 会平方 error。它还受 multicollinearity 影响，如果 features 之间高度相关，parameters 会变得 unstable。

另一个重点是 extrapolation unreliable。模型只在 training data 覆盖的 range 内比较可信，超出 observed range 后，line 不一定还成立。

所以我可以这样记：

> Linear Regression 简单、快、可解释，但它只适合大概 linear 的问题，并且要小心 outlier、correlated features 和 extrapolation。

---

## Lecture 7 总结

Lecture 7 的核心是：

> Linear Regression 用一条 line / hyperplane 去预测 continuous value，而 training 就是找一组 parameters，让 prediction error 最小。

我需要重点记住：

Regression 预测 continuous target。
Linear Regression 假设 features 和 target 有 linear relationship。
Single-variable model 是：

$$
\hat{y}=\beta_0+\beta_1x
$$

Multiple-variable model 是：

$$
\hat{y}=\beta_0+\beta_1x_1+\dots+\beta_Dx_D
$$

(\beta_0) 是 intercept / bias，不是 slope。
(\beta_j) 是 feature weight。
Prediction error 是：

$$
\epsilon_i=y_i-\hat{y}_i
$$

MSE 是：

$$
MSE=
\frac{1}{N}
\sum_{i=1}^{N}
(y_i-\hat{y}_i)^2
$$

Training Linear Regression 就是 minimize MSE。
Optimisation 是找让 objective function 最好的一组 parameters。
Exact optimisation 的基本方法是 derivative = 0。
MLE spam example 最后得到：

$$
\hat{\theta}=\frac{x}{N}
$$

Linear Regression 可以有 closed-form solution：

$$
\hat{\boldsymbol{\beta}}
========================

(X^TX)^{-1}X^T\mathbf{y}
$$

Interpolation 是在 observed range 内预测。
Extrapolation 是在 observed range 外预测，通常很危险。
Independent variables 不应该高度 correlated。
Linear Regression 可解释、快速、适合做 baseline，但对 outliers、non-linearity、multicollinearity 和 extrapolation 敏感。

一句话总结：

> Lecture 7 把 Machine Learning 的问题正式写成 optimisation：我们先定义 model，再定义 loss function，最后寻找让 loss 最小的 parameters。
