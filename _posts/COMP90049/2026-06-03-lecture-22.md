# Lecture 22：Measuring and Mitigating Algorithmic Bias

## Measuring and Mitigating Algorithmic Bias

## 1. 这节课在讲什么

### 1.1 从 ML 模型到现实世界

前面几节课我们已经学了很多 machine learning 的技术部分：

* supervised learning
* feature selection
* evaluation
* neural networks
* unsupervised learning
* anomaly detection
* semi-supervised learning

这些内容大多是在问：

> model 怎么 train？
> model 怎么 predict？
> model performance 好不好？

Lecture 22 开始换一个角度。它不是只问 model accuracy 高不高，而是问：

> 当 machine learning model 被放进真实世界以后，它会不会对不同群体造成不公平？

这很重要，因为 ML model 的 output 很多时候不是一个无害的数字，而是会影响真实的人。例如：

* medical diagnosis：谁被判断为高风险？
* legal domain：谁被判为高再犯风险？
* predictive policing：哪个区域被更多警力巡逻？
* insurance：谁被推荐更贵的保险？
* credit scoring：谁能拿到贷款？
* hate speech detection：谁的语言更容易被误判？
* language generation / image generation：模型会不会 reproduce stereotypes？

所以这节课的核心是：

> ML models 不只是 technical systems，它们也会参与社会决策。因此我们要理解 bias 从哪里来、怎么 measure fairness、以及怎么 mitigate unfairness。

---

## 2. Bias 是什么

### 2.1 这里的 bias 不是只指 bias-variance 里的 bias

前面 Evaluation 里面我们学过 model bias 和 variance。那个 bias 主要指：

> model 系统性地预测太高或太低，或者 model assumption 太强导致 underfitting。

但 Lecture 22 的 bias 更接近 social / algorithmic bias。它指的是：

> model 对不同 groups 产生系统性不公平的 prediction 或 decision。

例如一个 loan classifier 对 humans 和 martians 都预测 credit-worthy，但它对 humans 的 true positives 很多，对 martians 的 false positives 很多。表面上两个 group 都有拿到 loan，但实际效果并不公平。

所以这节课里的 bias 更关注：

> model decision 是否会在 protected groups 之间造成 unequal treatment 或 unequal harm。

---

## 3. Bias 为什么会进入 ML system

### 3.1 Human bias

Machine learning model 是从 data 里学 pattern，而很多 data 是人类产生的。所以如果人类社会本来就有 bias，model 很容易把这些 bias 学进去。

一个例子是 out-group homogeneity bias。意思是人类容易把自己不属于的群体看成“都差不多”。这会形成 stereotypes。

例如：

> 某个群体的人都 lazy。
> 某个群体的人都 aggressive。
> 某个群体的人都适合某种职业。

如果这些 stereotype 反映在 text、image、hiring record、policing record 里面，model 就可能学到类似 pattern。

所以：

> human bias 可以通过 human-generated data 进入 model。

---

### 3.2 Correlation fallacy

另一个 human bias 是 correlation fallacy。人类经常把 correlation 当成 causation。

例如 lecture 里提到一个有趣例子：chocolate consumption 和 Nobel laureates 数量之间可能有很强 correlation。但这不代表：

> 吃巧克力会让人得 Nobel Prize。

它们只是 coincidentally correlated，可能背后有其他 confounding factors，例如国家财富、教育资源、科研投入等。

在 ML 里，这个问题很危险。因为 model 本来就是找 statistical patterns。如果某个 feature 和 label correlated，model 可能会用它做 prediction。但这个 feature 不一定是 causal。

例如 predictive policing：

> 某个 postcode 的 recorded crime 多，不一定代表那里真实 crime rate 更高。
> 可能只是因为警察本来就在那里巡逻更多，所以记录到更多 crime。

所以：

> model 学到 correlation，不代表它学到 fair 或 causal decision rule。

---

## 4. Data Bias

### 4.1 Historical bias

Historical bias 指的是：

> data 反映的是历史世界，而历史世界本身可能是不公平的。

即使我们 random sample，也不代表 data 就 fair。因为 sample 的 population 本身可能已经有 structural inequality。

例如：

* 搜索 professor，过去可能更容易出现 white male image。
* 搜索 nurse，过去可能更容易出现 female image。
* hiring data 里男性被录用更多，不一定说明男性更 qualified，而可能是过去 hiring system biased。
* policing data 里某些区域 arrest record 更多，不一定说明真实犯罪更多，而可能是 policing intensity 更高。

所以 historical bias 的重点是：

> data 可能准确反映了过去，但过去本身不公平。

这很重要，因为 ML model 如果直接学习 historical label，就会把过去的不公平延续到未来。

---

### 4.2 Representation bias / Reporting bias

Representation bias 指 dataset 没有 faithfully represent 整体 population。

例如某些 group 在 dataset 里 sample 太少：

* minority race faces 在 face recognition dataset 里太少
* female applicants 在 technical hiring data 里太少
* elderly patients 在 medical training data 里太少
* low-income regions 在 delivery optimization data 里太少

这样 model 就会对 underrepresented group 表现更差。

Reporting bias 是类似但更偏向：

> 被记录下来的事件不等于真实世界里发生的事件。

例如 text corpus 里 “murdered” 可能比 “was late” 更常见，因为 murder 更值得被报道。但现实中人迟到比谋杀常见得多。

所以如果 language model 从 reported text 里学 world distribution，它可能学到 distorted reality。

可以这样记：

> representation bias 是谁被放进 dataset 的问题。
> reporting bias 是哪些事情被记录或报道的问题。

---

### 4.3 Measurement bias

Measurement bias 指的是：

> 我们测量 target 或 feature 的方式本身有偏。

很多时候 ML task 里的 label 不是我们真正想预测的东西，而是一个 proxy。

例如 hiring：

真正想预测的是：

$$
candidate\ quality
$$

但 data 里可能只有：

$$
was\ hired
$$

于是 model 学的是过去谁被 hire，而不是谁真正 qualified。

如果过去 hiring decision 已经 biased，那么 model 就会把这种 bias 学进去。

再例如 predictive policing：

真正想知道的是：

$$
true\ crime\ rate
$$

但 data 里通常是：

$$
recorded\ crime
$$

而 recorded crime 受 police patrol intensity 影响。如果某个区域警察更多，recorded crime 就更多。然后 model 看到更多 recorded crime，就建议更多 policing。这样形成 feedback loop。

所以：

> measurement bias 经常来自用 noisy proxy 代替真正 target。

---

## 5. Model Bias、Loss Bias 和 Evaluation Bias

### 5.1 Model bias

Model bias 可以来自 model assumption。

例如一个 model 太简单，可能只依赖很少 feature。如果某个 feature 和 protected attribute strongly correlated，model 可能过度依赖这个 feature。

例如：

> postcode 和 race / income correlated。
> education system 和 species correlated。
> school name 和 social class correlated。

即使没有直接输入 protected attribute，model 也可能通过 proxy feature 做 biased prediction。

所以：

> 删除 protected attribute 不代表 model 不会学到 protected information。

---

### 5.2 Loss function bias

Loss function 也会引入 bias。

例如 accuracy 或 0/1 loss 在 imbalanced dataset 上可能很危险。

假设 dataset 里：

* 95% 是 majority group
* 5% 是 minority group

如果 model 对 majority group 表现很好，对 minority group 表现很差，overall accuracy 仍然可能很高。

所以：

> high accuracy 不代表 fair。

这和 evaluation lecture 里讲的 imbalanced class 问题类似。Accuracy 会被 majority group dominate，所以要看 precision、recall、FNR、TPR 等更细的 metrics。

---

### 5.3 Evaluation bias

Evaluation bias 指 evaluation process 本身不可靠。例如：

* test set 不代表 target population
* benchmark 被过度使用，model overfit 到 benchmark
* evaluation metric 忽略 minority group
* 只报告 average performance，不看 group-level performance

例如 face recognition model overall accuracy 很高，但 non-Caucasian faces accuracy 很低。如果只看 average accuracy，就会看不见这个问题。

所以：

> fairness evaluation 必须分 group 看 performance。

---

### 5.4 Deployment bias

Deployment bias 指 model 被用在它原本不适合的场景，或者 end users 没有正确理解 model output。

例如：

* 一个 model 只是辅助 decision support，但用户把它当 final decision。
* 一个 risk score 只是 probability，但警察或医生把它当成确定结论。
* 一个 model 在某个 country 的 data 上 train，却被部署到另一个 population。

所以：

> 即使 model 本身技术上合理，wrong deployment 也会造成 harm。

---

## 6. Feedback Loop

### 6.1 ML pipeline 不是单向的

传统 ML pipeline 看起来像：

$$
data \rightarrow model \rightarrow prediction
$$

但现实世界里更像：

$$
world \rightarrow data \rightarrow model \rightarrow action \rightarrow world
$$

model 的 action 会改变 world，然后新的 world 又产生新的 data。

所以这是一个 feedback loop。

---

### 6.2 Amazon same-day delivery 例子

Lecture 里的 case study 是 Amazon same-day delivery by zip-code。

假设 Amazon 的目标是：

> minimize cost, maximize efficiency

它训练一个 model 决定哪些 zip-code 可以 same-day delivery。

问题是：

* low-income areas 可能 order less
* model 认为这些区域 delivery efficiency 低
* Amazon 不给这些区域 same-day delivery
* 这些区域的人更少使用 Amazon
* order 更少
* model 更认为这些区域不值得服务

于是：

$$
lower\ income\ areas\ order\ less
\rightarrow
less\ delivery\ service
\rightarrow
even\ fewer\ orders
\rightarrow
even\ less\ priority
$$

这就是 feedback loop。

所以：

> model 不只是反映 inequality，它可能放大 inequality。

---

## 7. Quantifying Bias：Formal Setup

### 7.1 Notation

Lecture 22 用以下 notation 来 formalize fairness。

$$
X
$$

表示 non-sensitive features。例如：

* credit history
* job
* wealth
* education
* income
* spending habits

$$
A
$$

表示 sensitive attribute / protected attribute。例如：

* gender
* race
* age
* species
* disability status

$$
Y
$$

表示 true label。例如：

* truly credit-worthy
* actually has disease
* truly qualified
* actually positive

$$
\hat{Y}
$$

表示 predicted label。例如：

* predicted grant credit
* predicted high risk
* predicted positive
* predicted qualified

所以在 credit scoring example 里：

* (X)：credit history, job, wealth, education
* (A)：species, human or martian
* (Y)：whether the applicant is truly credit-worthy
* (\hat{Y})：whether the classifier grants credit

---

### 7.2 Protected attribute 不一定明显

一个 attribute 是否 sensitive，取决于 task。

例如 age：

* 在 hiring 里，age 通常不应该作为 decision basis。
* 在 medical diagnosis 里，age 可能是非常重要的 clinical feature。

又例如 gender：

* 在 job application 里，gender 通常应该 protected。
* 在某些 medical diagnosis 里，gender 可能和 disease risk 相关。

所以：

> sensitive attribute 的选择不是 purely technical，它和 task、law、ethics、domain context 有关。

---

## 8. Fairness Through Unawareness

### 8.1 基本想法

最简单的 fairness 方法叫：

> Fairness through Unawareness

意思是：

> 把 protected attribute 从 data 里删掉，然后训练 model。

也就是 model 只用 (X)，不用 (A)。

形式上希望：

$$
P(\hat{Y}_n|X_n,A_n) \approx P(\hat{Y}_n|X_n)
$$

也就是说，prediction 不应该依赖 sensitive attribute。

---

### 8.2 为什么这个方法不够

这个方法看起来很 intuitive：

> model 不知道 applicant 是 human 还是 martian，所以它应该 fair。

但问题是：

> sensitive information can leak through other features.

例如即使删掉 species：

* Martians 可能有不同 education system。
* Martians 可能 age distribution 不同。
* Martians 可能住在不同地区。
* Martians 可能 credit history pattern 不同。

所以 model 可以从 education、postcode、age、school、job 这些 features 间接推断出 species。

这叫 proxy discrimination。

所以：

> 删除 (A) 不等于删除和 (A) 相关的信息。

Lecture 的重点是：

> Fairness through unawareness 通常是 bad idea，除非你非常确定 protected attribute 不能从其他 features 推断出来。

---

## 9. Confusion Matrix Recap

在讲 formal fairness criteria 之前，需要先记住 confusion matrix。

| Actual / Predicted |         (\hat{y}=1) |         (\hat{y}=0) |
| ------------------ | ------------------: | ------------------: |
| (y=1)              |  True Positive (TP) | False Negative (FN) |
| (y=0)              | False Positive (FP) |  True Negative (TN) |

在 credit scoring 里：

* TP：model grant credit，而且 applicant 真的 credit-worthy
* FP：model grant credit，但 applicant 其实 not credit-worthy
* FN：model 不 grant credit，但 applicant 其实 credit-worthy
* TN：model 不 grant credit，而且 applicant 真的 not credit-worthy

---

## 10. Important Metrics

### 10.1 Precision / PPV

Precision 也叫 Positive Predictive Value：

$$
PPV = \frac{TP}{TP+FP}
$$

意思是：

> 在所有 predicted positive 里面，有多少是真的 positive。

在 credit scoring 里：

> 在所有被批准贷款的人里，有多少是真的 credit-worthy。

所以 precision 关心的是：

> model 说 yes 的时候，它有多可信？

---

### 10.2 Recall / TPR

Recall 也叫 True Positive Rate：

$$
TPR = \frac{TP}{TP+FN}
$$

意思是：

> 在所有 actual positive 里面，有多少被 model 找到了。

在 credit scoring 里：

> 在所有真正 credit-worthy 的人里，有多少真的拿到了 credit。

所以 recall 关心的是：

> model 有没有漏掉真正 positive 的人？

---

### 10.3 False Negative Rate / FNR

False Negative Rate 是：

$$
FNR = \frac{FN}{TP+FN}
$$

也可以写成：

$$
FNR = 1 - TPR
$$

意思是：

> 在所有 actual positive 里面，有多少被 model 错误预测成 negative。

在 credit scoring 里：

> 有多少真正 credit-worthy 的人被拒绝贷款。

所以 FNR 关心的是：

> model miss out 了多少应该被 positive 的人。

---

## 11. Credit Scoring Example

### 11.1 Problem setup

Lecture 用 humans vs martians 作为例子，避免直接讨论现实种族或性别。

场景是：

> 一个 bank 要训练 classifier，预测 applicant 是否应该 get credit。

Output 是 binary decision：

$$
grant\ credit
$$

或：

$$
not\ grant\ credit
$$

Features 包括：

* credit history
* job
* wealth
* education

Sensitive attribute 是：

$$
A = species
$$

也就是：

* human
* martian

目标是：

> classifier should make fair decisions for both human and martian applicants.

---

## 12. Formal Fairness Criteria

Lecture 22 主要讲四个 fairness criteria：

1. Group Fairness / Demographic Parity
2. Predictive Parity
3. Equal Opportunity
4. Individual Fairness

这几个公式看起来很像，但它们问的问题完全不同。

我可以先记成：

| Fairness criterion  | 主要看什么                                    | 对应 metric           |     |
| ------------------- | ---------------------------------------- | ------------------- | --- |
| Demographic Parity  | positive prediction rate 是否一样            | (P(\hat{Y}=1        | A)) |
| Predictive Parity   | predicted positive 里面真的 positive 的比例是否一样 | PPV / Precision     |     |
| Equal Opportunity   | actual positive 被抓到的比例是否一样               | TPR / Recall / FNR  |     |
| Individual Fairness | 相似 individuals 是否得到相似 predictions        | similarity function |     |

---

## 13. Group Fairness / Demographic Parity

### 13.1 Definition

Group Fairness 也叫 Demographic Parity。

它要求：

> sensitive attribute 和 prediction statistically independent。

公式是：

$$
\hat{Y} \perp A
$$

在 humans vs martians 的 credit scoring example 里：

$$
P(\hat{Y}=1|A=m) = P(\hat{Y}=1|A=h)
$$

意思是：

> Martians 和 Humans 应该有相同概率获得 positive prediction。

如果 (\hat{Y}=1) 表示 grant credit，那么：

> Martians 和 Humans 应该有相同机会拿到 credit。

---

### 13.2 例子

假设：

* 12 个 Martians
* 18 个 Humans

Demographic parity 要求 positive prediction rate 一样。

例如：

$$
\frac{4}{12} = \frac{6}{18} = \frac{1}{3}
$$

这表示：

* 12 个 Martians 里 4 个 grant credit
* 18 个 Humans 里 6 个 grant credit

两个 group 都是三分之一获得 credit。

---

### 13.3 重点：不看 ground truth

Demographic parity 最大特点是：

> 它不看 ground truth label (Y)。

它只关心：

$$
P(\hat{Y}=1|A=m)
$$

和：

$$
P(\hat{Y}=1|A=h)
$$

是否相等。

所以它不管被 grant credit 的人是不是真的 credit-worthy。

这会产生问题：

> model 可能对 majority group 预测 true positives，对 minority group 预测 false positives，但 demographic parity 仍然认为 fair。

例如：

* Humans 被批准的很多人是真的 credit-worthy。
* Martians 被批准的很多人其实不是 credit-worthy。

两个 group positive prediction rate 一样，但对 Martians 的 reputation 可能造成伤害，因为他们更可能被错误批准，然后 default。

所以：

> Demographic parity 简单直观，但可能忽略 prediction quality。

---

### 13.4 什么时候适合用

Demographic parity 适合一些重视 representation 的场景。

例如：

* 每个地区都要选代表。
* 某些 admissions policy 需要保证 group representation。
* 某些 resource allocation 希望不同 groups 有相似 access rate。

但在 credit scoring 这种需要判断真实还款能力的任务里，只用 demographic parity 可能不够。

所以：

> Demographic parity 适合关心 outcome distribution 的场景，但不适合单独用来保证 prediction correctness。

---

## 14. Predictive Parity

### 14.1 Definition

Predictive Parity 要求：

> all groups shall have the same PPV / precision。

也就是：

$$
P(Y=1|\hat{Y}=1,A=m) = P(Y=1|\hat{Y}=1,A=h)
$$

意思是：

> 当 model 预测 positive 时，这个 positive prediction 在 Martians 和 Humans 中应该同样可靠。

在 credit scoring 里：

> 如果 model 决定 grant credit，那么 Martians 和 Humans 里面真正 credit-worthy 的比例应该一样。

---

### 14.2 和 Demographic Parity 的区别

Demographic parity 看的是：

$$
P(\hat{Y}=1|A)
$$

Predictive parity 看的是：

$$
P(Y=1|\hat{Y}=1,A)
$$

这两个方向不同。

Demographic parity 问：

> 每个 group 有多少人被预测为 positive？

Predictive parity 问：

> 被预测为 positive 的人里面，有多少是真的 positive？

所以 predictive parity 开始考虑 ground truth (Y)。

---

### 14.3 例子

假设：

$$
\frac{2}{4} = \frac{3}{6} = \frac{1}{2}
$$

意思是：

* Martians 中 predicted grant credit 的 4 人里，2 人真的 credit-worthy。
* Humans 中 predicted grant credit 的 6 人里，3 人真的 credit-worthy。

两个 group 的 precision 都是 (1/2)。

所以 model 的 positive prediction 对两个 group 一样 reliable。

---

### 14.4 优点

Predictive parity 的优点是：

> 它确保 positive prediction 的 reliability across groups。

如果一个 model 对 Humans 的 positive prediction 很准，但对 Martians 的 positive prediction 很不准，那就是 unfair。

所以它适合关注：

> model 说 yes 的时候，不同 group 的 yes 是否同样可信？

例如：

* high-risk medical prediction
* credit approval
* fraud detection
* admission recommendation

---

### 14.5 缺点

Predictive parity 的缺点是：

> 它可能接受并放大 ground truth 里的 unfairness。

如果 training data 里的 (Y) 本身已经 biased，那么 predictive parity 仍然会把这个 (Y) 当作 truth。

例如 historical credit data 里 Humans 更容易有 good credit score，不一定是因为 Humans 更 trustworthy，可能是因为历史上 Martians 被 less access to banking。

如果 model 直接把这个 historical (Y) 当 truth，predictive parity 可能还是不公平。

所以：

> Predictive parity 比 demographic parity 更看重 correctness，但它依赖 ground truth 的公平性。

---

## 15. Equal Opportunity

### 15.1 Definition

Equal Opportunity 要求：

> all groups have the same TPR，等价于 same FNR。

也就是说，对于真正 positive 的人，不同 group 应该有相同机会被预测为 positive。

公式可以写成：

$$
P(\hat{Y}=1|Y=1,A=m) = P(\hat{Y}=1|Y=1,A=h)
$$

也可以写成：

$$
P(\hat{Y}=0|Y=1,A=m) = P(\hat{Y}=0|Y=1,A=h)
$$

第一条是 same TPR / recall。
第二条是 same FNR。

---

### 15.2 直觉

Equal opportunity 关心的是：

> 真正 qualified 的人，有没有被 model 公平地识别出来？

在 credit scoring 里：

> 真正 credit-worthy 的 Martians 和真正 credit-worthy 的 Humans，应该有相同概率拿到 credit。

这和 recall 有关。

如果 model 经常漏掉 Martians 中真正 credit-worthy 的 applicant，那么 Martians 的 false negative rate 就更高。

这就是 unfair。

---

### 15.3 例子

假设：

$$
\frac{4}{6} = \frac{4}{6} = \frac{2}{3}
$$

意思是：

* Martians 中真正 credit-worthy 的 6 人里，有 4 人被 grant credit。
* Humans 中真正 credit-worthy 的 6 人里，也有 4 人被 grant credit。

两个 group 的 TPR 都是 (2/3)。

所以：

> truly positive 的人，在两个 groups 里有相同机会被 model 抓到。

---

### 15.4 什么时候适合用

Equal opportunity 适合 false negative 很严重的场景。

例如：

* medical diagnosis：真正有病的人不应该被漏掉。
* loan approval：真正 credit-worthy 的人不应该被拒绝。
* scholarship / admission：真正 qualified 的人不应该被错过。
* fraud / safety：真正 high-risk case 不应该被漏掉。

所以：

> Equal opportunity 关心的是不要 miss out on qualified / truly positive people。

---

### 15.5 注意：opportunity 不一定总是好事

Lecture 里特别提醒，opportunity 不一定总是 positive 的东西。

例如 predictive policing 里，positive 可能表示：

$$
arrest
$$

或：

$$
high\ risk
$$

这时 equal opportunity 可能表示：

> truly criminal people across groups should be detected with same TPR。

但这不代表这个 system 本身就 ethical，因为 policing data 和 ground truth 可能有 serious measurement bias。

所以：

> Equal opportunity 是一个 statistical criterion，不自动代表 morally good。

---

### 15.6 缺点

和 predictive parity 一样，equal opportunity 也依赖 ground truth (Y)。

如果 (Y) 本身 biased，那么 equal opportunity 可能也会继承 bias。

例如：

* historical hiring labels biased
* recorded crime biased
* credit-worthiness labels biased by historical access to banking
* medical diagnosis labels biased by access to healthcare

所以：

> Equal opportunity 很适合控制 FNR / recall fairness，但前提是 ground truth 相对可信。

---

## 16. Individual Fairness

### 16.1 Definition

Individual Fairness 不从 group proportion 入手，而是比较 individual applicants。

它的核心思想是：

> similar individuals should receive similar predictions。

公式是：

$$
P(\hat{Y}_i=1|A_i,X_i) \approx P(\hat{Y}_j=1|A_j,X_j)
$$

if：

$$
sim(X_i,X_j) > \theta
$$

意思是：

> 如果两个人在 non-sensitive features (X) 上很相似，那么他们应该得到相似 prediction，不管他们的 protected attribute (A) 是什么。

---

### 16.2 例子

假设一个 Human applicant 和一个 Martian applicant：

* income 类似
* credit history 类似
* job stability 类似
* education 类似
* spending habit 类似

那么 individual fairness 要求：

> 他们应该有类似的 probability of getting credit。

所以 individual fairness 是在说：

> compare apples with apples。

---

### 16.3 优点

Individual fairness 的优点是很符合直觉。

它不是说：

> 每个 group 的比例一样就 fair。

而是说：

> 条件类似的人应该被类似对待。

这更接近日常生活中对 fairness 的理解。

---

### 16.4 难点

Individual fairness 很难 implement，因为它要求我们定义：

$$
sim(X_i,X_j)
$$

也就是 similarity function。

但 similarity 很难定义。

例如 income：

> 一个收入 $100,000 的人和一个收入 $200,000 的人算 similar 吗？

教育：

> Earth 的 bachelor degree 和 Mars 的 technical certificate 算 similar 吗？

job：

> software engineer 和 data analyst 算 similar 吗？

credit history：

> 没有 credit history 是 bad sign，还是因为这个 group historically had less access to banking？

所以：

> Individual fairness 的难点不是公式，而是如何定义 meaningful similarity。

还要选择 threshold：

$$
\theta
$$

也就是：

> similarity 到什么程度才算 similar enough？

所以：

> individual fairness 很 intuitive，但 practical implementation 很难。

---

## 17. 四个 Fairness Criteria 的对比

### 17.1 快速记忆

| Criterion           | Formula                         | 关注点                   | 不看什么            |                          |                 |
| ------------------- | ------------------------------- | --------------------- | --------------- | ------------------------ | --------------- |
| Demographic Parity  | (P(\hat{Y}=1                    | A=m)=P(\hat{Y}=1      | A=h))           | positive prediction rate | 不看 ground truth |
| Predictive Parity   | (P(Y=1                          | \hat{Y}=1,A=m)=P(Y=1  | \hat{Y}=1,A=h)) | precision / PPV          | 不保证 recall      |
| Equal Opportunity   | (P(\hat{Y}=1                    | Y=1,A=m)=P(\hat{Y}=1  | Y=1,A=h))       | recall / TPR / FNR       | 不保证 precision   |
| Individual Fairness | similar (X) → similar (\hat{Y}) | individual similarity | 需要定义 similarity |                          |                 |

---

### 17.2 最容易混淆的地方

Predictive Parity 和 Equal Opportunity 最容易混。

Predictive Parity 是：

$$
P(Y=1|\hat{Y}=1,A)
$$

它是 precision。它问：

> model 预测 positive 的人里面，有多少是真的 positive？

Equal Opportunity 是：

$$
P(\hat{Y}=1|Y=1,A)
$$

它是 recall。它问：

> 真的 positive 的人里面，有多少被 model 找到？

所以一个是：

> given predicted positive

另一个是：

> given actual positive

记忆方式：

> Predictive parity：prediction 出来以后，这个 prediction 是否可信。
> Equal opportunity：真正有资格的人，是否有平等机会被选中。

---

## 18. No Fair Free Lunch

### 18.1 不同 fairness definitions 可能冲突

Lecture 22 很重要的一点是：

> There is no fair free lunch.

不同 fairness criteria 会产生不同 predictions。

例如一个 classifier 如果满足 demographic parity，不一定满足 predictive parity。
满足 predictive parity，也不一定满足 equal opportunity。
满足 equal opportunity，也不一定满足 individual fairness。

在某些情况下，甚至不可能同时满足所有 fairness criteria。

所以不能简单说：

> 这个 model fair，因为它用了一个 fairness metric。

更准确的说法是：

> 这个 model 在某个 fairness definition 下比较 fair，但这不代表它在所有意义上 fair。

---

### 18.2 Fairness 和 performance 也可能 trade-off

有时候加入 fairness constraint 会降低 overall accuracy。

例如原本 model 为了 maximize accuracy，可能更关注 majority group。加入 group-level fairness constraint 后，可能 overall accuracy 会下降，但 minority group harm 减少。

所以要权衡：

* overall performance
* group-level performance
* false positive cost
* false negative cost
* legal / ethical constraints
* deployment context

所以：

> fairness 不是一个纯 technical optimization problem，而是 technical + ethical + domain-specific decision。

---

## 19. How to Create Fairer Classifiers

Lecture 最后讲如何让 classifier 更 fair。主要有三类方法：

1. Pre-processing
2. Training / Optimization
3. Post-processing

可以这样记：

| Stage                   | 做什么                            | 例子                       |
| ----------------------- | ------------------------------ | ------------------------ |
| Pre-processing          | train 之前改 data                 | balancing, re-weighting  |
| Training / Optimization | train 的时候加 fairness constraint | constrained optimization |
| Post-processing         | train 完之后改 predictions         | threshold adjustment     |

---

## 20. Pre-processing

### 20.1 Balancing the dataset

最简单的方法是 balance dataset。

如果 minority group 太少，可以：

> up-sample minority group

例如 Martians 少，就增加 Martians samples。

如果 majority group 太多，可以：

> down-sample majority group

例如 Humans 太多，就减少 Humans samples。

所以：

$$
minority\ group \uparrow
$$

或：

$$
majority\ group \downarrow
$$

---

### 20.2 为什么 balancing 有用

如果 dataset 里 Humans 很多，Martians 很少，model training 会更受 Humans pattern 影响。

结果可能是：

> model 对 Humans 学得很好，对 Martians 学得很差。

Balancing 可以让 model 在 training 时看到更多 minority group examples。

所以：

> balancing 主要解决 representation imbalance。

---

### 20.3 Re-weighting

除了 duplicate 或 remove samples，还可以 re-weight instances。

核心想法是：

> 让 observed distribution 更接近 expected fair distribution。

如果我们希望：

$$
A \perp Y
$$

也就是 sensitive attribute 和 label independent，那么 expected distribution 是：

$$
P_{exp}(A=a,Y=1)
=

P(A=a) \times P(Y=1)
$$

可以用 counts 估计：

$$
P_{exp}(A=a,Y=1)
=

\frac{#(A=a)}{|D|}
\times
\frac{#(Y=1)}{|D|}
$$

Observed distribution 是：

$$
P_{obs}(A=a,Y=1)
=

\frac{#(Y=1,A=a)}{|D|}
$$

然后每个 instance 的 weight 是：

$$
W(X_i={x_i,a_i,y_i})
=

\frac{
P_{exp}(A=a_i,Y=y_i)
}{
P_{obs}(A=a_i,Y=y_i)
}
$$

意思是：

> 如果某类组合在 observed data 里太少，就给更高 weight。
> 如果某类组合在 observed data 里太多，就给更低 weight。

---

### 20.4 Pre-processing 的优缺点

优点：

* 简单
* 不需要改 model
* 可以和很多 classifier 一起用
* 容易理解和 implement

缺点：

* 如果 label (Y) 本身 biased，balancing 不一定解决问题
* up-sampling 可能 overfit minority samples
* down-sampling 会丢掉 data
* re-weighting 需要合理定义 expected distribution

所以：

> pre-processing 是最直接的方法，但不是万能的。

---

## 21. Training / Optimization

### 21.1 基本想法

Training-time mitigation 是在 model training 时直接加入 fairness constraint。

普通 logistic regression 可能只是 minimize loss：

$$
\min \mathcal{L}(\theta)
$$

其中：

$$
\mathcal{L}(\theta)
$$

是 loss function。

如果要 enforce demographic parity，可以改成：

$$
\min \mathcal{L}(\theta)
$$

subject to：

$$
P(\hat{Y}=1|A=m)=P(\hat{Y}=1|A=h)
$$

意思是：

> 在 minimize loss 的同时，也要求 Martians 和 Humans 有相同 positive prediction rate。

---

### 21.2 为什么这个方法强

这个方法的优点是：

> fairness is directly added to the training procedure。

它不是 train 完再补救，而是从一开始就把 fairness 加进 model objective。

所以 model 会在 learning parameters 时考虑 fairness。

---

### 21.3 难点

缺点是：

> optimization problem becomes more complex。

原本只需要 minimize loss，现在还要满足 constraints。

这可能导致：

* optimization 更难
* computation cost 更高
* constraint 不一定容易写成 differentiable form
* fairness 和 accuracy 之间有 trade-off
* 多个 fairness constraints 可能冲突

所以：

> training-time fairness 很 principled，但 implementation 比 pre-processing 更难。

---

## 22. Post-processing

### 22.1 基本想法

Post-processing 是 model 已经 train 好以后，再修改 predictions。

例如 binary classifier 通常有 score：

$$
w \cdot x_i
$$

然后用 threshold：

$$
\theta
$$

做 decision：

$$
\hat{y}_i = 1 \quad \text{if } w \cdot x_i > \theta
$$

$$
\hat{y}_i = 0 \quad \text{if } w \cdot x_i \le \theta
$$

如果默认 threshold 是 0.5，我们可以调整 threshold 来改变：

* PPV
* TPR
* FNR
* positive prediction rate

---

### 22.2 Difficult instances

Lecture 也提到可以对 difficult instances 使用 special strategy。

Difficult instances 是指：

$$
P(\hat{y}_i) \approx 0.5
$$

也就是 model 很 uncertain 的 cases。

对于这些 cases，可以：

* 交给 human review
* 使用不同 threshold
* 要求更多 evidence
* 暂缓 automatic decision

所以：

> post-processing 可以在 decision stage 控制 fairness behaviour。

---

### 22.3 优点

Post-processing 的优点是：

* model-independent
* 不需要 retrain
* 可以用于 black-box / proprietary models
* 可以用于 API output
* implementation 相对容易

例如如果你只能访问一个 black-box model 的 prediction score，不能 access model weights，也不能 retrain，那么 post-processing 仍然可用。

所以：

> post-processing 很适合不能改 model 的场景。

---

### 22.4 缺点

Post-processing 的主要缺点是：

> needs access to protected attribute at test time。

也就是说，在 prediction 阶段你可能还需要知道 applicant 是 Martian 还是 Human，才能调整 threshold 或 decision。

这可能带来 legal / ethical / privacy 问题。

另外，post-processing 也可能被质疑：

> 为什么不同 groups 用不同 threshold？

所以它虽然 practical，但需要 careful justification。

---

## 23. 三类 mitigation 方法对比

| Method                  | Stage      | 优点                              | 缺点                               |
| ----------------------- | ---------- | ------------------------------- | -------------------------------- |
| Pre-processing          | training 前 | 简单，不改 model                     | label bias 仍可能存在                 |
| Training / Optimization | training 中 | fairness 直接进入 objective         | optimization 更复杂                 |
| Post-processing         | training 后 | model-independent，可用于 black-box | test time 需要 protected attribute |

可以这样记：

> Pre-processing 改 data。
> Training 改 objective。
> Post-processing 改 decision。

---

## 24. 如何选择 Fairness Metric

### 24.1 先问 false positive 和 false negative 哪个更严重

选择 fairness metric 时，不能只看公式。要先问：

> 哪种 error harm 更大？

如果 false negative 更严重，例如 medical diagnosis 漏掉病人，那应该重视：

$$
TPR / Recall / FNR
$$

也就是 equal opportunity。

如果 false positive 更严重，例如错误把 innocent person 标记为 criminal，那应该重视：

$$
FPR
$$

虽然这节课主要讲 equal opportunity，但现实中也会考虑 equalized odds 或 FPR parity。

如果 positive prediction 的 reliability 很重要，例如 loan approval 或 high-risk medical label，那应该重视：

$$
PPV / Precision
$$

也就是 predictive parity。

---

### 24.2 再问 ground truth 是否可信

如果 (Y) 是 biased historical label，那么 predictive parity 和 equal opportunity 都要小心。

例如：

* historical hiring decision
* historical policing record
* historical credit score
* past medical diagnosis record

这些 label 可能不是 objective truth，而是 past biased system 的 output。

所以：

> 如果 ground truth 不可信，基于 (Y) 的 fairness metric 也可能继承 bias。

---

### 24.3 再问 task 是否需要 representation

如果 task 重点是 representation 或 resource allocation，而不是 prediction accuracy，那么 demographic parity 可能有意义。

例如：

* 每个地区分配代表
* admission policy 中考虑 underrepresented groups
* public resource access

但如果 task 是 credit risk prediction，只看 demographic parity 可能不够。

---

### 24.4 再问能否定义 similarity

如果可以合理定义 similarity function，那么 individual fairness 很有吸引力。

但如果 similarity 很难定义，就很难 implement。

例如：

* job similarity
* education equivalence
* income similarity
* health status similarity
* credit history similarity

都不是完全 objective 的。

所以：

> individual fairness 的关键是 similarity function 是否合理。

---

## 25. 应用场景分析

### 25.1 Credit scoring

Credit scoring 中：

* false positive：给不该拿贷款的人贷款，bank 可能损失，applicant 也可能陷入 debt。
* false negative：拒绝真正 credit-worthy 的人，造成 unfair exclusion。

如果关心真正 qualified applicants 不被漏掉，可以用：

$$
Equal\ Opportunity
$$

如果关心被批准的人确实可靠，可以用：

$$
Predictive\ Parity
$$

如果关心不同 groups 的 approval rate，可以用：

$$
Demographic\ Parity
$$

但要注意 credit-worthiness 本身可能受到历史不平等影响，所以 (Y) 不一定完全 fair。

---

### 25.2 Medical diagnosis

Medical diagnosis 中，false negative 通常非常严重。

例如一个人真的有病，但 model 预测没病，这可能导致延误治疗。

所以通常要关注：

$$
TPR
$$

和：

$$
FNR
$$

也就是 Equal Opportunity。

但 false positive 也可能有 harm，例如不必要治疗、心理压力、资源浪费。因此不能只看 recall，还要看 precision。

所以 medical fairness 通常需要 multiple metrics。

---

### 25.3 Predictive policing

Predictive policing 特别危险，因为 data 可能有强 measurement bias。

Recorded crime 不等于 true crime。

如果某个地区本来被 patrol 更多，recorded crime 会更多。model 看到更多 crime data，就建议更多 patrol。于是形成 feedback loop。

所以在 predictive policing 里，不能只说：

> model accuracy high。

还要问：

* data 是怎么 collected 的？
* recorded crime 是否是 biased proxy？
* 哪些 groups 承受更多 false positives？
* deployment 会不会放大历史不平等？

---

### 25.4 College admission

College admission 中，demographic parity 可能用于 representation，因为不同 groups 的 scores 可能受 unequal social environment 影响。

但如果只看 historical admission labels，可能继承过去 admission bias。

所以可能需要结合：

* demographic parity
* individual fairness
* contextual information
* domain-specific policy

这说明 fairness 不是一个公式能解决的。

---

## 26. 和之前 Lectures 的连接

### 26.1 和 Evaluation 的连接

Lecture 10 和 11 讲过 accuracy、precision、recall、F-score、bias-variance、generalization。

Lecture 22 把这些 evaluation metrics 放到 group fairness 里。

以前我们问：

> classifier overall precision 是多少？
> classifier overall recall 是多少？

现在我们还要问：

> Martians 的 precision 是多少？
> Humans 的 precision 是多少？
> Martians 的 recall 是多少？
> Humans 的 recall 是多少？
> 不同 groups 的 FNR 是否相同？

所以：

> fairness evaluation 是 evaluation 的 extension，只是它要求 group-level analysis。

---

### 26.2 和 Feature Selection 的连接

Feature selection 里我们会选择 useful attributes。但 Lecture 22 提醒：

> useful feature 不一定 ethical。

例如 postcode 可能对 credit prediction 很 useful，但它也可能是 race / income 的 proxy。

所以做 feature selection 时要问：

> 这个 feature 是否直接或间接 encode protected attribute？

这就是 fairness 和 feature engineering 的连接。

---

### 26.3 和 Loss Function 的连接

前面 logistic regression、neural network 里我们学了 loss function 和 optimization。

Lecture 22 里，fairness 可以作为 constraint 加进 optimization：

$$
\min \mathcal{L}(\theta)
$$

subject to fairness condition。

所以：

> fairness 可以被 formalized 成 optimization constraint。

---

### 26.4 和 Deployment 的连接

前面很多 lecture 偏 train/test split 和 model performance，但 Lecture 22 强调：

> model deployment 会改变 world。

这和 feedback loop 有关。

一个 model 在 test set 上 fair，不代表 deployed 后一直 fair。因为 model 的 decision 会改变 future data distribution。

所以：

> fairness 不是一次 evaluation 完就结束，而是需要 deployment monitoring。

---

## 27. Exam / Assignment 重点

### 27.1 必须会区分四个 criteria

考试里很可能给一个 scenario，然后问应该用哪个 fairness metric。

你要能快速判断：

Demographic Parity：

$$
P(\hat{Y}=1|A=m)=P(\hat{Y}=1|A=h)
$$

看 positive prediction rate。

Predictive Parity：

$$
P(Y=1|\hat{Y}=1,A=m)=P(Y=1|\hat{Y}=1,A=h)
$$

看 precision / PPV。

Equal Opportunity：

$$
P(\hat{Y}=1|Y=1,A=m)=P(\hat{Y}=1|Y=1,A=h)
$$

看 recall / TPR / FNR。

Individual Fairness：

$$
sim(X_i,X_j)>\theta
\Rightarrow
\hat{Y}_i \approx \hat{Y}_j
$$

看 similar individuals 是否得到 similar prediction。

---

### 27.2 必须会解释 Fairness Through Unawareness 的问题

重点句：

> Removing sensitive attributes does not guarantee fairness because protected information can leak through correlated proxy features.

例如：

* postcode
* education
* school
* income
* job type
* language use

都可能 encode protected attribute。

所以：

> fairness through unawareness is usually insufficient.

---

### 27.3 必须会解释 no fair free lunch

重点句：

> Different fairness criteria can lead to different predictions, and it may be impossible to satisfy all fairness definitions simultaneously.

所以回答时不要写：

> fairness means equal prediction rates。

更好的写法是：

> fairness depends on the selected criterion and the harm we want to reduce.

---

### 27.4 必须会比较 mitigation methods

Pre-processing：

> modify data before training, e.g., up-sampling, down-sampling, re-weighting.

Training / Optimization：

> include fairness constraints in the optimization objective.

Post-processing：

> modify predictions or thresholds after model training.

---

## 28. Lecture 22 最重要的公式

### 28.1 Fairness through Unawareness

$$
P(\hat{Y}_n|X_n,A_n) \approx P(\hat{Y}_n|X_n)
$$

意思是：

> prediction 不应该依赖 sensitive attribute。

但这个方法的问题是 proxy leakage。

---

### 28.2 Demographic Parity

$$
\hat{Y} \perp A
$$

$$
P(\hat{Y}=1|A=m)=P(\hat{Y}=1|A=h)
$$

意思是：

> 不同 groups 有相同 positive prediction rate。

---

### 28.3 Predictive Parity

$$
P(Y=1|\hat{Y}=1,A=m)
=

P(Y=1|\hat{Y}=1,A=h)
$$

意思是：

> predicted positive 的 correctness 在不同 groups 中一样。

---

### 28.4 Equal Opportunity

$$
P(\hat{Y}=1|Y=1,A=m)
=

P(\hat{Y}=1|Y=1,A=h)
$$

或：

$$
P(\hat{Y}=0|Y=1,A=m)
=

P(\hat{Y}=0|Y=1,A=h)
$$

意思是：

> truly positive 的人，在不同 groups 中有同样机会被预测为 positive。

---

### 28.5 Individual Fairness

$$
P(\hat{Y}_i=1|A_i,X_i)
\approx
P(\hat{Y}_j=1|A_j,X_j)
$$

if：

$$
sim(X_i,X_j) > \theta
$$

意思是：

> features similar 的 individuals 应该得到 similar classifier scores。

---

### 28.6 Re-weighting

Expected distribution：

$$
P_{exp}(A=a,Y=1)
=

P(A=a) \times P(Y=1)
$$

Observed distribution：

$$
P_{obs}(A=a,Y=1)
=

\frac{#(Y=1,A=a)}{|D|}
$$

Weight：

$$
W(X_i={x_i,a_i,y_i})
=

\frac{
P_{exp}(A=a_i,Y=y_i)
}{
P_{obs}(A=a_i,Y=y_i)
}
$$

意思是：

> observed data 里 underrepresented 的组合给更高 weight，overrepresented 的组合给更低 weight。

---

### 28.7 Fairness-constrained Optimization

普通 training：

$$
\min \mathcal{L}(\theta)
$$

加入 demographic parity：

$$
\min \mathcal{L}(\theta)
$$

subject to：

$$
P(\hat{Y}=1|A=m)=P(\hat{Y}=1|A=h)
$$

意思是：

> minimize loss 的同时 enforce fairness condition。

---

### 28.8 Threshold Post-processing

$$
\hat{y}_i=1 \quad \text{if } w \cdot x_i > \theta
$$

$$
\hat{y}_i=0 \quad \text{if } w \cdot x_i \le \theta
$$

意思是：

> 通过调整 threshold 改变 classifier 的 PPV、TPR、FNR 或 positive rate。

---

## 29. Lecture 22 总结

Lecture 22 的核心是：

> ML systems can reproduce and amplify social bias. Fairness must be measured formally, but no single fairness definition is always correct.

我需要重点记住：

Bias 可以来自 human bias、historical bias、representation bias、reporting bias、measurement bias、model bias、loss function bias、evaluation bias 和 deployment bias。

Human bias 会进入 human-generated data。
Correlation 不代表 causation。
Historical data 可能准确反映过去，但过去本身可能不公平。
Representation bias 是 dataset 没有代表整体 population。
Reporting bias 是 recorded / reported events 不代表 real-world frequency。
Measurement bias 经常来自用 proxy label 代替真正 target。
Model bias 可能来自 model assumptions 或 proxy features。
Loss function bias 可能来自 imbalanced data 和 majority-class dominance。
Evaluation bias 可能来自 unrepresentative test set 或只看 average metrics。
Deployment bias 可能来自 model 被错误使用。
Feedback loop 会让 model decision 改变 future data，然后进一步放大 bias。
Sensitive attribute 是可能导致 discrimination 的 protected attribute。
(X) 是 non-sensitive features。
(A) 是 sensitive attribute。
(Y) 是 true label。
(\hat{Y}) 是 predicted label。
Fairness through unawareness 是删除 sensitive attribute。
Fairness through unawareness 不够，因为 protected information 可以通过 proxy features leak。
Confusion matrix 里的 TP、FP、FN、TN 是 fairness metrics 的基础。
Precision / PPV 是 (TP/(TP+FP))。
Recall / TPR 是 (TP/(TP+FN))。
FNR 是 (FN/(TP+FN)=1-TPR)。
Demographic parity 要求 positive prediction rate across groups 一样。
Demographic parity 不看 ground truth。
Predictive parity 要求 precision / PPV across groups 一样。
Predictive parity 看 predicted positive 是否真的 positive。
Equal opportunity 要求 TPR / FNR across groups 一样。
Equal opportunity 看 truly positive 是否被公平识别。
Individual fairness 要求 similar individuals receive similar predictions。
Individual fairness 很 intuitive，但需要定义 similarity function 和 threshold。
不同 fairness criteria 会产生不同 prediction。
有时不可能同时满足所有 fairness criteria。
Fairness 和 overall performance 可能 trade-off。
Pre-processing 在 training 前处理 data，例如 balancing 和 re-weighting。
Training / optimization 在 loss optimization 中加入 fairness constraint。
Post-processing 在 model train 完之后调整 prediction 或 threshold。
Pre-processing 改 data。
Training 改 objective。
Post-processing 改 decision。
选择 fairness metric 要看 task context、protected group、ground truth 是否可信，以及 false positive / false negative 哪个 harm 更大。

一句话总结：

> Lecture 22 讲的是：bias 可以从现实世界、数据、模型、evaluation 和 deployment 中产生；fairness 可以用 demographic parity、predictive parity、equal opportunity 和 individual fairness 来 formalize；但不同 fairness definitions 会冲突，所以 mitigation 需要结合具体任务，通过 pre-processing、training constraints 或 post-processing 来减少 unfair harm。
