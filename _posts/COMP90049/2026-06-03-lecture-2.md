# Lecture 2：Machine Learning Concepts

## 1. 从 “Learning” 到 “Data Representation”

Lecture 1 主要介绍了 Machine Learning 的整体概念，而 Lecture 2 开始真正定义：

> ML 到底在学习什么，以及 data 应该如何表示。

课程一开始重新强调：

> Machine Learning 本质上是 learning from examples。

也就是说，模型不是凭空学习，而是从 dataset 中的 instances 学习 pattern。为了让模型能够处理 data，我们必须先统一 data 的表示方式，因此 Lecture 2 的重点开始转向：

* instance
* feature
* concept
* learning paradigm
* data type

这些是后面所有 ML model 的基础。

---

## 2. Instance、Feature 和 Concept

Lecture 2 最核心的内容之一，是定义 dataset 的结构。

课程把 dataset 看成一个 table：

| Outlook | Temperature | Humidity | Windy | Play |
| ------- | ----------- | -------- | ----- | ---- |
| Sunny   | Hot         | High     | False | No   |

这里每一行叫做：

> Instance

代表一个 example。

每一列叫做：

> Feature / Attribute

代表 instance 的某个性质。

而我们想预测的那一列：

> Play

则称为：

> Concept / Label

课程强调：

> Machine Learning 本质上是在学习 feature 和 concept 之间的关系。

---

## 3. Learning Paradigm

Lecture 2 开始正式区分不同 learning paradigms。

### 3.1 Supervised Learning

Supervised Learning 使用：

> Labelled data

也就是 dataset 中每个 input 都有对应 output：

[
(x, y)
]

模型目标是学习：

[
x \rightarrow y
]

例如：

* Email → Spam / Not Spam
* House Features → House Price

课程中提到：

> Supervised learning 的目标是对 unseen instance 做 prediction。

而 supervised learning 又可以分成：

* Classification
* Regression

---

### 3.2 Unsupervised Learning

Unsupervised Learning 使用：

> Unlabelled data

也就是说 dataset 里面只有 features，没有 label。

因此模型不能直接学习正确答案，而是尝试：

> 自动发现 data 中隐藏的 structure。

例如：

* Clustering
* Anomaly Detection
* Market Basket Analysis

Lecture 2 特别强调：

> Clustering 的 evaluation 通常比较困难，因为没有 ground truth label。

---

### 3.3 Semi-supervised Learning

课程也 briefly 提到：

> Semi-supervised learning 同时使用 labelled 与 unlabelled data。

这种情况通常发生在：

* label 很少
* label 很贵
* unlabelled data 很多

例如：

只有少量人工标记的 medical image，但有大量未标记数据。

---

## 4. Classification、Regression 和 Clustering

Lecture 2 接着区分不同 learning task。

### 4.1 Classification

Classification 是：

> Predicting discrete labels.

例如：

* Spam / Not Spam
* Fraud / Normal
* Play / Not Play

课程强调：

> classification 的 output 是有限类别。

因此 evaluation 通常是：

* correct / incorrect

---

### 4.2 Regression

Regression 是：

> Predicting continuous numerical values.

例如：

* Stock price
* Temperature
* House price

课程指出：

> Regression 和 classification 最大差别在于，regression 的 output 可能有无限多种数值。

因此 regression 更关注：

> prediction 是否 sufficiently close。

而不是完全正确。

---

### 4.3 Clustering

Clustering 属于 unsupervised learning。

目标是：

> 将相似 instance grouping 在一起。

例如：

* Customer Segmentation
* Student Grouping
* Similar Stock Behaviour

课程特别提到：

> clustering 并不知道正确答案，它只是尝试寻找 similarity structure。

---

## 5. Feature Vector

Lecture 2 开始把 instance 表示成：

> Feature Vector

例如：

Fruit:

* Color
* Shape
* Sweetness

可以写成：

[
x = [color, shape, sweetness]
]

后面的模型，例如：

* KNN
* Logistic Regression
* SVM

都会把 instance 表示成 vector 进行计算。

因此：

> Feature vector 是 ML 中统一的数据表示方式。

---

## 6. Data Types

Lecture 2 很强调：

> 不同 feature type 会影响 model 的使用方式。

因此课程开始区分 feature data types。

---

### 6.1 Nominal

Nominal data 是：

> 没有顺序关系的 category。

例如：

* red
* blue
* green

课程强调：

> nominal feature 只能比较 equality，不能比较大小。

例如：

[
red > blue
]

没有意义。

---

### 6.2 Ordinal

Ordinal data 是：

> 有顺序关系，但没有固定距离的 category。

例如：

* low
* medium
* high

课程特别指出：

> ordinal data 可以排序，但不能做数学运算。

例如：

[
high - low
]

并没有实际意义。

---

### 6.3 Numerical

Numerical data 是：

> 具有真实数学意义的数值。

例如：

* temperature
* weight
* stock price

Numerical feature 可以：

* addition
* subtraction
* multiplication
* distance calculation

这类 feature 后面会广泛用于：

* distance-based learning
* regression
* optimisation

---

## 7. Encoding 与 Data Transformation

Lecture 2 的后半段开始讨论一个非常现实的问题：

> 即使我们已经有 data，model 也不一定能直接使用。

原因是：

> 不同 machine learning model 对 data type 有不同要求。

例如：

* Logistic Regression
* Linear Regression
* Neural Network
* SVM

这些 model 本质上都需要 numerical computation，因此：

> categorical feature 通常不能直接输入 model。

因此课程开始讨论：

* 如何把 nominal data 转换成 numerical representation
* 如何把 numerical data 转换成 category
* 如何让 feature 更适合 model 使用

也就是说：

> ML 不只是 train model，更多时候是在处理 data representation。

---

### 7.1 One-hot Encoding

Lecture 2 提出：

> 不能直接把 nominal category 随便编号。

例如：

| Color |
| ----- |
| Red   |
| Blue  |
| Green |

如果直接写成：

| Color |
| ----- |
| 0     |
| 1     |
| 2     |

模型可能会误以为：

[
Green > Blue > Red
]

甚至会认为：

[
Green - Red = 2
]

但实际上：

> nominal feature 本身没有大小关系。

Red 并不“大于” Blue。

因此课程提出：

> One-hot Encoding

把每个 category 拆成独立 binary feature：

| Red | Blue | Green |
| --- | ---- | ----- |
| 1   | 0    | 0     |

这样模型只会知道：

> 这个 instance 属于哪个 category。

而不会产生错误的 ordinal relationship。

---

Lecture 2 同时强调：

> One-hot encoding 的代价是 dimensionality increase。

例如：

如果一个 feature 有：

* 5 个 categories

会变成：

* 5 个新的 columns

如果 category 很多，例如：

* postcode
* product id
* movie id

feature dimension 会快速爆炸。

这会造成：

> Sparsity

也就是：

> dataset 大部分值都是 0。

例如：

| Red | Blue | Green |
| --- | ---- | ----- |
| 1   | 0    | 0     |
| 0   | 1    | 0     |
| 0   | 0    | 1     |

每一行大部分 feature 都是 0。

课程后面很多 model，例如：

* KNN
* SVM
* Neural Network

都会受到 high dimensional sparse data 的影响。

因此：

> Data representation 会直接影响 model performance。

---

### 7.2 Discretisation / Binning

Lecture 2 接着讨论相反的问题：

> 如果 data 是 numerical，我们能不能把它变成 category？

这个过程叫：

> Discretisation / Binning

例如：

House Price：

| Price |
| ----- |
| 100K  |
| 500K  |
| 2M    |

可以转换成：

| Category |
| -------- |
| Low      |
| Medium   |
| High     |

课程强调：

> Binning 本质上是在降低 data resolution。

也就是说：

原本连续的数值，会被压缩成有限区间。

---

Lecture 2 提到一种最简单的方法：

> Equal-width binning

也就是：

> 把数值范围平均切成几个 intervals。

例如：

[
0 \sim 100
]

切成：

* 0–25
* 25–50
* 50–75
* 75–100

这样 continuous variable 就会变成 ordinal category。

---

课程同时暗示：

> Binning 有好处，也有代价。

好处：

* 降低 noise
* 更容易解释
* 某些 model 更稳定

例如：

年龄：

18 vs 19

差距可能没那么重要。

但：

“Teenager” vs “Adult”

可能更有意义。

---

但坏处是：

> 会丢失 information。

例如：

| Original |
| -------- |
| 49       |
| 50       |

如果 bin boundary 在 50：

| Category |
| -------- |
| Low      |
| High     |

两个非常接近的值， suddenly 被分到不同 group。

因此：

> Discretisation 是一种 simplification。

它让 model 更简单，但也可能损失 detail。

---

## 8. Real World Data Problems

Lecture 2 最后开始把 focus 从 “ideal data” 转向：

> Real-world data。

课程强调：

> 真正的 dataset 几乎永远不是干净的。

可能会出现：

* missing value
* noisy data
* inaccurate data
* inconsistent data
* duplicated data
* outlier

因此：

> 实际 Machine Learning project 很多时间并不是在 train model，而是在 cleaning data。

---

### 8.1 Missing Value

例如：

| Age | Income |
| --- | ------ |
| 25  | ?      |

某些 feature 可能缺失。

课程开始让学生思考：

> model 无法直接处理 missing value。

因此必须决定：

* 删除 instance
* 删除 feature
* 用平均值填补
* 用 median 填补
* 用 model prediction 填补

这个过程叫：

> Imputation

---

### 8.2 Noisy Data

Lecture 2 也提到：

> data 可能包含错误 measurement。

例如：

* sensor error
* typo
* human annotation mistake

股票里也很常见：

* flash crash spike
* bad tick data
* delayed trade

课程希望学生开始意识到：

> dataset 不一定等于 reality。

因此：

> preprocessing 是 Machine Learning pipeline 的重要部分。

---

### 8.3 Why Data Preprocessing Matters

Lecture 2 的真正重点其实是：

> Model performance 不只来自 algorithm，本质上更来自 data quality。

很多时候：

* wrong encoding
* poor scaling
* missing values
* noisy features

会比 model choice 更影响结果。

因此：

> “Garbage in, garbage out.”

如果 data representation 错误，即使使用复杂 model，也无法得到好的 prediction。

---

## 9. Lecture Summary

Lecture 2 后半段的核心，其实是在建立：

> Data representation 与 preprocessing 的概念。

重点包括：

* nominal feature 不能直接编号
* one-hot encoding 可以避免错误 ordering
* one-hot encoding 会增加 dimensionality 与 sparsity
* discretisation 可以把 continuous value 转成 category
* binning 会降低 noise，但也会丢失 information
* real-world data 通常不完美
* preprocessing 是 ML pipeline 的重要部分

课程开始让学生意识到：

> Machine Learning 并不只是 “选 model”。

更多时候：

> 真正困难的是如何正确表示与处理 data。
