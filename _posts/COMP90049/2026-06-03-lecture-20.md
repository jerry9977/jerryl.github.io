# Lecture 20：半监督学习与主动学习

## Semi-Supervised and Active Learning

## 1. 这节课在回答什么问题

### 1.1 从 supervised 和 unsupervised 的中间地带开始

前面 Lecture 19 讲了 unsupervised learning，例如 clustering。Unsupervised learning 的特点是：我们没有 labels，只能让 model 自己从 data 里面找 structure。

但问题是：

> model 找到的 structure 不一定是我们真正想要的 class。

例如 clustering 可能把数据分成几个 group，但这些 group 不一定对应人类能理解的类别，也不一定对 downstream task 有用。

Supervised learning 相反。它有 labelled data，所以目标很清楚，也容易 evaluate。我们知道 true label，然后看 prediction 对不对。

但 supervised learning 最大的问题是：

> labelled data 很贵，而且通常很少。

所以 Lecture 20 的核心问题是：

> 如果 labelled data 很少，但 unlabelled data 很多，我们怎么利用这些 unlabelled data？

这节课给了四个方向：

* Semi-supervised learning
* Active learning
* Data augmentation
* Pre-training and self-supervised learning

我可以这样理解：

> Lecture 20 不是在讲一个单独 classifier，而是在讲 label scarce 的情况下怎么更聪明地用 data。

---

## 2. 为什么 labelled data 是 bottleneck

### 2.1 Label 为什么贵

在 real-world ML 里面，unlabelled data 通常很多。比如 images、text、logs、sensor readings 都可以大量收集。

但是 labelled data 很少，因为 label 可能需要：

* 人工标注
* domain expert
* medical diagnosis
* legal judgement
* privacy-sensitive access
* special devices or experiments

例如医院数据里，raw measurements 可能很多，但 diagnosis label 可能需要医生确认。

所以 data 的问题不是“没有 data”，而是：

> 有很多 data，但没有 enough reliable labels。

---

### 2.2 Humans 是怎么学的

Lecture 用小孩学 cat 的例子解释。

小孩不会看到每一只猫都被父母标注：

> this is a cat

他们可能只听过几次 “look, it’s a cat”，然后通过大量观察，自己学会不同猫之间的共同特征。

胖猫、瘦猫、长毛猫、短毛猫、卡通 Hello Kitty，看起来不一样，但小孩还是能 generalise 出 “catness”。

所以人类学习不是 pure supervised，也不是 pure unsupervised，而是：

> 少量 labelled examples + 大量 unlabelled observations。

这正是 semi-supervised learning 想模仿的东西。

---

## 3. Supervised vs Unsupervised vs Semi-supervised

### 3.1 Supervised Learning

Supervised learning 有 labelled data。

形式上：

$$
D = {(x_i, y_i)}_{i=1}^{n}
$$

其中：

* (x_i) 是 instance / features
* (y_i) 是 label

目标是学一个 classifier：

$$
f(x) \rightarrow y
$$

优点：

* 目标明确
* evaluation 清楚
* 可以直接计算 accuracy、precision、recall 等 metrics

缺点：

* labelled data expensive
* label 可能少
* label 由人类定义，可能带入 human assumption

我可以这样记：

> supervised learning 清楚，但 label 贵。

---

### 3.2 Unsupervised Learning

Unsupervised learning 没有 label。

形式上：

$$
D = {x_i}_{i=1}^{n}
$$

目标是发现 data 里面的 hidden structure，例如 clusters。

优点：

* data abundant
* 不需要人工 label
* 可能发现新的 pattern

缺点：

* 结果难解释
* cluster 不一定等于 class
* evaluation 很困难
* model 可能找到 useless structure

我可以这样记：

> unsupervised learning 便宜，但 interpretation 难。

---

### 3.3 Semi-supervised Learning

Semi-supervised learning 介于两者之间。

它同时有：

$$
L = {(x_i, y_i)}_{i=1}^{l}
$$

和：

$$
U = {x_i}_{i=l+1}^{l+u}
$$

通常：

$$
U \gg L
$$

也就是说，unlabelled data 远多于 labelled data。

目标是：

> 用 (L \cup U) 训练出比只用 (L) 更好的 classifier。

所以：

> semi-supervised learning = 少量 labelled data + 大量 unlabelled data。

---

## 4. Semi-supervised Learning 的基本想法

### 4.1 用 unlabelled data 帮助 supervised model

如果只有 labelled data，model 可能因为 data 太少而 overfit。

如果加上 unlabelled data，model 至少可以知道 data distribution 的 shape。

例如：

labelled points 只有几个，但 unlabelled points 可以告诉我们：

* 哪些 points 靠得近
* 哪些 regions 很 dense
* 哪些 regions 很 sparse
* class boundary 大概不应该穿过 dense region

Semi-supervised learning 的基本 assumption 是：

> similar points are likely to have the same label。

也就是：

> 靠近的 points 通常应该属于同一个 class。

这个 assumption 不一定永远对，但在很多 practical cases 里是有用的。

---

## 5. Clustering + Majority Voting

### 5.1 最 naive 的做法

最简单的 semi-supervised 方法是：

1. 把 labelled + unlabelled data 一起 cluster。
2. 看每个 cluster 里面 labelled examples 的 majority label。
3. 把这个 majority label 分配给 cluster 里面所有 unlabelled examples。

例如：

一个 cluster 里面 labelled points 大多数是 cat，那么这个 cluster 里的 unlabelled points 也标成 cat。

这个方法的直觉是：

> 同一个 cluster 里的 examples 应该比较 similar，所以 label 也应该一样。

---

### 5.2 为什么这个方法可能很差

这个方法的问题是：

> cluster 不一定等于 class。

Clustering 只是根据 similarity 分组，但 similarity 的定义可能和 label 没有关系。

例如：

如果用 image brightness 做 clustering，model 可能把所有暗色图片放在一起，但这不代表它们是同一个 object class。

常见问题包括：

* outliers
* cluster shape 不规则
* wrong distance metric
* wrong number of clusters
* labelled points 太少，majority label 不可靠
* clusters 和 actual classes 不一致

所以：

> clustering + majority voting 是一个直观但危险的 idea。

我自己的理解：

> clustering 只能告诉我们“哪些东西看起来靠近”，不能保证“它们的 label 一样”。

---

## 6. Self-training / Bootstrapping

### 6.1 Self-training 是什么

Self-training 是这节课最重要的 semi-supervised 方法。

它也叫 bootstrapping。

核心想法：

> 先用少量 labelled data 训练 model，然后让 model 给 unlabelled data 打 pseudo-label。只把 high-confidence pseudo-label 加回 labelled set。

所以 model 会逐渐扩大自己的 training data。

---

### 6.2 Self-training Algorithm

Self-training 的流程是：

1. Start with labelled set (L) and unlabelled set (U)。

2. Train classifier (f) on (L)。

3. Use (f) to predict labels for instances in (U)。

4. Select high-confidence predictions。

5. Move selected examples from (U) to (L)，using predicted labels as pseudo-labels。

6. Retrain model on updated (L)。

7. Repeat until (L) does not change or changes become very small。

可以写成：

$$
L \leftarrow L \cup {(x, \hat{y}) : confidence(f(x)) > \tau }
$$

其中：

* (\hat{y}) 是 predicted label
* (\tau) 是 confidence threshold

我可以这样记：

> train → predict → select confident → add pseudo-label → retrain。

---

### 6.3 为什么叫 Bootstrapping

Bootstrapping 的意思是：

> solving a problem without external resources。

在这里，model 一开始只有一点点 labelled data，但它通过自己的 confident prediction 扩大 labelled set。

这有点像：

> model 自己教自己。

但要注意，这里的 “自己教自己” 不是完全安全的。因为如果它早期教错了，后面会越学越歪。

---

## 7. Self-training with 1-NN

### 7.1 1-NN 的 self-training 直觉

如果用 1-nearest neighbour 做 self-training：

unlabelled point 的 label 来自它最近的 labelled neighbour。

例如：

一个 unlabelled point 最近的 labelled point 是 red class，那么它也被标成 red。

但是不能所有 point 都直接加进去。

需要 confidence threshold。

对于 1-NN，confidence 可以用 distance 表示：

$$
d(x, nearest\ labelled\ neighbour) < \tau
$$

如果距离小于 threshold，说明这个 point 和 labelled point 很近，可以比较 confident。

如果距离太远，就不要加。

---

### 7.2 1-NN Self-training Algorithm

1-NN self-training 可以写成：

1. Start with (L) and (U)。

2. For each (x \in U)，find nearest labelled neighbour in (L)。

3. Predict label using that neighbour。

4. If nearest-neighbour distance is small enough, add (x) to (L)。

5. Remove (x) from (U)。

6. Repeat。

所以它像是从 labelled points 往外扩散：

> labels propagate from known points to nearby unknown points。

---

### 7.3 1-NN 的风险

风险是：

* 对 initial labelled points 很 sensitive
* 对 distance metric 很 sensitive
* 对 threshold (\tau) 很 sensitive
* early mistakes can propagate

如果一开始某个 point 被错标，下一轮这个错标 point 又会影响它附近的 points。

所以：

> self-training 的关键不是 pseudo-label 本身，而是只选择足够 confident 的 pseudo-label。

---

## 8. Self-training with Naive Bayes

### 8.1 NB 怎么判断 confidence

Naive Bayes 可以输出 class probabilities。

例如一个 unlabelled example：

$$
P(Cat|x)=0.95
$$

$$
P(Dog|x)=0.03
$$

$$
P(Pig|x)=0.02
$$

这个 prediction 很 confident，可以加进 (L)。

但如果：

$$
P(Cat|x)=0.40
$$

$$
P(Dog|x)=0.35
$$

$$
P(Pig|x)=0.25
$$

那就不应该加，因为 model 很不确定。

---

### 8.2 NB Self-training Algorithm

Naive Bayes self-training：

1. Train NB on labelled set (L)。

2. Predict class probabilities for each instance in (U)。

3. Select examples with high confidence：

$$
\max_y P(y|x) > \tau
$$

4. Add selected examples to (L) with predicted labels。

5. Retrain NB。

6. Repeat。

所以 NB 的 confidence 是 probability-based。

---

## 9. Self-training 的核心假设和问题

### 9.1 核心假设

Self-training 依赖一个 assumption：

> nearby / similar points are likely to have the same label。

如果这个 assumption 不成立，self-training 很容易失败。

例如有些 data 里，class boundary 可能穿过 dense region。那 model 把附近 points 标成同一类就会出错。

---

### 9.2 最大问题：Error Propagation

Self-training 最大问题是：

> classification errors can propagate。

也就是说：

一开始 model 错标一个 point。
这个 point 被加入 labelled set。
下一轮 model 把这个错误当成 ground truth 学。
然后错标更多 points。
错误不断扩大。

所以 self-training 必须有 safety net。

---

### 9.3 Safety Net：Confidence Threshold

最重要的 safety net 是：

> only add high-confidence predictions。

对于 1-NN：

$$
distance < \tau
$$

对于 NB：

$$
P(\hat{y}|x) > \tau
$$

也可以选 top-N most confident predictions。

但 threshold 太高，可能加不进去多少 data。
threshold 太低，可能加入很多错误 pseudo-label。

所以 threshold 是 trade-off。

---

## 10. Active Learning

### 10.1 Active Learning 是什么

Active learning 和 semi-supervised learning 很像，但关键区别是：

> active learning 不让 model 自己决定 label，而是让 model 选择哪些 examples 最值得问 human annotator。

Active learning 的前提是：

* unlabelled data 很多
* labelling budget 有限
* human annotator 很贵
* random labelling 可能浪费 budget

所以我们希望：

> 用最少的 labels，让 model 学到最多东西。

---

### 10.2 Active Learning 的基本流程

Active learning algorithm：

1. Start with a small labelled set (L) and large unlabelled set (U)。

2. Train model on (L)。

3. Apply model to (U)。

4. Choose the most informative examples from (U)。

5. Ask oracle / human annotator to label them。

6. Add newly labelled examples to (L)。

7. Retrain model。

8. Repeat until budget runs out。

所以 active learning 是：

> model decides what to ask, human provides true label。

---

### 10.3 Semi-supervised vs Active Learning

Semi-supervised learning:

> model labels unlabelled data itself。

Active learning:

> model selects examples, human labels them。

可以这样记：

| Method                          | 谁给 label                  | 重点                  |
| ------------------------------- | ------------------------- | ------------------- |
| Semi-supervised / self-training | model 自己给 pseudo-label    | 扩大 labelled set     |
| Active learning                 | human oracle 给 true label | 节省 labelling budget |

所以它们都用 unlabelled data，但方式不同。

---

## 11. Active Learning 的核心直觉

### 11.1 哪些 examples 最值得 label

不是所有 unlabelled examples 都一样有价值。

有些 examples 很 obvious：

$$
P(Cat|x)=0.99
$$

这种不值得问 human，因为 model 已经很确定。

有些 examples 很 ambiguous：

$$
P(Cat|x)=0.34
$$

$$
P(Dog|x)=0.33
$$

$$
P(Pig|x)=0.33
$$

这种很值得问，因为 model 很不确定。

所以 active learning 通常选择：

* model uncertain 的 examples
* decision boundary 附近的 examples
* sparse label regions 的 examples
* models disagreement 最大的 examples

我的理解：

> active learning 不是找最容易的 examples，而是找最能帮助 model 改善 decision boundary 的 examples。

---

## 12. Query Strategies

## 12.1 Least Confidence Sampling

Least confidence sampling 选择：

> model 最没有 confidence 的 sample。

具体做法：

对每个 unlabelled instance，找出最大 class probability：

$$
\max_y P(y|x)
$$

然后选择这个最大 probability 最小的 sample：

$$
x^* = \arg\min_x \max_y P(y|x)
$$

例子：

| Sample |  Cat |  Dog |  Pig | max probability |
| ------ | ---: | ---: | ---: | --------------: |
| A      | 0.70 | 0.05 | 0.25 |            0.70 |
| B      | 0.45 | 0.05 | 0.50 |            0.50 |
| C      | 0.34 | 0.33 | 0.33 |            0.34 |

Least confidence 选 C。

因为 C 的最高 probability 只有 0.34，说明 model 最不确定。

记法：

> 看最高概率。最高概率越低，越值得问。

---

## 12.2 Margin Sampling

Margin sampling 选择：

> top two classes 差距最小的 sample。

具体做法：

找到 top 1 class probability 和 top 2 class probability：

$$
P(y_1|x)
$$

$$
P(y_2|x)
$$

计算 margin：

$$
margin(x)=P(y_1|x)-P(y_2|x)
$$

选择 margin 最小的 sample：

$$
x^* = \arg\min_x margin(x)
$$

例子：

A:

$$
0.70 - 0.25 = 0.45
$$

B:

$$
0.50 - 0.45 = 0.05
$$

C:

$$
0.34 - 0.33 = 0.01
$$

Margin sampling 选 C。

因为 top two classes 最接近。

记法：

> 只看前两名。前两名越接近，model 越纠结。

---

## 12.3 Entropy Sampling

Entropy sampling 选择：

> probability distribution 最 flat 的 sample。

公式：

$$
H(x)=-\sum_y P(y|x)\log P(y|x)
$$

选择 entropy 最大的 sample：

$$
x^*=\arg\max_x H(x)
$$

如果一个 sample 的 distribution 是：

$$
[0.90, 0.05, 0.05]
$$

entropy 低，因为 model 很确定。

如果 distribution 是：

$$
[0.34, 0.33, 0.33]
$$

entropy 高，因为 model 几乎不知道选哪个 class。

所以：

> distribution 越平均，entropy 越高。

记法：

> least confidence 看最高概率。
> margin sampling 看前两名差距。
> entropy sampling 看整个 distribution。

---

## 12.4 Query by Committee

Query by Committee，简称 QBC。

它不是只训练一个 model，而是训练多个 models，形成一个 committee。

然后对每个 unlabelled instance，看这些 models 是否 disagree。

如果所有 models 都预测 cat：

$$
[cat, cat, cat, cat]
$$

那不值得问。

如果 models 分歧很大：

$$
[cat, dog, pig, cat]
$$

那这个 example 很 informative，值得问 human oracle。

所以 QBC 的核心是：

> disagreement = uncertainty。

---

## 13. Active Learning 的优点和问题

### 13.1 优点

Active learning 的优点：

* 用更少 labels 达到更好 performance
* 节省 annotation budget
* 适合 expert labelling expensive 的场景
* 比 random sampling 更有效率
* 可以主动探索 decision boundary

例如 medical annotation 很贵时，active learning 可以让医生只标最关键的 cases。

---

### 13.2 问题

Active learning 也有问题。

第一，它可能选到 outliers。

Uncertainty sampling 喜欢找 model 不确定的 points，但不确定不一定代表有用。有些 points 只是 noise 或 outliers。

第二，它可能造成 sampling bias。

因为 active learning 不是 random sampling，而是 model-driven sampling。最后 labelled set 的 distribution 可能不代表真实 population。

第三，它依赖当前 model。

如果当前 model 很差，它选择的 examples 可能也不好。

所以：

> active learning efficient，但可能 biased。

---

## 14. Data Augmentation

### 14.1 Data augmentation 是什么

Data augmentation 是另一种解决 labelled data 少的方法。

核心：

> 对已有 labelled examples 做 label-preserving transformations，制造更多 training examples。

也就是说，data 变了，但 label 不变。

例如一张 dog image：

* rotate 一点
* crop 一点
* change brightness
* add noise
* flip horizontally

这些变化后，它还是 dog。

所以 label 仍然是 dog。

---

### 14.2 Image Augmentation

常见 image augmentation：

* rotation
* cropping
* flipping
* scaling
* brightness adjustment
* contrast adjustment
* adding noise

这些可以让 model 看到更多 variations，从而更 robust。

例如，如果 model 只见过正脸 dog，它可能不认识侧脸 dog。augmentation 可以让它见到更多 angle。

---

### 14.3 Audio Augmentation

Audio 也可以 augmentation：

* change volume
* add background noise
* time shift
* speed change
* pitch shift

目标也是模拟 real-world variation。

---

### 14.4 Text Augmentation

Text augmentation 比 image 更难，因为随便改 word 可能改变 meaning。

常见方法：

* synonym replacement
* paraphrasing
* back translation
* random deletion
* sentence reordering

例如：

English sentence → Chinese → English

如果 meaning 保持不变，就可以当作 augmented example。

但 text augmentation 要小心，因为一个 word 的改变可能改变 sentiment 或 label。

---

### 14.5 Data augmentation 的关键条件

Data augmentation 最重要条件是：

> transformation must preserve the label。

如果 transformation 改变了 label，那就是 bad augmentation。

例如：

原图是 dog。
如果 crop 后只剩下 grass，没有 dog，那 label 还是 dog 就错了。

又例如：

狗的图片被改成不现实的蓝红色。如果真实世界里没有这种狗，model 可能学到奇怪 pattern。

所以 augmentation 不是乱改，而是：

> 模拟真实世界中可能出现的变化。

---

## 15. Pre-training and Self-supervised Learning

### 15.1 Self-supervised 和 Self-training 不一样

这两个名字很像，但要分清楚。

Self-training:

> model 给 unlabelled data 打 pseudo-label。

Self-supervised learning:

> label 从 data 本身自动产生，不需要 human annotation。

例如 next-token prediction：

sentence 是：

$$
The\ cat\ sat\ on\ the
$$

true next token 是：

$$
mat
$$

这里 “mat” 就是 label，但它不是人类额外标的，而是原本就在 text 里面。

所以：

> self-supervised learning 的 label 是 automatically derived from data。

---

### 15.2 Pre-training 是什么

Pre-training 是先在大量 unlabelled data 上训练 model，让它学 general representation。

然后再 fine-tune 到 specific supervised task。

流程：

1. Pre-train on large unlabelled dataset。
2. Learn general patterns。
3. Add task-specific layer。
4. Fine-tune on smaller labelled dataset。

所以：

> pre-training 学 general knowledge。
> fine-tuning 学 task-specific behaviour。

---

### 15.3 为什么 Pre-training 有用

因为大量 unlabelled data 便宜。

如果 model 可以先从 unlabelled data 学到：

* word relationships
* image structures
* semantic patterns
* object shapes
* language syntax
* visual features

那么后面 supervised fine-tuning 只需要较少 labelled data。

这就是 modern deep learning 很重要的思路。

---

## 16. Text 里的 Self-supervised Tasks

### 16.1 Next-token Prediction

Next-token prediction 是 LLM 的核心任务。

给前面的 tokens：

$$
x_1,x_2,\dots,x_{t-1}
$$

预测：

$$
x_t
$$

label 就是原文中的 next token。

所以不需要人工 label。

---

### 16.2 Masked Language Modelling

BERT 使用 masked language modelling。

做法：

原句：

$$
The\ cat\ sat\ on\ the\ mat
$$

mask 掉一个 word：

$$
The\ cat\ sat\ on\ the\ [MASK]
$$

model 要预测：

$$
mat
$$

这里被 mask 的 word 就是自动 label。

---

### 16.3 Sentence Order / Next Sentence Prediction

另一种 task 是判断两个 sentences 是否相邻，或者恢复句子顺序。

例如：

Sentence A: The dog ran outside.
Sentence B: It started barking.

model 要判断 B 是否是 A 后面的 next sentence。

这些任务都不需要人工 label，因为 sentence order 原本就在 corpus 里。

---

## 17. Image 里的 Self-supervised Tasks

### 17.1 Autoencoder

Autoencoder 的任务是：

> input 一张 image，然后 reconstruct 这张 image。

中间有一个 compressed representation。

model 必须学习 image 的 useful features，才能 reconstruct。

---

### 17.2 Contrastive Learning

Contrastive learning 的想法是：

> 同一张 image 的不同 augmented versions 应该在 representation space 里接近。

例如：

一张 dog image 被 crop、rotate、change brightness。

model 应该知道它们还是 same dog image。

不同 images 的 representation 应该远一些。

所以 contrastive learning 学的是：

> what makes two views belong to the same underlying object。

---

### 17.3 Diffusion

Diffusion 的 idea 是：

1. 对 clean image 加 noise。
2. model 学会从 noisy image 还原 clean image。

所以 training target 是原始 clean image。

这个 target 也是 data 自己提供的，不需要人工 label。

---

## 18. 四种方法的对比

| Method                       | Data Setting                                   | 谁提供 label          | 核心目标                     | 风险                             |
| ---------------------------- | ---------------------------------------------- | ------------------ | ------------------------ | ------------------------------ |
| Self-training                | 少量 labelled + 大量 unlabelled                    | model pseudo-label | 扩大 labelled set          | error propagation              |
| Active learning              | 少量 labelled + 大量 unlabelled + labelling budget | human oracle       | 选择最值得标的 examples         | sampling bias / outlier        |
| Data augmentation            | labelled data 少                                | 原 label 保持不变       | 制造更多 labelled examples   | bad augmentation 改变 label      |
| Self-supervised pre-training | 大量 unlabelled data                             | data itself        | 学 general representation | downstream task 仍需 fine-tuning |

---

## 19. 最容易混淆的点

### 19.1 Self-training vs Self-supervised Learning

Self-training:

> model 自己给 unlabelled examples 打 pseudo-label。

Self-supervised:

> label 从 data 本身自动生成。

例子：

Self-training：
model 看一张 unlabelled image，预测它是 dog，然后把 dog 当 pseudo-label。

Self-supervised：
把一张 image 加 noise，让 model 还原原图。原图就是 target。

---

### 19.2 Semi-supervised vs Active Learning

Semi-supervised:

> model 自己标一部分 unlabelled data。

Active learning:

> model 选择哪些 data 应该给 human 标。

区别在于谁给 final label：

* semi-supervised：model
* active learning：human oracle

---

### 19.3 Least Confidence vs Margin vs Entropy

Least confidence:

> 看最高 probability。最高 probability 越低越不确定。

Margin:

> 看 top 1 和 top 2 的差距。差距越小越不确定。

Entropy:

> 看整个 distribution。越 flat 越不确定。

例子：

$$
[0.34, 0.33, 0.33]
$$

这三个方法通常都会觉得它很 uncertain。

但有时候它们会选不同 sample，因为它们关注的 uncertainty 不一样。

---

## 20. Exam 重点

### 20.1 可能考 Query Strategy

考试可能给一个 probability table，让你选择 active learning 应该 query 哪一个 example。

需要会：

Least confidence:

$$
x^* = \arg\min_x \max_y P(y|x)
$$

Margin sampling:

$$
x^* = \arg\min_x [P(y_1|x)-P(y_2|x)]
$$

Entropy sampling:

$$
x^* = \arg\max_x -\sum_y P(y|x)\log P(y|x)
$$

Query by committee:

> choose instance with maximum disagreement between models。

---

### 20.2 可能考 Self-training Algorithm

要会写：

1. Train model on labelled data。
2. Predict labels for unlabelled data。
3. Select high-confidence predictions。
4. Add them to labelled set as pseudo-labels。
5. Retrain。
6. Repeat。

要提到：

> errors can propagate, so use confidence threshold。

---

### 20.3 可能考 Data Augmentation

要记住：

> augmentation must preserve label and should reflect realistic variation。

如果 transformation 改变 label，就是 bad augmentation。

---

### 20.4 可能考 Self-supervised Learning

要记住：

> self-supervised labels are derived automatically from the data itself。

例子：

* next-token prediction
* masked token prediction
* image reconstruction
* denoising
* contrastive learning

---

## 21. Lecture 20 总结

Lecture 20 的核心是：

> labelled data 很少时，我们可以通过 semi-supervised learning、active learning、data augmentation 和 self-supervised pre-training 来更有效地使用 data。

我需要重点记住：

Semi-supervised learning 使用 labelled + unlabelled data。
Self-training 是 semi-supervised 的一种方法。
Self-training 会用 model 自己的 high-confidence predictions 当 pseudo-label。
Self-training 的风险是 error propagation。
Confidence threshold 是 safety net。
1-NN self-training 可以用 nearest-neighbour distance 判断 confidence。
Naive Bayes self-training 可以用 predicted probability 判断 confidence。
Clustering + majority voting 很直观，但 cluster 不一定等于 class。
Active learning 是让 model 选择最值得 human label 的 examples。
Active learning 假设 labelling 是 finite resource。
Active learning 通常选择 uncertain examples 或 sparse regions。
Least confidence 选择 maximum probability 最低的 sample。
Margin sampling 选择 top two class probabilities 差距最小的 sample。
Entropy sampling 选择 probability distribution 最 flat 的 sample。
Query by Committee 选择 models disagreement 最大的 sample。
Active learning 可以节省 labelling budget，但可能引入 sampling bias。
Data augmentation 用 label-preserving transformations 制造更多 labelled data。
Augmentation 必须 realistic，否则会让 model 学到错误 pattern。
Self-supervised learning 的 label 来自 data itself。
Self-supervised 不等于 self-training。
Pre-training 用大量 unlabelled data 学 general representation。
Fine-tuning 用较少 labelled data 调整到 specific task。
Text self-supervised tasks 包括 next-token prediction 和 masked language modelling。
Image self-supervised tasks 包括 reconstruction、contrastive learning 和 diffusion denoising。

一句话总结：

> Lecture 20 讲的是：当 labels 很少时，不要只等更多人工标注，而是利用 unlabelled data、聪明选择 labelling examples、扩增已有 data，或者先做 self-supervised pre-training。
