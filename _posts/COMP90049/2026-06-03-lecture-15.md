# Lecture 15：反向传播

## Backpropagation

## 1. 从 Neural Network Recap 开始

### 1.1 这节课在解决什么问题

Lecture 14 讲了 Multi-layer Perceptron / Feed-forward Neural Network。我们知道一个 neural network 会有：

* input layer
* hidden layers
* output layer
* activation functions
* loss function
* weights
* bias terms

Forward pass 的时候，input 一层一层往前传，最后得到 prediction：

$$
x \rightarrow hidden\ layers \rightarrow \hat{y}
$$

但是 Lecture 15 的问题是反过来的：

> 如果 final prediction 错了，hidden layers 里的 weights 应该怎么改？

这就是 backpropagation 要解决的问题。

Perceptron 只有一个 neuron，所以 prediction 错了，直接更新 weights 就可以。但 MLP 有很多 hidden layers。我们只知道 final output 错了，却不知道每一个 hidden neuron 到底错了多少、每一条 weight 对 error 贡献了多少。所以需要一个方法，把 final error 分配回 network 里面的每一层。

所以这节课的核心是：

> Backpropagation = 把 output error 往回传，让每个 weight 知道自己对 error 贡献多少，然后用 gradient descent 更新。

---

## 2. Output Function 和 Loss Function Recap

### 2.1 Binary Classification

如果 task 是 binary classification，output layer 通常只有一个 output node，并且使用 sigmoid function。

Sigmoid 会把任何 real number 压到 0 到 1 之间：

$$
\sigma(z)=\frac{1}{1+e^{-z}}
$$

所以 output 可以理解成：

$$
\hat{y}=P(y=1|x)
$$

如果：

$$
\hat{y}>0.5
$$

就预测 class 1。

如果：

$$
\hat{y}\leq0.5
$$

就预测 class 0。

这里要注意：loss 不是看 threshold 之后的 hard prediction，而是看 raw probability。也就是说，如果 true label 是 1，model 输出 0.99 和 0.6 都会被判断为 class 1，但它们的 confidence 不一样，loss 也不一样。

Binary classification 常用 Binary Cross-Entropy：

$$
L
=

*

[
y\log(\hat{y})
+
(1-y)\log(1-\hat{y})
]
$$

如果 true label 是：

$$
y=1
$$

第二项会消失，loss 主要看：

$$
-\log(\hat{y})
$$

如果 true label 是：

$$
y=0
$$

第一项会消失，loss 主要看：

$$
-\log(1-\hat{y})
$$

所以我可以这样记：

> Binary cross-entropy 惩罚 confident but wrong 的 prediction。

如果 true label 是 1，但 model 很有信心地预测接近 0，loss 会非常大。

---

### 2.2 Multi-class Classification

如果 task 是 multi-class classification，output layer 通常有 (K) 个 output nodes，每个 class 一个 score / logit。

这些 logits 会一起通过 softmax，而不是每个 node 单独套 softmax。

Softmax 是：

$$
\hat{p}_k
=

# P(y=k|x)

\frac{e^{z_k}}
{\sum_{j=1}^{K}e^{z_j}}
$$

它会输出一个 probability distribution：

$$
\hat{p}_1+\hat{p}_2+\dots+\hat{p}_K=1
$$

例如三个 classes：

* dog
* cat
* pig

softmax 可能输出：

$$
[0.6,\ 0.4,\ 0.0]
$$

这表示 model 觉得 dog 最可能，但 cat 也还有一定可能性。

Multi-class label 通常要用 one-hot encoding。例如：

$$
dog=[1,0,0]
$$

$$
cat=[0,1,0]
$$

$$
pig=[0,0,1]
$$

Multi-class classification 常用 Categorical Cross-Entropy：

$$
L
=

*

\sum_{k=1}^{K}
y_k\log(\hat{p}_k)
$$

因为 one-hot label 里面只有 true class 的 (y_k=1)，其他都是 0，所以最后 loss 只关心：

> model 给 true class 分配了多少 probability。

所以：

> Multi-class classification = softmax output + categorical cross-entropy。

---

### 2.3 Regression

如果 task 是 regression，output layer 通常用 linear / identity output。也就是说，model 输出什么 real value，就直接拿来当 prediction：

$$
\hat{y}=z
$$

Regression 不需要把 output 压到 0 到 1，因为 target 本身就是 continuous value。

常见 loss 是 Mean Squared Error：

$$
MSE
=

\frac{1}{N}
\sum_{i=1}^{N}
(y_i-\hat{y}_i)^2
$$

在 backprop 推导时，有时会用更简单的形式：

$$
E=\frac{1}{2}(y-\hat{y})^2
$$

这里的：

$$
\frac{1}{2}
$$

只是为了 derivative 方便，因为平方项求导会带出 2，刚好抵消。

所以：

> Regression = linear output + MSE。

---

## 3. Activation Functions

### 3.1 为什么需要 activation function

Neural network 每一层都要做：

$$
z = Wx+b
$$

如果没有 activation function，整个 network 就只是很多 linear transformations 叠在一起。

例如：

$$
h^{(1)}=W^{(1)}x
$$

$$
h^{(2)}=W^{(2)}h^{(1)}
$$

代入后：

$$
h^{(2)}=W^{(2)}W^{(1)}x
$$

这仍然是 linear transformation。

所以：

> 多层 linear layers 叠起来，还是 linear model。

这就是为什么每层需要 nonlinear activation function。Activation function 的作用是：

> break linearity，让 network 可以学习 nonlinear patterns。

---

### 3.2 Sigmoid

Sigmoid 是：

$$
\sigma(z)=\frac{1}{1+e^{-z}}
$$

它把 value 压到：

$$
(0,1)
$$

所以很适合 binary classification output。

它的 derivative 是：

$$
\sigma'(z)=\sigma(z)(1-\sigma(z))
$$

Sigmoid 的问题是：当 (z) 很大或很小时，sigmoid 会非常接近 0 或 1，这时候 derivative 会很小。也就是说 gradient 会变得很小。

在 deep network 里，如果很多层都用 sigmoid，这些很小的 gradients 会一层一层相乘，最后传到前面 layers 时几乎变成 0。

这叫：

> Vanishing Gradient Problem

所以我可以这样记：

> Sigmoid 好解释，但 deep network 里容易让 gradient 消失。

---

### 3.3 Tanh

Tanh 是 hyperbolic tangent function：

$$
\tanh(z)
$$

它把 value 压到：

$$
(-1,1)
$$

相比 sigmoid，tanh 的 output 是 zero-centered，而且中间区域的 slope 更明显，所以在一些情况下 gradient signal 会比 sigmoid 更好。

它的 derivative 可以写成：

$$
\frac{d}{dz}\tanh(z)=1-\tanh^2(z)
$$

但是 tanh 仍然有 saturation problem。如果 (z) 很大或很小，它的 derivative 也会变小。所以 tanh 只是缓解，不是完全解决 vanishing gradient。

---

### 3.4 ReLU

ReLU 是 Rectified Linear Unit：

$$
ReLU(z)=\max(0,z)
$$

也就是：

$$
ReLU(z)=
\begin{cases}
0 & z\leq0 \
z & z>0
\end{cases}
$$

它的 derivative 通常写成：

$$
ReLU'(z)=
\begin{cases}
0 & z<0 \
1 & z>0
\end{cases}
$$

在 (z=0) 的地方严格来说不可导，但实践里通常人为设成 0 或 1。

ReLU 的好处是：如果 value 是 positive，gradient 可以直接传下去，不会像 sigmoid 那样被压得特别小。

所以 ReLU 比较能缓解 vanishing gradient。

但是 ReLU 也会把 negative values 变成 0，所以某些 connections 可能完全不更新。这也是它会“delete unnecessary weights”的直觉。

我可以这样记：

> ReLU negative side 是 0，positive side 是 identity。
> 它简单、有效，比较适合 deep networks。

---

### 3.5 为什么不用 Step Function

Perceptron 用的是 step function：

$$
step(z)=
\begin{cases}
1 & z>0\
0 \text{ or } -1 & z\leq0
\end{cases}
$$

但 step function 不适合 backpropagation。

原因有两个：

第一，它在 0 的地方不可导。
第二，它在其他地方是 flat，所以 derivative 基本是 0。

如果 derivative 是 0，gradient descent 就没有 useful signal。也就是说，model 不知道 weights 应该往哪里改。

所以：

> Step function 可以做 hard decision，但不能用于 smooth gradient-based training。

这就是为什么 neural network 需要 sigmoid、tanh、ReLU 这种可以提供 gradient signal 的 activation function。

---

## 4. Backpropagation 为什么必要

### 4.1 Perceptron 可以直接更新

Perceptron 的 update 很简单。如果 prediction 错了：

$$
\theta \leftarrow \theta+\eta yx
$$

因为只有一个 neuron，error 直接对应到 weights。

---

### 4.2 MLP 不能直接这样做

但 MLP 有 hidden layers。

假设 network 是：

$$
x \rightarrow h^{(1)} \rightarrow h^{(2)} \rightarrow \hat{y}
$$

我们知道：

$$
\hat{y}
$$

和 true label：

$$
y
$$

所以可以算 final error。

但是我们不知道：

* hidden layer 1 的 correct output 应该是多少
* hidden layer 2 的 correct output 应该是多少
* 哪个 hidden neuron 贡献了 error
* 哪条 weight 该增加
* 哪条 weight 该减少

所以不能像 Perceptron 一样直接更新所有 weights。

Backpropagation 的作用就是：

> 根据 final error，计算每个 hidden weight 对 error 的 contribution。

---

## 5. Notation：Z 和 A

### 5.1 Pre-activation (z)

在每个 neuron 里面，先计算 weighted sum：

$$
z_j
=

\sum_i w_{ji}a_i+b_j
$$

这个 (z_j) 是 activation function 之前的 value，所以叫：

> pre-activation

或者：

> weighted input

---

### 5.2 Activation (a)

然后把 (z_j) 放进 activation function：

$$
a_j=g(z_j)
$$

这个 (a_j) 是 neuron 的 output，会传给下一层。

所以：

> (z) 是进入 activation function 之前的 weighted sum。
> (a) 是 activation function 之后的 output。

这个 notation 很重要，因为 backpropagation 会不断用到：

$$
\frac{\partial E}{\partial z}
$$

和：

$$
\frac{\partial E}{\partial w}
$$

---

## 6. Gradient Descent Recap

### 6.1 Training 的目标

Neural network training 的目标是找到一组 weights，让 loss 最小：

$$
\hat{W}
=

\arg\min_W E(W)
$$

Gradient descent 的 update rule 是：

$$
w \leftarrow w-\eta\frac{\partial E}{\partial w}
$$

其中：

$$
\eta
$$

是 learning rate。

$$
\frac{\partial E}{\partial w}
$$

表示：

> 如果这个 weight 改变一点，error 会怎么变。

所以每条 weight 都需要自己的 gradient。

---

### 6.2 Gradient 的直觉

如果：

$$
\frac{\partial E}{\partial w}>0
$$

表示 (w) 增加会让 error 增加，所以我们应该减少 (w)。

如果：

$$
\frac{\partial E}{\partial w}<0
$$

表示 (w) 增加会让 error 减少，所以我们应该增加 (w)。

所以 gradient descent 永远往 error 下降的方向走。

我可以这样记：

> derivative 告诉我 error 对 weight 有多敏感；gradient descent 用它来决定 weight 怎么改。

---

## 7. Backpropagation 的核心直觉：Blame Signal

### 7.1 Error 不是平均分给所有 weights

Backpropagation 不是把 final error 平均分给所有 hidden neurons。因为不同 weights 对 final error 的贡献不一样。

有些 weights 很大，activation 也很大，可能对 final error 贡献很大。
有些 weights 很小，即使方向错，对 final error 的影响也小。
有些 hidden neuron 后面的 weight 接近 0，它前面再怎么错，也不太影响 final output。

所以 backpropagation 要做的是：

> 按照 contribution 分配 blame。

---

### 7.2 Blame signal 怎么传

Lecture 里老师用游戏解释：output layer 先知道自己错了多少，然后把一部分 “blame” 传给前一层。前一层再根据自己收到的 blame、自己的 output、连接 weights，继续把 blame 传给更前面的 layer。

所以：

> Backpropagation = error blame 从 output layer 往 input direction 传播。

Forward pass 是：

$$
input \rightarrow output
$$

Backward pass 是：

$$
output\ error \rightarrow hidden\ layers
$$

---

## 8. Output Layer 的 Delta

### 8.1 Delta 是什么

Backpropagation 里常用：

$$
\delta
$$

表示 error term。

它可以理解成：

> 这个 neuron 对 final error 的 blame signal。

对于 output layer，delta 比较直接，因为 output layer 可以直接和 true label 比较。

如果使用 MSE：

$$
E=\frac{1}{2}(y-\hat{y})^2
$$

那么 output error 的 derivative 会包含：

$$
\hat{y}-y
$$

如果 output activation 是 (g)，并且：

$$
\hat{y}=g(z)
$$

那么 output layer 的 delta 是：

$$
\delta^{(out)}
=

(\hat{y}-y)g'(z)
$$

这里：

$$
\hat{y}-y
$$

表示 prediction error。

$$
g'(z)
$$

表示 activation function 的 derivative。

所以：

> output delta = prediction error × activation derivative。

---

### 8.2 Weight gradient at output layer

假设某个 previous neuron 的 activation 是：

$$
a_j
$$

它连到 output neuron 的 weight 是：

$$
w_j
$$

那么这个 weight 的 gradient 是：

$$
\frac{\partial E}{\partial w_j}
=

\delta^{(out)}a_j
$$

也就是说：

> weight gradient = 当前 neuron 的 delta × previous activation。

这个公式非常重要，因为 hidden layer 也会用同样结构。

---

## 9. Hidden Layer 的 Delta

### 9.1 Hidden layer 为什么更复杂

Hidden neuron 没有直接的 true label，所以不能直接算：

$$
\hat{y}-y
$$

它的 error 来自下一层。

也就是说，hidden neuron 的 blame 要看：

* 下一层传回来的 delta
* 这个 hidden neuron 连到下一层的 weights
* 自己 activation function 的 derivative

---

### 9.2 Hidden delta formula

对于 hidden neuron (j)，它的 delta 可以写成：

$$
\delta_j^{(l)}
=

g'(z_j^{(l)})
\sum_k
w_{kj}^{(l+1)}
\delta_k^{(l+1)}
$$

这里：

$$
\delta_k^{(l+1)}
$$

是下一层 neuron (k) 的 error term。

$$
w_{kj}^{(l+1)}
$$

是 hidden neuron (j) 到下一层 neuron (k) 的 weight。

$$
g'(z_j^{(l)})
$$

是当前 hidden neuron activation function 的 derivative。

这个公式的意思是：

> hidden neuron 的 error = 下一层传回来的 weighted blame × 自己的 activation derivative。

所以我可以这样记：

> output layer 直接从 prediction error 得到 delta。
> hidden layer 从下一层 delta 反推自己的 delta。

---

### 9.3 Generalised Delta Rule

这个从 output layer 到 hidden layer、再到更早 layers 的递推过程，就叫：

> Generalised Delta Rule

Perceptron 的 update rule 只能处理一个 neuron。Generalised delta rule 可以处理多层 network，因为它用 chain rule 把 final loss 对每个 weight 的影响拆开。

所以：

> Backpropagation 本质上就是用 chain rule 递归计算 gradients。

---

## 10. Chain Rule 的作用

### 10.1 为什么需要 chain rule

Error (E) 不是直接由某个早期 weight 决定的。它中间经过很多步骤：

$$
w \rightarrow z \rightarrow a \rightarrow next\ z \rightarrow next\ a \rightarrow \hat{y} \rightarrow E
$$

所以如果我们想知道：

$$
\frac{\partial E}{\partial w}
$$

就必须把中间路径全部拆开。

这就是 chain rule：

$$
\frac{\partial E}{\partial w}
=

\frac{\partial E}{\partial a}
\frac{\partial a}{\partial z}
\frac{\partial z}{\partial w}
$$

对于更深的 layer，中间还会有更多 terms。

---

### 10.2 为什么 backprop efficient

如果每条 weight 都从头展开 chain rule，会非常复杂、计算量很大。

Backpropagation 的聪明之处是：

> 先算后面 layer 的 delta，然后前面 layers 复用这些 delta。

所以不用每次重新推整条 chain。只要把 delta 一层一层传回去，就可以高效计算所有 gradients。

这也是为什么 backpropagation 是 neural network training 的核心算法。

---

## 11. Weight Update

### 11.1 计算 gradient

一旦某个 neuron 的 delta 已经算出来，该 neuron incoming weight 的 gradient 就很简单：

$$
\frac{\partial E}{\partial w_{ji}^{(l)}}
=

\delta_j^{(l)}a_i^{(l-1)}
$$

其中：

$$
a_i^{(l-1)}
$$

是上一层 neuron (i) 的 activation。

所以：

> 每条 weight 的 gradient = 目标 neuron 的 delta × 来源 neuron 的 activation。

---

### 11.2 更新 weight

然后用 gradient descent 更新：

$$
w_{ji}^{(l)}
\leftarrow
w_{ji}^{(l)}
------------

\eta
\frac{\partial E}{\partial w_{ji}^{(l)}
}
$$

代入 gradient：

$$
w_{ji}^{(l)}
\leftarrow
w_{ji}^{(l)}
------------

\eta
\delta_j^{(l)}a_i^{(l-1)}
$$

这里要注意 sign。我们是减去 gradient，因为要 minimise loss。

所以我可以这样记：

> Backprop 算 gradient，gradient descent 用 gradient 更新 weight。

---

## 12. Backpropagation 的完整流程

### 12.1 Forward Pass

第一步是 forward pass。

从 input 开始，一层一层计算：

$$
z^{(l)}=W^{(l)}a^{(l-1)}+b^{(l)}
$$

$$
a^{(l)}=g(z^{(l)})
$$

直到 output layer 得到：

$$
\hat{y}
$$

---

### 12.2 Compute Loss

第二步，比较 prediction 和 true label：

$$
E=L(y,\hat{y})
$$

例如 binary classification 用 BCE，regression 用 MSE。

---

### 12.3 Backward Pass

第三步，从 output layer 开始计算 delta。

Output layer：

$$
\delta^{(out)}
=

(\hat{y}-y)g'(z^{(out)})
$$

Hidden layers：

$$
\delta^{(l)}
=

g'(z^{(l)})
(W^{(l+1)})^T
\delta^{(l+1)}
$$

这是 vector form。意思就是：

> 当前 layer 的 delta 由下一层 delta 反传回来。

---

### 12.4 Update Weights

第四步，对所有 weights 同时更新：

$$
W^{(l)}
\leftarrow
W^{(l)}
-------

\eta
\delta^{(l)}(a^{(l-1)})^T
$$

这个过程会重复很多 epochs，直到 loss 变小或达到 stopping criterion。

所以：

> Forward pass 算 prediction。
> Loss 算错多少。
> Backward pass 算每个 weight 该负责多少。
> Gradient descent 更新 weights。

---

## 13. Bias Term 在 Backprop 里做什么

### 13.1 Bias 也有 weight

Bias node 的 value 通常固定为：

$$
1
$$

但它连接出去的 weight 是 trainable 的。

所以 bias 的作用还是：

> 让 decision boundary / activation 有 offset，不被迫经过 origin。

在 neural network 中，每一层通常都有 bias term。它给每个 neuron 更大的 flexibility。

---

### 13.2 Bias 怎么更新

Bias 可以看成一个 input 恒等于 1 的 weight。

如果：

$$
a_0=1
$$

那么 bias weight 的 gradient 是：

$$
\frac{\partial E}{\partial b_j}
=

\delta_j
$$

因为：

$$
\frac{\partial z_j}{\partial b_j}=1
$$

所以 bias update 是：

$$
b_j
\leftarrow
b_j-\eta\delta_j
$$

所以：

> bias 不是 data feature，但它像一个固定 input 的 weight，一样通过 backprop 更新。

---

## 14. Backpropagation 和 Perceptron 的区别

### 14.1 Perceptron Update

Perceptron 是：

$$
\theta \leftarrow \theta+\eta yx
$$

只有 misclassified 时才 update。

它的逻辑是：

> 错了，就往正确 label 方向推。

---

### 14.2 Neural Network Update

Neural network 不只是看 hard mistake，而是看 loss。即使 prediction class 是对的，只要 confidence 不够好，也可能有 loss，也会更新。

例如 binary classification：

true label 是 1。

如果 model output：

$$
\hat{y}=0.6
$$

class prediction 可能已经是 1，但 loss 仍然不小，因为 model 不够 confident。

所以 neural network update 更细：

> 不是只问对不对，而是问 prediction 离 target 有多远。

---

### 14.3 Hidden layer 的 difference

Perceptron 没有 hidden layers，所以 error 直接更新 weights。

MLP 有 hidden layers，所以必须用 backpropagation 把 error 传回去。

所以：

> Perceptron 是 direct correction。
> Backpropagation 是 distributed blame assignment。

---

## 15. Backpropagation 和 Gradient Descent 的关系

Backpropagation 和 gradient descent 不是同一个东西。

Backpropagation 负责：

> efficient computation of gradients。

Gradient descent 负责：

> using gradients to update parameters。

也就是说：

1. Backprop 算出：

$$
\frac{\partial E}{\partial w}
$$

2. Gradient descent 用它更新：

$$
w \leftarrow w-\eta\frac{\partial E}{\partial w}
$$

所以我可以这样记：

> Backprop 是算方向；Gradient descent 是沿着方向走。

---

## 16. Vanishing Gradient 和 Activation Choice

### 16.1 为什么 sigmoid 会导致 vanishing gradient

Sigmoid derivative 最大也不大，而且在两端接近 0。

如果一个 network 有很多 layers，每一层 backward pass 都乘上一个很小的 derivative：

$$
g'(z)
$$

那么 gradient 会越来越小。

最后前面 layers 收到的 signal 可能接近 0，导致它们几乎学不到东西。

所以：

> deep sigmoid networks 容易 vanishing gradient。

---

### 16.2 ReLU 为什么有帮助

ReLU 在 positive side 的 derivative 是 1：

$$
ReLU'(z)=1,\quad z>0
$$

所以如果 neuron 是 active 的，gradient 可以比较直接地传回去，不会被压得特别小。

这就是为什么 ReLU 在 deeper networks 中很常见。

但 ReLU 也不是完美。如果某个 neuron 长期在 negative side，它的 derivative 是 0，也可能变成 dead neuron。

---

## 17. Lecture 15 里你最该会的手算

这节课可能不会要求你手推很复杂的 network，但可能会要求你看一个小 network，然后做简单 forward / backward pass。

你需要会的流程是：

### 17.1 Forward

给定 input 和 weights，先算每个 node 的 weighted sum：

$$
z=\sum_i w_ix_i+b
$$

如果有 activation，再算：

$$
a=g(z)
$$

继续传到下一层，最后得到：

$$
\hat{y}
$$

---

### 17.2 Error

根据 task 算 error / loss。

如果是简单 regression exercise，可能会给：

$$
E=\frac{1}{2}(y-\hat{y})^2
$$

或者直接让你用：

$$
y-\hat{y}
$$

---

### 17.3 Backward

从 output layer 开始算 error term：

$$
\delta
$$

然后往回传：

$$
\delta_j^{(l)}
=

g'(z_j^{(l)})
\sum_k
w_{kj}^{(l+1)}
\delta_k^{(l+1)}
$$

---

### 17.4 Update

最后更新 weight：

$$
w \leftarrow w-\eta\delta a
$$

这里的 (a) 是这条 weight 的 input activation。

所以最简版记忆是：

> forward 算 output，backward 传 blame，update 改 weight。

---

## 18. Exam / Interview 常见问法

### 18.1 可能问 output function

看到 network diagram，判断：

* binary classification → sigmoid
* multi-class classification → softmax
* regression → linear

---

### 18.2 可能问 loss function

看到 loss formula，判断：

* binary cross-entropy → binary classification
* categorical cross-entropy → multi-class classification
* MSE → regression

---

### 18.3 可能问 activation function

要能解释：

* sigmoid：0–1，可能 vanishing gradient
* tanh：-1–1，比 sigmoid 居中，但仍可能 saturation
* ReLU：max(0,z)，缓解 vanishing gradient，但可能 dead neuron
* step function：不可导 / derivative useless，不适合 backprop

---

### 18.4 可能问 backprop intuition

要能用一句话解释：

> Backpropagation uses the chain rule to propagate output error backwards through the network and compute how much each weight contributed to the loss.

中文就是：

> Backprop 用 chain rule 把 output error 往回传，算出每个 weight 对 loss 的贡献，再用 gradient descent 更新。

---

## Lecture 15 总结

Lecture 15 的核心是：

> Backpropagation 让 multi-layer neural network 可以训练。它通过 chain rule 把 output error 分配回每一层，计算每个 weight 的 gradient，然后用 gradient descent 更新 weights。

我需要重点记住：

Binary classification 通常用 sigmoid output。
Binary cross-entropy 是：

$$
L=
--

[
y\log(\hat{y})
+
(1-y)\log(1-\hat{y})
]
$$

Multi-class classification 用 softmax。
Softmax 是：

$$
\hat{p}*k=
\frac{e^{z_k}}
{\sum*{j=1}^{K}e^{z_j}}
$$

Categorical cross-entropy 是：

$$
L=
-\sum_{k=1}^{K}y_k\log(\hat{p}_k)
$$

Regression 通常用 linear output 和 MSE。
MSE 可以写成：

$$
MSE=
\frac{1}{N}
\sum_{i=1}^{N}
(y_i-\hat{y}_i)^2
$$

每个 neuron 先算 pre-activation：

$$
z=\sum_i w_ia_i+b
$$

再算 activation：

$$
a=g(z)
$$

Sigmoid 会 squish 到 0–1，但可能导致 vanishing gradient。
Tanh 会 squish 到 -1–1，比 sigmoid 更 centered，但仍可能 saturation。
ReLU 是：

$$
ReLU(z)=\max(0,z)
$$

ReLU 可以缓解 vanishing gradient。
Step function 不适合 backprop，因为 derivative 没有 useful signal。
Backpropagation 的核心是把 final error 往回传。
Delta 是 error term / blame signal。
Output delta 可以理解成：

$$
\delta^{(out)}
=

(\hat{y}-y)g'(z)
$$

Hidden delta 是：

$$
\delta_j^{(l)}
=

g'(z_j^{(l)})
\sum_k
w_{kj}^{(l+1)}
\delta_k^{(l+1)}
$$

Weight gradient 是：

$$
\frac{\partial E}{\partial w_{ji}^{(l)}}
=

\delta_j^{(l)}a_i^{(l-1)}
$$

Weight update 是：

$$
w_{ji}^{(l)}
\leftarrow
w_{ji}^{(l)}
------------

\eta
\delta_j^{(l)}a_i^{(l-1)}
$$

Backprop 算 gradient，gradient descent 用 gradient 更新 weight。
Bias term 每层通常都有，它的 value 固定为 1，但 bias weight 会被更新。
Perceptron 是错了才直接更新；MLP 是根据 loss 和 gradients 更新。
Backprop 的数学核心是 chain rule。

一句话总结：

> Lecture 15 讲的是 neural network 真正“怎么学”：forward pass 得到 prediction，loss 衡量错多少，backprop 用 chain rule 把 error 一层层传回去，最后 gradient descent 根据每个 weight 的责任大小去更新它。
