# Lecture 8：迭代优化与逻辑回归

## Iterative Optimisation and Logistic Regression

## 1. 从 Exact Optimisation 到 Iterative Optimisation

### 1.1 为什么 Lecture 8 继续讲 Optimisation

Lecture 7 讲的是 Linear Regression 和 exact optimisation。我们当时看到，如果 objective function 有 closed-form solution，就可以通过数学推导直接解出 optimal parameter。例如对 function 求 derivative，然后 set derivative to zero：

$$
\frac{\partial f}{\partial \theta}=0
$$

这种方法很干净，因为可以一步一步把 optimal (\theta) 解出来。

但是 Lecture 8 开始讲另一种情况：很多 machine learning model 的 loss function 没有简单的 closed-form solution。也就是说，我们知道 loss function 长什么样，也知道想 minimize 它，但不能直接用 algebra 解出 optimal parameter。

所以这节课的重点是：

> 如果不能一次性解出 optimal parameters，就用 iterative optimisation 一步一步接近它。

---

### 1.2 Closed-form vs Iterative Optimisation

Closed-form optimisation 是直接求解。例如 Lecture 7 的 binomial spam example，最后可以推出：

$$
\hat{\theta}=\frac{x}{N}
$$

这类问题可以通过 derivative = 0 直接求出 answer。

Iterative optimisation 则不同。它不是一次解出来，而是先随机或手动初始化一个 parameter，然后不断更新这个 parameter，让 loss 慢慢变小。也就是说：

> exact optimisation 是直接找到答案；iterative optimisation 是一步一步走向答案。

我可以这样记：

Closed-form:
先推公式，再直接得到 optimal (\theta)。

Iterative:
先猜一个 (\theta)，再根据 loss 的变化方向不断 update。

---

## 2. Gradient Descent 的核心直觉

### 2.1 下山的比喻

Gradient Descent 的直觉可以想成“下山”。假设你站在一座山上，周围有雾，你看不到整个 landscape，只能感受到当前位置附近哪里更陡。如果你的目标是走到山谷底部，你会选择往下降最快的方向走。

在 machine learning 里：

* 山的高度 = loss function value
* 你的位置 = 当前 parameters
* 下山方向 = negative gradient
* 走多远 = learning rate

所以 Gradient Descent 的目标是：

> 沿着 loss function 下降最快的方向，不断更新 parameters，让 loss 越来越小。

---

### 2.2 Gradient 是什么

Gradient 可以理解成 function 上升最快的方向。如果是 single parameter，gradient 就是 derivative：

$$
\frac{\partial f}{\partial \theta}
$$

它告诉我们：

> 当 (\theta) 改变一点点时，function (f(\theta)) 会怎么变。

如果 derivative 是 positive，表示 (\theta) 增加时，(f(\theta)) 会增加。
如果 derivative 是 negative，表示 (\theta) 增加时，(f(\theta)) 会减少。

但我们要 minimize loss，所以不能往 gradient 的方向走，而是要往 opposite direction 走。这就是为什么叫 gradient descent。

---

### 2.3 Single Parameter Update Rule

Gradient Descent 的 update rule 是：

$$
\theta^{(t+1)}
==============

## \theta^{(t)}

\eta
\frac{\partial f}{\partial \theta^{(t)}}
$$

这里：

$$
\theta^{(t)}
$$

是当前 iteration 的 parameter。

$$
\theta^{(t+1)}
$$

是更新后的 parameter。

$$
\eta
$$

是 learning rate。

$$
\frac{\partial f}{\partial \theta^{(t)}}
$$

是当前点的 gradient。

这个公式可以理解成：

> 新参数 = 旧参数 − learning rate × 当前 slope

因为我们要下降，所以是 minus gradient。

---

## 3. Gradient Descent 的 Algorithm

### 3.1 Single Parameter Algorithm

Gradient Descent 的流程是：

1. Define objective function (f(\theta))
2. Initialise parameter (\theta^{(0)})
3. For each iteration:

   * compute derivative
   * update parameter
4. Stop when enough iterations, or loss 不再明显下降

用公式写就是：

$$
\theta^{(t+1)}
==============

## \theta^{(t)}

\eta
\frac{\partial f}{\partial \theta^{(t)}}
$$

这里我需要记住：Gradient Descent 不需要知道整个 function 的 global shape。它只需要知道当前位置的 gradient，然后一步一步走。

---

### 3.2 Multiple Parameters

现实中的 model 通常不只有一个 parameter，而是有很多 parameters：

$$
\theta = [\theta_1,\theta_2,\dots,\theta_F]
$$

这时候我们要对每个 parameter 分别计算 partial derivative：

$$
\frac{\partial f}{\partial \theta_1},
\frac{\partial f}{\partial \theta_2},
\dots,
\frac{\partial f}{\partial \theta_F}
$$

这些 partial derivatives 组成一个 gradient vector：

$$
\nabla f(\theta)
================

\left[
\frac{\partial f}{\partial \theta_1},
\frac{\partial f}{\partial \theta_2},
\dots,
\frac{\partial f}{\partial \theta_F}
\right]
$$

然后统一更新：

$$
\theta^{(t+1)}
==============

## \theta^{(t)}

\eta \nabla f(\theta^{(t)})
$$

所以 multiple-parameter gradient descent 的本质和 single parameter 一样，只是从 scalar update 变成 vector update。

---

## 4. Learning Rate

### 4.1 Learning Rate 控制什么

Learning rate (\eta) 控制每一步走多远。

如果 (\eta) 太小，每一步都很短，model 会慢慢下降，通常比较稳定，但 convergence 很慢。

如果 (\eta) 太大，每一步都太大，可能会直接跳过 minimum，甚至让 loss 越来越大，最后无法 converge。

所以 learning rate 是一个非常重要的 hyperparameter。

---

### 4.2 Learning Rate 太小

如果 learning rate 太小，update rule 里面的 change 会很小：

$$
\eta
\frac{\partial f}{\partial \theta}
\approx 0
$$

这时候 model 会一点一点移动，可能需要很多 iterations 才能到 minimum。

直觉上就是：

> 方向对了，但走太慢。

---

### 4.3 Learning Rate 太大

如果 learning rate 太大，model 可能每一步都跨太远。它可能从 minimum 的左边跳到右边，再从右边跳回左边，来回 oscillate。

更严重时，它会直接跳出合理区域，loss 不降反升，最后 diverge。

所以我需要记住：

> learning rate 太小会慢；learning rate 太大会不稳定。

---

### 4.4 怎么停止 Gradient Descent

Gradient Descent 不可能无限跑，所以需要 stopping criterion。常见方法包括：

* 固定 iterations 数量
* loss function 变化非常小
* validation performance 不再提升
* gradient 非常接近 0

所以停止条件通常不是“我一定找到了 global optimum”，而是：

> 继续更新已经没有明显收益。

---

## 5. Global Minimum 和 Local Minimum

### 5.1 Global vs Local

Global minimum 是整个 function 里面最低的点。Local minimum 是某个局部区域里的最低点，但不一定是全局最低。

如果 function 是 simple convex function，Gradient Descent 比较容易找到 global minimum。

如果 function 是复杂 non-convex function，就可能有很多 local minima。Gradient Descent 从不同初始点出发，可能会走到不同的 local minimum。

---

### 5.2 Initialisation 为什么重要

Gradient Descent 要先 initialise parameters。不同 initialisation 可能导致不同结果。

如果 initial point 在 global minimum 附近，可能会走到 global minimum。
如果 initial point 在某个 local minimum 附近，可能会卡在那里。

所以 transcript 里老师强调：Gradient Descent 没有保证一定找到 global optimum，尤其是在 complex function 里面。

我可以这样记：

> convex function + suitable learning rate → 可以找到 global minimum。
> non-convex function + suitable learning rate → 通常只能保证找到 local minimum。

---

### 5.3 如何减少卡在 local minimum 的风险

常见方法包括：

* 使用不同 random initialisations 多跑几次
* 调整 learning rate
* 使用 adaptive learning rate
* 使用 momentum / gradient history
* 使用 stochastic gradient descent

这些不是 Lecture 8 的考试重点，但要知道：Gradient Descent 的效果不只取决于公式，也取决于 initialisation、learning rate 和 loss surface 的形状。

---

## 6. 从 Naive Bayes 到 Logistic Regression

### 6.1 Naive Bayes 的角度

Naive Bayes 是 probabilistic generative model。它学习的是 joint probability：

$$
P(x,y)
$$

Prediction 时，它用 Bayes Rule 得到：

$$
P(y|x)
$$

Naive Bayes 需要估计：

$$
P(y)
$$

和：

$$
P(x|y)
$$

所以它会建模：

> given class，features 长什么样。

这也是为什么 Naive Bayes 有 feature independence assumption：

$$
P(x_1,x_2,\dots,x_M|y)
\approx
\prod_{m=1}^{M}P(x_m|y)
$$

---

### 6.2 Logistic Regression 的角度

Logistic Regression 换了一个角度。它不去学习：

$$
P(x|y)
$$

而是直接学习：

$$
P(y|x)
$$

也就是说，它直接问：

> given features，class 是 positive 的 probability 是多少？

所以 Logistic Regression 是 probabilistic discriminative model。

它不尝试生成 class 的 features，也不假设 features conditionally independent。它只关心怎么把不同 classes 分开。

所以这里的核心对比是：

> Naive Bayes 学 class 如何生成 features。
> Logistic Regression 直接学 decision boundary。

---

## 7. Logistic Regression 为什么叫 Regression

### 7.1 它其实是 Classification Model

Logistic Regression 名字里有 regression，但它主要用于 binary classification。

例如：

$$
y \in {0,1}
$$

其中：

* (y=1)：positive class
* (y=0)：negative class

它的目标是预测：

$$
P(y=1|x;\theta)
$$

如果 probability 大于 0.5，就预测 class 1；否则预测 class 0。

所以它是 classification model，但它预测的是一个 continuous probability。

这就是为什么它叫 regression：

> 它对 probability 做 regression，再用 threshold 变成 class prediction。

---

### 7.2 不能直接用 Linear Regression 预测 Probability

我们可能会想，直接用 linear function 预测 probability：

$$
p(x)=\theta_0+\theta_1x_1+\dots+\theta_Fx_F
$$

但问题是 probability 必须在 0 到 1 之间：

$$
0 \leq p(x) \leq 1
$$

而 linear function 没有 bound。它可能小于 0，也可能大于 1。

所以 Logistic Regression 需要一个 function，把任意 real number 转换成 0 到 1 之间的 probability。

这个 function 就是 sigmoid function。

---

## 8. Odds、Logit 和 Sigmoid

### 8.1 Probability vs Odds

Probability 是 event 发生的 chance。例如袋子里有 2 个 red balls 和 3 个 blue balls：

$$
P(red)=\frac{2}{5}
$$

Odds 比较的是 event 发生和不发生的相对可能性：

$$
Odds(red)=\frac{P(red)}{1-P(red)}
$$

代入：

$$
Odds(red)=\frac{2/5}{3/5}=\frac{2}{3}
$$

所以 probability 看的是“占全部的比例”，odds 看的是“发生 vs 不发生”的比例。

---

### 8.2 Logit Function

Raw odds 不对称，所以我们通常对 odds 取 log，得到 logit：

$$
logit(p)
========

\log
\frac{p}{1-p}
$$

Logistic Regression 的核心假设是：

$$
logit(p(x))=\theta \cdot x
$$

也就是：

$$
\log
\frac{p(x)}{1-p(x)}
===================

\theta_0+\theta_1x_1+\dots+\theta_Fx_F
$$

这里的意思是：

> features 的 linear combination 不直接预测 probability，而是预测 log-odds。

---

### 8.3 Sigmoid Function

从 logit equation 重新整理，可以得到 sigmoid function：

$$
p(x)
====

# P(y=1|x;\theta)

\frac{1}{1+e^{-\theta\cdot x}}
$$

这个 function 会把任意 real number 映射到 0 和 1 之间。

如果：

$$
\theta\cdot x=0
$$

那么：

$$
p(x)=0.5
$$

如果：

$$
\theta\cdot x>0
$$

那么：

$$
p(x)>0.5
$$

如果：

$$
\theta\cdot x<0
$$

那么：

$$
p(x)<0.5
$$

所以 Logistic Regression 的 decision boundary 是：

$$
\theta\cdot x=0
$$

---

## 9. Logistic Regression Prediction

### 9.1 Binary Prediction Rule

Logistic Regression 先计算：

$$
z=\theta\cdot x
$$

然后用 sigmoid 转成 probability：

$$
P(y=1|x;\theta)=\frac{1}{1+e^{-z}}
$$

最后用 threshold 做 prediction。通常 threshold 是 0.5：

$$
P(y=1|x;\theta)>0.5 \Rightarrow \hat{y}=1
$$

$$
P(y=1|x;\theta)\leq 0.5 \Rightarrow \hat{y}=0
$$

所以我可以这样记：

> Logistic Regression = linear score + sigmoid + threshold。

---

### 9.2 Income Classification Example

Lecture 7 用 income 做 regression，预测 continuous income。Lecture 8 把它变成 classification：例如 income 是否高于 50K。

Target 变成：

$$
y=
\begin{cases}
1 & income > 50K \
0 & income \leq 50K
\end{cases}
$$

Features 可以是：

* Age
* Edu-num
* Hours-per-week

Model 会学习：

$$
P(high\ income=1|Age,EduNum,HoursPerWeek)
$$

如果 probability 大于 0.5，就预测 high income；否则预测 low income。

这就是 logistic regression 如何把 continuous income problem 转成 binary classification problem。

---

## 10. Training Logistic Regression

### 10.1 Logistic Regression 学什么

Logistic Regression 要学习的是 parameter vector：

$$
\theta=[\theta_0,\theta_1,\dots,\theta_F]
$$

这些 parameters 定义了 decision boundary：

$$
\theta\cdot x=0
$$

Training 的目标是找到一组 (\theta)，让 observed training labels 的 likelihood 最大，或者等价地，让 negative log-likelihood 最小。

---

### 10.2 Likelihood

对于一个 training instance ((x_i,y_i))，Logistic Regression 预测：

$$
p_i=P(y_i=1|x_i;\theta)
$$

如果真实 label 是 (y_i=1)，我们希望 (p_i) 越大越好。
如果真实 label 是 (y_i=0)，我们希望 (1-p_i) 越大越好。

所以单个 instance 的 likelihood 可以写成：

$$
p_i^{y_i}(1-p_i)^{1-y_i}
$$

所有 training instances 独立，所以 total likelihood 是 product：

$$
L(\theta)
=========

\prod_{i=1}^{N}
p_i^{y_i}(1-p_i)^{1-y_i}
$$

---

### 10.3 Negative Log-Likelihood

为了方便 optimisation，我们通常取 log，并且把 maximisation 转成 minimisation。

Negative log-likelihood 是：

$$
NLL(\theta)
===========

*

\sum_{i=1}^{N}
\left[
y_i\log p_i
+
(1-y_i)\log(1-p_i)
\right]
$$

这个 loss 也叫 cross-entropy loss。

所以 Logistic Regression 的 training objective 是：

$$
\hat{\theta}
============

\arg\min_{\theta}
NLL(\theta)
$$

---

### 10.4 为什么用 Gradient Descent

Lecture 8 强调：Logistic Regression 的 derivative 可以写出来，但 set derivative to zero 后，(\theta) 没有简单 closed-form solution。

所以我们用 Gradient Descent：

$$
\theta^{(t+1)}
==============

## \theta^{(t)}

\eta
\nabla NLL(\theta^{(t)})
$$

也就是说，先 initialise (\theta)，然后不断计算 gradient、更新 parameters，让 negative log-likelihood 越来越小。

所以 Logistic Regression 是 Lecture 8 把 Gradient Descent 用到真实 ML model 的主要例子。

---

## 11. Multiclass Logistic Regression

### 11.1 One-vs-Rest

Logistic Regression 本身最直接是 binary classifier。如果有多个 classes，可以使用 one-vs-rest。

例如有三类：

* A
* B
* C

可以训练三个 binary classifiers：

* A vs not A
* B vs not B
* C vs not C

最后选择 probability 最高的 class。

---

### 11.2 Softmax

更常见的方法是使用 softmax。Softmax 可以把每个 class 的 score 转成 probability，并保证所有 class probabilities 加起来是 1。

对于 class (k)，先算 score：

$$
z_k=\theta_k\cdot x
$$

然后：

$$
P(y=k|x)
========

\frac{e^{z_k}}
{\sum_{j=1}^{K}e^{z_j}}
$$

如果有三类 A、B、C，那么：

$$
P(y=A|x)+P(y=B|x)+P(y=C|x)=1
$$

最后选择 probability 最大的 class：

$$
\hat{y}=\arg\max_k P(y=k|x)
$$

所以：

> Sigmoid 用于 binary classification。
> Softmax 用于 multiclass classification。

---

## 12. Generative vs Discriminative Models

### 12.1 Naive Bayes 是 Generative Model

Naive Bayes 是 generative model，因为它学习的是：

$$
P(x,y)
$$

或者分解成：

$$
P(y)P(x|y)
$$

它建模的是：

> class 如何生成 features。

例如它会学习：

* dog class 的 features 长什么样
* cat class 的 features 长什么样

所以理论上，generative model 可以用来生成新的 class members。

---

### 12.2 Logistic Regression 是 Discriminative Model

Logistic Regression 是 discriminative model，因为它直接学习：

$$
P(y|x)
$$

它不关心 features 是怎么被 class 生成的，也不建模：

$$
P(x|y)
$$

它只关心：

> given features，应该判成哪个 class。

所以 Logistic Regression 学的是 decision boundary，而不是 class 的生成过程。

---

### 12.3 对比总结

Naive Bayes:

$$
P(x,y)
$$

学习 features 和 class 的 joint distribution。
需要 conditional independence assumption。
属于 generative model。

Logistic Regression:

$$
P(y|x)
$$

直接学习 class given features。
不需要 feature independence assumption。
属于 discriminative model。

所以我可以这样记：

> Naive Bayes 问：这个 class 会生成怎样的 features？
> Logistic Regression 问：这些 features 应该属于哪个 class？

---

## 13. Logistic Regression 的优点和缺点

### 13.1 优点

Logistic Regression 有 probabilistic interpretation。它不是只输出 class，而是输出：

$$
P(y=1|x)
$$

所以我们可以知道 model 的 confidence。

它也没有 Naive Bayes 那种 restrictive feature independence assumption。Features 可以互相关联，model 不需要假设它们 independent。

它通常比 Naive Bayes 更 flexible，也常用于 frequency-based features，例如 text classification 里的 word frequency。

---

### 13.2 缺点

Logistic Regression 的 decision boundary 是 linear 的：

$$
\theta\cdot x=0
$$

所以如果真实 boundary 很 non-linear，Logistic Regression 可能学不好。

它也可能受 feature scaling 影响。因为 model 依赖 feature weights 和 gradient descent，如果 feature scale 差距很大，training 会变得不稳定或收敛慢。

它通常需要比较多 data 才能表现好。相比 Naive Bayes，Logistic Regression 的 assumptions 少，但这也意味着它需要更多 data 来学习 decision boundary。

最后，它可能 overfit，所以 regularisation 很重要。

---

## Lecture 8 总结

Lecture 8 的核心是两件事：

> 第一，Gradient Descent 是当 closed-form solution 不好求时，用 iterative update 找 optimal parameters 的方法。
> 第二，Logistic Regression 是一个用 sigmoid / softmax 直接建模 (P(y|x)) 的 discriminative classifier。

我需要重点记住：

Gradient 是 function 上升最快的方向。
Gradient Descent 走的是 negative gradient direction。
Update rule 是：

$$
\theta^{(t+1)}
==============

## \theta^{(t)}

\eta
\nabla f(\theta^{(t)})
$$

(\eta) 是 learning rate。
Learning rate 太小会慢，太大会 overshoot 或 diverge。
Gradient Descent 在 convex function 上可以找到 global minimum。
在 non-convex function 上通常只能保证 local minimum。
Logistic Regression 是 binary classification model。
它直接建模：

$$
P(y|x)
$$

它是 discriminative model。
它没有 Naive Bayes 的 feature independence assumption。
Logit 是：

$$
\log\frac{p}{1-p}
$$

Sigmoid 是：

$$
P(y=1|x;\theta)=\frac{1}{1+e^{-\theta\cdot x}}
$$

Decision boundary 是：

$$
\theta\cdot x=0
$$

Training Logistic Regression 是 minimize negative log-likelihood：

$$
NLL(\theta)
===========

*

\sum_{i=1}^{N}
\left[
y_i\log p_i
+
(1-y_i)\log(1-p_i)
\right]
$$

Multiclass 可以用 one-vs-rest 或 softmax。
Softmax 是：

$$
P(y=k|x)
========

\frac{e^{\theta_k\cdot x}}
{\sum_{j=1}^{K}e^{\theta_j\cdot x}}
$$

一句话总结：

> Lecture 8 把 optimisation 从“能直接解”的 closed-form 推到“需要一步一步走”的 Gradient Descent，并用 Logistic Regression 展示如何通过 sigmoid 把 linear score 变成 classification probability。
