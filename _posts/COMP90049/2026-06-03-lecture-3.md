# Lecture 3: K-Nearest Neighbour

## 1. KNN 的核心直觉

Lecture 3 开始真正进入第一个 machine learning algorithm：K-Nearest Neighbour。这个 algorithm 的想法很直观，就是如果一个新的 instance 跟过去某些 training instances 很像，那么它们很可能有相似的 label。比如一张新手写数字图片，如果它看起来很像以前见过的几个 “3”，那我们就预测它也是 3。

所以 KNN 的核心不是先学出一条复杂 rule，而是保留过去见过的 examples。预测的时候，它把新的 data point 拿来跟 training data 逐个比较，然后找出最近的 K 个 neighbours。也就是说，KNN 的重点其实是 similarity，而 similarity 在数学里通常就是 distance。

---

## 2. KNN 是 Lazy Learning

KNN 很特别，因为它几乎没有 training。一般 model 会在 training phase 学 parameters，但 KNN 只是把 training examples 存起来。真正的计算发生在 testing / prediction 的时候。

所以我可以这样理解：

- Training：store all training examples
- Testing：calculate distance → find K nearest neighbours → predict label / value

这就是为什么 KNN 被叫做 lazy learning 或 instance-based learning。它不像 eager learning 那样先训练一个 general model，而是等到 test instance 出现时，才临时比较它跟所有 stored instances 的距离。

---

## 3. KNN 可以做 Classification，也可以做 Regression

KNN Classification 是用来预测 discrete label。它会找出最近的 K 个 neighbours，然后看这些 neighbours 里面哪个 class 最多。这个过程叫 majority voting。

例如 K = 5，最近的五个 neighbours 是：

Cat, Cat, Dog, Cat, Dog

因为 Cat 有 3 个，Dog 有 2 个，所以 prediction 是 Cat。

KNN Regression 则是预测 continuous value。它不是 voting，而是对 K 个 neighbours 的 target value 取平均值。例如最近三个房子的价格是 900K、950K、1M，那么 prediction 就是：

$$
\hat{y} = \frac{900 + 950 + 1000}{3}
$$

所以我可以简单记：classification 看最多的 label，regression 看平均 value。

---

## 4. KNN 的四个核心问题

Lecture 3 其实围绕四个问题展开。

第一个问题是：How to represent each data point？也就是每个 instance 要怎么变成 feature vector。因为 KNN 要比较 distance，所以每个 data point 必须被表示成可以比较的形式。

第二个问题是：How to measure distance？不同 data type 要用不同 distance metric。Numerical data 可以用 Manhattan 或 Euclidean distance；nominal data 可能要先 one-hot encoding，然后用 Hamming、Simple Matching 或 Jaccard distance。

第三个问题是：What if neighbours disagree？如果 K 个 neighbours 里面有不同 class，我们要决定怎么 aggregate labels。最简单的方法是 majority voting，也可以用 weighted voting，让更近的 neighbour 权重更大。

第四个问题是：How to select K？K 太小会太敏感，K 太大会太平滑。所以 K 不是随便选的，通常要用 validation data 或 cross-validation 来试。

---

## 5. Feature Vector：先把 data 变成可以比较的形式

KNN 需要先把每个 instance 表示成 feature vector。例如一个 instance 有四个 features：

$$
x = [x_1, x_2, x_3, x_4]
$$

这样我们才能计算两个 instances 之间的 distance。这里要连接 Lecture 2 的内容：feature 可以是 nominal、ordinal 或 numerical，不同 type 的 feature 不能全部用同一种方式处理。

如果是 numerical feature，通常可以直接计算 distance。如果是 nominal feature，例如 red / blue / green，就要先转换成 numeric representation。如果是 ordinal feature，例如 low / medium / high，需要先保留顺序关系，再转换成 rank 或 numeric value。

---

## 6. Nominal Feature 的 Distance

Nominal feature 没有大小顺序，所以不能直接说 red 比 blue 大。课程里先把 nominal features 转成 binary feature vectors，然后再比较。

### 6.1 Hamming Distance

Hamming Distance 计算的是两个 vectors 中不同的位置有多少个。

公式：

$$
d(a,b)=\sum_{i=1}^{n} I(a_i \neq b_i)
$$

如果两个 vectors 有 6 个位置，其中 4 个位置不同，那么 distance 就是 4。这个方法很直观：不同越多，distance 越大。

### 6.2 Simple Matching Distance

Simple Matching Distance 看的是有多少 feature 是 matching 的，然后用：

$$
d = 1 - \frac{k}{m}
$$

其中 k 是 matching features 的数量，m 是 feature 总数。如果两个 instances 有 6 个 features，其中 2 个 match，那么：

$$
d = 1 - \frac{2}{6} = \frac{2}{3}
$$

所以 Simple Matching 的直觉是：match 越多，distance 越小。

### 6.3 Jaccard Distance

Jaccard Distance 更适合 binary / set-like data。它关注两个 sets 的 intersection 和 union。

$$
J = \frac{|A \cap B|}{|A \cup B|}
$$

$$
d = 1 - J
$$

如果两个 fruits 共同拥有的 feature 只有 sweet，但总共有 red、yellow、round、curved、sweet 五个 unique features，那么：

$$
d = 1 - \frac{1}{5} = \frac{4}{5}
$$

我可以这样记：Hamming 看不同位置；Simple Matching 看 match 比例；Jaccard 看 intersection over union。

---

## 7. Numerical Feature 的 Distance

Numerical feature 可以直接做数学计算，所以 Lecture 3 重点讲了 Manhattan、Euclidean 和 Cosine distance。

### 7.1 Manhattan Distance

Manhattan Distance 是每个 feature 的 absolute difference 加起来：

$$
d(a,b)=\sum_{i=1}^{m}|a_i-b_i|
$$

它像是在城市街区里走路，只能横着走或竖着走。它不会平方 difference，所以比 Euclidean 对 extreme difference 稍微没那么敏感。

### 7.2 Euclidean Distance

Euclidean Distance 是直线距离：

$$
d(a,b)=\sqrt{\sum_{i=1}^{m}(a_i-b_i)^2}
$$

这是最常见的 distance。因为 difference 会平方，所以某个 feature 如果差距特别大，它会对 total distance 产生很大影响。

### 7.3 Cosine Distance

Cosine Distance 比较的是两个 vectors 的方向，而不是绝对大小。

$$
cos(a,b)=\frac{a\cdot b}{||a||||b||}
$$

$$
d(a,b)=1-cos(a,b)
$$

它特别适合 text data。例如两个 documents 长度不同，但词的比例很像，Cosine similarity 可能仍然很高。所以 Cosine 比较适合 high-dimensional sparse data，例如 word count vector。

---

## 8. Ordinal Feature 的处理

Ordinal feature 有顺序，但不能直接假设距离相等。例如 low、medium、high 有顺序，但 low 到 medium 和 medium 到 high 的差距不一定真的一样。

Lecture 3 的处理方式是 normalized rank。先把 ordinal values 排序，再把 rank map 到 0 到 1 之间。例如有 5 个等级，rank 可以是：

$$
0,1,2,3,4
$$

然后转换成：

$$
z=\frac{r}{m}
$$

这样 ordinal feature 就可以被转成 numerical value，再使用 Euclidean 或其他 numerical distance。

---
## 9. Neighbours Disagree 怎么办？

当 (K > 1) 时，KNN 找到的 neighbours 不一定都会有同一个 label。比如最近的 4 个 neighbours 里面，有些是 red，有些是 blue，那 model 就需要决定这些 neighbours 的 label 要怎么 combine。Lecture 3 这里其实是在回答第三个核心问题：

> What if the neighbors disagree?

也就是：

> How do we aggregate the labels from the neighbours?

---

### 9.1 Majority Voting

最简单的方法是 **Majority Voting**。也就是说，每个 neighbour 都有一样的权重，每个 neighbour 都投一票，哪个 class 得票最多，就预测哪个 class。

例如 (K = 4)，四个 neighbours 的权重都是：

$$
w_1 = w_2 = w_3 = w_4 = 1
$$

如果结果是：

| Neighbour | Label | Weight |
| --------- | ----- | -----: |
| 1         | red   |      1 |
| 2         | blue  |      1 |
| 3         | blue  |      1 |
| 4         | blue  |      1 |

那么：

$$
score(red)=1
$$

$$
score(blue)=1+1+1=3
$$

所以 prediction 是 blue。

这里的重点是：majority voting 完全不管 neighbour 到 test instance 的 distance。只要在 K 个 neighbours 里面，每个 neighbour 的 vote 都一样重要。

---

### 9.2 Majority Voting 的问题

Majority voting 很直观，但它有一个问题：它假设所有 neighbours 都一样可信。可是 KNN 的基本逻辑是：

> 距离越近，越相似。

如果一个 red neighbour 距离 test instance 非常近，而三个 blue neighbours 虽然也在 K 个 neighbours 里面，但距离比较远，那么 majority voting 还是会预测 blue。这个结果可能不合理，因为最近的那个 red neighbour 可能更能代表 test instance。

所以这里自然引出 weighted voting：

> closer neighbours should have larger influence.

---

### 9.3 Weighted KNN: Inverse Distance

第一种 weighted KNN 是 **Inverse Distance Weighting**。它的想法是：

> distance 越小，weight 越大。

公式是：

$$
w_j = \frac{1}{d_j + \epsilon}
$$

其中：

$$
d_j = \text{distance of the } j\text{th neighbour}
$$

$$
\epsilon \approx 0
$$

这里加上 ($\epsilon$) 是为了避免 distance 等于 0 时除以 0。Lecture 的例子里用了一个很小的值，例如：

$$
\epsilon = 1e^{-5}
$$

如果某个 neighbour 跟 test instance 距离是 0，那么它的权重会非常大。直觉上就是：如果 test instance 几乎跟某个 training instance 一模一样，那这个 training instance 的 label 应该非常有说服力。

例如 Lecture 的例子：

$$
d_1=0,\quad d_2=1,\quad d_3=1.5,\quad d_4=1.5
$$

如果第一个 neighbour 是 red，其他三个是 blue，那么 red 的 score 是：

$$
score(red)=\frac{1}{0+\epsilon}
$$

如果：

$$
\epsilon = 1e^{-5}
$$

那么：

$$
score(red)=100000
$$

blue 的 score 是：

$$
score(blue)=\frac{1}{1+\epsilon}+\frac{1}{1.5+\epsilon}+\frac{1}{1.5+\epsilon}
$$

大概是：

$$
score(blue)=1.0+0.67+0.67=2.34
$$

所以虽然 blue 有三个 neighbours，red 只有一个 neighbour，但 weighted KNN 会预测 red。因为 red neighbour 太近了，它的 influence 远远大于其他 neighbours。

这就是 weighted KNN 和 majority voting 的核心差别：majority voting 看数量，weighted voting 看距离影响力。

---

### 9.4 Weighted KNN: Inverse Linear Distance

Lecture 3 还讲了另一种 weighting 方法，叫 **Inverse Linear Distance**。它不是直接用 (1/d)，而是根据 neighbour 在最近距离和最远距离之间的位置来分配权重。

公式是：

$$
w_j = \frac{d_k - d_j}{d_k - d_1}
$$

其中：

$$
d_1 = \text{minimum distance among neighbours}
$$

$$
d_k = \text{maximum distance among neighbours}
$$

$$
d_j = \text{distance of the } j\text{th neighbour}
$$

这个公式的意思是：最近的 neighbour 权重最大，最远的 neighbour 权重会接近 0。也就是说，在 K 个 neighbours 里面，越靠近 test instance 的 neighbour 越重要，越靠近边界最远端的 neighbour 越不重要。

继续用 Lecture 的例子：

$$
d_1=0,\quad d_2=1,\quad d_3=1.5,\quad d_4=1.5
$$

因为：

$$
d_k = 1.5
$$

所以第一个 neighbour 的 weight 是：

$$
w_1 = \frac{1.5-0}{1.5-0}=1
$$

第二个 neighbour 的 weight 是：

$$
w_2 = \frac{1.5-1}{1.5-0}=0.33
$$

第三和第四个 neighbour 的 distance 都是 1.5，所以：

$$
w_3 = \frac{1.5-1.5}{1.5-0}=0
$$

$$
w_4 = \frac{1.5-1.5}{1.5-0}=0
$$

如果第一个 neighbour 是 red，其他三个是 blue，那么：

$$
score(red)=1
$$

$$
score(blue)=0.33+0+0=0.33
$$

所以 prediction 还是 red。

---

### 9.5 Majority vs Weighted Voting

这里我需要记住：KNN 的 prediction rule 不只有一种。

Majority voting 是最简单的：

> 每个 neighbour 一票。

Weighted voting 更细一点：

> neighbour 越近，vote 越重要。

Inverse distance weighting 会让 distance 很小的 neighbour 影响非常大，尤其当 (d=0) 的时候，所以需要 (\epsilon)。Inverse linear distance 比较温和，它把 neighbour 的 distance 映射到一个相对权重，让最远的 neighbour 权重接近 0。

所以这部分的重点不是背哪一种一定最好，而是理解：

> KNN 找到 neighbours 之后，还要决定如何 aggregate neighbour labels。

不同 aggregation rule 可能会给出不同 prediction。

---

## 10. 如何选择 K

K 是 KNN 最重要的 hyperparameter。

如果 K = 1，prediction 只看最近的一个 neighbour。这样 model 很 flexible，可以 fit 很复杂的 boundary，但也很容易被 noise 影响。如果最近的那个 neighbour 是错误 label，prediction 也会错。

所以：

Small K → jagged decision boundary → 容易 capture noise → high variance

如果 K 很大，prediction 会变得很 smooth。它比较稳定，不容易被单个 noisy point 影响，但也可能把本来不同的 class 混在一起。

所以：

Large K → smooth decision boundary → 可能 underfit → high bias

如果 K = N，也就是把所有 training instances 都拿来 voting，那么 model 基本上只会预测 majority class，这就失去了 local similarity 的意义。

所以我需要记住：K 不能凭感觉选，通常要用 validation error 来比较不同 K 的效果，选 validation performance 最好的 K。

---

## 11. Tie Breaking

Lecture 3 也提到 tie 的问题。KNN 可能出现两种 tie。

第一种是 tied distances。例如两个 neighbours 到 test instance 的距离完全一样，但 label 不同。第二种是 tied votes。例如 K = 4，两个 class 各有 2 票。

这种时候需要一个 tie-breaking rule，例如：

* 选择距离更近的 class
* 使用 weighted voting
* 选择 training order 里先出现的 class
* 随机选择
* 调整 K，避免偶数 K 造成平票

重点不是背哪一种，而是知道 KNN implementation 必须处理 tie，不同 implementation 可能结果不同。

---

## 12. KNN 的优点和缺点

KNN 的优点是非常 intuitive and simple。它没有太多 model assumptions，也可以同时支持 classification 和 regression。因为它不需要真正 training，所以新 data 加进来以后，model 可以马上使用。

但 KNN 的缺点也很明显。
- 第一，prediction expensive，因为每次 test 都要跟所有 training instances 算 distance。
- 第二，distance function 很重要，选错 distance 会让结果很差。
- 第三，feature scaling 很重要，如果 feature 没有 normalised，大尺度 feature 会 dominate distance。
- 第四，K 的选择会严重影响 performance。

所以 KNN 简单，但不是随便用。它的效果依赖三个选择：

* feature representation
* distance metric
* K value

---

## 13. Lazy Learning vs Eager Learning

Lecture 3 最后用 KNN 引出 lazy learning 和 eager learning 的区别。

KNN 是 Lazy Learning，因为它只是 store training data，不主动 build 一个 general model。Prediction 时，它才去比较 test instance 和 stored instances。

Eager Learning 则相反。它会先用 training data 训练出一个 model，然后用这个 model 预测 unseen data。后面的 Decision Tree、Naive Bayes、Logistic Regression、SVM 都更接近 eager learning。

---

## 14. Lecture 3 Summary

Lecture 3 的核心是：

> KNN 用 similarity 来做 prediction。

1. Store all training examples
2. Represent each instance as a feature vector
3. Choose a distance metric
4. For a test instance, calculate distance to all training instances
5. Find K nearest neighbours
6. Classification 用 majority / weighted voting
7. Regression 用 average value
8. 用 validation 选择合适的 K
