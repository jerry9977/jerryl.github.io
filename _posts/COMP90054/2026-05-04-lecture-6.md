# Model-based RL：Value Iteration 与 MCTS

## 1. Value Iteration 概述

Value Iteration（值迭代）是一种经典的模型求解方法，适用于已知 MDP 的状态转移概率和奖励函数。它通过反复更新状态价值函数 $V(s)$，直到收敛到最优价值函数 $V^{*}(s)$。

Value Iteration 的核心更新公式为：

$$
V_{k+1}(s) = \max_{a} \sum_{s'} P(s'\mid s,a) \left[ R(s,a,s') + \gamma V_{k}(s') \right]
$$

其中：

- $s$ 是当前状态。
- $a$ 是动作。
- $s'$ 是下一个状态。
- $P(s'\mid s,a)$ 是转移概率。
- $R(s,a,s')$ 是即时奖励。
- $\gamma$ 是折扣因子。
- $V_{k}(s)$ 表示第 $k$ 次迭代时的价值估计。

Value Iteration 的步骤：

1. 初始化所有状态价值 $V(s)$，通常设为 0 或随机值。
2. 对每个状态 $s$，计算每个动作 $a$ 的期望回报。 
3. 取其中最大的动作值，更新 $V(s)$。
4. 重复迭代直到 $V(s)$ 收敛。


>For each state $s$, the algorithm first computes the expected return for every possible action $a$. The algorithm then selects the action that produces the maximum expected return, and uses this maximum value to update the value of the current state.

## 2. Value Iteration 例子

考虑一个简单 MDP，状态集合 $S=\{s_{1}, s_{2}, s_{3}\}$，动作集合 $A=\{a_{1}, a_{2}\}$。转移与奖励如下：

- 从 $s_{1}$：
  - $a_{1}$ 转移到 $s_{2}$，奖励 $+5$；
  - $a_{2}$ 转移到 $s_{3}$，奖励 $+10$。
- 从 $s_{2}$：
  - $a_{1}$ 保持 $s_{2}$，奖励 $0$；
  - $a_{2}$ 转移到 $s_{3}$，奖励 $+2$。
- 从 $s_{3}$：
  - $a_{1}$ 保持 $s_{3}$，奖励 $0$；
  - $a_{2}$ 保持 $s_{3}$，奖励 $0$。

这里假设状态转移确定性，折扣因子 $\gamma = 0.9$。

### 2.1 初始化

初始价值：

$$
V_{0}(s_{1}) = V_{0}(s_{2}) = V_{0}(s_{3}) = 0.
$$

### 2.2 第一次迭代

计算每个状态的动作价值：

- $s_{1}$：
  - $a_{1}$: $5 + 0.9 V_{0}(s_{2}) = 5$。
  - $a_{2}$: $10 + 0.9 V_{0}(s_{3}) = 10$。
  - 取最大值：$V_{1}(s_{1}) = 10$。
- $s_{2}$：
  - $a_{1}$: $0 + 0.9 V_{0}(s_{2}) = 0$。
  - $a_{2}$: $2 + 0.9 V_{0}(s_{3}) = 2$。
  - 取最大值：$V_{1}(s_{2}) = 2$。
- $s_{3}$：
  - $a_{1}$: $0 + 0.9 V_{0}(s_{3}) = 0$。
  - $a_{2}$: $0 + 0.9 V_{0}(s_{3}) = 0$。
  - 取最大值：$V_{1}(s_{3}) = 0$。

结果：

- $V_{1}(s_{1}) = 10$
- $V_{1}(s_{2}) = 2$
- $V_{1}(s_{3}) = 0$

### 2.3 第二次迭代

根据 $V_{1}$ 继续计算：

- $s_{1}$：
  - $a_{1}$: $5 + 0.9 V_{1}(s_{2}) = 5 + 0.9 \times 2 = 6.8$。
  - $a_{2}$: $10 + 0.9 V_{1}(s_{3}) = 10$。
  - $V_{2}(s_{1}) = 10$。
- $s_{2}$：
  - $a_{1}$: $0 + 0.9 V_{1}(s_{2}) = 1.8$。
  - $a_{2}$: $2 + 0.9 V_{1}(s_{3}) = 2$。
  - $V_{2}(s_{2}) = 2$。
- $s_{3}$：仍然为 0。

这说明 $V(s)$ 已经收敛到：

- $V^{*}(s_{1}) = 10$
- $V^{*}(s_{2}) = 2$
- $V^{*}(s_{3}) = 0$

### 2.4 读懂结果

- 在 $s_{1}$，最优动作是 $a_{2}$，因为直接获得更高奖励。
- 在 $s_{2}$，最优动作是 $a_{2}$，因为它比留在当前状态更有价值。
- $s_{3}$ 是终止状态或奖励 0 的循环状态。

## 3. MCTS 概述

Monte Carlo Tree Search（蒙特卡洛树搜索，MCTS）是一种用于决策和规划的搜索算法，常用于游戏 AI（如围棋、国际象棋）和复杂的策略搜索问题。

MCTS 不依赖完整状态转移模型的显式计算，而是通过随机模拟来估计动作价值。核心思想是在搜索树中反复采样，从而找到最优动作。

MCTS 的主要步骤：

1. Selection：从根节点开始，根据树策略选择一个叶节点。
2. Expansion：如果叶节点不是终止状态，则扩展一个或多个子节点。
3. Simulation：从新扩展的节点随机模拟一个完整轨迹，得到回报。
4. Backpropagation：将模拟结果沿路径回传，更新经过节点的统计值。

常用的树策略是 Upper Confidence Bound for Trees（UCT）：

$$
U(s,a) = Q(s,a) + c \sqrt{\frac{\ln N(s)}{N(s,a)}}
$$

- $Q(s,a)$：动作平均回报。
- $N(s)$：状态 $s$ 被访问的次数。
- $N(s,a)$：动作 $a$ 在状态 $s$ 被选择的次数。
- $c$：探索常数。

## 4. MCTS 例子

假设一个简单的游戏状态 $s_{0}$，可选动作 $A=\{a_{1}, a_{2}\}$。我们希望用 MCTS 估计哪个动作更好。

### 4.1 初始树

初始时树只有根节点 $s_{0}$，统计值都为 0。

### 4.2 第一次模拟

1. Selection：从 $s_{0}$ 选择一个动作。初始时 $U(s_{0},a)$ 相同，假设选择 $a_{1}$。
2. Expansion：生成子节点 $s_{1}$。
3. Simulation：从 $s_{1}$ 随机模拟得到回报 $r=3$。
4. Backpropagation：更新根节点统计值：
   - $N(s_{0}) = 1$。
   - $N(s_{0},a_{1}) = 1$。
   - $Q(s_{0},a_{1}) = 3$。

### 4.3 第二次模拟

1. Selection：计算根节点的 UCT 值。
   - $U(s_{0},a_{1}) = 3 + c \sqrt{\ln 1 / 1} = 3$。
   - $U(s_{0},a_{2})$ 由于 $N(s_{0},a_{2})=0$，通常优先选择未探索动作，假设选择 $a_{2}$。
2. Expansion：生成子节点 $s_{2}$。
3. Simulation：从 $s_{2}$ 随机模拟得到回报 $r=1$。
4. Backpropagation：
   - $N(s_{0}) = 2$。
   - $N(s_{0},a_{2}) = 1$。
   - $Q(s_{0},a_{2}) = 1$。

### 4.4 第三次模拟

继续选择动作：
- $a_{1}$ 的 UCT：$3 + c \sqrt{\ln 2 / 1}$。
- $a_{2}$ 的 UCT：$1 + c \sqrt{\ln 2 / 1}$。

如果探索因子 $c$ 相同，$a_{1}$ 的平均回报更高，因此更可能被选择。通过进一步模拟，MCTS 会逐步积累不同动作的均值和访问次数。

最终，根节点会选择平均回报更高、且经过充分探索的动作。

## 5. Value Iteration 与 MCTS 对比

- Value Iteration：需要完整的 MDP 模型，适合状态空间有限、转移概率已知的场景。它直接计算最优价值。
- MCTS：适合复杂决策问题或模型不完全已知的场景，通过模拟估计动作价值，常用于策略搜索和博弈。

## 6. 结论

- Value Iteration 是经典的动态规划方法，适合模型明确、状态转移可计算的 MDP。
- MCTS 是基于模拟的搜索方法，适合大规模、复杂、甚至确定性转移结构不完全可知的问题。
- 两者都属于 model-based 方法，但 Value Iteration 依赖完整概率模型，MCTS 更依赖模拟和探索策略。
