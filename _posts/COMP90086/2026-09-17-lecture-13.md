# COMP90086 — Depth and Stereo

> 本讲讨论如何从二维图像恢复三维世界中的深度：单张图像依赖视觉线索与假设，而双目视觉可以通过已知相机几何进行测量。核心内容包括 disparity 与 depth 的关系、stereo correspondence、全局优化，以及 monocular depth learning。

## 1. 从二维图像理解三维深度

相机把三维世界投影到二维 image plane 时，会丢失一个维度。具体而言，每个 image pixel 只能确定一条从 camera centre 出发的 ray，却无法直接确定场景点在这条 ray 上的具体位置。因此，**同一张二维图像可以由无限多个不同的三维场景产生**。

Ames room 展示了这种歧义：房间的地板、墙壁、窗户和纹理都经过特殊设计，使观察者误以为它是一个普通矩形房间。人沿房间移动时，看起来会突然变大或缩小。视觉系统并没有真正测量到房间深度，而是根据平行线、规则纹理和熟悉物体大小等经验作出推断；当这些假设被故意破坏时，推断就会失败。

### 单张图像中的 depth cues

| Depth cue | 解释 | 隐含假设 |
|---|---|---|
| Perspective | 平行线向 vanishing point 汇聚；相等间距随距离增加而压缩 | 场景中的线原本平行、间距原本相等 |
| Texture gradient | 均匀纹理在远处看起来更小、更密，形状也会随 surface orientation 改变 | 纹理在真实表面上近似均匀 |
| Occlusion | 遮挡其他物体的表面通常位于前方 | 图像边界确实由遮挡产生 |
| Familiar size | 根据人、车等熟悉物体的典型尺寸推断距离 | 物体具有正常大小 |
| Height in frame | 对位于同一地面的物体，图像中位置更高通常代表更远 | 物体位于相同或连续的 ground plane |

这些 **monocular cues 都是 heuristics**：大多数情况下有效，但并不是由图像几何唯一确定的测量结果。

从多个视角则可以获得更直接的深度信息：

- **Binocular disparity**：两个相隔固定距离的相机在不同 image positions 观察到同一个 world point。
- **Motion parallax**：同一相机移动后形成两个不同时刻的 viewpoints；近处物体在图像中的相对移动通常更大。

🟨 **核心区别：** 单视图线索依赖关于场景的假设；如果两台相机的几何关系已知，双目 disparity 可以通过 triangulation 测量 depth。但这种测量的前提是能在两幅图像中找到同一个 world point。

## 2. Stereo geometry：由 disparity 计算 depth

先考虑最简单的 rectified stereo setup：

- 两台 pinhole cameras 朝向完全相同；
- image planes 平行；
- focal length 相同；
- 两个 camera centres 只沿 $x$ 轴相隔 baseline $b$；
- 同一个 world point 在左右图像中的 vertical coordinate 相同。

设一个 world point 的 depth 为 $z$，它在左、右图像中的 horizontal coordinates 分别为 $x$ 和 $x'$。定义 disparity：

$$
d = x-x'
$$

由 similar triangles 可得：

$$
\frac{z}{b}=\frac{f}{d}
$$

因此：

$$
\boxed{z=\frac{fb}{d}=\frac{fb}{x-x'}}
$$

其中：

- $z$：沿相机 optical axis 测得的 depth；
- $f$：focal length，通常以 pixels 表示；
- $b$：两个 camera centres 之间的 baseline；
- $d$：同一 world point 在两幅图像中的 disparity，通常以 pixels 表示。

这里的 $z$ 是 optical-axis depth，而不是 world point 到某一个相机的 Euclidean distance。因此，当物体只沿水平方向移动、$z$ 保持不变时，disparity 也保持不变。

### Disparity 与 depth 的关系

Depth 与 disparity 成反比：

- 物体越近，$d$ 越大；
- 物体越远，$d$ 越小；
- 当 $d\approx 0$ 时，$z\to\infty$，表示物体远到在两幅图像中的位置几乎不变。

在本讲采用的相机排列和定义 $d=x-x'$ 下，位于相机前方的正常对应点应满足 $d\ge 0$。若匹配得到 $d<0$，两条 viewing rays 会在相机后方相交，因此这不是一个物理上有效的前方场景点。即使该位置具有最低 matching cost，也应该通过合法 disparity range 将其排除。

🟦 **注意：** “负 disparity”不是指两个物体交换了位置，而是当前候选 correspondence 与已知 stereo geometry 不一致，因而很可能是错误匹配。

### Depth uncertainty

实际图像只能以 pixels 采样，$x$ 与 $x'$ 的定位通常存在约一个 pixel 的误差。由

$$
z=\frac{fb}{d}
$$

对 $d$ 求偏导：

$$
\frac{\partial z}{\partial d}
=-\frac{fb}{d^2}
=-\frac{z^2}{fb}
$$

因此，小的 disparity error $\Delta d$ 会产生近似 depth error：

$$
|\Delta z|\approx \frac{z^2}{fb}|\Delta d|
$$

这说明 depth uncertainty 随距离的平方增长：物体距离加倍时，相同的 one-pixel disparity error 会造成约四倍的 depth error。

| 参数变化 | 对几何精度的影响 | 同时带来的代价 |
|---|---|---|
| 增大 baseline $b$ | disparity 增大，depth error 减小 | 两幅图像 viewpoint 差异更大，correspondence 更难 |
| 增大 focal length $f$ | disparity 对 depth 更敏感，精度提高 | field of view 通常变窄 |
| 增大 depth $z$ | depth error 以 $z^2$ 增长 | 远处物体的 disparity 可能小到难以分辨 |

🟨 **关键 trade-off：** wider baseline 提高 triangulation 精度，却也使左右图像看起来更不相似，从而增加匹配失败的概率。

## 3. Correspondence：沿 scanline 寻找匹配

要使用 $z=fb/d$，必须先测量每个 pixel 的 disparity，也就是解决 **correspondence problem**。在 aligned stereo images 中，同一个 world point 在两幅图像里具有相同的 $y$ coordinate，因此不需要搜索整张图，只需要沿同一条 horizontal scanline 搜索。

一个基本的 dense stereo algorithm 如下：

```text
左图中的 pixel x
  ↓
取 x 周围的 local window
  ↓
沿右图同一 row 滑动候选 window
  ↓
计算每个位置的 matching score
  ↓
选择最佳位置 x'
  ↓
d = x - x'，再由 z = fb/d 得到 depth
```

如果已知场景的最小可能深度 $z_{\min}$，还能由

$$
d_{\max}=\frac{fb}{z_{\min}}
$$

限制最大搜索范围。结合 $d\ge 0$，可避免搜索不可能产生前方场景点的区域。

### SSD 与 NCC

最直接的 window matching score 是 sum of squared differences（SSD）：

$$
\operatorname{SSD}(w,w')=
\sum_{u,v}\left(w_{u,v}-w'_{u,v}\right)^2
$$

SSD 计算便宜，并且 score 越小表示两个 patches 越相似。但两台相机的 exposure、white balance 或 black level 可能不同；即使观察同一表面，对应 patches 的 brightness 也不一定一致，SSD 会把这种 photometric difference 当成 mismatch。

Normalized cross-correlation（NCC）通常更稳健。先对每个 window 减去自己的 mean，再计算：

$$
\operatorname{NCC}(w,w')=
\frac{\sum_{u,v}\tilde w_{u,v}\tilde w'_{u,v}}
{\lVert\tilde w\rVert_2\lVert\tilde w'\rVert_2}
$$

其中 $\tilde w=w-\bar w$，$\tilde w'=w'-\bar w'$。NCC 对线性的 brightness gain 和 offset 更不敏感；score 越大通常代表匹配越好。

### Window size 的 trade-off

- **Small window** 能保留细小结构和 sharp depth boundaries，但提供的信息少，matching cost 容易受 noise 或偶然相似影响。
- **Large window** 包含更多 texture，因此匹配更稳定；但若 window 横跨 foreground 与 background，它会混合不同 depths，使边界被模糊，甚至让小物体取得背景的 disparity。

🟩 课堂示例中，一个 window 原本位于建筑前的灌木上。较小 window 得到灌木自身的 disparity；window 扩大并包含更多墙面后，最佳 disparity 突然变成建筑背景的值。扩大 window 降低了噪声，却牺牲了 depth edge。

## 4. 为什么局部匹配会失败，以及如何全局优化

即使限制在同一 scanline，per-pixel window matching 仍然存在多种固有歧义：

| Failure case | 原因 |
|---|---|
| No texture | 空白墙面内的多个 windows 几乎完全相同，没有唯一最佳匹配 |
| Repeated texture | 砖墙、栅栏等重复结构产生多个 local minima |
| Occlusion | 某个 world point 只在一个 viewpoint 可见，另一幅图中根本不存在正确 correspondence |
| Specular surface | highlight 取决于 viewpoint；左右相机看到的亮点可能落在不同 surface points 上 |
| Transparency | 图像是玻璃表面、反射与背景的混合，单一 pixel 不再对应单一 depth |

当 cost curve 中存在两个相近的 minima 时，仅凭当前 patch 可能无法判断哪一个正确。重复结构甚至可能导致第一根柱子匹配第二根、第二根又匹配第一根。此时需要利用整幅 disparity map 的结构，而不只是逐 pixel 独立决策。

### 三个常用约束

1. **Uniqueness**：一个 point 在另一幅图像中最多有一个 match。
2. **Ordering**：同一 scanline 上的 points 通常在左右图中保持相同的 left-to-right order。
3. **Smoothness**：大多数相邻 pixels 的 disparity 相近，但 object boundaries 允许突然变化。

Ordering 并非绝对成立。例如，细的 foreground object 可能让左右相机看到其两侧不同的背景区域；transparent surfaces 也会破坏简单排序关系。因此这些更适合作为 soft constraints，而不是永远不可违反的 hard rules。

### 全局 energy function

可将 disparity map $D$ 的求解写成一个 global energy minimisation：

$$
E(D)=
\sum_i \left(W_1(i)-W_2(i+D(i))\right)^2
+\lambda\sum_{i,j\in\mathcal N}\rho\left(D(i)-D(j)\right)
$$

第一项是 **data term / match quality**：要求 pixel $i$ 在另一幅图像的 $i+D(i)$ 位置匹配良好。第二项是 **smoothness term**：要求 neighbourhood $\mathcal N$ 中的相邻 pixels 具有相近 disparities。

- $\lambda$ 太小：data term 主导，disparity map 仍然 noisy；
- $\lambda$ 太大：过度平滑，真实 object boundaries 也会被抹去；
- $\rho$ 应缓慢增长或在一定差异后饱和，使真正的 depth discontinuity 需要付出代价，但不会被禁止。

Lecture 介绍用 **graph cuts** 近似优化这个目标。若暂时只有两个 disparity labels，可把每个 pixel 与两个 labels 连接，并把相邻 pixels 相连；cut 的 cost 对应被切断 edges 的总代价。最小代价的 cut 决定每个 pixel 属于哪个 disparity。对于多个 disparity values，可使用类似 $\alpha$-expansion 的过程：让每个 pixel 在“保留当前 disparity”和“切换到 $\alpha$”之间选择，再依次 sweep 不同的 $\alpha$，直到 energy 不再降低。

这样做的关键收益不是改变 local matching cost，而是让每个 pixel 的答案同时受到 neighbours 约束。因此，某个位置即使具有两个相近 minima，也可能根据周围 pixels 一致支持的 disparity 选择正确解。

### Rectification

实际 stereo cameras 未必只沿 $x$ 轴平移，它们可能还存在 rotation。对于一般相机配置，一个 image point 的对应点不再位于同一 horizontal row，而是位于另一幅图像的一条 **epipolar line** 上。

Stereo rectification 分别对两幅图像应用 homographies $H_1$ 和 $H_2$，把对应的 epipolar lines 变换到相同 horizontal rows。于是一般 stereo pair 被转化为前面假设的 aligned pair，二维 correspondence search 再次简化为一维 scanline search。Epipolar geometry 与 rectifying homographies 的推导留到下一讲。

## 5. 从单张图像学习 depth

Stereo 能测量 depth，但需要两台相机以及可靠 correspondence。在小型 drone 等场景中，系统可能只能携带一个 camera，因此需要从单张图像估计 per-pixel depth。

Monocular depth estimation 通常训练一个 image-to-image neural network：输入 RGB image，输出与输入空间位置对应的 depth map。训练所需的 ground-truth depth 可以由 depth camera、LiDAR 或其他测距系统获得。课堂提到 Microsoft Kinect：它向环境投射已知的 pseudo-random infrared dot pattern，再用有 baseline 的 infrared camera 观察图案位移，本质上利用 active stereo 获得 depth。

### Loss 为什么常在 log depth 上计算

场景 depth 可能跨越多个数量级。如果直接最小化 absolute depth error，那么远处物体的误差会主导训练。例如，同样是一米误差，对近处物体非常严重，对一公里外的物体却相对很小。

令预测和真实 depth 分别为 $\hat z$ 与 $z$，比较

$$
\log \hat z-\log z
=\log\left(\frac{\hat z}{z}\right)
$$

更接近比较 relative error：预测相差 $10\%$ 时，无论物体近或远，都产生类似惩罚。Scale-invariant loss 还可减少不同场景 mean depth 的影响，避免模型只学习“室内房间通常有多深”这类平均值。

### Coarse-to-fine prediction

Eigen、Puhrsch 与 Fergus（2014）的 multi-scale network 先在低分辨率预测场景的 global depth layout，再由 refinement network 加入 local detail：

```text
RGB image
  ↓
coarse network：整体 scene layout
  ↓
low-resolution depth
  ↓
refinement network：结合局部 image features
  ↓
higher-resolution depth map
```

Global cues 与 local cues 因而被分阶段学习。此后许多 monocular depth systems 也采用 coarse-to-fine 或 multi-scale 思路。

### 用 stereo pairs 进行 self-supervision

训练时不一定需要真实 depth map。Godard、Mac Aodha 与 Brostow（2017）使用 rectified stereo pairs：network 从单张图像预测 disparity，再利用 predicted disparity 将另一幅图像 warp 到当前 viewpoint。如果 disparity 正确，reconstructed image 应与真实图像相似。

其训练信号通常包括：

- **Appearance reconstruction loss**：重建图像与真实图像应相似；
- **Disparity smoothness loss**：相邻位置的 disparity 通常平滑；
- **Left-right consistency loss**：左右方向预测应彼此一致，可帮助识别 appearance loss 难以处理的 occlusions。

模型训练时使用 stereo rig 提供监督，部署时却只需要单张图像。

## 6. Monocular depth 的限制与整体结论

Monocular network 并没有从一张图像中获得新的几何测量；它学习的是训练数据中经常成立的 depth heuristics，例如 texture gradient、perspective、familiar object size 和 scene layout。因此它继承了几个根本限制：

- **Blurred depth edges**：连续的 network output 倾向在 foreground 与 background 之间插值，而真实 depth discontinuity 恰好是不连续的。
- **Training-distribution dependence**：只在 indoor scenes 上训练的模型学习的是 indoor layout，不能保证泛化到 outdoor scenes 或训练中从未出现的距离范围。
- **Scale ambiguity**：单张图像无法区分“较小物体在近处”与“较大物体在远处”。
- **Camera dependence**：模型可能把训练相机的 focal length 内化为隐含假设。换成 wide-angle camera 后，同距离物体在图像中变小，模型可能误判为更远；整体 depth 也可能按 focal-length ratio 产生 scale error。

若训练包含多个 cameras，并把 focal length 或其他 camera intrinsics 明确提供给模型，camera change 的影响可以减轻。也有系统尝试同时估计 focal length，但这仍依赖 learned priors，而不是仅由单张图像完成绝对尺度测量。

🟨 **整讲核心：**

1. 单张图像保留了许多 depth cues，但它们都是可能被破坏的 assumptions。
2. 两个已知几何关系的 aligned views 可以通过 $z=fb/d$ 测量 depth。
3. Stereo depth 的主要困难不是公式，而是 correspondence；depth accuracy 随距离平方恶化。
4. Local window matching 会受到纹理缺失、重复结构、occlusion、specularity 与 transparency 影响，因此需要 uniqueness、ordering、smoothness 等全局信息。
5. Monocular learning 可以预测 dense depth，但其能力和尺度来自 training data、camera assumptions 与 learned heuristics，而非单视图中的唯一几何解。
