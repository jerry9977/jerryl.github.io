# Lecture 1–2：计算机视觉导论与图像形成

## Introduction to Computer Vision and Image Formation

## 1. 什么是 Computer Vision

### 1.1 Computer Vision 的定义

Computer Vision 研究的是：

> 如何让计算机从 image 或 video 中提取信息，并对现实世界产生一定程度的理解。

它的输入通常是 image-based information，输出则可能是：

* 图片中的 object class
* Object 的位置
* 每个 pixel 的类别
* Camera 的位置和方向
* Scene 的 3D structure
* Robot 下一步应该执行的 action
* 根据已有图像生成的新图像

所以 Computer Vision 不只是“看见图片”，而是：

> 将 visual data 转换成可以用于 reasoning、prediction 和 action 的信息。

---

### 1.2 Computer Vision 是跨学科领域

Computer Vision 会使用多个领域的知识：

* Machine Learning
* Deep Learning
* Image Processing
* Computer Graphics
* Geometry
* Linear Algebra
* Probability
* Optics and Physics
* Neuroscience
* Psychology
* Robotics

现代 Computer Vision 中，大部分复杂任务都会使用 Deep Learning，但传统的 image processing、camera geometry 和 3D mathematics 仍然非常重要。

---

## 2. Computer Vision 的主要任务

### 2.1 Image Classification

Image Classification 的目标是给整张图片一个 label。

例如给定一张图片，model 可能预测：

* Bicycle
* Dog
* Car
* Pedestrian

可以表示成：

$$
f(I)=y
$$

其中：

* (I) 是输入 image
* (y) 是预测 class

它回答的问题是：

> 这张图片里主要是什么？

但 classification 不会告诉我们 object 在图片的什么位置。

---

### 2.2 Object Detection

Object Detection 不只需要识别 object，还需要定位它。

输出通常包括：

* Object class
* Bounding box
* Confidence score

例如自动驾驶系统需要检测：

* Pedestrians
* Cars
* Cyclists
* Traffic signs

它回答的问题是：

> 图片里有哪些 objects？它们分别在哪里？

---

### 2.3 Semantic Segmentation

Semantic Segmentation 会对 image 中的每个 pixel 进行分类。

例如：

* Road
* Footpath
* Building
* Tree
* Sky
* Pedestrian
* Vehicle

可以表示为：

$$
f(I)_{x,y}=c
$$

其中 (c) 是 pixel ((x,y)) 所属的 semantic class。

所以：

> Classification 对整张图片分类；segmentation 对每个 pixel 分类。

---

### 2.4 Part Recognition

有时候只识别完整 object 还不够，还需要识别 object 的组成部分。

例如人体可以进一步分成：

* Head
* Torso
* Upper arm
* Lower arm
* Upper leg
* Lower leg

Vision-based game controller 可以通过识别人体各部分的位置，估计玩家正在进行的动作。

---

### 2.5 Surface Normal 和 Saliency

除了识别 object，还可能需要预测：

* Surface normal：表面垂直方向
* Object boundary：不同 object 之间的边界
* Saliency：图片中最值得关注的区域

Surface normal 可以帮助理解 object 的三维形状。

Saliency 则可以用来估计：

> 人类或 model 在理解图片时，最可能先关注哪些区域。

---

## 3. 3D Vision

### 3.1 从 2D Image 恢复 3D Structure

Camera 拍摄的是 2D image，但现实世界是 3D。

因此 Computer Vision 的一个重要任务是：

> 根据一个或多个 2D images，推断现实世界的 3D structure。

例如从不同角度看到同一个 point，可以利用 triangulation 推断这个 point 在 3D space 中的位置。

---

### 3.2 Multi-view Reconstruction

如果有大量从不同位置拍摄的 photos，可以：

1. 判断每张照片是从哪里拍摄的
2. 估计每个 camera 的 orientation
3. 找出不同图片中的相同 points
4. 使用 triangulation 恢复 3D points
5. 重建整个 scene

Lecture 中的 Dubrovnik example 使用了大量游客照片来重建城市的三维结构。

每张照片可以用一个 viewing frustum 表示：

* Frustum 顶点表示 camera position
* Frustum 朝向表示 camera viewing direction
* Frustum 范围表示 camera field of view

---

### 3.3 Camera Pose

Camera pose 一般包括：

* Position：camera 在世界中的位置
* Orientation：camera 面向的方向

Pose estimation 的目标是确定：

> Camera 在世界中的什么位置，以及它朝向哪里。

Camera pose 对以下任务非常重要：

* 3D reconstruction
* Augmented reality
* Robot navigation
* Autonomous driving

---

## 4. Computer Vision 的应用

### 4.1 Autonomous Driving

自动驾驶系统需要识别和定位：

* Pedestrians
* Vehicles
* Cyclists
* Road boundaries
* Traffic signs

系统必须理解这些 objects 的位置和移动，才能决定如何安全驾驶。

---

### 4.2 Robotics

Robot 可以使用 camera：

1. 查看周围环境
2. 找到目标 object
3. 估计 object 的位置
4. 规划 grasping strategy
5. Pick up object
6. 将 object 移动到指定位置

这类任务通常称为：

> Pick-and-place operation。

Robot 也可以通过 trial and error 不断改善 grasping strategy。

---

### 4.3 Augmented Reality

Augmented Reality 会将 virtual object 加入真实 scene。

为了让 virtual object 看起来真实，系统需要知道：

* Camera pose
* Floor 在哪里
* Room 的 3D structure
* Virtual object 应该放置在哪里
* Object 应该被哪些现实 objects 遮挡

例如 virtual Stormtrooper 必须正确地站在 floor 上，而不是漂浮在空中。

---

### 4.4 Medical Imaging

Computer Vision 也可以应用于：

* X-ray analysis
* CT reconstruction
* Tumour detection
* Medical image segmentation
* Synthetic medical image generation

Lecture 中提到，可以使用 generative model 根据 X-ray 生成与之相符的 CT-like data。

---

### 4.5 Generative Models

Computer Vision 不只分析图像，也可以生成图像。

课程会介绍：

* Generative Adversarial Networks，GANs
* Diffusion Models

GAN 会训练两个部分：

* Generator：生成 fake images
* Discriminator：判断 image 是 real 还是 fake

Generator 尝试欺骗 Discriminator，而 Discriminator 尝试识别 fake image。

Diffusion Model 通常从 noise 开始，通过多步 denoising 生成高质量 image。

---

## 5. Computer Vision、Image Processing 和 Computer Graphics

### 5.1 Image Processing

Image Processing 通常对 image 本身进行 transformation，例如：

* Blurring
* Sharpening
* Filtering
* Edge detection
* Cropping
* Resizing

它的重点通常是：

> 修改 image，或者从 image 中提取基础信息。

Computer Vision 则进一步尝试理解 image 的 meaning。

---

### 5.2 Computer Graphics

Computer Graphics 的方向是：

$$
World\ Description
\rightarrow
Image
$$

也就是说，先知道：

* Object 的形状
* Object 的位置
* Camera 的位置
* Lighting
* Material

然后将 scene render 成 image。

Computer Vision 的方向通常相反：

$$
Image
\rightarrow
Estimated\ World\ Description
$$

所以可以把 Computer Vision 看成一种 inverse graphics problem。

---

### 5.3 Graphics 如何帮助 Vision

假设 Vision system 估计 camera 在某个位置，可以使用 Computer Graphics render 一张预测图片。

然后比较：

$$
Rendered\ Image
\quad \text{vs} \quad
Observed\ Image
$$

两者之间的 error 可以用来调整：

* Camera pose
* Object position
* Scene structure

因此 graphics 和 vision 并不是完全分开的，它们经常在同一个 system 中互相配合。

## 7. Adversarial Images

### 7.1 什么是 Adversarial Image

Lecture 2 开头展示了 adversarial image。

一个 Neural Network 可能正确地将 handwritten digit 识别成 0。

但只要对少量 pixels 进行修改，就可能让 network 将它预测成：

* 6
* 9
* 其他完全不同的数字

这些修改对人类来说可能非常小，但对 model prediction 的影响非常大。

---

### 7.2 从 Noise 生成高置信度 Prediction

还可以从 random noise 开始，不断调整 pixels，使 model 非常确信这是一只 dog。

人类看到的仍然可能只是 noise，但 model 却给出很高的 confidence。

这说明：

> Neural Network 的 decision process 可能与人类视觉有很大差异。

---

### 7.3 Adversarial Robustness

Adversarial images 说明 Computer Vision system 可能存在 robustness 问题。

即使 model 在普通 test set 上表现很好，也不代表它面对：

* Small pixel perturbation
* Unusual lighting
* Noise
* Deliberate attack

时仍然可靠。

因此，让 vision model 对 adversarial changes 更 robust，仍然是一个重要挑战。

---

## 8. Image Formation

### 8.1 从现实世界到 Digital Image

一张 digital image 的形成过程可以概括为：

1. Light source 发出光
2. 光照射到现实世界的 surface
3. Surface 反射部分光线
4. 一部分 reflected photons 进入 camera
5. 光通过 lens
6. 光落在 imaging sensor 上
7. Sensor 将光转换成 electrical signal
8. Signal 经过 analogue-to-digital conversion
9. 最终得到 digital pixel values

所以 image 受到两类因素影响：

### World Properties

* Light source
* Surface geometry
* Surface colour
* Surface reflectance

### Camera Properties

* Camera position
* Camera orientation
* Focal length
* Aperture
* Lens distortion
* Sensor resolution

---

### 8.2 3D 到 2D 的 Projection

现实世界中的 point 有三个 coordinates：

$$
P=(X,Y,Z)
$$

Digital image 中的 point 只有两个 coordinates：

$$
p=(x_i,y_i)
$$

因此 camera formation process 实际上是：

$$
3D\ World
\rightarrow
2D\ Image
$$

这意味着一个 dimension 的信息在 projection 过程中丢失。

因此只看单张 image 时，通常无法直接知道 object 的真实 depth。

---

## 9. Pinhole Camera Model

### 9.1 Camera Obscura

Pinhole camera 的早期形式是 camera obscura：

* 外部环境明亮
* Room 内部较暗
* Wall 上有一个很小的 hole
* 光线穿过 hole
* Image 投影到对面的 wall

由于光沿直线传播：

* World 上方的 point 会投影到 image 下方
* World 左侧的 point 会投影到 image 右侧

所以真实 pinhole camera 形成的 image 是上下左右倒转的。

---

### 9.2 Camera Coordinate System

在简化的 pinhole model 中，可以将 camera optical centre 放在 origin：

$$
O=(0,0,0)
$$

通常 camera coordinate system 定义为：

* (X)：向右
* (Y)：向下
* (Z)：camera 面向的方向

Camera 可以看到 (Z>0) 的 objects。

现实中的 world coordinate system 和 camera coordinate system 通常不同，之后需要使用 rotation 和 translation 在两者之间进行转换。

---

### 9.3 Similar Triangles

假设现实世界中的 point 是：

$$
P=(X,Y,Z)
$$

Image plane 与 optical centre 的距离是 focal length (f)。

根据 similar triangles：

$$
\frac{x_i}{f}
=

\frac{X}{Z}
$$

因此：

$$
x_i
=

f\frac{X}{Z}
$$

同理：

$$
y_i
=

f\frac{Y}{Z}
$$

这就是基本的 pinhole projection equation。

---

### 9.4 Projection Equation 的直觉

Projection equation 是：

$$
x_i=f\frac{X}{Z},
\qquad
y_i=f\frac{Y}{Z}
$$

其中 (X) 或 (Y) 越大，point 离 image centre 越远。

(f) 越大，image 中的 object 越大。

(Z) 越大，object 离 camera 越远，因此 image 中的 object 越小。

所以：

> Near objects appear larger；far objects appear smaller。

---

## 10. Pinhole Camera 的限制

### 10.1 Hole 太小

Pinhole 必须非常小，才能让每个 world point 只投影到 image plane 上的一个小区域。

但 hole 太小时：

* 进入 camera 的光非常少
* Image 会非常暗
* 需要更长 exposure time

---

### 10.2 Hole 太大

如果将 hole 变大，会有更多 light 进入 camera，image 会变亮。

但同一个 world point 的光可以通过 aperture 的不同位置进入 camera。

结果是：

* 同一个 point 被投影到多个位置
* 多个相似 image 重叠
* Image 变得 blurry

所以只有扩大 pinhole，而不增加其他 optical component，并不能得到清晰 image。

---

### 10.3 Lens 的作用

解决方法是在 aperture 中加入 lens。

Lens 可以将来自同一个 world point 的不同 light rays 聚焦到 image plane 上的同一个位置。

因此 lens 同时提供：

* Larger aperture
* More incoming light
* Sharper image

所以现代 camera 使用 lens，而不是只使用 pinhole。

---

## 11. Focus 和 Focal Length

### 11.1 Focus

Near object 和 far object 的 light rays 可能会在不同位置聚焦。

为了让某个距离的 object 清晰，可以改变：

* Lens 与 imaging plane 的距离
* Lens 的 focal length

现代 camera focusing mechanism 通常会移动内部 lens component。

---

### 11.2 Focal Length 的定义

假设来自一个无限远 object 的 light rays 接近平行。

这些 parallel rays 通过 lens 后汇聚到 focal point。

Lens optical centre 到 focal point 的距离就是 focal length：

$$
f
=

Distance(Lens,Focal\ Point)
$$

Camera lens 通常会使用 millimetres 表示 focal length，例如：

* 28 mm
* 35 mm
* 50 mm
* 70 mm
* 210 mm

---

### 11.3 Focal Length 和 Field of View

较短 focal length：

* Wide field of view
* 可以看到更大的 scene
* Object 在 image 中较小
* 更容易出现 wide-angle distortion

较长 focal length：

* Narrow field of view
* 可以看到较小的 scene
* Object 在 image 中较大
* 有放大效果

所以：

> Short focal length = wide-angle lens
> Long focal length = telephoto lens

---

### 11.4 Focal Length in Pixels

在 Computer Vision 中，focal length 也经常使用 pixels 表示。

这是因为 digital image 中的计算最终发生在 pixel coordinate system 中。

如果：

* Image width 是 2000 pixels
* Focal length 是 1000 pixels
* Principal point 在 image centre

那么从 centre 到 image 左右边缘各有大约 1000 pixels，对应大约左右各 $45^\circ$，整体 field of view 约为 $90^\circ$。

---

## 12. Principal Point

Principal point 是 optical axis 与 image plane 相交的位置。

可以理解为：

> 从 camera optical centre 向 image plane 作一条 perpendicular line，这条线与 image plane 的交点就是 principal point。

Principal point 通常接近 image centre，但现实 camera 中不一定刚好位于正中心。

如果将 principal point 作为 image coordinate origin，就可以直接使用简化的 projection equation。

---

## 13. Aperture 和 Depth of Field

### 13.1 Aperture

Aperture 表示允许 light 通过的 opening size。

较大 aperture：

* More light
* Brighter image
* Shallower depth of field
* 只有较小范围保持清晰

较小 aperture：

* Less light
* Darker image
* Larger depth of field
* 更多距离范围保持清晰

---

### 13.2 F-number

Photography 通常使用 focal length 与 aperture diameter 的比值表示 aperture：

$$
N=\frac{f}{D}
$$

其中：

* (N) 是 f-number
* (f) 是 focal length
* (D) 是 aperture diameter

例如：

$$
f/5.6
$$

表示 aperture diameter 是：

$$
D=\frac{f}{5.6}
$$

因此 f-number 越大，实际 aperture 越小。

---

### 13.3 Depth of Field

Depth of field 表示 image 中保持清晰的距离范围。

可以这样记：

> Small aperture → large depth of field
> Large aperture → small depth of field

Pinhole camera 的 aperture 非常小，所以几乎所有距离都可以保持 focus，但 image 会非常暗。

---

## 14. Lens Distortion

### 14.1 Ideal Projection vs Real Lens

Ideal pinhole model 假设 light rays 按照理想直线关系投影。

但真实 lens 会弯曲 light rays，尤其是离 optical axis 很远的 rays。

因此靠近 image edge 的 points 可能不会出现在 ideal model 预测的位置。

---

### 14.2 Barrel Distortion

Wide-angle lens 经常出现 barrel distortion。

它的特点是：

* Image centre 附近相对正常
* 越靠近 image edge，distortion 越明显
* 原本笔直的 lines 会向外弯曲
* Rectangle 看起来像 barrel

这种 distortion 常见于：

* Wide-angle photography
* Real-estate photography
* Action cameras

Software 可以使用 lens distortion model 对其进行 correction。

---

## 15. Virtual Image Plane

真实 camera 的 imaging plane 位于 pinhole 或 lens 后方，因此形成的 image 是倒转的。

为了简化 mathematics，Computer Vision 通常假设 image plane 位于 camera 前方。

这个 plane 称为 virtual image plane。

这样 projection equation 可以直接写成：

$$
x_i=f\frac{X}{Z}
$$

$$
y_i=f\frac{Y}{Z}
$$

而不需要加入 negative sign。

需要记住：

> Virtual image plane 是数学上的简化，并不是 physical sensor 的真实位置。

---

## 16. Digital Image Representation

### 16.1 Image 是 3D Tensor

Colour image 通常表示成三维 array：

$$
Height
\times
Width
\times
Channels
$$

例如：

$$
1000
\times
1000
\times
3
$$

其中两个 dimensions 表示 image plane，第三个 dimension 表示 colour channels。

---

### 16.2 RGB Channels

普通 colour image 通常包含：

* Red channel
* Green channel
* Blue channel

因此：

$$
I(x,y)
=

[R(x,y),G(x,y),B(x,y)]
$$

每个 colour channel 单独查看时，可以看成一张 grayscale image。

RGB 使用三个 channels，主要是因为一般人类视觉具有三类 colour receptors。

---

### 16.3 Tensor Dimension Order

不同 framework 可能使用不同的 dimension order。

例如：

### Channels Last

$$
Height
\times
Width
\times
Channels
$$

常写成：

```text
H × W × C
```

### Channels First

$$
Channels
\times
Height
\times
Width
$$

常写成：

```text
C × H × W
```

TensorFlow 和 PyTorch 的默认 convention 可能不同，因此使用 model 或 dataset 时需要检查 shape。

---

### 16.4 RGB 和 BGR

Colour channel 的顺序也可能不同：

* RGB
* BGR

如果错误地读取 channel order，image 的 colour 会明显不正常。

所以在使用 image library 时需要确认：

> 当前 library 使用 RGB 还是 BGR？

---

## 17. Pixel Coordinates

### 17.1 Coordinate Origin

Digital image 通常使用 top-left 作为 origin：

$$
(0,0)
$$

Coordinate direction 是：

* (x) 向右增加
* (y) 向下增加

因此 image coordinate system 与普通 Cartesian coordinate system 不同。

---

### 17.2 Zero-based Indexing

Pixel index 一般从 0 开始。

如果一个 pixel 位于：

* 第二 column
* 第三 row

它的 coordinate 是：

$$
(x,y)=(1,2)
$$

而不是 ((2,3))。

---

## 18. Pixel Values 和 Data Types

### 18.1 8-bit Image

最常见的 image datatype 是 unsigned 8-bit integer：

```text
uint8
```

它可以表示：

$$
0\leq value\leq255
$$

RGB examples：

$$
(0,0,0)=Black
$$

$$
(255,255,255)=White
$$

$$
(255,0,0)=Red
$$

$$
(0,255,0)=Green
$$

$$
(0,0,255)=Blue
$$

---

### 18.2 Floating-point Image

在 TensorFlow 或 PyTorch 中，image 经常会转换成 floating-point value，例如：

```text
float32
```

并将 range normalization 成：

$$
0\leq value\leq1
$$

Medical images 也可能使用：

* 16-bit integer
* 32-bit integer
* Float values

因为它们可能需要比普通照片更大的 dynamic range。

---

## 19. Image Compression

### 19.1 Lossy Compression

JPEG 是 lossy compression。

它可以显著减少 file size，但不能完全恢复原始 pixel values。

JPEG compression artefacts 在以下区域更明显：

* Fine details
* Sharp edges
* Text
* High-frequency patterns

---

### 19.2 Lossless Compression

Lossless format 可以完整恢复原始 information。

Lecture 中提到的常见 lossless formats 包括：

* PNG
* BMP
* GIF
* TIFF

可以这样记：

> JPEG 优先减少 file size；PNG 优先保留准确 pixel information。

---

## 20. Image Manipulation

### 20.1 Cropping

Cropping 是从原 image 中提取一个 subset。

它不会缩放 object，只会删除 image 的部分区域。

例如：

$$
I'
=

I[y_1:y_2,;x_1:x_2]
$$

---

### 20.2 Resizing

Resizing 会改变 image dimensions。

例如：

$$
768\times512
\rightarrow
512\times512
$$

如果没有保持 aspect ratio，image 中的 object 可能被拉伸或压缩。

---

### 20.3 Aspect Ratio

Aspect ratio 是：

$$
Aspect\ Ratio
=

\frac{Width}{Height}
$$

保持 aspect ratio 可以避免：

* Circle 变成 ellipse
* Square 变成 rectangle
* Object 被横向或纵向拉伸

---

## 21. Image Resampling

### 21.1 为什么需要 Resampling

改变 image size 后，新的 pixel grid 与原始 pixel grid 通常不会完全重合。

因此需要决定：

> 新 image 中每个 pixel 的 value 应该从哪里获得？

这个过程称为 resampling 或 interpolation。

---

### 21.2 Nearest-neighbour Sampling

Nearest neighbour 会选择距离 target position 最近的 source pixel。

优点：

* 简单
* 计算速度快
* 保留离散 label value

缺点：

* Image 容易 blocky
* Edge 呈现 jagged shape
* Downsampling 时可能丢失大量信息

Nearest neighbour 比较适合：

* Segmentation mask
* Class label image
* Pixel art

因为这些数据不适合产生中间 value。

---

### 21.3 Pixel Averaging

在 downsampling 时，可以将多个 source pixels 取平均。

例如将 (2\times2) 的四个 pixels 组合成一个 pixel：

$$
I'
=

\frac{
I_1+I_2+I_3+I_4
}{4}
$$

相比只选择一个 nearest pixel，averaging 通常可以保留更多整体 image structure。

---

### 21.4 Bilinear Interpolation

Bilinear interpolation 使用 target position 周围的四个 pixels。

假设 horizontal offset 是 (h)，vertical offset 是 (v)，则四个 weights 可以写成：

$$
(1-h)(1-v)
$$

$$
h(1-v)
$$

$$
(1-h)v
$$

$$
hv
$$

四个 weights 相加为：

$$
(1-h)(1-v)+h(1-v)+(1-h)v+hv=1
$$

Target pixel 是四个 neighbour pixels 的 weighted average。

所以：

> 离 target position 越近的 source pixel，weight 越大。

---

### 21.5 Bilinear 的效果

Bilinear interpolation 相比 nearest neighbour：

* Image 更平滑
* Jagged edge 更少
* Blocky artefact 更少

但因为它会 average pixels，所以 image 也可能变得稍微模糊。

---

### 21.6 Bicubic Interpolation

Bicubic interpolation 会使用更大的 pixel neighbourhood，通常是：

$$
4\times4
$$

也就是 16 个 pixels。

它使用 cubic function 进行 interpolation，通常可以获得比 bilinear 更平滑、更清晰的效果，但计算量更高。

---

### 21.7 Lanczos Sampling

Lanczos 是另一种高质量 resampling method。

它通常可以较好地保留：

* Edge
* Fine detail
* Image sharpness

但计算复杂度也高于 nearest neighbour 和 bilinear。

---

### 21.8 Blur Before Downsampling

如果直接 downsample image，可能会发生：

* Aliasing
* Jagged patterns
* Fine details 被错误表示
* Moiré pattern

一种方法是在 sampling 前先 blur image。

Blur 会减少 high-frequency details，使新的低分辨率 pixel grid 更稳定地表示原 image。

Bilinear interpolation 本身会 average neighbouring pixels，因此已经包含了一定程度的 smoothing。

---

## 22. Resampling 方法对比

| Method            |       使用的 Pixels | 优点                 | 缺点                 |
| ----------------- | ---------------: | ------------------ | ------------------ |
| Nearest neighbour |                1 | 快、简单、适合 label      | Blocky、容易 aliasing |
| Pixel averaging   |      多个固定 pixels | Downsampling 效果较稳定 | 可能模糊               |
| Bilinear          |                4 | 平滑、速度较快            | Detail 可能减少        |
| Bicubic           |               16 | 较清晰、较平滑            | 计算量较高              |
| Lanczos           | 较大 neighbourhood | Detail 保留较好        | 计算复杂               |

## 23. 核心概念对比

### Classification vs Detection vs Segmentation

Classification：

> 这张 image 是什么？

Detection：

> Image 中有哪些 objects？它们在哪里？

Segmentation：

> 每一个 pixel 属于什么 class？

---

### Computer Graphics vs Computer Vision

Computer Graphics：

$$
Scene
\rightarrow
Image
$$

Computer Vision：

$$
Image
\rightarrow
Estimated\ Scene
$$

---

### Short vs Long Focal Length

Short focal length：

* Wide field of view
* Object 较小
* Distortion 可能较明显

Long focal length：

* Narrow field of view
* Object 较大
* Telephoto effect

---

### Small vs Large Aperture

Small aperture：

* Less light
* Larger depth of field
* 更多区域清晰

Large aperture：

* More light
* Smaller depth of field
* Background 更容易模糊

---

### Nearest Neighbour vs Bilinear

Nearest neighbour：

* 直接选择最近 pixel
* 快
* 容易 blocky

Bilinear：

* 对四个 pixels weighted average
* 更平滑
* 可能稍微模糊

对于 world point：

$$

$$
x_i=f\frac{X}{Z}
$$

y_i=f\frac{Y}{Z}

其中：

* (f) 控制 image scale 和 field of view
* (Z) 控制 object 在 image 中的大小
* Object 越远，在 image 中越小

* Large aperture 产生 smaller depth of field
* Wide-angle lens 容易产生 barrel distortion
