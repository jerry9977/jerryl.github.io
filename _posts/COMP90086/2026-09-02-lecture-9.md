# COMP90086 — Vision Transformers

> 本讲从 CNN 的归纳偏置出发，解释 Vision Transformer（ViT）如何把图像表示成 patch token 序列，并通过 self-attention 建立远距离区域之间的关系。重点包括 scaled dot-product attention、positional encoding、multi-head attention、Transformer encoder block，以及 ViT 与 CNN 在数据需求、计算成本和泛化能力上的取舍。

## 1. Inductive Bias：模型在看到数据前作出的假设

计算机视觉问题通常存在许多可能的解法，而图像本身维度很高，训练样本数量甚至可能少于模型参数或输入维度。为了从有限数据中找到合理解，模型通常依赖**归纳偏置（inductive bias）**。

🟦 **定义：** inductive bias 是算法预先加入的假设或限制，它使模型倾向于从多个可能解中选择某一类解。

### CNN 的两个关键归纳偏置

**局部性(locality)** 假设有意义的低层特征通常来自相邻或附近 pixels。例如，一个 pixel 无法表示“眼睛”，但一个局部 patch 可能包含边缘、弧线等足够的信息。CNN 先在局部形成 edges、circles 等低层特征，再逐层组合成更复杂的语义特征；这个层次结构在每一级仍保留局部关系。

**平移等变性（translation equivariance）** 来自 weight sharing：同一个 convolution kernel 会滑过图像的不同位置，并以相同权重处理每个 patch。因此，特征移到另一个位置时，CNN 仍会以相同方式检测它。直观上，一辆自行车无论出现在图像左侧还是右侧，都应该仍被识别成自行车。

课程 slides 有时将这个性质写成 translation invariance / equivariance，但严格区分如下：

- **Equivariance**：输入发生平移时，feature map 也相应平移。
- **Invariance**：输入发生平移时，最终分类结果不变。

对于 stride 为 1、没有 dilation 的连续 $3\times3$ convolution，堆叠 $L$ 层后的理论 receptive field 为：

$$
R_L = 1 + 2L
$$

因此，CNN 必须通过多层堆叠才能让一个输出单元接触较远的图像区域。相反，self-attention 在第一层就可以让每个 patch 查看整张图像。

🟨 **核心取舍：** CNN 把 locality 和 translation equivariance 直接写进架构，因此在较少数据下也容易学到合理特征；ViT 放弃了大部分这种强假设，获得更灵活的全局关系建模能力，但通常需要更多数据来学回这些结构。

## 2. 从 Bag of Words 到 Image Patches

Transformer 最初来自 natural language processing（NLP）。语言天然可以拆成 words 或 tokens，但图像的基本语义单位并不明显：pixel 太细，物体和局部结构又可能以不同尺寸、方向和外观出现。

早期的 **bag of words** 只记录词频而忽略顺序。因此：

```text
the cat sat on the mat
the mat sat on the cat
```

虽然语义不同，却会产生相同的 word-frequency histogram。视觉中的 **bag of features** 使用相似想法：从图像中提取许多局部 patches，用 k-means 等方法把它们聚类成 visual codewords，再以 codeword histogram 表示整张图像。

这种方法可以让背景和方向不同的两辆车产生相似 histogram，但存在两个根本问题：

- 每个 patch 被独立处理，无法描述 feature 之间的关系；
- histogram 不记录 feature 来自哪里，空间结构被丢失。

例如，“两只眼睛并排，位于鼻子和嘴巴上方”可能表明一张脸，但 bag of features 无法自然表达这种关系。ViT 的思路是仍将图像拆成局部单元，同时用 attention 让这些单元交换信息。

### Patch embedding

假设输入图像大小为 $H\times W\times C$，每个 patch 大小为 $P\times P$。在 $H$ 和 $W$ 都可被 $P$ 整除时，patch 数量为：

$$
N = \frac{H}{P}\frac{W}{P}
$$

每个 patch 被 flatten 成长度 $P^2C$ 的向量，再通过共享的 linear projection 映射到 $D$ 维 embedding：

$$
\mathbf{x}_i = \operatorname{vec}(\text{patch}_i)\mathbf{W}_E + \mathbf{b}_E,
\qquad \mathbf{x}_i\in\mathbb{R}^{D}
$$

也可以用一个小型 MLP 或训练过的 CNN 产生 embedding，但经典 ViT 通常使用 linear projection。同一个 projection 应用于所有 patches，所以仍保留少量共享处理的偏置；不过，不重叠 patches 不再具有 CNN 滑动窗口那种连续而平滑的 equivariance。

对于 image classification，通常还会加入一个可学习的 **class token（`[CLS]`）**。它像其他 tokens 一样参与 attention，在最后汇总全图信息，并用于预测整张图像的类别。因此总 token 数通常为：

$$
N_{\text{tokens}} = \left(\frac{H}{P}\right)^2 + 1
$$

其中额外的 $1$ 就是 class token。

## 3. Self-Attention：让每个 Patch 从其他 Patches 读取信息

每个 input embedding 都经过三个不同的 learned projections，生成 query、key 和 value：

$$
Q=XW_Q,\qquad K=XW_K,\qquad V=XW_V
$$

可以用以下直觉理解三者：

| 向量 | 直觉含义 | 作用 |
|---|---|---|
| Query | “我正在寻找什么？” | 当前 token 向其他 tokens 发出的检索需求 |
| Key | “怎样找到我？” | 每个 token 用来描述自己、供 query 匹配的索引 |
| Value | “我能提供什么信息？” | 匹配成功后真正被读取和聚合的内容 |

对于第 $i$ 个 query 和第 $j$ 个 key，其相似度首先由点积得到：

$$
a_{ij}=\frac{\mathbf{q}_i^\top\mathbf{k}_j}{\sqrt{d_k}}
$$

然后在每个 query 对应的 row 上应用 softmax：

$$
\alpha_{ij}
=
\frac{\exp(a_{ij})}{\sum_{m=1}^{N}\exp(a_{im})}
$$

因此，对固定的 query $i$，所有 attention weights 满足：

$$
\sum_{j=1}^{N}\alpha_{ij}=1
$$

最后，第 $i$ 个输出是所有 values 的加权和：

$$
\mathbf{y}_i=\sum_{j=1}^{N}\alpha_{ij}\mathbf{v}_j
$$

把所有 queries 一次写成矩阵形式，就是 **scaled dot-product attention**：

$$
\operatorname{Attention}(Q,K,V)
=
\operatorname{softmax}\left(\frac{QK^\top}{\sqrt{d_k}}\right)V
$$

> Slides 的图可能因矩阵采用 row-vector 或 column-vector 排列而写成 $Q^\top K$。两种写法表达的是同一操作：计算所有 query–key pairs 的点积。关键是最终 attention matrix 的大小为 $N\times N$。

### 为什么除以 $\sqrt{d_k}$？

当 key/query 维度 $d_k$ 增大时，随机向量点积的典型幅度也会增大。过大的 logits 会使 softmax 迅速饱和：少数位置的权重接近 1，其余接近 0，梯度变小并造成训练不稳定。除以 $\sqrt{d_k}$ 可以控制点积尺度，让 softmax 保持在更适合学习的范围。

课堂用 temperature 解释了同一现象：较“冷”的 softmax 分布更尖锐，只关注少数 keys；较“热”的分布更平坦，会平均读取更多 values。缩放项可避免维度增加时分布无意中过度变“冷”。

### 矩阵维度

若 $X\in\mathbb{R}^{N\times D}$，则可设：

$$
W_Q,W_K\in\mathbb{R}^{D\times d_k},
\qquad
W_V\in\mathbb{R}^{D\times d_v}
$$

于是：

$$
Q,K\in\mathbb{R}^{N\times d_k},
\quad
QK^\top\in\mathbb{R}^{N\times N},
\quad
Y\in\mathbb{R}^{N\times d_v}
$$

Query 与 Key 的长度必须相同，否则无法计算点积；输出长度则由 Value 的长度决定。$W_Q,W_K,W_V$ 的参数数量不依赖 token 数 $N$，所以同一个 attention head 原理上可以处理不同数量的 patches。不过，计算产生的 $N\times N$ attention matrix 会随 $N$ 增长。

🟨 **Self-attention 的本质：** 先用 Query–Key 决定“该从哪里读”，再对相应 Values 做加权平均，得到包含其他 patches 信息的新 token representation。

## 4. Position、Multi-Head 与完整 Transformer Encoder

### Positional encoding

不加入位置时，self-attention 是 **permutation-equivariant**：如果 input tokens 的顺序被重新排列，outputs 也只会跟着做相同排列。模型知道有哪些 patches，却不知道它们原本位于图像哪里。

因此，ViT 将 positional encoding 加到 patch embeddings 上：

$$
Z_0 = X_{\text{patch}} + E_{\text{pos}}
$$

位置编码是**相加（addition）**，不是简单 concatenation。课程介绍了：

- 1D sinusoidal encoding：用不同 frequency 和 phase 的 sine/cosine 表示序列索引；
- 2D positional encoding：分别编码 patch 的 $x$ 与 $y$ coordinate；
- learnable positional encoding：位置向量由训练直接学习。

2D 编码更直接地把 grid structure 提供给模型。即使 tokens 被打乱，只要位置编码跟随对应 patch，模型仍有信息重建原始空间排列。

### Multi-head attention

单个 attention head 只产生一种 query–key 匹配方式。**Multi-head attention** 同时运行 $h$ 个 heads，使不同 heads 可以学习不同关系。例如，一个 head 可能关注相似纹理，另一个关注物体部件之间的远距离关系。

对第 $r$ 个 head：

$$
\operatorname{head}_r
=
\operatorname{Attention}(XW_Q^{(r)},XW_K^{(r)},XW_V^{(r)})
$$

所有 heads 的输出被 concatenated，再投影回 $D$ 维：

$$
\operatorname{MHA}(X)
=
\operatorname{Concat}(\operatorname{head}_1,\ldots,\operatorname{head}_h)W_O
$$

通常令每个 head 的宽度为：

$$
d_k=d_v=\frac{D}{h}
$$

所以增加 head 数时，每个 head 变窄；concatenate 后仍恢复成 $D$ 维。以 $D=768$ 为例：

| 配置 | 每个 head 宽度 | $W_Q,W_K,W_V$ 总规模 | $W_O$ | 总参数量 |
|---|---:|---:|---:|---:|
| $h=1$ | 768 | $3\times768\times768$ | $768\times768$ | 约 2.36M |
| $h=4$ | 192 | $4\times3\times768\times192$ | $768\times768$ | 约 2.36M |

因此，在固定 $D$ 时，改变 head 数一般不会改变 MHA 的总参数量，也基本不改变主要 floating-point operations。课程引用的 NLP 实验说明：multi-head 通常优于 single-head，但 head 越多并不一定越好；每个 head 太窄时性能可能再次下降。

### Transformer encoder block

一个 pre-norm Transformer encoder block 可写为：

$$
Z'_\ell
=
Z_{\ell-1}
+
\operatorname{MHA}(\operatorname{LN}(Z_{\ell-1}))
$$

$$
Z_\ell
=
Z'_\ell
+
\operatorname{MLP}(\operatorname{LN}(Z'_\ell))
$$

其信息流为：

```text
patch embeddings + positional encoding
  ↓
LayerNorm → Multi-head self-attention → residual addition
  ↓
LayerNorm → per-token MLP → residual addition
  ↓
下一 encoder block
```

两种操作交替完成不同任务：

- **Attention** 是 tokens 相互交换信息的地方，即“横向”传递 patch 之间的信息；
- **MLP** 对每个 token 独立且使用相同参数进行内部处理，通常 hidden width 约为 $4D$；
- **Residual connections** 使 attention 或 MLP 学习对已有 representation 的修正，而不是完全替换它；
- **LayerNorm** 控制激活尺度，改善 optimization conditioning，并提供一定 regularisation 效果。

Position code 只在进入第一层前加入一次，然后整个 block 重复 $L$ 次。用于图像理解的 encoder self-attention 是 non-causal 的：任意 patch 都可以关注任意其他 patch；这不同于自回归语言生成中只能查看先前 tokens 的 causal attention。

### 典型 ViT 配置

ViT 架构主要由 patch size $P$、层数 $L$、embedding width $D$、head 数 $h$ 和 MLP hidden width 决定。例如 ViT-B/16 使用：

- $P=16$ pixels；
- $L=12$ encoder blocks；
- $D=768$；
- $h=12$，所以每个 head 宽度为 $64$；
- 对 $224\times224$ 输入，共有 $14\times14+1=197$ tokens。

## 5. ViT 的数据需求与计算代价

### 缺少强归纳偏置，需要更多数据

ViT 没有像 CNN 那样把 locality 和 translation equivariance 强制写入架构，而且 softmax attention 提供了很强的非线性表达能力。因此，它在小数据集上通常更容易 overfit。

原始 ViT 工作先在 JFT-300M（约 3 亿张 images）上 pre-train，再在 ImageNet 等较小数据集上 fine-tune。课程给出的对比显示：

| Pre-training 数据规模 | ResNet152x4 top-1 | 最佳 ViT top-1 | 结果 |
|---:|---:|---:|---|
| 1.3M | 81.30 | 77.91（ViT-B/16） | CNN 明显领先 |
| 14M | 85.39 | 85.15（ViT-L/16） | 两者接近 |
| 300M | 87.54 | 88.04（ViT-H/14） | ViT 略微领先 |

🟨 **解释：** CNN 的 inductive bias 相当于提前告诉模型“局部和位置平移很重要”；ViT 则需要从大规模数据中自己学习这些规律。数据越多，较弱偏置带来的灵活性才越可能转化为性能优势。

不过，这些结果不能简单解读成“ViT 架构一定更强”。同期训练方法也发生了显著改进；把 Transformer 的 training recipe 移植到现代 ConvNet 后，CNN 可以重新追上。当 pre-training compute budget 被控制为相同时，ViT 和 CNN 在 ImageNet 上的结果可能非常接近。课程因此强调：许多已报道的差距来自 training recipe，而不只是 architecture。

### Attention 的二次复杂度

Self-attention 必须建立 $N\times N$ 的 token-pair matrix，因此 attention 部分的时间与内存成本相对于 token 数为：

$$
O(N^2)
$$

如果输入尺寸固定，而 patch width 从 $P$ 减半到 $P/2$，horizontal 和 vertical 方向的 patch 数都加倍，因此 token 数变为原来的 4 倍：

$$
N' = 4N
$$

attention pair 数则变为：

$$
(N')^2=(4N)^2=16N^2
$$

以 $224\times224$ 图像为例：

| Patch size | Patch tokens $N$ | 相对 attention cost |
|---:|---:|---:|
| $32\times32$ | 49 | $0.06\times$ |
| $16\times16$ | 196 | $1\times$ |
| $8\times8$ | 784 | $16\times$ |
| $4\times4$ | 3136 | $256\times$ |

这解释了经典 ViT 常使用约 $14$–$16$ pixel 的 patch：patch 太大会损失细节并产生硬边界，patch 太小又会使 attention cost 急剧增长。

## 6. ViT 与 CNN：没有绝对胜者

| 比较维度 | CNN | Vision Transformer |
|---|---|---|
| Locality | 架构直接强制 | 主要从数据中学习；全局 attention 不优先局部区域 |
| Translation equivariance | 通过 sliding kernels 与 weight sharing 强化 | 非重叠 patching 会削弱连续平移等变性 |
| Receptive field | 随网络深度逐渐扩大 | 第一层 attention 即可覆盖全图 |
| 远距离关系 | 需多层间接传播 | 可直接连接任意两个 patches |
| 小数据表现 | 通常较好，较不易 overfit | 通常需要更多 pre-training data |
| Patch / feature 边界 | overlapping convolution windows 较平滑 | 固定 grid 和硬边界可能切断重要 feature |
| 计算扩展 | 卷积成本随 spatial size 增长 | full attention 对 token 数为 $O(N^2)$ |
| Multimodal compatibility | 可以使用，但不是天然 token-based | 与 language tokens 和 Transformer 架构自然统一 |

ViT 并不是“没有 inductive bias”。它只是拥有**不同的偏置**：

- positional encoding 假设某种空间关系表达方式；
- 固定大小、固定尺度的 patch grid 假设图像应以这种粒度切分；
- attention 本身偏好更少依赖 input order 的函数。

简单 patching 会忽略尺度，而且重要 feature 可能被 patch boundary 切开。可考虑 overlapping patches 或 multi-scale patches，但它们通常会增加 token 数与计算量。**Swin Transformer** 是一种折中方案：只在 local windows 内计算 attention，并在后续层移动（shift）窗口，使信息能跨窗口边界传播。它重新引入了某种 locality，看起来也因此更接近 convolutional hierarchy。

🟨 **最终理解：** CNN 以强而合适的视觉假设换取 data efficiency；ViT 以较弱的视觉假设换取全局关系建模和跨模态统一性。实际选择取决于数据规模、pre-training compute、任务是否需要远距离关系、spatial resolution，以及所使用的完整 training recipe，而不能只凭“Transformer 更新”就判断其一定更好。
