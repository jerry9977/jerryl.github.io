# COMP90086 — Representation Learning

> 本讲讨论如何不依赖人工类别标签来学习有用的 image representations。主要内容包括 self-supervised contrastive learning、CLIP 的 image–text joint embedding、feature space 与模型决策的可视化方法，以及视觉模型面对 lighting、translation、rotation、scale、3D pose 和 dataset shift 时的 invariance 与 generalisation。

> 注：所提供的 Lecture 10 slides 标注为 Semester 2, 2025；本笔记保留该来源标记。

## 1. Representation Learning 与 Self-Supervised Learning

**Representation learning** 的目标不是直接完成整个 classification task，而是学习一个 encoder，将输入图像 $x$ 转换为能表达其重要语义的向量：

$$
z=f_\theta(x), \qquad z\in\mathbb{R}^{D}
$$

对于一个已训练的 CNN，可以把最后的 classification layer 去掉，将倒数第二层的输出作为 image representation。对于带 class token 的 Vision Transformer（ViT），则可以使用最后一层 class token 的 embedding 表示整张图像。

一个好的 representation 应让语义相近的图像在 feature space 中彼此靠近，即使它们在 pixel level 上具有不同的 pose、colour、background 或 viewpoint。学习到这样的通用 representation 后，可以把它用于 retrieval、nearest-neighbour classification、transfer learning 或其他下游任务。

### 三种学习范式

| 学习方式 | Training signal 来源 | 例子 |
|---|---|---|
| Supervised learning | 人工提供的 ground-truth labels | 用类别标签训练 image classifier |
| Unsupervised learning | 不使用 labels，直接发现数据结构 | k-means、PCA |
| Self-supervised learning | 从数据本身自动构造 proxy labels | 预测被遮挡区域；匹配同一图像的两个 views |

Self-supervised learning 并不是“没有监督信号”。它仍然有 target，只是 target 由数据本身产生，而不是由 annotator 手工标注。例如：

- 遮住图像的一部分，让模型预测缺失内容；
- 对同一张图像做两次不同的 augmentation，让模型判断哪些 views 来自同一个原图。

🟨 **核心优势：** 大量未人工标注的数据也可以用于训练 encoder，从而降低 annotation 成本，并支持比固定类别表更广泛的概念学习。

## 2. Contrastive Learning：把 Representation Learning 变成分类问题

Contrastive learning 的核心目标是：

- **拉近 positive pairs**：来自同一图像或语义匹配的两个 views；
- **推远 negative pairs**：来自不同图像或语义不匹配的 views。

### 从 mini-batch 自动建立 vocabulary

假设 mini-batch 中有 $N$ 张图像。对每张图像分别应用随机 crop、zoom、mirror 或 colour transformation 等 augmentation，得到两个 views：

$$
x_i \rightarrow (\tilde{x}_i,\tilde{x}'_i)
$$

它们经过同一个 encoder 得到 representations：

$$
z_i=f_\theta(\tilde{x}_i),
\qquad
z'_i=f_\theta(\tilde{x}'_i)
$$

同一原图产生的 $(z_i,z'_i)$ 是 positive pair，其余组合是 negative pairs。两个 views 不能完全相同，否则任务过于容易，模型不必学习对 transformation 的容忍性。

在普通 supervised classifier 中，classification layer 的每个 weight vector 对应一个固定 class，因此 columns 形成类别 vocabulary。Contrastive learning 没有人工类别表，便直接把 batch 内其他 examples 的 embeddings 当成临时 vocabulary：对每个 $z_i$，正确“类别”就是与它来自同一原图的 $z'_i$。

### Cosine similarity

两个 embeddings 的 cosine similarity 为：

$$
\operatorname{sim}(u,v)
=
\frac{u^\top v}{\lVert u\rVert_2\lVert v\rVert_2}
$$

它衡量两个向量的方向是否一致，而不是直接比较 magnitude。对 batch 中所有 pairs 计算 similarity 后，会得到 $N\times N$ matrix；理想情况下，对角线上的 matched pairs 应具有最高 similarity。

### Row-wise contrastive loss

对 anchor $z_i$，在第二组 $N$ 个 views 上进行 row-wise softmax：

$$
p_{ij}
=
\frac{
\exp\left(\operatorname{sim}(z_i,z'_j)/\tau\right)
}{
\sum_{k=1}^{N}
\exp\left(\operatorname{sim}(z_i,z'_k)/\tau\right)
}
$$

正确匹配是 diagonal entry $j=i$，因此单个 anchor 的 loss 是：

$$
\ell_i=-\log p_{ii}
$$

最小化该 loss 会提高 positive similarity，同时降低同一 row 内 negative similarities。它在数学形式上就是一个 $N$-class classification problem，只是 classes 由当前 batch 动态产生。

### NT-Xent / SimCLR 形式

SimCLR 会把两组 views 都作为候选 negatives。Batch 中共有 $2N$ 个 views；对 anchor $i$ 而言，排除自己后有 $2N-1$ 个候选，其中：

- 1 个 positive；
- $2(N-1)$ 个 negatives。

若 $j(i)$ 表示 anchor $i$ 对应的 positive index，则 NT-Xent loss 可写为：

$$
\ell_i
=
-\log
\frac{
\exp\left(\operatorname{sim}(z_i,z_{j(i)})/\tau\right)
}{
\sum_{k=1}^{2N}
\mathbb{1}_{[k\neq i]}
\exp\left(\operatorname{sim}(z_i,z_k)/\tau\right)
}
$$

indicator $\mathbb{1}_{[k\neq i]}$ 用来排除 anchor 与自身的比较。

### Temperature $\tau$

Temperature 控制 softmax distribution 的尖锐程度：

- 较小的 $\tau$ 会放大 similarity 差异，使概率集中在最高值上；
- 较大的 $\tau$ 会使分布变平，接近均匀分布，模型更难区分 match 与 stranger。

🟨 **不要把低 temperature 理解成一定更好。** 它让模型更强烈关注最相似 example，但过于尖锐也可能使 optimization 对少数 pairs 过度敏感。$\tau$ 是需要选择的 training hyperparameter。

随着 encoder 变强，普通 negative pairs 可能变得太容易，例如 beach 与 house 很容易分开。此时可以使用 **hard negative mining**，主动选择外观或语义相似但并非正确匹配的 examples，例如让一张 beach image 与另一张不同的 beach image 竞争，迫使 encoder 学习更细致的信息。

## 3. CLIP：把 Images 与 Text 放进同一个 Embedding Space

**CLIP（Contrastive Language–Image Pretraining）**把同样的 contrastive learning 思想应用到 image–caption pairs。它包含两个 encoders：

```text
image → image encoder → image embedding
                              ↘
                        shared space
                              ↗
text  → text encoder  → text embedding
```

训练目标是让匹配的 image 和 caption 在 joint embedding space 中靠近，让不匹配的组合远离。与 ImageNet 的固定 1000 个 classes 相比，CLIP 的概念 vocabulary 来自人们实际写下的 text，因此覆盖范围更广。

### Contrastive pre-training

对于 batch 中的 $N$ 个 image–text pairs，共有：

$$
N^2 \text{ possible pairings}
$$

其中有 $N$ 个 diagonal true matches，以及：

$$
N^2-N=N(N-1)
$$

个 false matches。设 image embeddings 为 $I_i$，text embeddings 为 $T_j$，CLIP 用 cosine similarity 建立 $N\times N$ matrix，并通过 multi-class N-pair loss 使 diagonal 获胜。

原始 CLIP 使用约 4 亿个 image–text pairs 训练。这里的“self-supervised”强调 paired data 自带监督关系：哪段文字与哪张图片共同出现本身就是 label，不需要把每张图片人工归类到预先定义的 class list。

### Zero-shot classification

CLIP 没有专门为某个下游 classification dataset 训练，也能在 inference 时临时构造 classifier。假设候选类别是 `dog`、`cat` 和 `car`，先使用 prompt template 将 class names 写成 captions：

```text
"a photo of a dog"
"a photo of a cat"
"a photo of a car"
```

Text encoder 将每个 caption 转成 class embedding。随后计算 input image embedding 与所有 class embeddings 的 cosine similarity，并选择最接近的 caption：

$$
\hat{y}
=
\arg\max_{c}
\operatorname{sim}\left(f_{\text{image}}(x),f_{\text{text}}(t_c)\right)
$$

这叫 **zero-shot classification**，因为模型没有针对当前下游 task 的 labeled training examples 做额外训练；类别仅在 inference 时通过 text prompts 给出。

### CLIP 为什么有用

CLIP 的主要价值是生成通用且可与语言对齐的 embeddings：

- 用 large-scale pretraining 得到较强的 image representation；
- image 与 text 共用 embedding space，可从 text 产生 pseudo-labels；
- 可用于自动标注大规模 image datasets，例如 LAION 的构建流程；
- 可作为 multimodal LLM 的 image embedding provider；
- 在某些 shifted distributions，例如 sketches、rendered objects 或特殊 crops 上，比只针对单一 supervised dataset 训练的模型更 robust。

不过，zero-shot 表现依赖 pre-training distribution 和 prompt wording，不能把“未针对当前 task 训练”误解为模型从未见过相关概念或数据分布。

## 4. 如何观察高维 Feature Space

模型的 representation 通常是高维向量，无法直接画在二维屏幕上。课程介绍了两种互补思路：在 feature space 中查看 local neighbours，或者先进行 dimensionality reduction。

### Nearest neighbours

给定 query image embedding，可以找出 feature space 中距离最近的 images。如果 representation 学到了语义，那么 neighbours 应共享 object identity 或概念，而不只是相似 pixels。

例如，同一物体即使具有不同 pose、colour 和 background，也可能成为 nearest neighbours。这比只查看 classification accuracy 更直接地展示 encoder 如何组织数据。

也可以用 held-out classes 测试 representation generalisation：训练时排除一部分 bird species 或 car models，然后查看这些 unseen classes 的 embeddings 是否仍会各自聚集。若一个 unseen image 的 nearest neighbour 经常属于同一 unseen class，说明 learned mapping 捕捉到了可迁移的结构，而不是只记住 training classes。

### PCA 与 t-SNE

| 方法 | 主要目标 | 正确解读方式 | 局限 |
|---|---|---|---|
| PCA | 显示 variance 最大的线性方向 | 观察前几个 principal components | 只能展示少数 dimensions，语义可能难解释 |
| t-SNE | 将高维数据压到 2D/3D，同时保留 local neighbourhood | 观察局部 clusters 和近邻关系 | 远距离 clusters 之间的距离没有可靠全局含义 |

PCA 提供从原空间到低维空间的线性 mapping；t-SNE 更强调近邻结构，使高维中相近的 points 在低维图中也尽量相近。对于原本已相距很远的 points，t-SNE 只需要让它们分开，并不会准确保存它们之间的相对距离。

🟨 **阅读 t-SNE 图时应看局部，不应过度解读全局。** 两个 clusters 在图上相隔两倍远，并不表示它们在原始 feature space 中也相隔两倍远。

## 5. “Where”：模型依赖图像中的什么位置？

Localization explanations 试图回答：为了预测某个 class，图像中的哪些区域最重要？这可以帮助发现模型是否真正查看 object，还是依赖 background、context 或其他 shortcut。

### Occlusion sensitivity

Occlusion 方法在图像不同位置放置遮挡块，并重复计算目标 class score。若遮住某区域后 score 大幅下降，说明该区域对当前 prediction 很重要。

例如，原图被判定为 African elephant，confidence 为 $0.98$：

- 遮住无关 background 后变为 $0.96$，下降 $0.02$；
- 遮住 elephant head 后变为 $0.70$，下降 $0.28$。

将遮挡窗口滑过所有位置，就能把 score drop 绘制成 spatial importance map。对 go-kart 的实验不仅突出 kart 本身，也突出 racing track context，说明模型会依赖与类别共现的背景信息。

Occlusion 容易理解且不需要改变网络，但必须对许多位置反复 forward pass，因此成本较高；遮挡块的大小和填充值也会影响结果。

### CAM：Class Activation Mapping

CAM 要求 CNN 在 classification layer 前具有 **global average pooling（GAP）**。设最后一层 convolution 产生 feature maps $A_k(x,y)$，GAP 对每个 channel 求空间平均：

$$
\bar{A}_k=\frac{1}{HW}\sum_x\sum_y A_k(x,y)
$$

若 class $c$ 的 classifier weight 是 $w_k^c$，则对应的 class activation map 为：

$$
M_c(x,y)=\sum_k w_k^c A_k(x,y)
$$

这里，classifier weights 表示各 channels 对 class $c$ 的重要程度，而 feature maps 保留这些 channels 在哪里被激活。由于 GAP 和 weighted sum 都是 linear operations，可以交换两者顺序，于是把 class weights 投影回 spatial maps，得到 class-specific heatmap。

同一 image 对不同 class 会产生不同 CAM。例如询问 `dome`、`palace` 或 `church` 时，模型可以突出不同区域。

### Grad-CAM

Grad-CAM 不要求网络必须采用 GAP classifier。它从目标 class score $y^c$ 向某个 convolutional feature layer 反向传播，用 gradients 对每个 feature map 计算重要性权重：

$$
\alpha_k^c
=
\frac{1}{HW}
\sum_x\sum_y
\frac{\partial y^c}{\partial A_k(x,y)}
$$

然后组合 feature maps：

$$
L_{\text{Grad-CAM}}^c
=
\operatorname{ReLU}
\left(
\sum_k \alpha_k^c A_k
\right)
$$

因此，Grad-CAM 用 class score 的 gradient 估计 channels 对当前 decision 的贡献，不需要为了可视化而重新设计 classifier architecture。同一张同时包含 cat 和 dog 的图像，从不同 class score 反向传播，可分别得到对应区域的 heatmaps。

## 6. “What”：Layer、Neuron 或 Attention Head 编码了什么？

除了问模型“在哪里看”，还可以问内部某个 component 表示“什么”。常见方法包括：

- 直接 visualise filters 或 activation maps；
- 收集能让某个 neuron 产生高 response 的 images；
- 分析某个 attention head 或 layer 对最终 representation 的贡献；
- 在 CLIP 中，寻找与内部 contribution 最接近的 text descriptions。

### 分解 ViT class token

ViT encoder 中每个 attention block 和 MLP block 都通过 residual connection 向 residual stream 添加 contribution。最终 class token 因此可以看成初始 class embedding 与各层 residual contributions 的累积：

$$
x_{\mathrm{CLS}}^{\mathrm{final}}
=
x_{\mathrm{CLS}}^{0}
+
\sum_{\ell=1}^{L}
\left(
\Delta_{\mathrm{attn}}^{(\ell)}
+
\Delta_{\mathrm{MLP}}^{(\ell)}
\right)
$$

Attention contribution 还可以继续按照 layer $\ell$、head $h$ 和 source patch $i$ 分解。设 $y_{i,h,\ell}$ 是 patch $i$ 在 layer $\ell$ 的 head $h$ 对 class token residual 的贡献，则可进行两种聚合：

- 对 patches 求和，保留 head 与 layer：分析**某个 attention head 在编码什么（what）**；
- 对 heads 与 layers 求和，保留 patch：分析**某个位置贡献了什么（where）**。

在 CLIP ViT 中，这些 contribution vectors 可以与 text embeddings 比较，从而产生语言解释。例如，一个 head 可能与 numbers 相关，另一个与 shapes 或 colours 相关；某组 pyramid patches 的总贡献可能接近 “a photo of a pyramid”，camel patches 则接近 “a photo of a camel”。

这种 decomposition 将 head-level semantic content 与 patch-level spatial location 联系起来。不过，它仍是对固定模型的外部分析，而不是保证模型存在人类可理解的离散“概念模块”。

### 三类模型检查方法

| 问题 | 方法 | 主要观察对象 |
|---|---|---|
| Feature space 怎样组织 images？ | Nearest neighbours、PCA、t-SNE | representations 之间的关系 |
| 模型在图像哪里寻找证据？ | Occlusion、CAM、Grad-CAM | spatial importance |
| 内部 component 编码什么？ | Activation inspection、head/patch decomposition | neuron、layer、attention head 的 response |

这些方法都可以在训练完成的 fixed network 上使用，不一定需要 retraining；但 CAM 要求网络具有特定的 GAP-based architecture。

## 7. Invariance、Generalisation 与 Dataset Bias

理想的视觉模型应在不会改变 object identity 的图像变化下保持预测稳定。课程关注以下变化：

- **Lighting**：同一表面处于不同 illumination；
- **Translation**：object 出现在 frame 的不同位置；
- **In-plane rotation**：camera 倾斜导致图像内旋转；
- **Scale**：object 因距离不同而变大或变小；
- **3D pose**：object 转向后露出不同 surfaces。

这些 invariances 有些来自 architecture 的 inductive bias，例如 convolution 提供一定 translation equivariance；另一些则主要来自 training data 和 data augmentation。

### CNN 的 texture bias

CNN 的 locality bias 使它非常善于利用局部 texture。BagNet 实验表明，即使模型只查看 small patches、完全没有 global shape，也能在 ImageNet 上取得相当好的 classification performance。

进一步实验显示：

- 移除 texture、只保留 silhouette 或 edges 时，CNN accuracy 大幅下降，而 humans 仍能较好识别；
- 只保留 texture 时，CNN performance 可以恢复到很高水平；
- 把 global shape 打乱、保留局部 texture 后，VGG-16 accuracy 仅从约 $90\%$ 降到 $79\%$。

🟨 **这说明高 ImageNet accuracy 不等于模型使用了与人类相同的 shape reasoning。** 模型可能主要利用局部 texture 或 background shortcuts，而不是 global object structure。

### 对 distortion 的 tolerance 通常来自训练分布

某些加入 noise、降低 contrast、edge detection 或 rotation 的图像对 humans 仍容易，却会让只在普通 images 上训练的模型失败。如果针对某一种 distortion 重新训练，模型通常能处理该 manipulation，但能力不一定迁移到其他 distortions。

因此，更准确的表述是：

> CNN 通常容忍 training distribution 中出现过的 variation，但不保证 generalise 到 distribution 之外的变化。

这也解释了为什么 data augmentation 有效：它明确告诉模型哪些 transformations 不应改变语义。然而，仅为一种变化做 augmentation 并不会自动产生对所有其他变化的 invariance。

### Geographic 与 socioeconomic bias

模型的 training distribution 并不等于真实世界。课程展示的 Open Images 来源高度集中于美国等地区，因此地理分布并不代表全球 population。类似 object 如果拍摄于较贫困 household，模型 recognition accuracy 也可能更低。

数据偏差会转化成实际 performance gap：

```text
谁拍摄、在哪里拍摄、生活环境如何
  ↓
决定 training images 的 appearance distribution
  ↓
模型学习 distribution 中频繁出现的 patterns
  ↓
不同地区与收入群体获得不同 accuracy
```

🟨 **最终结论：** 模型的 invariance 不是抽象、自动获得的能力，而是 architecture bias、training examples、augmentation 和 deployment distribution 共同作用的结果。评估 generalisation 时，必须同时检查模型使用的视觉证据，以及 training data 来自哪里、遗漏了哪些人和环境。
