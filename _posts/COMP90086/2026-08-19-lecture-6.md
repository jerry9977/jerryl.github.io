# COMP90086 - Convolutional Neural Networks I

> 本节从 image recognition 的任务定义出发，回顾 fully connected neural network 的基本计算与训练方式，再解释 CNN 如何通过 **local connectivity** 和 **weight sharing** 更有效地学习图像中的重复 spatial patterns。

---

## 1. Image Recognition 是什么？

本节所说的 **image recognition** 主要指 **category-level、whole-image classification**：给定一张 image，输出一个代表整张图像主要内容的 class label。

Category 的粒度可以不同。例如，同一张图像可以根据 dataset 的 label design 被标记为 `bird`、`duck` 或 `Australian wood duck`。模型最终能够预测什么，取决于 training set 中定义了哪些 classes。如果 dataset 只有 `couch` 而没有 `dog`，即使图像的主要内容是一只狗，模型也只能从已有 label set 中选择答案。

### 1.1 与其他 vision tasks 的区别

| Task | 输出目标 | 典型输出 |
|---|---|---|
| Image classification | 整张 image | 一个 class label |
| Object detection | 找出 object 的类别与位置 | class + bounding box |
| Semantic segmentation | 为每个 pixel 指定 category | pixel-level class mask |
| Instance segmentation | 区分同类别中的不同 objects | 每个 instance 的独立 mask / ID |

**Category-level recognition** 识别某个 group；**instance-level recognition** 则识别某一个具体个体。比如识别“person”属于 category level，而区分教室里的每一个人属于 instance level。

### 1.2 Recognition 为什么困难？

Recognition 同时面对两种相反的困难：

- **Inter-category similarity**：不同 categories 可能外观非常接近；
- **Intra-category variability**：同一 category 内可能因为 instance、illumination、scale、viewpoint、pose、background 或 occlusion 而出现巨大差异。

因此，image recognition 的核心目标是学习一种合适的 **representation**：

1. 能够区分不同 categories；
2. 对同一 category 内不重要的变化保持 invariant 或 tolerant。

🟨 **核心关系：** 好的 representation 不是记录所有 pixel differences，而是保留与 category 有关的信息，同时忽略 illumination、pose、background 等无关变化。

## 2. 从 Hand-crafted Features 到 Deep Learning

早期 computer vision 通常依赖人工设计的 **hand-crafted features**。研究者根据经验选择 kernels 或 descriptors，从 image 中提取 edges、corners、textures 和 gradient patterns。

Lecture 提到的例子包括：

- **Local Binary Pattern (LBP)**：比较中心 pixel 与邻域 pixels，并用 binary encoding 表示 local texture；
- **Histogram of Oriented Gradients (HOG)**：统计不同方向的 local gradients，主要描述 edge structure；
- **Gabor filters**：在不同 scales 和 orientations 上提取 texture / edge responses；
- Gaussian derivatives、Difference of Gaussians 等 filter families。

这些 features 的问题是：它们由人根据经验提前选定。某个 feature 在一个 dataset 上有用，不代表它能 generalise 到另一类 images；而且大量候选 features 中并不是每一个都与目标 task 有关。

Deep learning 的变化在于：网络不再只使用固定的 hand-crafted descriptors，而是直接从 labelled data 中学习适合任务的 representations。

### 2.1 为什么 neural networks 在 2010 年后成为主流？

课程总结了三个主要条件：

1. **GPU parallel computation**：CUDA 等技术使大量 pixel / local-region operations 可以并行执行；
2. **Algorithm improvements**：包括 ReLU、regularisation、dropout 和早期的 unsupervised pretraining；
3. **Large labelled datasets**：互联网提供了大量 images 与 human-annotated labels。

ImageNet 基于 WordNet concepts 建立。Slides 提到完整 collection 超过 5,000 classes，而常用版本选择其中 1,000 classes。大规模 supervised dataset 使网络能够学习比 hand-crafted features 更复杂的 patterns。

🟦 **Supervised learning** 在这里就是学习从 image input 到 class label output 的 mapping。

## 3. Neural Network / MLP 回顾

一个 multilayer perceptron（MLP）通常包含 input layer、一个或多个 hidden layers，以及 output layer。在 **fully connected layer** 中，每个 neuron 都连接到上一层的所有 outputs。

单个 neuron 首先计算 weighted sum，再通过 non-linear activation function：

$$
y=f\left(\sum_j w_jx_j+b\right)=f(\mathbf{w}^{\top}\mathbf{x}+b)
$$

其中：

- $x_j$：input；
- $w_j$：learned weight；
- $b$：learned bias；
- $f$：non-linear activation function；
- $y$：neuron output / response。

### 3.1 Non-linear activation functions

课程介绍了三种常见 activation functions。

**Sigmoid**：

$$
\sigma(x)=\frac{1}{1+e^{-x}}
$$

其输出范围为 $(0,1)$。

**Hyperbolic tangent**：

$$
\tanh(x)=\frac{e^{2x}-1}{e^{2x}+1}
$$

其输出范围为 $(-1,1)$。

**Rectified Linear Unit (ReLU)**：

$$
\operatorname{ReLU}(x)=\max(0,x)
$$

ReLU 保留 non-negative inputs，并把 negative inputs 设为 0。

Non-linearity 是 deep network 能学习复杂 patterns 的关键。如果所有 layers 都只是 linear transformations，多层 linear operations 最终仍可合并成一个 linear function；单纯增加 depth 并不会增加 model 的表达能力。

### 3.2 Backpropagation 与 parameter update

Network 使用 **backpropagation** 计算 loss 对 parameters 的 gradients。计算从 output layer 开始，再逐层传播到 earlier layers，并用 gradient descent 调整 weights 和 biases。

第 $l$ 层 parameters 的基本 update 可以表示为：

$$
\theta_{t+1}^{(l)}=\theta_t^{(l)}-\eta\nabla_{\theta^{(l)}}\mathcal{L}
$$

其中：

- $\theta^{(l)}$：第 $l$ 层的 weights 与 biases；
- $\mathcal{L}$：prediction 与 ground truth 之间的 loss；
- $\eta$：learning rate，决定每次 update 的 step size；
- gradient 决定 parameter 应改变的方向。

Ground truth 在 classification 中通常使用 **one-hot label**：正确 class 为 1，其余 classes 为 0。

### 3.3 MLP 的优势与限制

| 优势 | 限制 |
|---|---|
| 能近似复杂 continuous functions | 可能包含 millions / billions of parameters |
| 自动学习 feature embedding | memory、time 和 data requirements 很高 |
| 同一 layer 内 neurons 可并行计算 | 容易 overfit |

Fully connected network 可以用于 image recognition，但 image 很大时，把所有 pixels 与所有 neurons 相连会产生极多 parameters，而且没有直接利用 image 的 local spatial structure。

## 4. Convolutional Layer 如何工作？

CNN 仍然是 neural network，但它把早期的 fully connected layers 替换为 **convolutional layers**。每个 convolutional neuron 只查看 input 的一个 local patch，并在不同 spatial locations 重复使用相同 weights。

这种设计包含两个重要思想：

- **Local connectivity**：neuron 只与附近 pixels / activations 相连；
- **Weight sharing**：同一个 kernel 在整张 input 上重复使用，用来识别不同位置出现的相同 pattern。

因此，CNN 能够以更少 parameters 学习 local、repeated features，同时保留 feature 出现的位置。

### 4.1 Kernel、stride 与 channels

Convolutional layer 由以下元素定义：

- **Kernel / filter**：覆盖 local region，并与 input values 进行 element-wise product 后求和；
- **Stride $S$**：kernel 每次在 spatial dimensions 上移动多少 positions；
- **Input channels $C_{in}$**：例如 RGB image 有 3 channels，因此 kernel depth 也必须是 3；
- **Number of filters $C_{out}$**：决定 output activation maps 的数量。

严格来说，多数 deep-learning implementations 计算的是 **cross-correlation**，即 kernel 不会像 mathematical convolution 那样先翻转。但课程与常见 frameworks 仍把这个 operation 称为 convolution。

对二维 input，单个 filter 的 cross-correlation 可以写成：

$$
Y(i,j)=\sum_{u}\sum_{v}\sum_{c=1}^{C_{in}}K(u,v,c)X(i+u,j+v,c)+b
$$

一个 filter 产生一张 activation map；如果 layer 学习 $C_{out}$ 个 filters，就会产生 $C_{out}$ 张 activation maps，并堆叠成下一层的 multi-channel input。

### 4.2 Output spatial size

对于 input size $N$、kernel size $K$、padding $P$ 和 stride $S$，一维 spatial output size 为：

$$
O=\left\lfloor\frac{N+2P-K}{S}\right\rfloor+1
$$

`+1` 位于 fraction 外部。Valid convolution 使用 $P=0$，当 $K>1$ 时 output 会比 input 小。如果希望保持相同 spatial size，可以加入 padding；zero padding 是最常见的方式。

🟩 例如 $32\times32$ input、$5\times5$ kernel、stride $S=1$ 且没有 padding：

$$
O=\frac{32-5}{1}+1=28
$$

若使用 $P=2$：

$$
O=\frac{32+2(2)-5}{1}+1=32
$$

## 5. Fully Connected 与 Convolutional Layer

两类 layers 最核心的区别是 connectivity。

| | Fully connected layer | Convolutional layer |
|---|---|---|
| Receptive input | 每个 neuron 查看整个 input | 每个 neuron 查看一个 local patch |
| Learned operation | 整个 input 的 weighted combination | 在各位置重复使用的 local kernel |
| Output | neuron response vector | 保留 spatial layout 的 activation map |
| Weight sharing | 无 | 有 |
| Parameter count | 通常很大 | 通常明显更少 |

### 5.1 Parameter count

如果 input 是 $32\times32\times3$，一个 fully connected neuron 需要：

$$
32\times32\times3+1=3073
$$

这里包含 3,072 个 weights 和 1 个 bias。

如果改用一个 $5\times5\times3$ convolution filter，则只需要：

$$
5\times5\times3+1=76
$$

对于 $C_{out}$ 个 filters，parameter count 为：

$$
C_{out}\left(K_hK_wC_{in}+1\right)
$$

同一个 filter 会在所有 spatial locations 重复使用，因此 parameter count 不会随着 kernel 移动次数增加。

### 5.2 Layer depth 与 feature hierarchy

不同 depths 的 convolutional layers 会学习不同 levels 的 representation：

```text
Early layers
edges / simple orientations
  ↓
Middle layers
textures / corners / local shapes
  ↓
Deeper layers
object parts / higher-level structures
```

Early-layer kernels 往往类似 edge filters；随着 layers 加深，network 会把 local responses 组合成更复杂的 textures、parts 和 object-level patterns。

Convolutional layers 的优势是 parameter-efficient、能够识别出现在不同位置的相同 feature，并保留 spatial relations。限制则来自 local receptive field：如果 kernel 太小或 network 不够深，单层 neuron 只能看到局部内容，无法直接表达较大的 global structure。

🟨 **整体理解：** CNN 并不是放弃 fully connected layers，而是先用 convolutional layers 高效学习 spatial features，再由后续 layers 完成更高层的 representation 与 classification。

## 重点总结

- Image recognition 在本节中指 category-level whole-image classification。
- 理想 representation 应区分不同 categories，同时容忍同类别内的 appearance variation。
- Neural network 通过 weighted sum、non-linear activation 与 backpropagation 学习 features。
- CNN 使用 local connectivity 和 weight sharing，更适合 large images 与 repeated spatial patterns。
- 一个 convolution filter 产生一张 activation map；filters 数量决定 output channels。
- 多数 CNN 实现实际执行 cross-correlation，但通常仍称为 convolution。
- 相比 fully connected layer，convolutional layer 通常使用更少 parameters，并保留 spatial relations。
