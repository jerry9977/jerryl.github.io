# COMP90086 — Convolutional Neural Networks & Image Classification

> 这份笔记按照 lecture transcript 整理。为了可读性，明显的语音转写术语统一成常见写法，例如 **kernel, Sobel, ReLU, softmax, MNIST, ground truth, overfitting**。  
> 重点不是背 architecture 名字，而是理解：**为什么图像任务适合 convolution，以及 CNN 和普通 fully connected neural network 到底差在哪里。**

---

## 1. Image Classification 是什么？

这节课从一个最基本的 computer vision task 开始：**image classification**。

Image classification 的输入是一张 image，输出通常是一个 **class label**。比如输入一张狗的图片，模型可能输出 `dog`。但这个答案取决于训练时定义了哪些 classes：如果 dataset 里没有 `dog`，却有 `couch`，那么即使人类第一眼看到的是狗，网络也只能从它认识的 labels 中选择。

所以 classification 本质上不是“模型理解世界上所有东西”，而是：

\[
f(\text{image}) \rightarrow \text{class label}
\]

也就是说，网络学习的是一个从 **input image → predefined label space** 的 mapping。

这里还要区分不同层级的视觉任务。**Image-level classification** 通常一张图只有一个整体 label；**object detection** 不只告诉你是什么，还返回 bounding box；**semantic segmentation** 是对每个 pixel 做 category classification；如果还需要区分同一类别里的不同个体，就进入 instance-level 的概念。

例如一张教室照片里有很多人：

- image classification 可能只说：`human`
- object detection 会找出每个人的位置
- semantic segmentation 会把所有属于 human 的 pixel 标成同一个类别
- instance segmentation 则会进一步区分 person 1、person 2、person 3

分类真正困难的地方，是 **inter-class similarity** 和 **intra-class variation**。

两个不同类别可能外观看起来很像，这叫 inter-class similarity；同一个类别内部又可能因为 lighting、pose、occlusion、background、scale 等因素看起来差很多，这叫 intra-class variation。

因此好的 visual representation 应该尽量对这些无关变化保持 **robust / invariant**。

## 2. 从 Handcrafted Features 到 Learned Features

在 deep learning 普及之前，computer vision 很依赖 **handcrafted features**。

意思是：我们人工设计某种 feature extractor，然后把它应用到图像上。例如之前学过的 Gaussian、Difference of Gaussians、Sobel、Derivative of Gaussian，本质上都属于人为设计的局部 filtering operation。

Lecture 还提到几个经典例子：

**Local Binary Pattern (LBP)** 会看一个局部 neighborhood，把周围 pixel 和中心 pixel 比较，再将比较结果编码成 binary pattern。这里的重点是：它是 **local** 的，而且 pattern 的位置也很重要。

**Histogram of Oriented Gradients (HOG)** 主要依赖局部 gradient orientation，因此和 edge information 密切相关。

还有 multi-scale、multi-direction 的 filters，可以在不同尺度和方向提取 pattern。

问题在于，这些 features 都是人工选择的。我们根据经验认为某种 edge、texture 或 pattern 可能有用，但它不一定能很好地 transfer 到另一个 dataset 或另一种视觉任务。

Neural network 的核心变化是：**feature 不再完全由人手设计，而是从 training data 中学习出来。**

可以把整个过程理解成：

```text
Raw pixels
   ↓
Low-level features
(edges / corners)
   ↓
Mid-level features
(textures / local structures)
   ↓
High-level features
(parts / object structure)
   ↓
Semantic concept
(dog / human / chair ...)
```

随着网络越来越深，feature 通常从低层的 edge、corner，逐渐变成更抽象的 structure、texture 和 semantic representation。

这和 lecture 中提到的人类视觉系统类比类似：视觉不是一下子直接从 pixels 得到“这是一只狗”，而是经过很多层次的处理。

## 3. Neural Network 基础：Neuron、Activation 与 Learning

普通 neural network 在这节课里主要指由 **fully connected layers** 组成的网络。

一个 neuron 的核心计算是 weighted sum：

\[
z = \sum_i w_i x_i + b
\]

或者写成 vector form：

\[
z = \mathbf{w}^\top \mathbf{x} + b
\]

其中：

- \(x_i\)：input
- \(w_i\)：learnable weight
- \(b\)：bias
- \(z\)：linear output

但只有 linear operations 不够。

如果连续很多层都是线性的，那么：

\[
W_3(W_2(W_1x))
\]

仍然可以合并成一个大的 linear transformation：

\[
W'x
\]

这样增加很多层就没有真正增加表达能力。

所以 neural network 中必须加入 **non-linear activation function**。

Lecture 提到的典型 activation 包括 sigmoid、tanh 和 ReLU。

Sigmoid 输出大致在 \(0\) 到 \(1\)：

\[
\sigma(x)=\frac{1}{1+e^{-x}}
\]

tanh 输出大致在 \(-1\) 到 \(1\)。

ReLU 则是：

\[
\operatorname{ReLU}(x)=\max(0,x)
\]

也就是负数变成 0，正数保留。

因此一层 neural network 可以粗略理解为：

\[
\text{input}
\rightarrow
\text{linear transformation}
\rightarrow
\text{non-linearity}
\rightarrow
\text{feature}
\]

网络中一层层的 linear + nonlinear operation，让模型能够学习复杂的 image patterns。

## 4. Training：Loss、Backpropagation 与 Gradient Descent

Supervised learning 中，我们有 input image 和它对应的 **ground-truth label**。

模型先进行 prediction，然后用 **loss function** 衡量 prediction 和 ground truth 之间的差异。

可以抽象成：

\[
L(\hat{y},y)
\]

其中：

- \(y\)：ground truth
- \(\hat y\)：prediction
- \(L\)：loss

对于 classification，ground-truth label 常可以表示成 one-hot vector。

例如有 4 个 classes，真实类别是第 2 类：

\[
y=[0,1,0,0]
\]

Training 的目标就是调整 network parameters，让 loss 越来越小。

Backpropagation 会计算 loss 对 parameters 的 gradient：

\[
\nabla_\theta L
\]

其中 \(\theta\) 可以代表 weights \(W\) 和 biases \(b\)。

最基本的 parameter update 可以写成：

\[
\theta_{t+1}
=
\theta_t
-
\eta \nabla_\theta L
\]

其中：

- \(\eta\)：learning rate
- gradient：告诉我们 parameter 应该往哪个方向变化
- learning rate：决定一次走多大一步

Lecture 也提到 SGD、Adam 这类 optimizer。

可以把这个过程记成：

```text
Image
  ↓
Forward pass
  ↓
Prediction
  ↓
Compare with ground truth
  ↓
Loss
  ↓
Backpropagation
  ↓
Gradient
  ↓
Update W and b
```

如果 model 太强、training data 太少，或者 training distribution 和 testing distribution 差异很大，就可能出现 **overfitting**：training data 上很好，换到新数据表现明显下降。

Lecture 还强调 dataset balance。比如有 100 张 cat、10 张 dog，如果模型全部预测 cat，accuracy 仍然可能看起来很高，所以仅看 accuracy 可能具有欺骗性。

大规模 dataset 和 GPU 的出现，是 deep learning 能够真正成功的重要条件。GPU 适合大量 parallel computation，而 image processing 和 neural networks 中有大量可以并行计算的 operations。

## 5. 为什么图像更适合 CNN？

Fully connected network 最大的问题之一，是每个 neuron 和上一层所有 input 都连接。

假设一张 RGB image 是：

\[
32 \times 32 \times 3
\]

flatten 后 input dimension 是：

\[
32 \cdot 32 \cdot 3 = 3072
\]

如果一个 fully connected neuron 连接所有 input，就已经需要大约 3072 个 weights，再加 bias。

如果有很多 neurons，parameter count 会迅速增加。

但图像有一个很重要的 property：**local spatial structure**。

例如一个 edge，只需要看它附近的一小块 pixels；一个眼睛、corner、texture，也通常首先是 local pattern。

CNN 利用两个关键想法：

**Local connectivity**

一个 convolution kernel 只看 input 的一个小 neighborhood，例如 \(3\times3\) 或 \(5\times5\)。

**Weight sharing**

同一个 kernel 会在整张 image 上滑动。

这表示如果某种 edge pattern 出现在左上角和右下角，我们不需要重新学习两套 weights。同一个 filter 可以在不同位置检测相似 pattern。

例如一个 \(5\times5\) kernel 作用在 RGB image 上，一个 filter 的主要 weights 数量是：

\[
5\times5\times3
\]

而不是：

\[
32\times32\times3
\]

因此 convolution layer 相比 fully connected layer 可以大幅减少 parameters。

这也是 CNN 的关键 inductive bias：

> 图像中的重要 pattern 通常是 local 的，而且相似 pattern 可能出现在不同 spatial locations。

## 6. Convolution Layer：Kernel、Stride、Padding 与 Feature Map

在 CNN 中，一个 convolution layer 会用 learnable **kernel / filter** 在 image 上滑动。

输入可以写成：

\[
H \times W \times C_{\text{in}}
\]

例如 RGB image：

\[
32\times32\times3
\]

一个 convolution kernel 则可能是：

\[
K_h \times K_w \times C_{\text{in}}
\]

例如：

\[
5\times5\times3
\]

这里 kernel depth 必须覆盖 input channels。

每个 filter 会产生一个 output feature map。多个 filters 就会产生多个 output channels。

所以如果有 \(C_{\text{out}}\) 个 filters，parameter count 大致是：

\[
K_hK_wC_{\text{in}}C_{\text{out}} + C_{\text{out}}
\]

最后一项来自每个 output channel 的 bias。

### Stride

Stride \(S\) 表示 kernel 每次移动多少 pixels。

如果 \(S=1\)，kernel 每次移动一个 pixel；stride 越大，output spatial size 通常越小，同时可能跳过更多细节。

### Padding

如果不 padding，kernel 无法完整覆盖 image boundary，因此 output 会缩小。

加入 padding \(P\) 后，二维某一个方向的 output size 可以写成：

\[
O=
\left\lfloor
\frac{N+2P-K}{S}
\right\rfloor+1
\]

这里：

- \(N\)：input size
- \(P\)：padding
- \(K\)：kernel size
- \(S\)：stride
- \(O\)：output size

例如：

\[
N=32,\quad K=5,\quad S=1,\quad P=2
\]

那么：

\[
O=
\frac{32+4-5}{1}+1
=32
\]

所以这种设置可以保持 spatial size 不变。

### Feature / Activation Map

Kernel 对 image 做 linear filtering 后得到 feature map，再经过 activation function，例如 ReLU。

因此 CNN 中常见的基本结构是：

\[
\text{Convolution}
\rightarrow
\text{ReLU}
\]

Lecture 把 convolution 看作 linear operation，而 activation 提供 non-linearity。

还有一个需要特别记住的点：

> CNN 中通常被称为 “convolution” 的 operation，在数学实现上更接近之前学过的 **cross-correlation**，因为 kernel 通常不会像 signal-processing convolution 那样先 flip。

这就是 Week 2 的 convolution 和 CNN convolution 之间的重要区别。

## 7. CNN 如何逐层学到更高级的 Feature？

早期 convolution layers 的 receptive information 很 local，因此通常更容易学到：

- horizontal / vertical edges
- corners
- simple orientations
- small texture patterns

这些 learned kernels 有时看起来会和之前手工设计的 Sobel、Derivative of Gaussian 等 filter 很类似。

随着 network deeper，后面的 layers 会组合前面检测到的 features。

可以理解成：

```text
pixels
  ↓
edges
  ↓
corners / simple shapes
  ↓
textures / object parts
  ↓
larger structures
  ↓
semantic object representation
```

例如识别 dog 时，网络并不一定一开始就学一个完整的“dog detector”。

较浅层可能检测 edge 和 orientation；中间层可能组合出 fur texture、eye、ear 等 pattern；更深层才逐渐形成 dog face 或整体 dog structure 的 representation。

最后通常会接上 fully connected / classification layers，把 learned representation 映射到 class scores。

之后经过 softmax，可以把 logits 转换成一组相对的 class probabilities：

\[
p_i
=
\frac{e^{z_i}}
{\sum_j e^{z_j}}
\]

例如 MNIST 有 10 个 classes：

\[
0,1,2,\ldots,9
\]

网络最后输出 10 个 class scores，再得到每个 digit 的 confidence。

## 8. Fully Connected vs Convolutional Layer

| | Fully Connected Layer | Convolutional Layer |
|---|---|---|
| Connection | 每个 neuron 看全部 input | 只看 local neighborhood |
| Spatial structure | flatten 后空间关系弱化 | 保留 spatial relation |
| Weight sharing | 通常不共享 | 同一 kernel 在各位置共享 |
| Parameters | 很多 | 通常少很多 |
| Feature type | global mixing | local pattern extraction |
| Image efficiency | 大图时成本高 | 更适合 image |
| Limitation | parameter-heavy | kernel 太小时只能看 local information |

CNN 并不是说 fully connected layer 没用了。

经典 CNN architecture 通常是：

```text
Image
 ↓
Conv
 ↓
Activation
 ↓
Conv
 ↓
Activation
 ↓
...
 ↓
High-level representation
 ↓
Fully connected / classifier
 ↓
Class prediction
```

Convolution layers 负责提取 spatial visual features；后面的 classifier 负责把这些 features 转换成最终 class decision。

CNN 的限制也需要知道：如果 kernel 很小，每一层只能看到很 local 的区域。因此网络通常需要 stack 多层 convolution，让更深层逐渐聚合更大范围的信息。

## 9. Exam / Revision Cheat Sheet

**Image classification**

\[
\text{image}\rightarrow\text{one class label}
\]

模型只能预测训练时定义过的 label space。

**主要视觉任务区别**

```text
Classification → what?
Detection      → what + where?
Segmentation   → which pixels?
Instance level → which individual object?
```

**Neuron**

\[
z=\mathbf w^\top\mathbf x+b
\]

然后接 nonlinear activation。

**为什么需要 non-linearity？**

多个纯 linear layers 可以合并成一个 linear transform，因此 depth 没有充分意义。

**Training update**

\[
\theta_{t+1}
=
\theta_t-\eta\nabla_\theta L
\]

gradient 给 direction，learning rate 给 step size。

**CNN 两个核心思想**

```text
Local connectivity
+
Weight sharing
```

因此特别适合 image。

**Convolution parameter count**

\[
K_hK_wC_{\text{in}}C_{\text{out}}
+
C_{\text{out}}
\]

**Output size**

\[
O=
\left\lfloor
\frac{N+2P-K}{S}
\right\rfloor+1
\]

**Stride**

kernel 每次移动多少 pixels。

**Padding**

控制 boundary handling，并可帮助保持 output spatial size。

**CNN 中的 convolution**

通常实际计算更接近：

\[
\text{cross-correlation}
\]

因为没有执行 signal-processing convolution 的 kernel flipping。

**Feature hierarchy**

```text
pixels
→ edges
→ corners / textures
→ parts
→ structures
→ semantics
```

**Handcrafted vs learned features**

```text
Traditional CV:
human designs feature extractor

Deep learning:
network learns feature extractor from data
```

**CNN vs FC 最关键的一句话**

Fully connected layer 看全部输入；convolution layer 用共享的小 kernel 在 local regions 上滑动，因此 parameters 更少，并保留 image spatial structure。
