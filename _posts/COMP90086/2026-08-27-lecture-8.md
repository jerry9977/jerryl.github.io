# COMP90086 — Convolutional Neural Networks III

> 本讲从 architecture 层面讨论 CNN：先说明如何评价 ImageNet classification，再比较 AlexNet、VGG、GoogLeNet、ResNet、MobileNet 与 EfficientNet 的核心设计，最后介绍如何将 ImageNet pretrained network 用于 transfer learning。

## 1. ImageNet 分类结果与评价方式

ImageNet classification 包含 **1000 个 object classes**。模型输入一张图像，通过 `softmax` 输出在 1000 个类别上的 probability distribution；所有类别的概率之和为 1。

### Top-1 与 Top-N accuracy

- **Top-1 accuracy**：概率最高的类别必须与 `ground truth` 相同。
- **Top-N accuracy**：概率最高的 $N$ 个类别中，只要包含 `ground truth`，就算预测正确。

🟩 例如，某张图像在 `cat` 和 `dog` 上的预测概率分别为 $0.5$ 和 $0.3$，而 ground truth 是 `dog`。此时 Top-1 prediction 是 `cat`，因此 Top-1 错误；但 `dog` 位于前两个预测中，因此 Top-2 正确。

评价结果时必须先确认图表显示的是 **accuracy 还是 error rate**：

- accuracy 越高越好；
- error rate 越低越好。

从 ImageNet 的历史结果来看，更先进的 architectures 总体上显著降低了 Top-5 error、提高了 Top-1 和 Top-5 accuracy。讲义指出 CNN 在 ImageNet 上已超过相应的人类基准，但这并不表示模型具有人类一般性的视觉能力：人类视觉系统可适应很多任务，而一个 CNN 通常是针对特定任务训练的。

### 为什么有些图像更难分类？

容易分类的图像通常具有清晰的 foreground/background、良好光照、典型 viewing angle、较少 occlusion，而且主体尺寸合适。困难样本则可能出现：

- uncommon viewpoint 或主体只显示局部；
- small object、严重 occlusion 或 cluttered background；
- grayscale、低照度或其他与训练数据不同的成像条件；
- 多个物体同时出现，存在 competing class；
- cartoon、人工背景等在 training set 中较少见的形式；
- 类别本身细粒度相似，例如容器形状相近，仅靠文字才能区分。

🟨 **核心理解：** test set 与 training set 之间存在 distribution gap。即使网络学到了合理特征，非典型视角、小目标和不良成像条件仍会令 confidence 下降并产生可理解的错误。

## 2. 从 AlexNet 到 GoogLeNet：更有效地学习特征

### AlexNet：深度 CNN 的重要起点

AlexNet 在 2012 年 ImageNet competition 中取得突破。其输入约为 $224\times224\times3$ 的 RGB image，并在当时使用两个 GPU 训练。两个 computation streams 是沿 **channel / network parameters** 划分，而不是沿 batch 划分；例如两个各含 2048 个 neurons 的分支连接后得到 4096-dimensional representation。

AlexNet 的主要 innovations 包括：

- 使用 **ReLU（Rectified Linear Unit）**，提供 non-linearity 并加快训练；
- 使用 GPU parallelisation；
- overlapping max pooling 与 response normalisation，带来小幅 accuracy improvement；
- 使用 data augmentation 减少 overfitting，例如 random crop、小角度 rotation、horizontal flipping 与 colour/lighting adjustment；
- 使用 dropout，训练时随机停用部分 neurons，以减少 overfitting。

ReLU 定义为：

$$
\operatorname{ReLU}(x)=\max(0,x)
$$

### VGG：堆叠小 kernel

VGG-16、VGG-19 的数字表示带参数的 convolutional 和 fully connected layers 数量。VGG 的关键设计是大量使用 $3\times3$ convolution，而不是直接使用更大的 kernel。

在 stride 为 1、无 dilation 的情况下，连续堆叠 $3\times3$ convolution 会扩大 effective receptive field：

- 两层 $3\times3$ convolution：effective receptive field 为 $5\times5$；
- 三层 $3\times3$ convolution：effective receptive field 为 $7\times7$。

若暂时忽略 bias，并假设输入、隐藏和输出 channel 数均为 $C$，两层 $3\times3$ convolution 的参数量约为：

$$
2\times3\times3\times C^2=18C^2
$$

一个 $5\times5$ convolution 的参数量则为：

$$
5\times5\times C^2=25C^2
$$

因此，小 kernel 堆叠既能覆盖相同的 receptive field，又能减少参数；而且两层 convolution 之间可加入额外 activation function，从而学习更复杂的 nonlinear features。VGG 也移除了 AlexNet 的 response normalisation，以更快训练，代价只是很小的 accuracy drop。

🟨 **VGG 的核心不是单纯“更深”，而是用多层小 kernel，以较少参数和更多 non-linearity 替代一个大 kernel。**

### GoogLeNet / Inception：同时处理多种尺度

选择 kernel size 很困难，因为物体和 feature 可能以不同 scale 出现。**Inception module** 并行使用多种 operations，例如 $1\times1$、$3\times3$、$5\times5$ convolution 和 pooling，再沿 channel dimension concatenation，使模型同时学习不同 receptive fields 下的 features。

$1\times1$ convolution 不改变 spatial height 与 width，但能改变 channel 数。例如，可把 4096 channels 压缩到 1000 channels，再送入计算成本较高的 convolution，从而实现 dimensionality reduction 并减少 computation。

GoogLeNet 还加入 **auxiliary classifiers**。它们只在 training 时使用：从较早的 intermediate representation 直接做分类，并产生额外 loss。多个 loss 会按预设权重组合，使较浅层也能获得更直接的 training signal，从而缓解 vanishing gradient。Inference 时不需要这些 auxiliary classifiers。

## 3. ResNet：让深层网络真正能够训练

### 深度增加为什么反而可能变差？

直觉上，更深的网络至少应能模仿浅层网络：多出的 layers 只需学习 identity mapping 即可。然而实验显示，plain network 的 depth 增加后，performance 会先饱和再下降。CIFAR-10 上，56-layer plain network 甚至比 20-layer network 有更高的 **training error**。

这不是典型 overfitting，因为更差的结果已经出现在 training set 上；其本质是 **optimization / degradation problem**。讲课时特别把它与 vanishing gradient 联系起来：backpropagation 经过许多层后，传到早期 layers 的 gradient 可能接近 0，parameters 因而无法有效更新。

### Shortcut connection 与 residual learning

ResNet 加入跳过若干 layers 的 **shortcut connection（skip connection）**。若期望 block 学习的 mapping 为 $\mathcal{H}(x)$，则 residual branch 不直接学习 $\mathcal{H}(x)$，而是学习：

$$
\mathcal{F}(x)=\mathcal{H}(x)-x
$$

block 的最终输出为：

$$
y=\mathcal{F}(x)+x=\mathcal{H}(x)
$$

若最佳 mapping 接近 identity mapping，residual branch 只需令 $\mathcal{F}(x)\approx0$，通常比让一组 nonlinear layers 直接学习 $\mathcal{H}(x)=x$ 更容易。

从 gradient 传播来看：

$$
\frac{\partial y}{\partial x}
=
\frac{\partial \mathcal{F}(x)}{\partial x}+1
$$

其中 identity path 提供直接的 `+1` gradient component。即使 residual branch 的 gradient 很小，仍有一条较直接的路径把 gradient 向前传播。

🟨 **Residual block 同时改变了学习目标与 gradient flow：网络学习“需要在 input 上改多少”，而不是从头学习整个 mapping。** 这使更深的 ResNet 能够降低 classification error，而不是像 plain network 那样因加深而退化。

## 4. MobileNet 与 EfficientNet：accuracy 和 efficiency 的权衡

### MobileNet：depthwise separable convolution

MobileNet 面向 phones、mobile apps 与 real-time applications，目标是显著降低参数量和 computation。标准 convolution 同时完成：

1. 在 spatial dimensions 上提取 feature；
2. 在 channel dimensions 上组合信息。

MobileNet 将两者拆分为：

- **depthwise convolution**：每个 input channel 各自使用一个 $K\times K$ spatial filter；
- **pointwise convolution**：再用 $1\times1$ convolution 混合 channels 并产生新的 output channels。

设 feature map spatial size 为 $D\times D$，input channels 为 $M$，output channels 为 $N$，kernel size 为 $K\times K$。标准 convolution 的计算量近似为：

$$
D^2K^2MN
$$

depthwise separable convolution 的计算量近似为：

$$
D^2K^2M+D^2MN
$$

因此其 computation 和 parameter count 通常显著低于标准 convolution。代价是它限制了可学习 kernel 的形式——并非所有 3D kernels 都可以如此 separable。因此 MobileNet 往往比 VGG、ResNet 等更小、更快，但 accuracy 可能较低。

### EfficientNet：同时缩放 depth、width 与 resolution

CNN 的重要 user-defined parameters 包括：

- **depth $d$**：layers 的数量；
- **width $w$**：每层 kernels / channels 的数量；
- **resolution $r$**：输入图像的 spatial size（使用固定 kernel size 时尤其重要）。

单独增加任一维度通常能提高 accuracy，但会出现 diminishing returns。EfficientNet 的关键思想是：在有限 computational budget 下，不只加深或加宽网络，而是通过 grid search 找到小型 baseline model 中较好的 $d,w,r$ 组合，再进行 **compound scaling**。

讲义给出的近似 constraint 为：

$$
d\times w^2\times r^2\approx2,
\qquad d\ge1,\;w\ge1,\;r\ge1
$$

这是因为 computation 对 depth 近似 linear scaling，而对 width 和 resolution 近似 quadratic scaling。构造更大模型时，以 exponent $\phi$ 同时放大这些 dimensions，使 computational resources 约增加为 $2^\phi$。

🟦 **Diminishing returns** 表示成本增幅不会按比例转化为 performance 增幅。网络 architecture 的选择最终取决于 application 对 runtime、memory、processing power 与 accuracy 的共同要求。

## 5. Transfer learning：从 pixels 转向 reusable features

### Pixels 为什么不是理想的表示空间？

直接以 pixels 表示图像会得到高维空间。例如：

$$
256\times256\times3=196{,}608
$$

也就是说，一张 $256\times256$ RGB image 有 196,608 个 pixel attributes。translation、lighting、scale 或 rotation 的小变化都可能造成大量 pixel values 改变，即使图像的 semantic class 完全相同。因此 raw pixel space 对 classification 并不稳定。

CNN 将 pixels 转换为较低维的 **feature embedding / latent representation**。好的 feature space 应当：

- 比 raw pixels 低维，例如每张图像只有数千个 values；
- 把同类别图像映射到 feature space 中相近的位置；
- 对不影响类别的变化较稳定，例如 viewpoint、position、illumination 与 scale；
- 逐层从 edges、corners、textures，过渡到 object parts 与 semantic representation。

这也是 pretrained CNN 能够 generalise 的原因：ImageNet classification 学到的 high-level features 不只服务于原来的 1000-way classification，也能支持 object detection、segmentation、attribute prediction、instance retrieval、depth estimation 或 3D reconstruction 等任务。

### Off-the-shelf feature embedding

一种简单的 transfer learning 方法是移除 pretrained CNN 的原始 output layer，从较晚的一层提取 activations。例如 AlexNet 中，可将送入 1000-class classifier 之前的 4096 neuron activations 作为每张图像的 embedding：

```text
Image
  ↓
ImageNet pretrained CNN
  ↓
4096-dimensional feature embedding
  ↓
SVM / K-NN / another classifier
```

这种方法不必重新训练整个 backbone，而是把 learned representation 作为其他模型的 attributes。

### 替换 classifier 并进行 fine-tuning

若目标 dataset 只有 10 个 classes，可以移除原来的 1000-class output layer，换成适合新任务的 10-class layer。典型流程为：

1. 加载 ImageNet pretrained parameters；
2. 替换最后的 output layer；
3. 随机初始化新 layer；
4. freeze backbone，只训练新 layer；
5. 如有需要，再解冻部分 layers 进行 fine-tuning。

**Fine-tuning** 是对 pretrained CNN 的一部分 layers 继续训练。需要调整多少层，主要取决于：

| 条件 | 较合理的策略 | 原因 |
| --- | --- | --- |
| 新 dataset 较小且与 ImageNet 相似 | freeze 大部分 backbone，只训练新 classifier 或少量 late layers | 已有 features 可复用，解冻太多容易 overfitting |
| 新 dataset 较大且与 ImageNet 相似 | 可 fine-tune 更多 late layers | 有足够数据让 high-level features 适应新类别 |
| 新 dataset 与 ImageNet 差异较大 | 可能需要逐步解冻更早 layers | early layers 学到的 low-level edges / textures 也可能需要调整 |
| 新 dataset 很小且差异又大 | 需要谨慎折衷 | 任务需要改变 features，但数据不足又会增加 overfitting 风险 |

Fine-tuning pretrained parameters 时通常使用比新 layer 更小的 learning rate，例如将原 learning rate 缩放到 $0.1$、$0.05$ 或更低。因为这些 parameters 已经学到有效 features，应缓慢适应，而不是被大步更新破坏。

🟨 **Transfer learning 的本质：** 复用大型任务已经学到的 representation，只对新任务真正不同的部分进行训练，从而减少所需数据、training time 与 computation。

## 6. 架构之间的核心联系

| Architecture | 主要问题 | 核心设计 | 主要 trade-off |
| --- | --- | --- | --- |
| AlexNet | 深度 CNN 训练慢、易 overfit | ReLU、GPU、augmentation、dropout | 奠定基础，但结构和计算方式较早期 |
| VGG | 如何扩大 receptive field 并控制参数量 | 堆叠 $3\times3$ convolution | 结构简单，但整体参数量和计算仍较大 |
| GoogLeNet | feature scale 不固定、深层 gradient 较弱 | Inception module、$1\times1$ reduction、auxiliary classifiers | multi-scale 且较高效，但 module 更复杂 |
| ResNet | deeper plain network 出现 degradation | shortcut connection、residual learning | 可训练极深网络，但仍需相应算力 |
| MobileNet | mobile / real-time computation 受限 | depthwise separable convolution | 更小更快，但 kernel expressiveness 与 accuracy 可能降低 |
| EfficientNet | depth、width、resolution 如何共同分配 | grid search + compound scaling | 更有效利用算力，但最优配置搜索本身有成本 |

这些 architectures 看似各自不同，实际都围绕三个共同目标展开：**改善 feature learning、提高 optimization 能力，以及在 accuracy 与 computation efficiency 之间取得更好的平衡。** Transfer learning 则进一步把这些 backbone 学到的 features 从单一 ImageNet task 扩展到新的 datasets 与 vision tasks。
