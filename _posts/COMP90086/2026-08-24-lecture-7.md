# COMP90086 - Convolutional Neural Networks II

> 这节课延续 CNN 的基本结构，重点说明三件事：如何用 **downsampling** 控制 feature size，如何用 **regularisation** 减少 overfitting，以及如何通过 preprocessing、loss function 与 hyperparameters 完成 image recognition CNN 的训练。

---

## 1. CNN 中的 Downsampling

在 convolutional neural network 中，随着 convolution 不断产生 activation maps，如果始终保留较大的 spatial size，后续层的计算量和 memory usage 会迅速增加。因此，CNN 通常会在 convolutional layers 之间对 feature maps 进行 **downsampling**。

Downsampling 的主要目的包括：

- 减少 activation map 的 spatial size；
- 减少后续层需要执行的 computations；
- 增加对小幅 translation 的容忍度；
- 在保留重要 features 的同时逐步形成更紧凑的 representation。

例如，张量尺寸 $227\times227\times3$ 表示：

- $227\times227$：image 的 height 和 width；
- $3$：RGB channels；
- 后续的 $55\times55\times96$ 中，$55\times55$ 是 spatial size，而 $96$ 是 activation maps / channels 的数量。

🟨 **不要把 channel count 和 spatial resolution 混在一起。** 例如 $27\times27\times256$ 表示有 256 张大小为 $27\times27$ 的 activation maps。

### 1.1 Strided convolution

**Stride** 是相邻 convolution windows 之间移动的距离。当 stride $S=1$ 时，kernel 每次移动一个 pixel；当 $S>1$ 时，kernel 会跳过一部分 spatial locations，因此 convolution 本身就能实现 downsampling。

Slides 在无 padding 时给出的 output-size 形式为：

$$
O=\left\lceil\frac{N-K+1}{S}\right\rceil
$$

其中：

- $N$：input size；
- $K$：kernel size；
- $S$：stride；
- $O$：output size。

有 padding，并采用保持边界覆盖的设置时，slides 将其简化为：

$$
O=\left\lceil\frac{N}{S}\right\rceil
$$

具体采用 `ceil` 还是 `floor` 取决于 implementation 对边缘不完整 window 的处理方式，因此实际编码时要检查 framework 的 padding convention。

Strided convolution 的优势是 **efficient**：stride 越大，需要进行的 convolution operations 越少。缺点是 kernel 可能完全跳过某些位置，从而遗漏重要的 local features。

### 1.2 Max pooling 与 Average pooling

Pooling 在每一张 activation map 上分别进行，不会把不同 channels 混合在一起。Pooling window 在 spatial dimensions 上移动，并把一个区域压缩成一个输出值。

**Max pooling** 会选取 window 中的最大值，并丢弃其他 values。Backpropagation 时，gradient 只通过被选中的 maximum position 传播。它更可能保留强烈的 edge、texture 或其他显著 feature，因此在早期 CNN 中较常见。

**Average pooling** 会计算 window 内所有 values 的平均值，因此 gradient 会分配到区域中的每个 input。它保留了整体响应，但容易把强 feature 与附近较弱的 values 平均，产生类似 blur 的效果。

| 方法 | 核心操作 | 优点 | 主要风险 |
|---|---|---|---|
| Strided convolution | 用 $S>1$ 的 kernel 直接跳步 convolution | 运算较快 | 可能跳过重要 features |
| Max pooling | 保留 window 内最大值 | 更容易保留显著 features | 丢弃多数 activation values |
| Average pooling | 取 window 内平均值 | 汇总区域整体响应 | 可能模糊 edges 或弱化显著 feature |

🟨 **核心关系：** Downsampling 提高 efficiency 和一定程度的 translation tolerance，但越激进的 downsampling 越可能丢失 spatial information。

## 2. Regularisation：控制 Overfitting

CNN 通常含有大量 parameters，即使 dataset 很大，也可能学习到只适用于 training set 的 patterns。当 training performance 持续提高，但 validation/test performance 变差时，就出现了 **overfitting**。

Regularisation 会限制模型过度依赖特定 parameters 或 neuron combinations。课程介绍了三类常见方法：

1. L1 / L2 regularisation；
2. Dropout；
3. Early stopping。

### 2.1 L1 与 L2 regularisation

Regularisation 会在原本的 supervised-learning loss 上加入 penalty：

$$
\mathcal{L}_{total}=\mathcal{L}_{task}+\lambda\mathcal{R}(\theta)
$$

其中，$\lambda$ 是控制 regularisation strength 的 hyperparameter。

L1 regularisation 使用：

$$
\mathcal{R}_{L1}(\theta)=\sum_i|\theta_i|
$$

除零点以外，L1 对单个 parameter 的 gradient magnitude 基本保持固定，因此会持续把 parameter 推向 0，容易产生 **sparse representation**，即许多 parameters 变成 0。

L2 regularisation 使用：

$$
\mathcal{R}_{L2}(\theta)=\sum_i\theta_i^2
$$

L2 的 gradient 会随着 $|\theta_i|$ 变小而减小，所以它通常让 parameters 接近 0，但不一定恰好等于 0。

可以自由决定：

- $\lambda$ 应该多大；
- regularise 所有 layers，还是只处理 later layers；
- 同时处理 weights 和 biases，还是只处理 weights。

Regularisation 太强会限制模型学习有区分力的 features。例如 weights 全部过小，edge 与 non-edge responses 的差异也会变小，最后造成 **underfitting**。

### 2.2 Dropout

Dropout 会在 training 时随机停用一部分 neurons，例如 drop 20% 或 50%。这迫使 neurons 更独立地学习 useful features，也可以理解为同时训练许多不同的 network sub-architectures。

Dropout 常应用在 connections 较密集的 later / fully connected layers，而且不同 layers 可以采用不同 drop rates。它可能需要更多 epochs 才能收敛，因此整体 training time 可能增加。

🟨 **Training 与 evaluation 必须区分：** Dropout 只在 training 阶段随机关闭 neurons；validation 和 test 时所有 neurons 都应启用。

### 2.3 Early stopping

Early stopping 会持续监控 validation set。Training loss 通常继续下降，但当 validation loss 不再下降、甚至开始上升时，模型可能已经开始过度贴合 training set。此时应保留 validation performance 最佳 epoch 的 weights，而不是使用最后一个 epoch。

🟦 **资料澄清：** Slide 22 的 “a decrease suggests overfitting” 与 transcript 中相似表述容易产生歧义。结合 slide 40 的曲线，本节应理解为：**validation performance 下降，或 validation loss 停止下降并开始上升**，才是 early stopping 的信号。

Regularisation 没有适用于所有任务的唯一组合。L1、L2、dropout 和 early stopping 可以一起使用，但具体强度和位置通常需要通过 experiments 决定。

## 3. Image Recognition CNN 的输出与 Loss

典型 image recognition CNN 可以理解为两个部分：

```text
Image
  ↓
Convolutional layers + downsampling
  ↓
High-level feature vector
  ↓
Fully connected classifier
  ↓
Softmax class scores
```

Convolutional layers 负责 **feature embedding**：把 raw pixels 转换为 edges、textures、object parts 等更有用的 representation。Fully connected layers 则根据 high-level features 完成分类。

### 3.1 Softmax

最后一层会产生每个 class 的 logits $z_i$。Softmax 将它们转换为总和为 1 的 class scores：

$$
\hat{y}_i=\frac{e^{z_i}}{\sum_{j=1}^{C}e^{z_j}}
$$

其中 $C$ 是 classes 数量。每个 $\hat{y}_i\in(0,1)$，而且：

$$
\sum_{i=1}^{C}\hat{y}_i=1
$$

Lecture 将它解释为 probability-like confidence：最大 softmax value 所对应的 class 会成为 prediction。

### 3.2 Cross-entropy loss

Ground truth 通常采用 **one-hot encoding**：正确 class 的 $y_i=1$，其他 classes 为 0。Cross-entropy 衡量 ground-truth distribution 与 model output 之间的差异：

$$
\mathcal{L}_{CE}=-\sum_{i=1}^{C}y_i\log(\hat{y}_i)
$$

因为只有正确 class 的 $y_i=1$，最小化 loss 会推动网络提高正确 class 的 softmax score。

课程中的任务属于 closed-set classification：模型只能识别 training label set 中出现的 classes。未在训练类别中定义的新 class 不会自动成为一个新的输出类别。

## 4. 数据准备：Splits、Whitening 与 Augmentation

训练前通常将 dataset 分成：

- **Training set**：用于计算 gradients 和更新 parameters；
- **Validation set**：用于选择 hyperparameters、监控 overfitting 和 early stopping；
- **Test set**：只用于最后的 unbiased evaluation。

Transcript 提到 `60% / 20% / 20%` 可以作为一种 split，但不是固定规则。

### 4.1 Image whitening / normalisation

课程将 image whitening 描述为：先统一 image scale，再使 pixels 的 mean 接近 0，并可进一步令 standard deviation 接近 1。其目的不是改变 semantic content，而是让输入数值落在更适合 optimisation 的范围。

如果直接使用范围很大的 raw values，例如 0-255，经过多层 parameter multiplication 或 exponential operation 后更容易产生 numerical instability。Mean subtraction 与 scaling 可以让 gradient-based learning 更稳定。

### 4.2 Data augmentation

Data augmentation 不会增加新的人工 labels，而是根据已有 images 产生保持类别不变的 variations，从而增加 data variety 并减少 overfitting。

常见方法包括：

- 从 $256\times256$ image 中 random crop $224\times224$；
- horizontal reflection；
- 小幅 colour / contrast adjustment，用来模拟 camera settings 或不同 illumination；
- small rotation、scale 或 occlusion，但这些操作可能较慢。

Vertical reflection 和大幅 colour change 通常不采用，因为它们可能产生现实中不会出现的 training samples。例如倒置的动物可能迫使网络学习 test distribution 中不需要的 features。

🟨 **核心原则：** Augmentation 必须符合实际 deployment domain。若实际任务确实包含倒置 objects，vertical flip 就可能合理；否则它只会增加不必要的 learning complexity。

## 5. Training Process 与 Hyperparameters

一个 mini-batch 的基本 training loop 是：

```text
Load and preprocess a mini-batch
  ↓
Forward pass and classification
  ↓
Compute task loss (+ regularisation loss)
  ↓
Backpropagation
  ↓
Optimiser updates parameters
```

训练开始前通常需要：

- 将 weights 初始化为接近 0 的小随机值，例如 zero-centred Gaussian samples；
- 将 biases 初始化为 0 或较小正值；
- 选择 batch size、optimiser、learning rate 和 learning-rate decay；
- 在 training 过程中记录 training / validation loss 和 accuracy。

### 5.1 Batch size

**Mini-batch size** 是一次 parameter update 使用的 training samples 数量。如果 dataset 有 100 张 images，`batch size = 50`，则一个 epoch 包含 2 个 mini-batches，也就是 2 次 parameter updates。

| | Smaller batch | Larger batch |
|---|---|---|
| Updates per epoch | 更多 | 更少 |
| 单次 computation | 较快 | 较慢 |
| Gradient | noise / variance 较大 | 较稳定 |
| Data variety per update | 较少 | 较丰富 |
| 主要限制 | optimisation noise | GPU memory |

Mini-batch 的重要现实原因是整个 dataset 往往无法一次放入 GPU memory。Transcript 也强调，小 batch 可能只包含少数 classes 或更容易受到 outliers 影响；大 batch 的 gradient 较稳定，但每次 update 更昂贵。

### 5.2 Optimiser

课程介绍了：

- **SGD (Stochastic Gradient Descent)**；
- **RMSprop**；
- **Adam (Adaptive Moment Estimation)**。

SGD 通常以一个 shared learning rate 更新 parameters。Adam 会维护 gradient 及 squared gradient 的 moving averages，从而为不同 parameters 自适应地调整 effective step sizes。Transcript 将 SGD 描述为通常更 gradual / stable，而 Adam 往往能够更快地改变 parameters；实际结果仍取决于任务和 hyperparameter settings。

### 5.3 Learning rate

Learning rate 决定每次 update 改变 parameters 的幅度：

- 太大：可能跨过 optimum，在 loss surface 两侧反复跳动，甚至 divergence；
- 太小：变化稳定但非常缓慢，需要更多 updates / epochs；
- 合适：loss 较快下降，并逐渐在较低位置稳定。

🟨 **不要只看最初下降速度。** Very high learning rate 可能在早期快速降低 loss，却无法靠近真正 optimum。

### 5.4 训练多久？

训练时应同时观察 training 和 validation curves：

- 两者都没有下降：可能是 learning rate、implementation 或其他 settings 有问题；
- 两者稳定下降：模型正在学习；
- training loss 下降而 validation loss 上升：出现 overfitting；
- validation loss 已经稳定：继续训练可能没有明显收益。

因此，CNN training 并不是只设定一个很大的 epoch 数后等待完成。需要根据 curves 检查 optimisation 是否稳定、是否 overfit，以及 batch size、optimiser、learning rate、regularisation 和 augmentation 是否合适。

## 重点总结

- Downsampling 通过 strided convolution、max pooling 或 average pooling 减少 spatial size 和后续 computation。
- Max pooling 倾向保留最强 feature；average pooling 可能把 feature response 平均得更模糊。
- L1 倾向产生 sparse parameters；L2 倾向让 parameters 接近但不必等于 0。
- Dropout 只在 training 使用；early stopping 根据 validation performance 选择最佳 checkpoint。
- CNN 的 convolutional layers 负责 feature embedding，fully connected layers 与 softmax 完成 classification。
- Preprocessing 改善 numerical scale；augmentation 增加符合真实 domain 的 data variety。
- Batch size、optimiser 和 learning rate 会共同决定 training speed、stability 和最终 performance。
